本讲的习题围绕动态贝叶斯博弈的基本结构、完美贝叶斯均衡（PBE）、分离与混同信号、半分离混合策略、教育信号以及廉价交流展开。每题均在题目后给出答案和推导。涉及动态博弈时，均衡必须同时交代完整策略、信念，以及每个信息集上的最优性。

## 题 01｜动态贝叶斯博弈、策略与完美贝叶斯均衡

<strong>题目</strong>

考虑一个信号博弈。自然首先决定发送者的类型 $`\theta\in\{H,L\}`$，发送者观察自己的类型，接收者不知道类型。发送者选择公开信号 $`s\in\{0,1\}`$，接收者观察信号后选择行动 $`a\in\{I,R\}`$。双方收益取决于类型、信号与行动。

（1）说明该博弈为何属于动态贝叶斯博弈。它与静态贝叶斯博弈最根本的区别是什么？

（2）分别写出发送者与接收者的纯策略集合，并解释为什么发送者的策略不能仅写成“选择 $`s=1`$”。

（3）何谓接收者的信念？在什么条件下必须使用贝叶斯公式？

（4）说明纳什均衡、子博弈精炼纳什均衡（SPNE）、完美贝叶斯均衡（PBE）与序贯均衡（SE）在这个模型中的作用。

<strong>答案与解析</strong>

（1）这是一个<strong>参与人行动有先后顺序，且后行动者无法观察先行动者私人类型</strong>的博弈。先有自然选类型，再有知情者选信号，最后不知情者根据观察到的信号行动。发送者不仅要考虑自己当前的信号成本，还要预测信号如何改变接收者对其类型的判断，进而影响接收者行动。

静态贝叶斯博弈同样存在私人信息，但通常研究参与人如何在给定类型下同时选择行动；动态贝叶斯博弈进一步要求分析观察、推断与后续反应之间的关系。

（2）发送者的纯策略是一张<strong>按类型规定行动的完整计划</strong>：

```math
s_H=s(H)\in\{0,1\},\qquad s_L=s(L)\in\{0,1\}.
```

因此有四种纯策略：

| 发送者策略 | $`H`$ 型选择 | $`L`$ 型选择 | 类型 |
| --- | --- | --- | --- |
| $`(0,0)`$ | $`0`$ | $`0`$ | 混同 |
| $`(0,1)`$ | $`0`$ | $`1`$ | 分离 |
| $`(1,0)`$ | $`1`$ | $`0`$ | 分离 |
| $`(1,1)`$ | $`1`$ | $`1`$ | 混同 |

这里 $`(s_H,s_L)`$ 表示两类发送者各自应该做什么，不能只写一个 $`s`$，因为“发送者”实际上可能有两种私人类型。

接收者的纯策略是一张<strong>按观察信号规定行动的完整计划</strong>：

```math
a_0=a(s=0)\in\{I,R\},\qquad
a_1=a(s=1)\in\{I,R\}.
```

接收者同样有四种纯策略 $`(I,I),(I,R),(R,I),(R,R)`$。即使某条信号在均衡中从不出现，也必须规定收到该信号后的行动。

（3）接收者在观察 $`s`$ 后，对发送者属于高类型的条件概率为：

```math
\mu_s=\Pr(H\mid s),\qquad
1-\mu_s=\Pr(L\mid s).
```

如果信号 $`s`$ 在候选均衡策略下以<strong>正概率</strong>出现，信念必须由先验概率和两种类型发送该信号的概率按贝叶斯公式计算。若该信号在均衡中出现的概率为零，通常的贝叶斯公式分母为零，不能直接求出路径外信念；在本讲采用的弱 PBE 定义下，路径外信念可被指定，但接收者的行动仍必须对指定信念最优。

（4）四个概念的侧重点不同：

| 概念 | 核心要求 | 在信号博弈中的关注点 |
| --- | --- | --- |
| 纳什均衡（NE） | 给定对方完整策略，任何人不愿单方面改变自己的完整策略 | 不一定能排除不可信的路径外行动 |
| 子博弈精炼纳什均衡（SPNE） | 每个子博弈中的策略都是纳什均衡 | 在信息集不能被拆开的信号博弈中，往往不足以限制所有路径外反应 |
| 完美贝叶斯均衡（PBE） | 每个信息集上的序贯理性，并要求路径内信念符合贝叶斯法则 | 同时检验发送者激励、接收者最优行动和信念一致性 |
| 序贯均衡（SE） | 序贯理性，并要求信念可由一列趋近候选策略的完全混合策略按贝叶斯更新后取极限得到 | 比本讲采用的弱 PBE 更严格地约束路径外信念的形成 |

本讲做 PBE 题时，要写出：

```math
\boxed{
\text{PBE}=
\text{完整策略}+\text{信念}+
\text{序贯理性}+\text{贝叶斯一致性}
}
```

仅求出参与人的最佳行动而未说明信念，不能算完整的 PBE 解答。

## 题 02｜贝叶斯更新：两种类型使用不同的混合信号

<strong>题目</strong>

设高类型先验概率为 $`\Pr(H)=0.3`$，低类型为 $`\Pr(L)=0.7`$。高类型发送 $`s=1`$ 的概率为 $`0.8`$，低类型发送 $`s=1`$ 的概率为 $`0.2`$。

（1）计算接收者观察 $`s=1`$ 后的后验概率 $`\Pr(H\mid s=1)`$。

（2）计算观察 $`s=0`$ 后的后验概率 $`\Pr(H\mid s=0)`$。

（3）验证两个信号的发生概率之和为 $`1`$；解释“发送 $`s=1`$ 更像高类型”是否等同于“收到 $`s=1`$ 后高类型概率为 $`0.8`$”。

<strong>答案与解析</strong>

已知：

```math
\Pr(H)=0.3,\quad \Pr(L)=0.7,
```

```math
\Pr(1\mid H)=0.8,\quad
\Pr(1\mid L)=0.2.
```

首先算信号 $`1`$ 的总体发生概率：

```math
\begin{aligned}
\Pr(1)
&=\Pr(H)\Pr(1\mid H)+\Pr(L)\Pr(1\mid L)\\
&=0.3(0.8)+0.7(0.2)\\
&=0.24+0.14=0.38.
\end{aligned}
```

（1）观察 $`1`$ 的后验为：

```math
\begin{aligned}
\Pr(H\mid 1)
&=\frac{\Pr(H)\Pr(1\mid H)}{\Pr(1)}\\
&=\frac{0.3(0.8)}{0.38}
=\frac{0.24}{0.38}
=\boxed{\frac{12}{19}\approx0.6316}.
\end{aligned}
```

（2）高、低类型发 $`0`$ 的概率分别为 $`0.2`$ 与 $`0.8`$，因此：

```math
\begin{aligned}
\Pr(0)
&=0.3(0.2)+0.7(0.8)\\
&=0.06+0.56=0.62,\\[4pt]
\Pr(H\mid 0)
&=\frac{0.3(0.2)}{0.62}
=\boxed{\frac{3}{31}\approx0.0968}.
\end{aligned}
```

（3）一致性检查：

```math
\Pr(1)+\Pr(0)=0.38+0.62=1.
```

还可以检查“后验的加权平均等于先验”：

```math
0.38\left(\frac{12}{19}\right)
+0.62\left(\frac{3}{31}\right)
=0.24+0.06
=0.30.
```

这说明更新没有遗漏任何类型或信号。

特别注意：$`0.8`$ 是 $`\Pr(1\mid H)`$，含义是<strong>已知发送者为高类型，他发送 $`1`$ 的概率</strong>。题目要求的 $`\Pr(H\mid1)`$ 则是<strong>已观察到信号 $`1`$，发送者为高类型的概率</strong>。两个条件概率顺序相反，不能互换。由于低类型也有 $`0.2`$ 的概率发送 $`1`$，收到该信号后高类型的概率只升至约 $`0.6316`$，并非 $`0.8`$。

## 题 03｜接收者的投资阈值与最优反应

<strong>题目</strong>

在投资信号博弈中，接收者可以选择投资 $`I`$ 或拒绝 $`R`$。如果投资而发送者是高类型，接收者收益为 $`3`$；如果是低类型，收益为 $`-1`$；拒绝时收益为 $`0`$。

（1）设接收者观察信号后的高类型信念为 $`\mu`$，推导投资的最优反应函数。

（2）分别判断 $`\mu=0.2`$、$`\mu=0.25`$ 和 $`\mu=0.4`$ 时的最优行动。

（3）假设投资收益改为高类型 $`5`$、低类型 $`-3`$，重新求投资阈值。

（4）解释为什么单独知道投资阈值仍不能断定整个信号博弈的 PBE。

<strong>答案与解析</strong>

（1）设观察某一信号后的信念是 $`\mu=\Pr(H\mid s)`$。投资的期望收益为：

```math
\begin{aligned}
U_R(I\mid\mu)
&=\mu\cdot3+(1-\mu)(-1)\\
&=3\mu-1+\mu\\
&=4\mu-1.
\end{aligned}
```

拒绝的期望收益是：

```math
U_R(R\mid\mu)=0.
```

比较两者：

```math
4\mu-1
\begin{cases}
>0,&\mu>\frac{1}{4},\\
=0,&\mu=\frac{1}{4},\\
<0,&\mu<\frac{1}{4}.
\end{cases}
```

因此最优反应对应为：

```math
BR_R(\mu)=
\begin{cases}
\{I\},&\mu>\frac{1}{4},\\
\{I,R\}\text{及二者任意混合},&\mu=\frac{1}{4},\\
\{R\},&\mu<\frac{1}{4}.
\end{cases}
```

（2）代入：

| 高类型后验 $`\mu`$ | 投资期望收益 $`4\mu-1`$ | 最优行动 |
| --- | ---: | --- |
| $`0.20`$ | $`-0.20`$ | 拒绝 |
| $`0.25`$ | $`0`$ | 投资、拒绝或任意混合均可 |
| $`0.40`$ | $`0.60`$ | 投资 |

关键在等号情形。$`\mu=1/4`$ 时接收者并非“一定投资”，而是对投资和拒绝无差异，这正是半分离均衡中接收者可能混合行动的依据。

（3）收益改变后：

```math
\begin{aligned}
U_R(I\mid\mu)
&=5\mu-3(1-\mu)\\
&=8\mu-3.
\end{aligned}
```

因此：

```math
8\mu-3\ge0
\quad\Longleftrightarrow\quad
\boxed{\mu\ge\frac{3}{8}}.
```

在 $`\mu=3/8`$ 时接收者无差异，大于阈值严格投资，小于阈值严格拒绝。

（4）投资阈值只解决<strong>接收者给定信念后的最优行动</strong>。判断 PBE 还需要回答三个问题：哪些类型会发送哪些信号？接收者收到各信号后的信念从何而来？在接收者采取相应行动时，各类型是否愿意维持自己的信号选择？如果某类型通过改换信号获得更高收益，候选策略即使满足投资阈值也不是 PBE。

## 题 04｜二元投资信号博弈：完整推导分离型 PBE

<strong>题目</strong>

现考虑本讲的基本投资信号模型：

自然以相同概率产生高类型 $`H`$ 与低类型 $`L`$。发送者先选择 $`s\in\{0,1\}`$；接收者观察信号后决定投资或拒绝。接收者投资收益为：遇 $`H`$ 得 $`3`$，遇 $`L`$ 得 $`-1`$，拒绝得 $`0`$。

发送者如果获得投资，产生毛收益 $`2`$；被拒绝则毛收益 $`0`$。选择 $`s=0`$ 不花费成本；选择 $`s=1`$ 时，高类型成本 $`0.5`$，低类型成本 $`3`$。

求并完整验证以下候选分离均衡：

```math
s_H=1,\qquad s_L=0.
```

要求写出接收者在两个信号后的行动、两个后验信念、两类发送者的偏离比较，并说明为什么“高类型成本更低”不代表高类型一定选择高成本信号。

<strong>答案与解析</strong>

（1）先明确发送者的收益：

```math
U_S(\theta,s,a)
=2\,\mathbf 1\{a=I\}-c_\theta(s),
```

其中 $`c_H(0)=c_L(0)=0`$，$`c_H(1)=0.5`$，$`c_L(1)=3`$。

（2）假设 $`H`$ 发 $`1`$、$`L`$ 发 $`0`$。因为先验中两类概率均为正，且各自信号完全不同，观察信号后就能确定类型：

```math
\begin{aligned}
\mu_1&=\Pr(H\mid s=1)=1,\\
\mu_0&=\Pr(H\mid s=0)=0.
\end{aligned}
```

两个信号均以 $`1/2`$ 的正概率出现，因此两项后验都由贝叶斯法则确定，并不存在需要自由指定的路径外信念。

（3）利用题 03 的阈值 $`1/4`$：

```math
\begin{aligned}
U_R(I\mid s=1)&=4(1)-1=3>0,\\
U_R(I\mid s=0)&=4(0)-1=-1<0.
\end{aligned}
```

故接收者在看到 $`1`$ 时投资，看到 $`0`$ 时拒绝。完整接收者策略为：

```math
a(1)=I,\qquad a(0)=R.
```

（4）逐类型检查发送者是否愿意偏离。

高类型遵守策略发 $`1`$ 时得到投资，但支付信号成本：

```math
U_H(1)=2-0.5=1.5.
```

若高类型改发 $`0`$，按接收者的完整策略将被拒绝，且无成本：

```math
U_H(0)=0.
```

所以 $`1.5>0`$，高类型严格偏好发 $`1`$。

低类型遵守策略发 $`0`$ 时被拒绝：

```math
U_L(0)=0.
```

低类型如果模仿高类型发 $`1`$，虽能吸引投资，但成本太高：

```math
U_L(1)=2-3=-1.
```

所以 $`0>-1`$，低类型严格偏好发 $`0`$。

（5）完整均衡是：

```math
\boxed{
\begin{gathered}
s_H=1,\quad s_L=0,\\
a(1)=I,\quad a(0)=R,\\
\mu_1=1,\quad\mu_0=0.
\end{gathered}}
```

| 参与人 | 均衡选择与收益 | 单方面偏离与收益 | 结论 |
| --- | --- | --- | --- |
| $`H`$ 型 | 发 $`1`$，收益 $`1.5`$ | 发 $`0`$，收益 $`0`$ | 不偏离 |
| $`L`$ 型 | 发 $`0`$，收益 $`0`$ | 发 $`1`$，收益 $`-1`$ | 不偏离 |
| 接收者，见 $`1`$ | 投资，收益 $`3`$ | 拒绝，收益 $`0`$ | 不偏离 |
| 接收者，见 $`0`$ | 拒绝，收益 $`0`$ | 投资，收益 $`-1`$ | 不偏离 |

“高类型成本更低”只是使不同类型的<strong>激励相容约束</strong>有可能同时成立，并不能单独推出信号 $`1`$ 一定被发送。若接收者看到信号 $`1`$ 仍拒绝投资，高类型选择昂贵信号只会白白损失 $`0.5`$，也没有理由发送该信号。必须把<strong>信号后的投资反应</strong>与<strong>信号成本</strong>放在一起比较。

## 题 05｜同一投资博弈：构造混同型 PBE

<strong>题目</strong>

继续使用题 04 的完整收益数据与先验概率 $`\Pr(H)=\Pr(L)=0.5`$。

考虑候选策略：两种类型都发送 $`s=0`$；接收者观察 $`s=0`$ 后投资，观察 $`s=1`$ 后拒绝。

（1）求 $`s=0`$ 后的后验信念，并检查投资是否最优。

（2）设路径外信念 $`\mu_1=\Pr(H\mid s=1)=0`$，检验拒绝是否最优。

（3）分别检验两类发送者有没有偏离动机。

（4）指出该 PBE 与题 04 分离型 PBE 的实质差异。

<strong>答案与解析</strong>

（1）两类发送者都选择 $`0`$，信号并不区分类型。收到 $`0`$ 只能维持先验概率：

```math
\mu_0
=\Pr(H\mid0)
=\frac{(0.5)(1)}{(0.5)(1)+(0.5)(1)}
=\boxed{0.5}.
```

对应的投资期望收益：

```math
U_R(I\mid0)=4(0.5)-1=1>0.
```

因此投资严格优于拒绝。

（2）由于两类发送者都不选择 $`1`$，

```math
\Pr(s=1)=0.
```

此时无法用贝叶斯公式计算 $`\mu_1`$；在本讲弱 PBE 的设定下，可以指定：

```math
\mu_1=0.
```

接收者据此计算：

```math
U_R(I\mid1)=4(0)-1=-1<0.
```

所以在 $`1`$ 后拒绝是最优反应。注意这并非意味着路径外信念是事实，而是说它与该候选弱 PBE 所要求的序贯理性相容。

（3）两类发送者在均衡中发 $`0`$，都获得投资且无信号成本：

```math
U_H(0)=U_L(0)=2.
```

若高类型偏离发 $`1`$，接收者按策略拒绝，高类型支付 $`0.5`$：

```math
U_H(1)=0-0.5=-0.5<2.
```

若低类型偏离发 $`1`$，同样遭拒绝但支付 $`3`$：

```math
U_L(1)=0-3=-3<2.
```

所以双方都不偏离。完整弱 PBE 为：

```math
\boxed{
\begin{gathered}
s_H=s_L=0,\\
a(0)=I,\quad a(1)=R,\\
\mu_0=\frac{1}{2},\quad \mu_1=0.
\end{gathered}}
```

（4）与题 04 对比：

| 维度 | 题 04：分离均衡 | 题 05：混同均衡 |
| --- | --- | --- |
| 发送者信号 | $`H\to1,\ L\to0`$ | $`H,L\to0`$ |
| 信息揭示 | 收到信号即确定类型 | 收到 $`0`$ 后仍只有先验信息 |
| 接收者行动 | $`1`$ 后投、$`0`$ 后拒 | $`0`$ 后投、$`1`$ 后拒 |
| 低类型收益 | $`0`$ | $`2`$ |
| 高类型收益 | $`1.5`$ | $`2`$ |
| 关键支持机制 | 不同类型信号成本有差别 | 路径外信念使偏离信号失去吸引力 |

这个例子说明：<strong>同一个动态贝叶斯博弈可以存在不止一种 PBE</strong>。均衡选择不同，信号所传递的信息也不同，不能只靠先验概率或信号成本断言唯一结果。

## 题 06｜路径外信念的允许范围，以及为何不能混同在高成本信号

<strong>题目</strong>

仍考虑题 04 的投资博弈，先验 $`p=0.5`$。

（1）在题 05 所构造的“双方都发 $`0`$、接收者在 $`0`$ 后投资、在 $`1`$ 后拒绝”的弱 PBE 中，路径外信念 $`\mu_1`$ 是否必须恰好等于 $`0`$？求所有支持“见 $`1`$ 后拒绝”的信念范围。

（2）考虑另一种混同候选：双方都发 $`1`$，接收者看到 $`1`$ 后投资。无论收到 $`0`$ 后接收者采取什么行动，这一候选是否可能为 PBE？说明理由。

（3）解释“路径外信念可以指定”与“可以任意指定而不检查合理性”为什么不是一回事。

<strong>答案与解析</strong>

（1）题 05 中 $`s=1`$ 为路径外信号，弱 PBE 的贝叶斯更新条件不直接约束其后验，但接收者的拒绝行动要求：

```math
U_R(R\mid1)\ge U_R(I\mid1).
```

即：

```math
0\ge 4\mu_1-1
\quad\Longleftrightarrow\quad
\mu_1\le\frac{1}{4}.
```

由于信念是概率，还需 $`0\le\mu_1\le1`$。所以全部可行范围为：

```math
\boxed{0\le\mu_1\le\frac{1}{4}}.
```

当 $`\mu_1<1/4`$ 时拒绝是严格最优；当 $`\mu_1=1/4`$ 时拒绝与投资无差异，接收者仍可以纯粹选择拒绝。对于此区间的任何信念，发送者偏离到 $`1`$ 都会被拒绝，题 05 的发送者激励检验不变。

这也表明：<strong>一个均衡策略组合有时对应不止一组支持它的信念</strong>。若题目要求“求所有 PBE”，不能把随手选取的 $`\mu_1=0`$ 误写成唯一可能。

（2）若双方都发 $`1`$，路径内后验仍是：

```math
\mu_1=\Pr(H\mid1)=0.5.
```

因为 $`4(0.5)-1=1>0`$，接收者在 $`1`$ 后投资确实是最优行动。但低类型发送者的均衡收益为：

```math
U_L(s=1)=2-3=-1.
```

若低类型改发 $`0`$，信号成本为零，而且无论接收者在路径外选择投资、拒绝还是混合，低类型的收益都不会小于零：

```math
U_L(s=0)
=2\Pr(I\mid s=0)
\ge0.
```

因此：

```math
U_L(s=0)\ge0>-1=U_L(s=1).
```

低类型必然偏离。这一候选<strong>不可能构成 PBE</strong>，任何路径外信念与路径外接收者策略都救不了它。

（3）路径外信念不由通常的贝叶斯公式确定，意味着在弱 PBE 框架下具有一定自由度；但以下约束仍然存在：

第一，信念必须位于 $`[0,1]`$，是合法的概率。

第二，接收者选择的行动必须在指定信念下最优。若指定 $`\mu_1=0.9`$ 却要求接收者在 $`1`$ 后拒绝，那么投资收益为 $`2.6>0`$，直接违反序贯理性。

第三，发送者在预见接收者的完整反应后不能有盈利性偏离。题 06（2）正是反例：路径外怎样规定都无法阻止低类型改发无成本信号。

第四，本讲随后讨论的直觉准则等进一步精炼，会对一些形式上符合弱 PBE 的路径外信念提出更严格要求。

## 题 07｜半分离均衡：发送者与接收者为何同时混合

<strong>题目</strong>

考虑题 04 的变形。高类型先验为 $`p=0.2`$，低类型为 $`0.8`$。接收者投资高类型收益 $`3`$、投资低类型收益 $`-1`$，拒绝收益 $`0`$。发送者获得投资的毛收益是 $`2`$，发送 $`0`$ 不花费成本，发送 $`1`$ 的成本改为：

```math
c_H(1)=0,\qquad c_L(1)=1.
```

考虑半分离候选：

高类型总是发 $`1`$；低类型以概率 $`r`$ 发 $`1`$，以概率 $`1-r`$ 发 $`0`$；接收者看到 $`1`$ 后以概率 $`\beta`$ 投资，看到 $`0`$ 后拒绝。

（1）利用低类型的无差异条件求 $`\beta`$。

（2）利用接收者在 $`1`$ 后的无差异条件求 $`r`$。

（3）计算两个信号后的后验、信号发生概率，并检查高类型、低类型、接收者的序贯理性。

（4）解释为什么不能把 $`r`$ 和 $`\beta`$ 随意设为 $`1/2`$。

<strong>答案与解析</strong>

（1）由于低类型在候选中同时以正概率发出两个信号，其收益必须对两种信号无差异。

低类型发 $`1`$：接收者以概率 $`\beta`$ 投资、以概率 $`1-\beta`$ 拒绝。低类型支付成本 $`1`$：

```math
\begin{aligned}
U_L(1)
&=\beta(2-1)+(1-\beta)(0-1)\\
&=2\beta-1.
\end{aligned}
```

低类型发 $`0`$：被拒绝，不付信号成本，因此：

```math
U_L(0)=0.
```

令两者相等：

```math
2\beta-1=0
\quad\Longrightarrow\quad
\boxed{\beta=\frac{1}{2}}.
```

所以接收者之所以在 $`1`$ 后混合，是因为只有投资概率恰好等于 $`1/2`$，低类型才愿意同时使用两个信号。

（2）接收者在 $`1`$ 后也以正概率选择投资和拒绝，因此必须对两者无差异。已知投资收益是 $`4\mu_1-1`$，故：

```math
\mu_1=\frac{1}{4}.
```

由发送者混合策略计算贝叶斯后验：

```math
\begin{aligned}
\mu_1
&=\Pr(H\mid1)\\
&=\frac{\Pr(H)\Pr(1\mid H)}
{\Pr(H)\Pr(1\mid H)+\Pr(L)\Pr(1\mid L)}\\
&=\frac{0.2(1)}{0.2(1)+0.8r}.
\end{aligned}
```

令其等于 $`1/4`$：

```math
\begin{aligned}
\frac{0.2}{0.2+0.8r}&=\frac{1}{4},\\
0.8&=0.2+0.8r,\\
0.6&=0.8r,\\
\boxed{r&=\frac{3}{4}}.
\end{aligned}
```

也就是说，低类型以 $`3/4`$ 的概率模仿高类型发送 $`1`$，留下 $`1/4`$ 的概率发送 $`0`$。

（3）先检查信号发生概率：

```math
\begin{aligned}
\Pr(1)&=0.2(1)+0.8\left(\frac{3}{4}\right)=0.8,\\
\Pr(0)&=0.2(0)+0.8\left(\frac{1}{4}\right)=0.2.
\end{aligned}
```

两者之和为 $`1`$。后验分别为：

```math
\mu_1
=\frac{0.2}{0.8}
=\frac{1}{4},
\qquad
\mu_0
=\frac{0.2(0)}{0.2}
=0.
```

两个信号均正概率出现，信念必须由上述贝叶斯计算给出，不能任意指定。

接收者在 $`1`$ 后的投资期望收益为：

```math
4\left(\frac{1}{4}\right)-1=0.
```

所以以 $`\beta=1/2`$ 的概率投资是最优混合。在 $`0`$ 后，投资收益为 $`-1<0`$，因此严格偏好拒绝。

高类型遵守策略发 $`1`$ 时成本为零，预期得到投资毛收益：

```math
U_H(1)=2\left(\frac{1}{2}\right)-0=1.
```

偏离发 $`0`$ 时遭拒绝，收益为：

```math
U_H(0)=0.
```

高类型严格选择 $`1`$。

低类型发 $`1`$ 的收益为 $`2(1/2)-1=0`$，发 $`0`$ 的收益也为 $`0`$，恰好无差异，故可以按 $`3/4`$ 与 $`1/4`$ 的概率混合。

完整半分离 PBE 是：

```math
\boxed{
\begin{gathered}
\Pr(1\mid H)=1,\quad
\Pr(1\mid L)=\frac{3}{4},\\
\Pr(I\mid1)=\frac{1}{2},\quad
\Pr(I\mid0)=0,\\
\mu_1=\frac{1}{4},\quad \mu_0=0.
\end{gathered}}
```

（4）两个混合概率由<strong>两条不同的无差异方程</strong>决定：

| 待求概率 | 谁必须无差异 | 用来决定该概率的条件 | 结果 |
| --- | --- | --- | --- |
| $`\beta`$：接收者投不投资 | 低类型发送者 | $`U_L(1)=U_L(0)`$ | $`1/2`$ |
| $`r`$：低类型发 $`1`$ 的概率 | 接收者 | $`U_R(I\mid1)=U_R(R\mid1)`$ | $`3/4`$ |

这与静态博弈中的混合策略原理一致：<strong>一个参与人的混合概率，往往由另一个参与人的无差异条件确定</strong>。半分离博弈还必须把后验信念的贝叶斯更新加入求解。

## 题 08｜弱 PBE 与直觉准则：为什么有些混同均衡不稳健

<strong>题目</strong>

回到题 04 的成本数据 $`c_H(1)=0.5`$、$`c_L(1)=3`$，接收者投资收益仍为高类型 $`3`$、低类型 $`-1`$。但把高类型先验改为 $`p=0.2`$。

（1）构造一个两种类型都发 $`s=0`$、接收者见 $`0`$ 与见 $`1`$ 均拒绝的弱 PBE。指定路径外信念 $`\mu_1=0`$。

（2）逐项检验这个弱 PBE。

（3）若市场意外观察到 $`s=1`$，结合 Cho–Kreps 直觉准则（Intuitive Criterion）的基本思路，判断该混同均衡为何会受到挑战。要求分别计算高、低类型在“发 $`1`$ 且获得投资”情况下的净收益。

<strong>答案与解析</strong>

（1）设候选完整策略与信念为：

```math
\begin{gathered}
s_H=s_L=0,\\
a(0)=R,\qquad a(1)=R,\\
\mu_0=0.2,\qquad \mu_1=0.
\end{gathered}
```

（2）两类都发 $`0`$，故路径内后验等于先验：

```math
\mu_0=\Pr(H\mid0)=0.2.
```

收到 $`0`$ 后投资收益：

```math
4(0.2)-1=-0.2<0,
```

所以接收者拒绝是严格最优。收到路径外信号 $`1`$ 后指定 $`\mu_1=0`$，投资收益为 $`-1<0`$，同样应拒绝。

发送者发 $`0`$ 都被拒绝，且成本为零：

```math
U_H(0)=U_L(0)=0.
```

如果高类型偏离发 $`1`$，在候选接收者策略下仍被拒绝，收益 $`-0.5`$；低类型偏离则得到 $`-3`$。二者均不优于 $`0`$。因此策略、路径内信念与各信息集上的最优行动相容，形成一个<strong>弱 PBE</strong>。

（3）直觉准则要求思考：某个看似意外的信号，究竟<strong>哪些类型有可能通过发送该信号获益</strong>？

设发送者意外改发 $`1`$，即使接收者因此投资，两个类型的净收益也不同：

```math
\begin{aligned}
U_H(1,I)&=2-0.5=\boxed{1.5},\\
U_L(1,I)&=2-3=\boxed{-1}.
\end{aligned}
```

原混同均衡中两类发送者收益都为 $`0`$。于是：

高类型如果能靠 $`1`$ 吸引投资，收益会从 $`0`$ 提高到 $`1.5`$；低类型即使百分之百吸引投资，也只能得到 $`-1<0`$，没有理由发送该高成本信号。

由此，接收者看到意外的 $`1`$ 时，应考虑这一信号更可能来自<strong>有获利动机的高类型</strong>。如果据此形成 $`\mu_1=1`$，接收者投资收益就是 $`3>0`$，会选择投资；而高类型发现投资可得，就确实愿意偏离。

因此这个弱 PBE 虽然满足题目（2）的形式条件，却会被本例的直觉准则排除。要注意两者并不矛盾：<strong>弱 PBE 只对路径外信念施加较少限制；直觉准则进一步用各类型的可能偏离收益限制路径外信念。</strong>

## 题 09｜斯宾塞教育信号：分离均衡的激励相容区间

<strong>题目</strong>

考虑斯宾塞教育信号模型（Spence Signaling）。工人有高生产率 $`H`$ 和低生产率 $`L`$ 两种类型，满足 $`H>L>0`$。工人选择教育水平 $`e\ge0`$，雇主只能观察教育，不能直接观察真实生产率。

雇主在竞争条件下支付其对工人预期生产率的工资。教育本身不提高生产率，工人接受教育的成本分别为：

```math
c_H(e)=\frac{e}{H},
\qquad
c_L(e)=\frac{e}{L}.
```

研究分离候选：低类型选 $`e_L=0`$，高类型选 $`e_H=e^*>0`$，雇主见 $`e^*`$ 支付 $`H`$、见 $`0`$ 支付 $`L`$。

（1）写出两类工人的效用。

（2）分别推导高类型不愿伪装成低类型、低类型不愿伪装成高类型的激励相容条件。

（3）求支持分离的教育区间。

（4）取 $`H=4,L=2`$，判断 $`e^*=3`$、$`6`$、$`9`$ 中哪些满足上述激励相容约束。

（5）在 $`e^*=6`$ 时，完整规定路径外教育水平的雇主信念与工资，并检验这是一个弱 PBE。

<strong>答案与解析</strong>

（1）工人效用等于工资减教育成本。设雇主见教育 $`e`$ 后支付 $`w(e)`$：

```math
U_H(e)=w(e)-\frac{e}{H},
\qquad
U_L(e)=w(e)-\frac{e}{L}.
```

由于 $`H>L>0`$，对任何 $`e>0`$：

```math
\frac{e}{H}<\frac{e}{L}.
```

高类型接受相同教育的成本更低，这就是教育能够用来区分类型的关键条件。

（2）候选均衡中，高类型受教育 $`e^*`$ 并获得工资 $`H`$，效用为 $`H-e^*/H`$。若放弃教育并伪装成低类型，获得工资 $`L`$ 且成本为零。高类型的激励相容约束为：

```math
H-\frac{e^*}{H}\ge L.
```

移项：

```math
\boxed{e^*\le H(H-L)}.
```

低类型在候选中不受教育，工资为 $`L`$，效用为 $`L`$。若模仿高类型选择 $`e^*`$，工资升为 $`H`$，但教育成本为 $`e^*/L`$。低类型的激励相容条件为：

```math
L\ge H-\frac{e^*}{L}.
```

移项：

```math
\boxed{e^*\ge L(H-L)}.
```

（3）必须同时满足两个条件，因此：

```math
\boxed{
L(H-L)\le e^*\le H(H-L)
}.
```

可以从经济含义理解区间的两端。

下界 $`L(H-L)`$ 确保教育足够昂贵，使低类型不愿模仿。教育低于下界时，低类型愿意通过教育骗取高工资。

上界 $`H(H-L)`$ 确保教育对高类型不至于太昂贵。教育高于上界时，高类型宁可放弃教育、接受低工资。

（4）给定 $`H=4,L=2`$：

```math
\begin{aligned}
L(H-L)&=2(4-2)=4,\\
H(H-L)&=4(4-2)=8.
\end{aligned}
```

分离的必要激励相容区间是：

```math
\boxed{4\le e^*\le8}.
```

| 教育水平 | 高类型遵守净效用 $`4-e^*/4`$ | 低类型模仿净效用 $`4-e^*/2`$ | 判断 |
| --- | ---: | ---: | --- |
| $`e^*=3`$ | $`3.25`$，高于放弃教育的 $`2`$ | $`2.5`$，高于低类型遵守的 $`2`$ | 低类型会模仿 |
| $`e^*=6`$ | $`2.5`$，高于 $`2`$ | $`1`$，低于 $`2`$ | 双方均不偏离 |
| $`e^*=9`$ | $`1.75`$，低于 $`2`$ | $`-0.5`$，低于 $`2`$ | 高类型会放弃教育 |

所以在这三个候选中，只有 $`e^*=6`$ 满足要求。

（5）仅证明工人不愿在 $`0`$ 与 $`6`$ 之间互换，并不足以称为完整均衡，因为教育水平是连续的，工人还可以选择 $`e=1,2,5,7,\ldots`$。

下面给出一组完整支持规则：

```math
\Pr(H\mid e)=
\begin{cases}
1,&e=6,\\
0,&e\ne6.
\end{cases}
```

雇主按后验预期生产率支付：

```math
w(e)=
\begin{cases}
4,&e=6,\\
2,&e\ne6.
\end{cases}
```

路径内 $`e=6`$ 只有高类型发出，$`e=0`$ 只有低类型发出，因此两处后验满足贝叶斯法则；其余教育水平为路径外，按弱 PBE 可以指定对高类型的信念为 $`0`$。

高类型遵守 $`e=6`$ 的收益是 $`4-6/4=2.5`$。偏离至任一 $`e\ne6`$ 后工资为 $`2`$，收益：

```math
2-\frac{e}{4}\le2<2.5
\qquad(e\ge0).
```

低类型遵守 $`e=0`$ 收益为 $`2`$。偏离至 $`e=6`$ 后收益 $`4-6/2=1`$；偏离至其他 $`e>0`$ 后收益：

```math
2-\frac{e}{2}<2.
```

所以不存在盈利性偏离。雇主对每一个 $`e`$ 都按照指定后验支付竞争工资。完整均衡为工人策略 $`(e_H,e_L)=(6,0)`$、上述信念与工资安排。

这题的关键并非只会写区间，而是明白：<strong>离散的两点激励相容检验必须与连续行动空间中的路径外偏离检验配合使用</strong>。

## 题 10｜斯宾塞教育信号：混同均衡与路径外工资

<strong>题目</strong>

仍考虑题 09 的教育信号模型，设 $`\Pr(H)=\pi`$，$`\Pr(L)=1-\pi`$，其中 $`0<\pi<1`$。

现考虑混同候选：两种类型都选择同一个教育水平 $`e^*\ge0`$。雇主在看到 $`e^*`$ 后按平均生产率支付工资：

```math
\bar w=\pi H+(1-\pi)L.
```

假设雇主在观察到其他教育水平 $`e\ne e^*`$ 时均认为工人是低类型，支付工资 $`L`$。

（1）求 $`e^*>0`$ 时两种类型维持混同的条件。

（2）证明该条件主要由低类型的偏离激励决定。

（3）取 $`H=4,L=2,\pi=1/2`$，求满足上述构造的混同教育水平范围，并完整检验 $`e^*=2`$。

（4）单独讨论 $`e^*=0`$ 的情形。

<strong>答案与解析</strong>

（1）在混同路径上，教育没有揭示任何类型信息，雇主的后验仍是 $`\pi`$，所以工资为 $`\bar w`$。类型 $`\theta\in\{H,L\}`$ 遵守候选策略的净收益是：

```math
U_\theta(e^*)=\bar w-\frac{e^*}{\theta}.
```

若 $`e^*>0`$，偏离到 $`e=0`$ 是所有路径外教育水平中最便宜的选择，且按题目给定的路径外信念可以获得工资 $`L`$。因此偏离收益是：

```math
U_\theta(0)=L.
```

对低类型，激励相容要求：

```math
\bar w-\frac{e^*}{L}\ge L.
```

移项并利用 $`\bar w-L=\pi(H-L)`$：

```math
\begin{aligned}
e^*&\le L(\bar w-L)\\
&=\boxed{\pi L(H-L)}.
\end{aligned}
```

对高类型则要求：

```math
\bar w-\frac{e^*}{H}\ge L,
```

即：

```math
\boxed{e^*\le \pi H(H-L)}.
```

两者都必须满足，且 $`e^*\ge0`$，因此完整范围为：

```math
\boxed{0<e^*\le\pi L(H-L)}
\qquad(e^*>0).
```

（2）由于 $`H>L`$：

```math
\pi L(H-L)<\pi H(H-L).
```

低类型能够承受的最大教育水平更低，因此它的激励相容条件更严格。只要低类型不愿放弃昂贵教育改选无成本的 $`e=0`$，高类型在同样的信念与工资安排下也不会因为教育成本而放弃混同。

对任意其他 $`e>0`$ 且 $`e\ne e^*`$，工资依然只有 $`L`$，同时必须支付正成本，其收益严格低于选择 $`e=0`$ 的收益 $`L`$。所以检验无成本的 $`e=0`$ 已经涵盖了最有吸引力的路径外偏离。

（3）令 $`H=4,L=2,\pi=1/2`$：

```math
\bar w
=\frac{1}{2}(4)+\frac{1}{2}(2)
=3.
```

上界为：

```math
\pi L(H-L)
=\frac{1}{2}\cdot2\cdot(4-2)=2.
```

故本构造允许：

```math
\boxed{0\le e^*\le2}.
```

选 $`e^*=2`$ 时，雇主信念、工资和工人策略为：

```math
\begin{gathered}
e_H=e_L=2,\\
\Pr(H\mid e=2)=\frac{1}{2},\\
\Pr(H\mid e\ne2)=0,\\
w(2)=3,\qquad w(e\ne2)=2.
\end{gathered}
```

高类型遵守的净收益：

```math
U_H(2)=3-\frac{2}{4}=2.5.
```

低类型遵守的净收益：

```math
U_L(2)=3-\frac{2}{2}=2.
```

二者最好的路径外偏离都是教育 $`0`$，工资 $`2`$，收益 $`2`$。因此高类型严格不偏离、低类型在两种选择间无差异，选择 $`2`$ 仍是最优。其他路径外教育水平支付正成本且工资为 $`2`$，更不可能有利可图。

（4）当 $`e^*=0`$ 时，两种类型均不教育，雇主支付 $`\bar w`$。若有任何工人偏离到 $`e>0`$，按候选路径外信念只得工资 $`L`$ 且支付成本。因此：

```math
U_\theta(e>0)
=L-\frac{e}{\theta}
<L<\bar w=U_\theta(0),
```

其中 $`\bar w>L`$ 是因为 $`\pi>0`$ 且 $`H>L`$。故 $`e^*=0`$ 也可构成这一弱 PBE 构造，和前述正教育水平一起给出闭区间 $`[0,\pi L(H-L)]`$。

## 题 11｜教育信号的作用：信息筛选与社会成本

<strong>题目</strong>

继续使用题 09 的数值 $`H=4,L=2`$ 和分离候选 $`e_H=6,e_L=0`$。

（1）教育是否改变两种工人的生产率？为什么雇主仍可能以教育为依据支付不同工资？

（2）分别计算高、低类型在此分离配置下的真实教育成本。若高类型先验概率为 $`\pi=0.5`$，求每位工人的期望教育成本。

（3）从工人个体激励与社会总产出的角度，区分“有利于区分类型”和“提高实际生产率”。

<strong>答案与解析</strong>

（1）题目假定教育只承担<strong>信号</strong>的作用，不改变生产率。高类型始终生产 $`4`$，低类型始终生产 $`2`$。雇主之所以愿意针对 $`e=6`$ 支付工资 $`4`$，不是因为“教育把能力从 $`2`$ 提高到了 $`4`$”，而是由于高类型接受相同教育的成本更低，分离均衡使雇主能够从教育推断类型：

```math
\Pr(H\mid e=6)=1,
\qquad
\Pr(H\mid e=0)=0.
```

在竞争性雇佣条件下，工资对应所观察教育水平背后的条件期望生产率。

（2）成本分别为：

```math
\begin{aligned}
c_H(6)&=\frac{6}{4}=1.5,\\
c_L(0)&=\frac{0}{2}=0.
\end{aligned}
```

先验高类型概率为 $`0.5`$ 时，每位工人的期望教育成本：

```math
\begin{aligned}
\mathbb E[c(e)]
&=\Pr(H)c_H(6)+\Pr(L)c_L(0)\\
&=0.5(1.5)+0.5(0)\\
&=\boxed{0.75}.
\end{aligned}
```

（3）对个体来说，教育可以把原本观察不到的类型信息部分或全部传递给雇主，高类型有动机承担 $`1.5`$ 的成本换取较高工资；低类型因为模仿成本更高而选择不教育。<strong>信号有效</strong>意味着它能分辨类型，并不意味着信号本身增加实际产出。

在该模型既定假设下，产出没有因为教育而增加。若不把教育当作生产性投入，那么教育费用是真实资源成本，分离配置的期望教育成本 $`0.75`$ 不会变成额外产出。因此分析信号时要分别写清楚信息收益与信号成本。工资差异反映信息与转移支付，不等于社会新增产出。

## 题 12｜廉价交流：为什么完全真实报告未必成立

<strong>题目</strong>

考虑 Crawford–Sobel 廉价交流模型（Cheap Talk）。自然决定状态 $`w\sim U[0,1]`$。发送者知道 $`w`$，接收者不知道。发送者可以免费发送消息 $`m`$，接收者观察消息后决定行动 $`f\in\mathbb R`$。

双方效用分别为：

```math
U_R(f,w)=-(f-w)^2,
```

```math
U_S(f,w)=-(f-w-c)^2,\qquad c>0.
```

（1）分别求两方在知道真实状态 $`w`$ 时最希望接收者采取的行动。

（2）假定完全真实报告制度下，发送者报告 $`m=w`$，接收者听到 $`m`$ 后选 $`f=m`$。证明该候选一般不是均衡。

（3）说明“发消息不需要成本”为什么并不意味着“消息必然没有信息”。

<strong>答案与解析</strong>

（1）接收者希望最小化平方误差：

```math
\min_f(f-w)^2,
```

故其理想行动是：

```math
\boxed{f_R^*(w)=w}.
```

发送者希望最小化另一项平方误差：

```math
\min_f(f-w-c)^2,
```

故其理想行动是：

```math
\boxed{f_S^*(w)=w+c}.
```

因为 $`c>0`$，发送者在任何给定状态下都希望接收者把行动定得比实际状态高 $`c`$。双方目标存在系统性的偏离。

（2）在完全真实报告候选中，发送者真实报告 $`m=w`$ 时，接收者选择 $`f=w`$。发送者的效用为：

```math
U_S^{\mathrm{truth}}
=-(w-w-c)^2=-c^2.
```

例如 $`w=0.4,c=0.1`$。如果发送者如实报告 $`m=0.4`$，则接收者行动 $`f=0.4`$，发送者收益 $`-0.01`$。

但发送者可以假报 $`m=0.5`$，若接收者继续遵照候选策略选 $`f=m`$，则接收者选 $`f=0.5`$，恰好是发送者最理想行动：

```math
U_S^{\mathrm{lie}}
=-(0.5-0.4-0.1)^2=0>-0.01.
```

因此该类型有严格偏离动机，完全真实报告不满足发送者的激励相容要求。更一般地，只要消息和行动空间允许把接收者的行动从 $`w`$ 往 $`w+c`$ 推近，发送者就可能通过虚报获益。

（3）廉价交流意味着发消息没有直接成本，不等于发送者偏好与接收者完全相反。当 $`c`$ 较小、双方目标比较接近时，发送者仍可能愿意透露粗略的状态区间，让接收者采取相对合理的行动；但由于偏好不完全一致，精确到每一个状态的真实披露通常不能稳定实现。

因此本讲廉价交流的两个重要结论并不矛盾：可以存在完全不传递信息的<strong>无信息交流均衡</strong>，也可以存在只传递区间信息的<strong>部分信息交流均衡</strong>。

## 题 13｜廉价交流：无信息交流（Babbling Equilibrium）

<strong>题目</strong>

继续使用题 12 的统一状态、效用和偏差设定：

```math
w\sim U[0,1],\quad
U_R=-(f-w)^2,\quad
U_S=-(f-w-c)^2.
```

考虑候选策略：发送者可以任意选择消息，但接收者完全不依赖消息，始终选择 $`f=1/2`$。

（1）证明接收者不依赖消息时，最优行动确实是 $`f=1/2`$。

（2）证明发送者单方面更换消息不能提高收益。

（3）计算此均衡下接收者的事前期望效用以及发送者的事前期望效用。

（4）解释该均衡为什么被称为“无信息交流”，以及其存在是否意味着所有廉价交流都只能无信息。

<strong>答案与解析</strong>

（1）假设发送者消息不含有关 $`w`$ 的信息，接收者观察任何消息后对状态的信念仍为 $`U[0,1]`$。接收者选择 $`f`$ 最大化期望效用，即最小化：

```math
\mathbb E[(f-w)^2].
```

展开：

```math
\begin{aligned}
\mathbb E[(f-w)^2]
&=f^2-2f\mathbb E[w]+\mathbb E[w^2]\\
&=f^2-f+\frac{1}{3}.
\end{aligned}
```

对 $`f`$ 求导：

```math
\frac{d}{df}\left(f^2-f+\frac{1}{3}\right)
=2f-1.
```

令导数为零，得 $`f=1/2`$；二阶导数为 $`2>0`$，所以这是唯一最小值。

也可以直接使用平方损失下的条件均值性质：

```math
\boxed{f^*=\mathbb E[w\mid m]}.
```

当消息没有信息时 $`\mathbb E[w\mid m]=\mathbb E[w]=1/2`$。

（2）接收者无论看到什么消息都选 $`1/2`$，因此类型为 $`w`$ 的发送者发任何消息所得收益均为：

```math
U_S(m,w)
=-\left(\frac{1}{2}-w-c\right)^2.
```

该表达式中没有消息 $`m`$。改变消息不改变接收者行动，也不改变发送者收益，故发送者对所有消息无差异，选择候选的消息策略就是最优的。

只要发送者的消息规则使观察消息后的后验仍为先验，例如所有类型都发同一个消息，接收者在每个消息后取 $`1/2`$ 就满足最优性与信念一致性。

（3）因为 $`w\sim U[0,1]`$，有 $`\mathbb E[w]=1/2`$、$`\operatorname{Var}(w)=1/12`$。

接收者事前效用为：

```math
\begin{aligned}
\mathbb E[U_R]
&=-\mathbb E\left[\left(\frac{1}{2}-w\right)^2\right]\\
&=-\operatorname{Var}(w)\\
&=\boxed{-\frac{1}{12}}.
\end{aligned}
```

发送者事前效用是：

```math
\begin{aligned}
\mathbb E[U_S]
&=-\mathbb E\left[\left(\frac{1}{2}-w-c\right)^2\right]\\
&=-\left[
\operatorname{Var}(w)
+\left(\frac{1}{2}-\mathbb E[w]-c\right)^2
\right]\\
&=\boxed{-\left(\frac{1}{12}+c^2\right)}.
\end{aligned}
```

（4）“无信息”指消息不改变接收者关于状态的信念，所以接收者无论听到什么消息都只会按先验均值行动。它能够成为均衡，是因为发送者明知接收者忽略消息，也无法通过单方面改换消息来改变结果。

这不代表廉价交流必然无信息。题 14 和题 15 将构造<strong>不同状态区间对应不同消息和不同接收者行动</strong>的均衡；那种均衡虽然不能准确报告每个 $`w`$，但确实传递了可用信息。

## 题 14｜廉价交流：两个消息区间的部分信息均衡

<strong>题目</strong>

继续使用 Crawford–Sobel 模型：

```math
w\sim U[0,1],\quad
U_R=-(f-w)^2,\quad
U_S=-(f-w-c)^2,\quad c>0.
```

考虑发送者按状态发送两档消息：

```math
m(w)=
\begin{cases}
m_1,&0\le w<w_1,\\
m_2,&w_1\le w\le1.
\end{cases}
```

接收者看到 $`m_1`$ 后选择 $`f_1`$，看到 $`m_2`$ 后选择 $`f_2`$。

（1）由接收者的条件期望最优性求 $`f_1,f_2`$。

（2）利用临界状态 $`w_1`$ 的发送者无差异条件求 $`w_1`$。

（3）求两档消息均以正概率出现的参数范围。

（4）取 $`c=0.1`$，求临界状态、两个行动和各消息发生概率，并检验区间内部类型不愿改换消息。

<strong>答案与解析</strong>

（1）由于 $`w`$ 均匀分布在 $`[0,1]`$，在两档消息都正概率出现的候选中：

```math
w\mid m_1\sim U[0,w_1),
\qquad
w\mid m_2\sim U[w_1,1].
```

平方损失下接收者的最佳行动是条件均值：

```math
\boxed{
f_1=\frac{w_1}{2},
\qquad
f_2=\frac{w_1+1}{2}
}.
```

因为 $`w_1\in(0,1)`$，必有 $`f_2>f_1`$。

（2）临界状态 $`w_1`$ 的发送者在两档消息之间必须无差异。对于发送者，理想行动是 $`w_1+c`$，因此：

```math
-(f_1-w_1-c)^2
=-(f_2-w_1-c)^2.
```

等价于：

```math
(f_1-w_1-c)^2
=(f_2-w_1-c)^2.
```

由于 $`f_1<f_2`$，若无差异且两个行动不同，发送者的理想行动必须位于两个行动的正中点：

```math
w_1+c=\frac{f_1+f_2}{2}.
```

代入接收者最佳行动：

```math
\begin{aligned}
w_1+c
&=\frac{1}{2}\left(
\frac{w_1}{2}+\frac{w_1+1}{2}
\right)\\
&=\frac{2w_1+1}{4}.
\end{aligned}
```

两边乘以 $`4`$：

```math
4w_1+4c=2w_1+1,
```

所以：

```math
\boxed{w_1=\frac{1}{2}-2c}.
```

（3）两档消息都真正出现，必须保证 $`0<w_1<1`$。当 $`c>0`$ 时，上界 $`w_1<1`$ 自动满足；下界要求：

```math
\frac{1}{2}-2c>0
\quad\Longleftrightarrow\quad
\boxed{0<c<\frac{1}{4}}.
```

这就是说偏好差距不能太大，否则无法维持两档有信息消息。特别注意：当 $`c=1/4`$ 时计算得到 $`w_1=0`$，低区间概率为零，已经不是严格意义上两个正长度区间的划分。

（4）代入 $`c=0.1`$：

```math
\begin{aligned}
w_1&=\frac{1}{2}-2(0.1)=\boxed{0.3},\\
f_1&=\frac{0.3}{2}=\boxed{0.15},\\
f_2&=\frac{0.3+1}{2}=\boxed{0.65}.
\end{aligned}
```

由于状态均匀分布，消息概率为：

```math
\boxed{\Pr(m_1)=0.3,\quad\Pr(m_2)=0.7}.
```

先检查临界状态。此时发送者理想行动是：

```math
w_1+c=0.3+0.1=0.4.
```

而两个行动的中点也是：

```math
\frac{0.15+0.65}{2}=0.4.
```

所以 $`w_1`$ 类型对两档消息无差异，且两个行动距离理想点同为 $`0.25`$。

再检查临界点两侧。发送者总是偏好“离自己理想行动 $`w+c`$ 更近”的那档接收者行动。由于 $`f_1<f_2`$：

```math
\begin{cases}
f_1\text{ 更近},&w+c<\frac{f_1+f_2}{2},\\
f_2\text{ 更近},&w+c>\frac{f_1+f_2}{2}.
\end{cases}
```

这里中点为 $`0.4`$，所以：

```math
\begin{cases}
w<0.3\ \Longrightarrow\ w+0.1<0.4
\ \Longrightarrow\ m_1\text{ 最优},\\
w>0.3\ \Longrightarrow\ w+0.1>0.4
\ \Longrightarrow\ m_2\text{ 最优}.
\end{cases}
```

边界 $`w=0.3`$ 无差异，归入哪档消息都不影响连续分布下的概率和接收者的条件均值。

因此，这一候选满足发送者各类型的激励相容、接收者的条件均值最优性和正概率消息的贝叶斯信念一致性，构成两档部分信息交流均衡。它传递的是“$`w`$ 位于低区间还是高区间”，而不是精确状态。

## 题 15｜廉价交流：一般 $`K`$ 档区间与最大可传递信息量

<strong>题目</strong>

沿用题 14 的模型，设发送者将 $`[0,1]`$ 分成 $`K\ge2`$ 个连续区间，边界依次为：

```math
0=w_0<w_1<\cdots<w_{K-1}<w_K=1.
```

第 $`k`$ 档区间长度为 $`\ell_k=w_k-w_{k-1}`$，接收者在该消息下选区间中点：

```math
f_k=\frac{w_{k-1}+w_k}{2}.
```

（1）写出相邻两档消息的边界类型无差异条件，并证明：

```math
\ell_{k+1}=\ell_k+4c.
```

（2）由区间总长度为 $`1`$，求 $`\ell_1`$，进而得到 $`K`$ 档正长度区间存在的参数条件。

（3）取 $`c=0.1`$，判断两档、三档是否可能。

（4）取 $`c=0.05`$，构造三档划分，求三个区间长度、两个内部边界、三个接收者行动，并逐个检验边界发送者无差异。

<strong>答案与解析</strong>

（1）相邻消息 $`m_k,m_{k+1}`$ 的交界为 $`w_k`$。该类型在两种接收者行动之间无差异：

```math
(f_k-w_k-c)^2
=(f_{k+1}-w_k-c)^2.
```

由于 $`f_{k+1}>f_k`$，等价于：

```math
w_k+c=\frac{f_k+f_{k+1}}{2}.
```

代入两个区间的条件均值：

```math
\begin{aligned}
w_k+c
&=\frac{1}{2}\left(
\frac{w_{k-1}+w_k}{2}
+\frac{w_k+w_{k+1}}{2}
\right)\\
&=\frac{w_{k-1}+2w_k+w_{k+1}}{4}.
\end{aligned}
```

整理：

```math
\begin{aligned}
4w_k+4c
&=w_{k-1}+2w_k+w_{k+1},\\
4c
&=(w_{k+1}-w_k)-(w_k-w_{k-1})\\
&=\ell_{k+1}-\ell_k.
\end{aligned}
```

故：

```math
\boxed{\ell_{k+1}=\ell_k+4c}.
```

因为 $`c>0`$，相邻区间长度逐步增加：高状态对应的区间更宽。这与发送者倾向于推动接收者行动向更高方向偏移的偏好有关。

（2）递推式给出：

```math
\ell_k=\ell_1+4c(k-1).
```

总长度为：

```math
\begin{aligned}
1
&=\sum_{k=1}^K\ell_k\\
&=\sum_{k=1}^K[\ell_1+4c(k-1)]\\
&=K\ell_1+4c\frac{K(K-1)}{2}\\
&=K\ell_1+2cK(K-1).
\end{aligned}
```

解得：

```math
\boxed{
\ell_1=\frac{1-2cK(K-1)}{K}
}.
```

当 $`c>0`$ 时，$`\ell_k`$ 递增，因此只需保证最短的第一档有正长度：

```math
\ell_1>0
\quad\Longleftrightarrow\quad
\boxed{c<\frac{1}{2K(K-1)}}.
```

这正是存在 $`K`$ 档<strong>非退化连续区间</strong>的条件。它表明，$`K`$ 越大，允许的偏好差距 $`c`$ 越小。无论消息本身可以多精细地命名，均衡中能够可信传递的状态区间数仍受到激励相容约束。

（3）当 $`c=0.1`$：

```math
\begin{aligned}
K=2:&\quad \frac{1}{2(2)(1)}=\frac{1}{4}=0.25>0.1,\\
K=3:&\quad \frac{1}{2(3)(2)}=\frac{1}{12}\approx0.0833<0.1.
\end{aligned}
```

所以：

```math
\boxed{
c=0.1\ \Longrightarrow\
\text{两档可能，三档不可能}
}.
```

无信息交流均衡仍然可能存在，因此这里不是在说“唯一均衡只能是两档”，而是在比较非退化有信息区间划分可以细到什么程度。

（4）当 $`c=0.05=1/20`$、$`K=3`$ 时：

```math
\begin{aligned}
\ell_1
&=\frac{1-2(0.05)(3)(2)}{3}\\
&=\frac{1-0.6}{3}
=\boxed{\frac{2}{15}}.
\end{aligned}
```

由于 $`4c=0.2=1/5`$：

```math
\begin{aligned}
\ell_2&=\ell_1+\frac{1}{5}
=\frac{2}{15}+\frac{3}{15}
=\boxed{\frac{1}{3}},\\
\ell_3&=\ell_2+\frac{1}{5}
=\frac{5}{15}+\frac{3}{15}
=\boxed{\frac{8}{15}}.
\end{aligned}
```

检验总长度：

```math
\frac{2}{15}+\frac{5}{15}+\frac{8}{15}=1.
```

内部边界是：

```math
\boxed{
w_1=\frac{2}{15},\qquad
w_2=\frac{2}{15}+\frac{1}{3}=\frac{7}{15}
}.
```

各区间的接收者最优行动等于区间均值：

```math
\begin{aligned}
f_1&=\frac{0+\frac{2}{15}}{2}
=\boxed{\frac{1}{15}},\\
f_2&=\frac{\frac{2}{15}+\frac{7}{15}}{2}
=\boxed{\frac{3}{10}},\\
f_3&=\frac{\frac{7}{15}+1}{2}
=\boxed{\frac{11}{15}}.
\end{aligned}
```

整理为：

| 消息 | 状态区间 | 区间长度 | 接收者行动 |
| --- | --- | --- | --- |
| $`m_1`$ | $`[0,2/15)`$ | $`2/15`$ | $`f_1=1/15`$ |
| $`m_2`$ | $`[2/15,7/15)`$ | $`1/3`$ | $`f_2=3/10`$ |
| $`m_3`$ | $`[7/15,1]`$ | $`8/15`$ | $`f_3=11/15`$ |

第一个临界状态 $`w_1=2/15`$ 的发送者理想行动为：

```math
w_1+c
=\frac{2}{15}+\frac{1}{20}
=\frac{8+3}{60}
=\frac{11}{60}.
```

两相邻行动中点：

```math
\frac{f_1+f_2}{2}
=\frac{\frac{1}{15}+\frac{3}{10}}{2}
=\frac{\frac{2}{30}+\frac{9}{30}}{2}
=\frac{11}{60}.
```

第二个临界状态 $`w_2=7/15`$ 的发送者理想行动为：

```math
w_2+c
=\frac{7}{15}+\frac{1}{20}
=\frac{28+3}{60}
=\frac{31}{60}.
```

两相邻行动中点：

```math
\frac{f_2+f_3}{2}
=\frac{\frac{3}{10}+\frac{11}{15}}{2}
=\frac{\frac{9}{30}+\frac{22}{30}}{2}
=\frac{31}{60}.
```

两处边界无差异均成立。由于 $`f_1<f_2<f_3`$，类型的理想行动 $`w+c`$ 随 $`w`$ 单调增加，区间内各类型对相应行动的距离最小；接收者行动又等于该区间的条件均值，所以该划分构成三档部分信息交流均衡。

这一题的求解顺序可概括为：<strong>相邻边界无差异 → 区间长度递推 → 总长度约束 → 正长度条件 → 条件均值与偏离检查</strong>。

## 题 16｜信号传递、筛选和廉价交流的辨析

<strong>题目</strong>

判断以下情境分别更接近 Signaling（信号传递）、Screening（筛选），还是 Cheap Talk（廉价交流），并说明信息与行动的先后关系。

（1）求职者知道自己的能力，先自行选择教育水平；企业看到教育后开出工资。

（2）企业不知道求职者的真实能力，先设计一组不同工作量与薪酬组成的合同；求职者根据自己的能力选择其中一种。

（3）掌握当地真实需求状况的部门向资源配置者免费报告一个需求区间；资源配置者收到报告后决定资源配置量。报告不能被直接核实，两方希望的配置量存在一定差异。

（4）说明为什么“谁掌握私人信息”不能单独决定属于 Signaling 还是 Screening。

<strong>答案与解析</strong>

（1）属于<strong>信号传递</strong>。知情的一方即求职者先采取可观察行动 $`e`$，不知情的企业再根据教育信号更新能力信念并决定工资。教育成本随类型不同，因此即使企业不能直接看到能力，也可能形成分离均衡。

（2）属于<strong>筛选</strong>。不知情的企业先设计菜单；拥有私人信息的求职者根据自身类型进行自我选择。企业不必先准确识别求职者，只需使不同类型从不同合同中获得更高效用。设计筛选菜单时通常要考虑各类型的<strong>激励相容</strong>：每类参与人选择为自己设计的合同，应至少不差于模仿其他类型选合同；如果参与是自愿的，还需考虑参与约束。

（3）属于<strong>廉价交流</strong>。掌握私人信息的一方先发不带直接成本、难以验证的消息；接收者根据消息与信念决定资源配置。即使消息免费，也可能像题 14 的均衡那样揭示部分状态区间。双方偏好不完全一致时，全部精确真实披露可能不具备激励相容性。

（4）Signaling 与 Screening 都涉及知情类型与不知情方的推断，区分它们最直接的依据是<strong>谁先设计或选择用来区分类型的机制</strong>：

| 维度 | Signaling：信号传递 | Screening：筛选 | Cheap Talk：廉价交流 |
| --- | --- | --- | --- |
| 谁拥有私人信息 | 信号发送者 | 合同选择者 | 消息发送者 |
| 谁先行动 | 知情者先选择可观察信号 | 不知情者先设计菜单 | 知情者先发送消息 |
| 信息揭示渠道 | 类型相关的可观察行为或成本信号 | 不同类型对合同菜单的自我选择 | 免费、通常不可验证的消息 |
| 课内关键条件 | 发送者激励相容与接收者贝叶斯更新 | 自我选择的激励相容 | 发送者消息激励与接收者条件最优行动 |

因此，仅说“求职者知道能力、企业不知道”并不足以分类。还必须观察模型规定的先后次序：是求职者先投入教育，让企业从行为中推断；还是企业先给合同，让求职者自行选择。

## 题 17｜综合判断：从候选策略到完整 PBE 的检验清单

<strong>题目</strong>

针对题 04 的二元投资信号博弈，判断以下说法的正误，并解释原因。

（1）如果发送者分离，而且两个信号均以正概率出现，那么接收者对这两个信号的后验都可以根据贝叶斯公式确定。

（2）如果发送者混同在 $`s=0`$，那么接收者见 $`s=1`$ 后的后验一定等于先验概率。

（3）只要接收者见某信号后的投资期望收益非负，该信号就必定成为均衡信号。

（4）在半分离均衡中，只要一个类型真正混合使用两个信号，这个类型对两个信号所导致的期望效用必须无差异。

（5）若接收者在某信号后以严格介于 $`0`$ 和 $`1`$ 之间的概率混合投资与拒绝，那么投资与拒绝必须带来相同的条件期望收益。

（6）弱 PBE 一旦被找到，就不可能再被直觉准则等精炼概念排除。

（7）若高类型发送高成本信号的成本低于低类型，就必定只有分离均衡，不会存在混同均衡。

（8）在廉价交流模型中，发送者的消息无直接成本，所以必定只能存在无信息交流均衡。

（9）面对一个新的动态贝叶斯博弈计算题，按何种顺序组织答案可以保证不遗漏主要检验？

<strong>答案与解析</strong>

<strong>（1）正确。</strong> 如果两个信号都在均衡路径上以正概率出现，贝叶斯公式分母不为零，其后验由先验和发送信号的策略确定。例如题 04 的分离均衡中，$`\mu_1=1,\mu_0=0`$。但“分离”本身只说明不同类型使用不同信号，具体哪个信号对应高类型仍须根据发送者策略确定。

<strong>（2）错误。</strong> 混同在 $`0`$ 意味着 $`1`$ 在均衡中发生概率为零。对于 $`\Pr(H\mid1)`$，通常的贝叶斯公式出现零分母，不能用“收到信号后信念等于先验”直接代替。在本讲弱 PBE 中，路径外信念可以另行指定，但仍需支持接收者的序贯最优行动；题 05 中可取 $`\mu_1\in[0,1/4]`$。

<strong>（3）错误。</strong> 接收者投资期望收益非负只说明给定信念时投资是一个最优反应，并不能保证发送者愿意发该信号。如果低类型发送该信号的成本超过投资带来的全部毛收益，低类型仍可能偏离，题 06 中混同在 $`1`$ 失败就是例子。

<strong>（4）正确。</strong> 若某类型给两个信号都分配正概率，则其在均衡中的这两个纯行动必须同为最优，否则它会把概率全部放到收益更高的行动上。题 07 中低类型的无差异条件 $`2\beta-1=0`$ 决定接收者投资概率 $`\beta=1/2`$。

<strong>（5）正确。</strong> 接收者同时以正概率采用两种行动，要求两者都为最佳反应，因此期望收益相等。在原投资收益结构下，这要求 $`4\mu-1=0`$，即 $`\mu=1/4`$。这条条件与发送者对信号的无差异条件共同决定半分离均衡的混合概率。

<strong>（6）错误。</strong> 弱 PBE 与更强的均衡精炼是不同要求。题 08 中的低先验混同弱 PBE 能找到一组自洽的路径外信念，但意外高成本信号只有高类型可能从中获益，直觉准则会挑战支持该混同结果的悲观路径外判断。

<strong>（7）错误。</strong> 不同类型的成本差异为分离提供可能，但信号实际是否有利可图，取决于接收者看到信号后的行动。在同一组题 04 参数下，题 04 的分离均衡与题 05 的混同弱 PBE 可以同时存在。

<strong>（8）错误。</strong> 消息免费使真实报告的可信性受到挑战，但不代表所有消息都毫无信息。题 14 的两档均衡与题 15 的三档均衡都在偏好差距较小时成立。接收者至少可以从消息中判断状态落入哪个区间。

<strong>（9）建议按以下顺序写完整解答。</strong>

第一步，写清自然对类型的先验分布、私人信息属于谁、谁先行动以及完整收益函数。这一步区分“实际类型”与“对类型的判断”。

第二步，明确每个人在所有可能观察条件下的完整策略。发送者要按类型写信号选择，接收者要按每个可能信号写后续行动；出现混合策略时还须规定概率。

第三步，根据候选发送者策略找出哪些信号在均衡路径上正概率出现，并对这些信号逐一计算贝叶斯后验。路径外信号的后验需要另外说明，不能把 $`0/0`$ 当成概率。

第四步，在每个接收者信息集上计算各行动的条件期望收益，得到最优反应。混合行动必须满足无差异，纯行动则须比较大小；若恰好无差异，应保留边界可能性。

第五步，对发送者的每一种类型分别计算遵守策略与偏离策略的净收益。特别检查不同类型的信号成本，不能只比较投资毛收益。连续信号空间还需考虑未列出的其他偏离信号。

第六步，把满足上述条件的完整策略与信念写成一个明确的 PBE。若题目再要求直觉准则或其他精炼，才进一步判断哪些弱 PBE 可以保留。

对于纯策略二元信号博弈，最常见的遗漏是：<strong>只给出“谁发哪个信号”而不写接收者的路径外行动；或者只写后验与接收者收益，却没有检查低类型模仿高类型是否有利可图。</strong> 这两种答案都不完整。
