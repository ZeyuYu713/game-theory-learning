# Lecture 02｜连续策略博弈：计算题与完整解析

[本讲知识笔记](../notes/lecture-02-strategic-form-games.md) · [第一讲习题](lecture-01-exercises.md) · [学习目录](../README.md)

第二讲从有限支付矩阵转向连续决策：努力水平、产量、价格、退出时间与政策位置都可能由参与者自行选择。本讲最容易出现的问题，并不是不会求导，而是算出一阶条件后就把结果直接当成纳什均衡。连续策略题还必须检查行动约束、二阶条件、对手的最优反应，以及模型的决策顺序。

前 11 题沿用原有题目，补全其中省略的收益比较和计算步骤；第 12、13 题分别增加 Stackelberg 先后行动和 Cournot 零产量边界问题；第 14 题复现原始课件中超过 90% 才盈利的投资协调博弈。第 15–17 题逐页对应课件的 Bertrand 四段最佳反应、双城镇居住隔离与 Downs 选举最佳反应。涉及消耗战时，会明确同时退出的处理规则；涉及 Hotelling 需求时，会明确内部需求公式的适用范围。

## 题 1｜从支付矩阵求最佳反应的交点

<strong>题目：</strong> 两名参与者同时行动，支付矩阵为：

| 玩家 1 / 玩家 2 | 左 $`L`$ | 右 $`R`$ |
| --- | --- | --- |
| 上 $`U`$ | (3,1) | (0,2) |
| 下 $`D`$ | (1,0) | (2,3) |

分别列出双方纯策略最佳反应，求出全部纯策略纳什均衡。

<strong>答案：</strong> 唯一纯策略纳什均衡为 $`(D,R)`$，均衡支付是 (2,3)，它也是严格纳什均衡。

<strong>第一步：求行玩家的最佳反应。</strong>

玩家 1 在矩阵中选择行，支付是每个格子的第一个数字。求最佳反应时固定列玩家的行动，因此要在同一列内竖向比较：

| 玩家 2 的行动 | 玩家 1 选 $`U`$ | 玩家 1 选 $`D`$ | 最佳反应 |
| --- | ---: | ---: | --- |
| $`L`$ | 3 | 1 | $`U`$ |
| $`R`$ | 0 | 2 | $`D`$ |

第一列 $`3>1`$，第二列 $`2>0`$，所以：

```math
BR_1(L)=\{U\},\qquad BR_1(R)=\{D\}.
```

<strong>第二步：求列玩家的最佳反应。</strong>

玩家 2 使用每个格子的第二个数字。固定玩家 1 的行，横向比较 $`L`$ 与 $`R`$：

| 玩家 1 的行动 | 玩家 2 选 $`L`$ | 玩家 2 选 $`R`$ | 最佳反应 |
| --- | ---: | ---: | --- |
| $`U`$ | 1 | 2 | $`R`$ |
| $`D`$ | 0 | 3 | $`R`$ |

因此：

```math
BR_2(U)=\{R\},\qquad BR_2(D)=\{R\}.
```

注意玩家 2 无论面对哪一行都选 $`R`$，所以 $`R`$ 是玩家 2 的严格占优行动；玩家 1 则没有严格占优行动，因为其最佳反应依赖玩家 2 的选择。

<strong>第三步：寻找相互最佳反应。</strong>

在 $`(D,R)`$ 处，玩家 1 面对 $`R`$ 的最佳反应恰好是 $`D`$，玩家 2 面对 $`D`$ 的最佳反应恰好是 $`R`$。其余三个格子至少有一人想单独改变：

| 候选组合 | 为什么是或不是均衡 |
| --- | --- |
| $`(U,L)`$ | 玩家 2 改选 $`R`$，收益 $`1\to2`$ |
| $`(U,R)`$ | 玩家 1 改选 $`D`$，收益 $`0\to2`$ |
| $`(D,L)`$ | 玩家 1 改选 $`U`$，收益 $`1\to3`$；玩家 2 也愿改选 $`R`$ |
| $`(D,R)`$ | 玩家 1 改选 $`U`$ 会从 2 降到 0；玩家 2 改选 $`L`$ 会从 3 降到 0 |

因此只有 $`(D,R)`$ 是纯策略纳什均衡，且双方任何单方偏离都严格变差，所以它是严格均衡。

## 题 2｜合伙人努力：纳什均衡与团队最优

<strong>题目：</strong> 两人分别选择努力 $`s_i\in[0,4]`$，各自效用为：

```math
u_i(s_1,s_2)=2(s_1+s_2+bs_1s_2)-s_i^2,
\qquad b=\frac{1}{4}.
```

求双方最佳反应、对称纳什均衡努力、使两人总支付最大的对称努力，并比较两者。

<strong>答案：</strong> 最佳反应为 $`BR_1(s_2)=1+s_2/4`$、$`BR_2(s_1)=1+s_1/4`$；纳什均衡是 $`s_1^{NE}=s_2^{NE}=4/3`$；社会最优是 $`s_1^{SO}=s_2^{SO}=4`$。本题均衡努力小于社会最优努力。

<strong>第一步：把玩家 1 的目标函数整理成关于自己的二次函数。</strong>

固定玩家 2 的努力 $`s_2`$，玩家 1 只决定 $`s_1`$。原来的效用可以写成：

```math
u_1=2s_1+2s_2+2bs_1s_2-s_1^2.
```

对 $`s_1`$ 求偏导，注意 $`s_2`$ 此时视为常数：

```math
\frac{\partial u_1}{\partial s_1}
=2+2bs_2-2s_1.
```

令一阶导数等于零：

```math
2+2bs_2-2s_1=0
\quad\Longrightarrow\quad
s_1=1+bs_2.
```

二阶导数是：

```math
\frac{\partial^2u_1}{\partial s_1^2}=-2<0.
```

因此在其他条件不变时，效用关于自己的努力严格凹，一阶条件给出唯一内部最大值候选。

<strong>第二步：核对候选解是否满足努力上限。</strong>

因为 $`b=1/4`$，且对方可以选择的努力在 $`[0,4]`$ 之间，所以：

```math
1+\frac{1}{4}s_2\in[1,2]\subset[0,4].
```

这说明一阶条件算出的努力始终可行，不需要再把解截断到 0 或 4。因此玩家 1 的完整最佳反应确实是：

```math
BR_1(s_2)=1+\frac{s_2}{4}.
```

同理，对玩家 2 关于 $`s_2`$ 求偏导：

```math
BR_2(s_1)=1+\frac{s_1}{4}.
```

两条最佳反应斜率都是正的 $`1/4`$。对方多努力一点，我也更愿意努力，因为总产出中存在正的协同项 $`bs_1s_2`$。

<strong>第三步：联立最佳反应求纳什均衡。</strong>

纳什均衡必须让两人的行动同时满足：

```math
s_1=1+\frac{s_2}{4},
\qquad
s_2=1+\frac{s_1}{4}.
```

由对称性可以先设 $`s_1=s_2=s`$，得到：

```math
s=1+\frac{s}{4}
\quad\Longrightarrow\quad
\frac{3s}{4}=1
\quad\Longrightarrow\quad
s=\frac{4}{3}.
```

代回原来两条最佳反应，可验证：

```math
BR_1\left(\frac{4}{3}\right)
=1+\frac{1}{4}\cdot\frac{4}{3}
=\frac{4}{3}
=BR_2\left(\frac{4}{3}\right).
```

由于此线性方程组的解唯一，且两人的目标函数对自己的努力严格凹，所以得到唯一纯策略纳什均衡：

```math
(s_1^{NE},s_2^{NE})
=\left(\frac{4}{3},\frac{4}{3}\right).
```

<strong>第四步：改变评价目标，求团队总支付最大值。</strong>

个人最优化时，每个人只考虑自己的效用。社会最优则要把两人的效用相加：

```math
W(s_1,s_2)=u_1+u_2
=4(s_1+s_2+bs_1s_2)-s_1^2-s_2^2.
```

对 $`s_1`$ 与 $`s_2`$ 分别求偏导：

```math
\frac{\partial W}{\partial s_1}
=4+4bs_2-2s_1,
\qquad
\frac{\partial W}{\partial s_2}
=4+4bs_1-2s_2.
```

令两式为零，将 $`b=1/4`$ 代入：

```math
4+s_2-2s_1=0,\qquad
4+s_1-2s_2=0.
```

两式相减得 $`s_1=s_2`$；继续代回，$`4+s-2s=0`$，得到 $`s=4`$。

<strong>第五步：检查社会最优在边界上是否成立。</strong>

社会最优候选 $`(4,4)`$ 恰好到达两人的行动上界。不能因为它位于边界就否定一阶条件，也不能再允许努力超过 4。总收益的 Hessian 矩阵为：

```math
H_W=
\begin{pmatrix}
-2&4b\\
4b&-2
\end{pmatrix}
=
\begin{pmatrix}
-2&1\\
1&-2
\end{pmatrix}.
```

其特征值为 -1 和 -3，均为负，所以 $`W`$ 严格凹；结合 $`(4,4)`$ 可行，可以确认它就是唯一的社会最优点。

<strong>第六步：比较两个结果的实际收益。</strong>

在对称努力 $`s_1=s_2=s`$ 时，每人的效用可化为：

```math
u_i(s,s)=2\left(2s+\frac{s^2}{4}\right)-s^2
=4s-\frac{s^2}{2}.
```

纳什均衡下：

```math
u_i^{NE}
=4\cdot\frac{4}{3}
-\frac{1}{2}\left(\frac{4}{3}\right)^2
=\frac{40}{9}.
```

社会最优下：

```math
u_i^{SO}=4(4)-\frac{4^2}{2}=8.
```

| 结果 | 每人努力 | 每人收益 | 团队总收益 |
| --- | ---: | ---: | ---: |
| 纳什均衡 | $`4/3`$ | $`40/9`$ | $`80/9`$ |
| 社会最优 | 4 | 8 | 16 |

努力不足不是求导出错，而是两人平分共同产出、单独承担努力成本导致的外部性。社会规划者会计入一人的努力给另一人带来的额外好处；个人在原博弈中没有完全计入这一部分。

## 题 3｜Cournot 双寡头：从利润函数到均衡利润

<strong>题目：</strong> 两家企业同时决定产量，市场逆需求为 $`P=100-(q_1+q_2)`$，每家企业边际成本为 20、没有固定成本。求最佳反应函数、纳什均衡产量、总产量、市场价格及两家利润。

<strong>答案：</strong> $`q_1^{*}=q_2^{*}=80/3`$，总产量 $`Q^{*}=160/3`$，市场价格 $`P^{*}=140/3`$，每家利润 $`\pi_i^{*}=6400/9`$。

<strong>第一步：明确决策变量与约束。</strong>

Cournot 竞争中，两家企业同时决定各自的产量 $`q_1,q_2\ge0`$。市场价格不是任何一家直接选择的，而是总产量进入逆需求函数后的结果：

```math
Q=q_1+q_2,\qquad P(Q)=100-Q.
```

企业 1 的利润等于销售收入减生产成本：

```math
\pi_1=P(Q)q_1-20q_1
=\big[100-(q_1+q_2)-20\big]q_1.
```

整理为：

```math
\pi_1(q_1,q_2)
=(80-q_1-q_2)q_1
=80q_1-q_1^2-q_1q_2.
```

企业 2 的利润同理：

```math
\pi_2(q_1,q_2)
=80q_2-q_2^2-q_1q_2.
```

<strong>第二步：固定对手产量，对自己的产量求导。</strong>

企业 1 选择 $`q_1`$ 时，把 $`q_2`$ 视为给定量：

```math
\frac{\partial\pi_1}{\partial q_1}
=80-2q_1-q_2.
```

令一阶导数为零：

```math
80-2q_1-q_2=0
\quad\Longrightarrow\quad
q_1=40-\frac{q_2}{2}.
```

因为：

```math
\frac{\partial^2\pi_1}{\partial q_1^2}=-2<0,
```

该内部候选点给出利润最大值。但当对方产量非常大时，$`40-q_2/2`$ 可能是负数，违反 $`q_1\ge0`$。这时企业 1 的最佳行动应是停止生产，而不是选择负产量。因此完整最佳反应为：

```math
BR_1(q_2)=\max\left\{0,\ 40-\frac{q_2}{2}\right\}.
```

对企业 2 重复相同步骤：

```math
\frac{\partial\pi_2}{\partial q_2}
=80-q_1-2q_2=0,
```

```math
BR_2(q_1)=\max\left\{0,\ 40-\frac{q_1}{2}\right\}.
```

<strong>第三步：在双方产量均为正的区域联立。</strong>

暂设两家都积极生产，则最佳反应变为线性方程组：

```math
2q_1+q_2=80,\qquad
q_1+2q_2=80.
```

第一式减去第二式：

```math
q_1-q_2=0\quad\Longrightarrow\quad q_1=q_2.
```

设共同产量为 $`q`$，则：

```math
2q+q=80
\quad\Longrightarrow\quad
q=\frac{80}{3}.
```

因此：

```math
q_1^{*}=q_2^{*}=\frac{80}{3}.
```

<strong>第四步：检验非负性和最佳反应。</strong>

$`80/3>0`$，所以求得的解位于之前假设的正产量区域。代回最佳反应：

```math
BR_1\left(\frac{80}{3}\right)
=40-\frac{40}{3}
=\frac{80}{3},
```

企业 2 同样成立。这说明两家企业在对方给定均衡产量时，都已经选择了自身利润最大的产量，因而构成 Cournot–Nash 均衡。

<strong>第五步：计算价格与利润。</strong>

总产量：

```math
Q^{*}=q_1^{*}+q_2^{*}
=\frac{80}{3}+\frac{80}{3}
=\frac{160}{3}.
```

市场价格：

```math
P^{*}=100-Q^{*}
=100-\frac{160}{3}
=\frac{140}{3}.
```

单位产品利润为：

```math
P^{*}-c=\frac{140}{3}-20=\frac{80}{3}.
```

所以每家企业利润：

```math
\pi_i^{*}
=(P^{*}-c)q_i^{*}
=\frac{80}{3}\cdot\frac{80}{3}
=\frac{6400}{9}.
```

最后检查经济含义：两家每家的最佳反应都随对手产量增加而减少，斜率为 $`-1/2`$，所以产量是战略替代行动。不能把 $`q_1+q_2`$ 当成某一家企业的决策变量直接求导，否则就会错误地把 Cournot 问题写成垄断者的总产量选择。

## 题 4｜标准 Bertrand：为什么两家报价会降至边际成本

<strong>题目：</strong> 两家企业生产完全同质产品，均有无限产能，边际成本都为 20，同时选择价格。消费者向价格较低的企业购买；若报价相同，两家平分市场需求。求纯策略均衡价格，并说明两家都报价 30 为什么不是均衡。

<strong>答案：</strong> 在需求为正的标准 Bertrand 条件下，唯一纯策略均衡价格是 $`p_1^{*}=p_2^{*}=20`$。若两家都报 30，任一家小幅降价就可以取得全部需求，并提高利润。

<strong>第一步：写出需求如何由双方报价决定。</strong>

令 $`D(p)`$ 为市场在价格 $`p`$ 时的总需求。企业 1 实际销售量取决于双方相对价格：

```math
D_1(p_1,p_2)=
\begin{cases}
D(p_1),&p_1<p_2,\\
\frac{D(p_1)}{2},&p_1=p_2,\\
0,&p_1>p_2.
\end{cases}
```

因此企业 1 的利润是：

```math
\pi_1(p_1,p_2)=(p_1-20)D_1(p_1,p_2).
```

企业 2 的规则对称。这里与 Cournot 最大的不同是：只要报价略微低于对手，需求就可能从半个市场跳到整个市场，所以需求不是关于自身价格处处光滑的单一函数。

<strong>第二步：证明共同报价 30 不是均衡。</strong>

若两家同时报 30，各分得一半市场，每家利润为：

```math
\pi_i(30,30)=(30-20)\frac{D(30)}{2}
=5D(30).
```

如果企业 1 把价格从 30 降为 $`30-\varepsilon`$，其中 $`0<\varepsilon<10`$ 且充分小，则它的报价略低于企业 2，独占市场需求，利润变为：

```math
\pi_1(30-\varepsilon,30)
=(10-\varepsilon)D(30-\varepsilon).
```

只要需求在 30 附近连续且 $`D(30)>0`$，当 $`\varepsilon`$ 足够小时，降价后的利润接近 $`10D(30)`$，严格高于原来的 $`5D(30)`$。所以 $`(30,30)`$ 不是纳什均衡。

若沿用第 3 题的市场需求 $`D(p)=100-p`$，会得到更直观的数值。两家都报 30 时，每家销售 35 单位，利润是 $`10\times35=350`$；企业 1 改报 29.99 时，销售 70.01 单位，利润为 $`9.99\times70.01=699.3999`$，明显更高。

<strong>第三步：检验共同报价 20。</strong>

双方都报 $`p_1=p_2=20`$，由于价格等于成本，两家利润均为 0。

如果企业 1 单方面降到 20 以下，虽然可以吸收全部需求，但每卖出一单位就会亏损，利润为负，不如维持 0。

如果企业 1 单方面涨到 20 以上，产品与对手完全同质，消费者都选择继续报 20 的企业 2，企业 1 的销售量变为 0，利润仍是 0，无法严格提高。

因此，在玩家 2 报价 20 时，玩家 1 没有有利偏离；对玩家 2 同理，$`(20,20)`$ 是纳什均衡。

<strong>第四步：说明为什么标准假设下没有其他纯策略均衡。</strong>

若两家价格相等且高于成本，任一方都可以微小降价夺走整个市场。若报价不等且较低价格仍高于成本，较高报价者可以略微压过较低报价，获得正利润，原组合不稳定。若某家在成本以下销售，它至少可以通过退出需求争夺来避免亏损。若一方恰报成本而另一方价格更高，报成本的一方还可把价格提高到对手之下、取得正利润。因此在标准连续定价、同质产品与无产能约束的设定中，只有双方报价都等于成本才稳定。

这里出现的“伯特兰悖论”依赖同质产品、无差别消费者、可小幅调价及产能充足等条件。若产品有差异、顾客不愿频繁更换卖家，或低价企业不能服务全部消费者，则需求分配规则改变，不能直接推出 $`p=c`$。

## 题 5｜Hotelling 线性城市：从无差异消费者到均衡定价

<strong>题目：</strong> 消费者均匀分布在 $`[0,1]`$ 上，两家商店位于 0 和 1。位于 $`x`$ 的消费者购买两家的效用分别为：

```math
U_1(x)=v-p_1-2x^2,
\qquad
U_2(x)=v-p_2-2(1-x)^2.
```

双方边际成本均为 1。假定基础价值 $`v`$ 足够高，使市场完全覆盖。求无差异消费者、内部需求区域的价格最佳反应、对称价格均衡以及每家利润。

<strong>答案：</strong> 无差异点为 $`x^{*}=1/2+(p_2-p_1)/4`$；内部区域的价格最佳反应为 $`p_1=(3+p_2)/2`$、$`p_2=(3+p_1)/2`$；对称均衡 $`p_1^{*}=p_2^{*}=3`$，各占一半市场，每家利润为 1。

<strong>第一步：找出刚好对两家无差异的消费者。</strong>

在均匀分布的线性城市中，位于较左边的消费者通常偏好商店 1，较右边的消费者偏好商店 2。两家市场份额的分界点不是事先规定的，而是通过效用相等求出：

```math
v-p_1-2x^2=v-p_2-2(1-x)^2.
```

消去共同的 $`v`$，并展开右侧平方项：

```math
-p_1-2x^2
=-p_2-2(1-2x+x^2).
```

继续展开：

```math
-p_1-2x^2
=-p_2-2+4x-2x^2.
```

两边的 $`-2x^2`$ 抵消，整理为：

```math
4x=2+p_2-p_1.
```

故无差异点：

```math
x^{*}=\frac{1}{2}+\frac{p_2-p_1}{4}.
```

<strong>第二步：利用均匀分布写需求。</strong>

在分界点确实落在 $`(0,1)`$ 的情况下，商店 1 得到左侧 $`[0,x^{*}]`$ 的消费者，商店 2 得到右侧 $`[x^{*},1]`$ 的消费者。因此：

```math
D_1=x^{*}
=\frac{1}{2}+\frac{p_2-p_1}{4},
```

```math
D_2=1-x^{*}
=\frac{1}{2}+\frac{p_1-p_2}{4}.
```

这两个式子要求 $`0<x^{*}<1`$，即：

```math
-2<p_2-p_1<2.
```

如果价格差过大，分界点会落到线性城市区间之外，某一家可能拿走整个市场。此时不能继续使用未截断的线性需求，必须把市场份额限制在 0 与 1 之间。

<strong>第三步：写利润函数，对自身价格求导。</strong>

商店 1 的单位利润是 $`p_1-1`$，销售量为 $`D_1`$：

```math
\pi_1(p_1,p_2)
=(p_1-1)\left(\frac{1}{2}+\frac{p_2-p_1}{4}\right).
```

求导时使用乘积法则：

```math
\frac{\partial\pi_1}{\partial p_1}
=\left(\frac{1}{2}+\frac{p_2-p_1}{4}\right)
+(p_1-1)\left(-\frac{1}{4}\right).
```

整理：

```math
\frac{\partial\pi_1}{\partial p_1}
=\frac{3+p_2-2p_1}{4}.
```

令其为零：

```math
3+p_2-2p_1=0
\quad\Longrightarrow\quad
p_1=\frac{3+p_2}{2}.
```

二阶导数是：

```math
\frac{\partial^2\pi_1}{\partial p_1^2}
=-\frac{1}{2}<0,
```

所以在内部需求区域，这给出唯一利润最大化价格。同理可得商店 2 的内部最优价格：

```math
p_2=\frac{3+p_1}{2}.
```

这里常用的写法 $`BR_1(p_2)=(3+p_2)/2`$、$`BR_2(p_1)=(3+p_1)/2`$，严格来说是<strong>内部分界点成立时的最佳反应表达式</strong>。把它当作任意对手价格下的全局反应函数，可能算出不可行的市场份额。

<strong>第四步：联立得到对称价格均衡。</strong>

两条内部最佳反应同时成立：

```math
2p_1=3+p_2,\qquad
2p_2=3+p_1.
```

相减得 $`p_1=p_2`$。设共同价格为 $`p`$：

```math
2p=3+p
\quad\Longrightarrow\quad p=3.
```

因此：

```math
p_1^{*}=p_2^{*}=3.
```

代回无差异点与需求：

```math
x^{*}=\frac{1}{2},
\qquad
D_1^{*}=D_2^{*}=\frac{1}{2}.
```

两家的利润均为：

```math
\pi_i^{*}=(3-1)\cdot\frac{1}{2}=1.
```

<strong>第五步：检查这个对称均衡在完整需求规则下也稳定。</strong>

固定商店 2 报价 3。商店 1 的完整需求可按自身报价分段讨论：

| 商店 1 的报价 | 市场份额 | 商店 1 的利润 |
| --- | --- | --- |
| $`p_1\le1`$ | 1 | $`p_1-1\le0`$ |
| $`1<p_1<5`$ | $`(5-p_1)/4`$ | $`(p_1-1)(5-p_1)/4`$ |
| $`p_1\ge5`$ | 0 | 0 |

在中间区域：

```math
\pi_1(p_1,3)
=\frac{(p_1-1)(5-p_1)}{4}.
```

继续求导可得：

```math
\frac{d\pi_1(p_1,3)}{dp_1}
=\frac{3-p_1}{2},
```

利润在 $`p_1=3`$ 达到最大值 1；两端的利润不超过 0。因此，不仅内部一阶条件成立，考虑全部市场份额边界后，商店 1 也没有有利偏离。商店 2 对称，所以 $`(3,3)`$ 确实是纳什均衡。

<strong>经济解释：</strong> 同质 Bertrand 中，只要便宜一点就能争夺整个市场；这里顾客还承担距离损失，靠近商店 1 的人即使看到商店 2 略便宜，也可能继续在商店 1 购买。因此均衡价格可以高于成本。两条内部价格反应函数的斜率为正 $`1/2`$，体现价格战略互补。

## 题 6｜消耗战：纯策略退出时间为什么出现两个均衡集合

<strong>题目：</strong> 两名玩家争夺一份奖品，其估值分别为 $`v_1=3`$、$`v_2=5`$，时间成本率均为 1。双方同时承诺退出时间 $`t_1,t_2\ge0`$。先退出的一方输掉奖品并承担此前等待成本；后退出的一方赢得奖品，也承担直到对手退出的等待成本。求纯策略纳什均衡的退出时间集合。

<strong>答案：</strong> 在同时退出时平分中奖概率、双方均承担截至退出时的时间成本这一规则下，全部纯策略纳什均衡是：

```math
(t_1,t_2)=(0,t_2),\quad t_2\ge3,
```

或：

```math
(t_1,t_2)=(t_1,0),\quad t_1\ge5.
```

原题没有规定同一时刻退出时的收益，因此若不补充平局规则，严格说来只能列出典型的非同时退出均衡。本题采用上述常见规则，使“全部纯策略均衡”的判断有明确含义。

<strong>第一步：按谁先退出写支付函数。</strong>

如果玩家 1 在玩家 2 之前退出，即 $`t_1<t_2`$，玩家 1 在时间 $`t_1`$ 输掉奖品，收益为 $`-t_1`$；玩家 2 在同一时刻赢得奖品，收益为 $`5-t_1`$：

```math
(u_1,u_2)=(-t_1,\ 5-t_1),
\qquad t_1<t_2.
```

如果玩家 2 先退出，即 $`t_2<t_1`$：

```math
(u_1,u_2)=(3-t_2,\ -t_2),
\qquad t_2<t_1.
```

若同时退出，即 $`t_1=t_2=t`$，假定两人分别以 $`1/2`$ 概率获得奖品，则期望收益为：

```math
(u_1,u_2)=\left(\frac{3}{2}-t,\ \frac{5}{2}-t\right).
```

注意真正发生的等待时间是两人退出时间的较小值，而不是赢家事先承诺的时间。例如 $`(t_1,t_2)=(0,4)`$ 时，比赛在时间 0 就结束，玩家 2 不需要真的等到时间 4。

<strong>第二步：证明纯策略均衡中输家必须立刻退出。</strong>

假设在一个候选结果中，玩家 1 输掉奖品且在正时间 $`t_1>0`$ 才退出。由于玩家 1 最终仍然输掉奖品，他得到的是 $`-t_1<0`$。如果单独把退出时间改为 0，仍会输，却不再承担等待成本，收益提高到 0。因此原候选结果不可能是纳什均衡。

同理，若玩家 2 最终输掉奖品，也不可能在正时间退出。故不同时退出的纯策略均衡，必然形如“一方时间为 0，另一方时间严格为正”。

<strong>第三步：分析玩家 1 立即退出的情况。</strong>

设 $`t_1=0`$、$`t_2>0`$。玩家 1 当前收益是 0，玩家 2 立即赢得奖品，收益是 5。

固定玩家 2 承诺的 $`t_2`$，玩家 1 可以考虑三种偏离：

| 玩家 1 的选择 | 结果 | 玩家 1 的收益 |
| --- | --- | --- |
| 保持 $`t_1=0`$ | 立即退出 | 0 |
| 改为 $`0<t_1<t_2`$ | 仍先退出，白白等待 | $`-t_1<0`$ |
| 改为 $`t_1>t_2`$ | 等玩家 2 先退出后获得奖品 | $`3-t_2`$ |

真正可能提高玩家 1 收益的偏离是“坚持得比玩家 2 更久”。为了让这种偏离不比当前的 0 更好，必须满足：

```math
3-t_2\le0
\quad\Longleftrightarrow\quad
t_2\ge3.
```

如果二人同时在 $`t_2`$ 退出，玩家 1 的期望收益为 $`3/2-t_2`$。在 $`t_2\ge3`$ 时，这个数也小于 0，所以平局偏离不会推翻上述条件。

至于玩家 2，他当前无需等待便独得奖品，收益为 5。只要仍选择任意正的退出时间，就同样在时间 0 获胜，收益仍为 5；若改为时间 0，则变成同时退出，只能得到期望奖品价值 $`5/2`$，反而降低。因此玩家 2 也没有有利偏离。

所以第一类均衡为：

```math
\{(0,t_2):t_2\ge3\}.
```

例如 $`(0,4)`$ 属于该集合，但 $`(0,2)`$ 不是：若玩家 1 改为退出时间 3，就能在时间 2 赢得奖品，收益 $`3-2=1>0`$。

<strong>第四步：分析玩家 2 立即退出的情况。</strong>

设 $`t_2=0`$、$`t_1>0`$。玩家 2 当前收益为 0。若他坚持到比玩家 1 更晚退出，将在时间 $`t_1`$ 获得价值为 5 的奖品，净收益是 $`5-t_1`$。

为了让玩家 2 不愿意偏离，要求：

```math
5-t_1\le0
\quad\Longleftrightarrow\quad
t_1\ge5.
```

于是第二类均衡为：

```math
\{(t_1,0):t_1\ge5\}.
```

<strong>第五步：为什么不会遗漏同时退出的纯策略均衡？</strong>

若 $`t_1=t_2=t`$，双方按题设平局规则只能获得一半的中奖概率。任意一方只要把自己的退出时间稍微调到 $`t+\varepsilon`$，便可以在对方退出时获得整个奖品，实际等待成本仍是 $`t`$，从而增加期望收益 $`v_i/2>0`$。所以同时退出不能是纯策略均衡。

两类均衡不表示消耗战必然持续 3 或 5 个单位时间。只要有人承诺在时间 0 退出，比赛立即结束。退出时间变量表达的是双方愿意坚持到什么程度，不能直接当成最终实际经过的时间。

## 题 7｜位置竞争与中位选民：为什么双方选择 5

<strong>题目：</strong> 两名候选人只能在整数位置 1 至 9 中选择政策立场。选民理想位置关于 5 对称，每个整数位置都有正的选民质量。选民支持与自己理想点距离最近的候选人；若两人政策相同则平分选票。候选人以最大化选票份额为目标。说明 $`(5,5)`$ 为什么是纳什均衡。

<strong>答案：</strong> $`(5,5)`$ 是严格纯策略纳什均衡：双方各获得一半选票，任何一方单独偏离到 5 左侧或右侧，都会得到严格少于一半的选票。

<strong>第一步：求共同选择位置 5 时的收益。</strong>

两名候选人的政策位置完全相同，所以每位选民对两者距离相等，按照题设平分选票：

```math
V_1(5,5)=V_2(5,5)=\frac{1}{2}.
```

候选人的收益是选票份额，不是选民距离的总和。这一点决定了本题不能直接求“所有选民距离之和最小”的政策位置来替代候选人的最佳反应。

<strong>第二步：固定候选人 2 在位置 5，考察候选人 1 向左偏离。</strong>

设候选人 1 改选 $`k<5`$。任何理想位置位于 5 及其右侧的选民，都会更加接近仍在位置 5 的候选人 2；候选人 1 最多能够争取到中位数左侧的选民。

由于选民分布关于 5 对称，且位置 5 的选民质量严格为正，左侧选民的总质量严格小于 $`1/2`$。所以：

```math
V_1(k,5)<\frac{1}{2},
\qquad k<5.
```

候选人 1 向左偏离无法增加自己的选票份额。

<strong>第三步：考察向右偏离。</strong>

如果候选人 1 改选 $`k>5`$，留在位置 5 的候选人 2 至少吸引中位数及其左侧的选民。由分布对称性，候选人 1 最多只能拿到位置 5 右侧的选民，其总质量也严格小于一半：

```math
V_1(k,5)<\frac{1}{2},
\qquad k>5.
```

因此无论向左还是向右，只要离开 5，候选人 1 的得票份额都严格下降。候选人 2 的论证对称，所以双方均不愿单独偏离。

<strong>第四步：用等质量选民作数值示范。</strong>

如果 1 至 9 的每个位置各有 $`1/9`$ 的选民，双方都在 5 时各得 $`1/2`$。固定候选人 2 在 5，候选人 1 改到位置 4，则位置 1、2、3、4 的选民投给候选人 1，其余位置投给候选人 2：

```math
V_1(4,5)=\frac{4}{9}
<\frac{1}{2}.
```

向右移到 6 的结论相同；移得更远也不能拿到比中位数一侧更多的选票。所以 $`(5,5)`$ 满足严格纳什均衡条件。

这里的严格性依赖“位置 5 有正的选民质量”以及候选人以选票份额为目标。如果中位数不唯一、存在选民投票弃权、多维政策或候选人能力差异，不能直接沿用这一结论。

## 题 8｜严格支配、弱支配与逐次删除

<strong>题目：</strong> 给定以下三行三列的支付矩阵，找出可以直接删除的严格被支配纯行动，然后在简化后的博弈中继续检查支配关系与均衡。

| 玩家 1 / 玩家 2 | $`L`$ | $`C`$ | $`R`$ |
| --- | --- | --- | --- |
| $`U`$ | (7,3) | (0,4) | (4,4) |
| $`M`$ | (4,6) | (1,5) | (5,3) |
| $`D`$ | (3,8) | (0,2) | (3,0) |

<strong>答案：</strong> 玩家 1 的 $`D`$ 被 $`M`$ 严格支配，可以直接删除；删去 $`D`$ 后，玩家 2 的 $`R`$ 被 $`C`$ 弱支配，但不是严格支配，因此不能作为“逐次删除严格被支配策略”的一步直接删除。本题没有纯策略纳什均衡。

<strong>第一步：在所有列下，比较玩家 1 的行动。</strong>

玩家 1 的支付由每个格子的第一个数字构成：

| 玩家 1 行动 | 面对 $`L`$ | 面对 $`C`$ | 面对 $`R`$ |
| --- | ---: | ---: | ---: |
| $`U`$ | 7 | 0 | 4 |
| $`M`$ | 4 | 1 | 5 |
| $`D`$ | 3 | 0 | 3 |

比较 $`M`$ 与 $`D`$，在三列下分别有：

```math
4>3,\qquad 1>0,\qquad 5>3.
```

因此 $`M`$ 在对手每种可能行动下都给玩家 1 严格更高的支付。$`D`$ 被 $`M`$ 严格支配，可以删除。

对比 $`U`$ 与 $`M`$ 则不能删除任一方：面对 $`L`$，$`U`$ 得 7 高于 $`M`$ 的 4；面对 $`C`$ 与 $`R`$，$`M`$ 反而更好。所以二者之间没有纯行动的严格支配关系。

<strong>第二步：在删除 $`D`$ 后，重新检查玩家 2。</strong>

简化矩阵保留 $`U`$、$`M`$ 两行：

| 玩家 1 / 玩家 2 | $`L`$ | $`C`$ | $`R`$ |
| --- | --- | --- | --- |
| $`U`$ | (7,3) | (0,4) | (4,4) |
| $`M`$ | (4,6) | (1,5) | (5,3) |

玩家 2 的支付是：

| 玩家 2 行动 | 面对 $`U`$ | 面对 $`M`$ |
| --- | ---: | ---: |
| $`L`$ | 3 | 6 |
| $`C`$ | 4 | 5 |
| $`R`$ | 4 | 3 |

比较 $`C`$ 与 $`R`$：

```math
u_2(U,C)=4=4=u_2(U,R),
```

```math
u_2(M,C)=5>3=u_2(M,R).
```

所以 $`C`$ 弱支配 $`R`$：有一行相等，另一行严格更好。但它不严格支配 $`R`$，因为严格支配必须在对手的每一个可能行动下都出现严格不等式。

如果题目只允许“逐次删除严格被支配纯策略”，那么经过删除 $`D`$ 之后，不能把删除 $`R`$ 当作合规的第二步。

<strong>第三步：不依赖删除法，直接检查纯策略均衡。</strong>

原博弈中，玩家 1 的最佳反应为：

```math
BR_1(L)=\{U\},\quad
BR_1(C)=\{M\},\quad
BR_1(R)=\{M\}.
```

玩家 2 的最佳反应为：

```math
BR_2(U)=\{C,R\},\quad
BR_2(M)=\{L\},\quad
BR_2(D)=\{L\}.
```

逐格对照可以发现：玩家 1 面对 $`L`$ 要选 $`U`$，但玩家 2 面对 $`U`$ 要选 $`C`$ 或 $`R`$；玩家 1 面对 $`C`$ 或 $`R`$ 要选 $`M`$，但玩家 2 面对 $`M`$ 要选 $`L`$。不存在双方最佳反应同时成立的格子，所以本题没有纯策略纳什均衡。

<strong>延伸：混合均衡可以怎样求？</strong>

为了展示简化方法，先在 $`U,M`$ 与 $`L,C`$ 的二乘二子博弈中求内部混合均衡，之后回到原矩阵检查删除行动是否有利。

设玩家 1 选择 $`U`$ 的概率为 $`p`$，玩家 2 选择 $`L`$ 的概率为 $`q`$。玩家 1 对 $`U`$、$`M`$ 无差异要求：

```math
7q=4q+1(1-q)=1+3q
\quad\Longrightarrow\quad
q=\frac{1}{4}.
```

玩家 2 对 $`L`$、$`C`$ 无差异要求：

```math
3p+6(1-p)=4p+5(1-p),
```

```math
6-3p=5-p
\quad\Longrightarrow\quad
p=\frac{1}{2}.
```

在这个候选混合策略下，玩家 1 的 $`U`$、$`M`$ 期望支付都为 $`7/4`$；被删除的 $`D`$ 在 $`L,C`$ 混合下的收益为 $`3(1/4)+0(3/4)=3/4`$，严格更低。

玩家 2 的 $`L`$、$`C`$ 期望支付都为 $`9/2`$；改选 $`R`$ 的收益为 $`4(1/2)+3(1/2)=7/2`$，也更低。因此这一混合策略组合确实是原三乘三博弈的纳什均衡：

```math
\sigma_1=(\tfrac{1}{2},\tfrac{1}{2},0),
\qquad
\sigma_2=(\tfrac{1}{4},\tfrac{3}{4},0).
```

它还说明：严格支配删除可以缩小博弈，但如果剩下的纯行动仍无法形成最佳反应交点，就需要考虑混合策略，而不是随意继续删去弱被支配行动。

## 题 9｜垄断、Cournot、Bertrand：价格、剩余与福利比较

<strong>题目：</strong> 市场逆需求为 $`P=100-Q`$，边际成本恒为 $`c=20`$，没有固定成本。分别求单一垄断企业、两家同质企业进行 Cournot 产量竞争、两家同质企业进行标准 Bertrand 价格竞争时的价格、总产量、消费者剩余与社会总剩余。

<strong>答案：</strong>

| 市场结构 | 总产量 $`Q`$ | 价格 $`P`$ | 消费者剩余 $`CS`$ | 社会总剩余 $`TS`$ |
| --- | ---: | ---: | ---: | ---: |
| 垄断 | 40 | 60 | 800 | 2400 |
| 两家 Cournot | $`160/3`$ | $`140/3`$ | $`12800/9`$ | $`25600/9`$ |
| 同质 Bertrand | 80 | 20 | 3200 | 3200 |

<strong>第一步：先求垄断企业的最优产量。</strong>

垄断企业直接决定整个市场的产量 $`Q`$，利润为：

```math
\pi_M(Q)=(P(Q)-20)Q
=(100-Q-20)Q=80Q-Q^2.
```

求导：

```math
\frac{d\pi_M}{dQ}=80-2Q=0
\quad\Longrightarrow\quad Q_M=40.
```

二阶导数 $`d^2\pi_M/dQ^2=-2<0`$，所以这是唯一利润最大值。代回需求：

```math
P_M=100-40=60.
```

单位利润为 $`60-20=40`$，行业利润为：

```math
\Pi_M=(60-20)\cdot40=1600.
```

<strong>第二步：求两家 Cournot 的市场结果。</strong>

这是第 3 题的模型。两家同时决定产量，各自最佳反应的内点方程是：

```math
2q_1+q_2=80,\qquad q_1+2q_2=80.
```

联立得到：

```math
q_1^{C}=q_2^{C}=\frac{80}{3},
\qquad Q_C=\frac{160}{3}.
```

价格为：

```math
P_C=100-\frac{160}{3}=\frac{140}{3}.
```

单家利润为 $`6400/9`$，行业总利润为：

```math
\Pi_C=2\cdot\frac{6400}{9}
=\frac{12800}{9}.
```

<strong>第三步：求标准 Bertrand 的市场结果。</strong>

两家企业同时选择价格，产品同质、成本相同、无产能约束，故均衡为：

```math
P_B=c=20.
```

把价格代回市场需求：

```math
Q_B=100-P_B=80.
```

价格等于边际成本，因此行业总利润为：

```math
\Pi_B=(20-20)\cdot80=0.
```

<strong>第四步：推导消费者剩余，而不是直接背公式。</strong>

逆需求 $`P=100-Q`$ 表示消费者最高愿付价格从 100 开始，产量越大边际愿付价格越低。给定市场价格 $`P`$ 与成交总量 $`Q`$，消费者剩余是需求曲线下、价格线上的三角形面积：

```math
CS=\frac{1}{2}(100-P)Q.
```

由于需求曲线满足 $`100-P=Q`$，因此：

```math
CS=\frac{Q^2}{2}.
```

分别代入三种市场结构：

```math
CS_M=\frac{40^2}{2}=800,
```

```math
CS_C=\frac{(160/3)^2}{2}
=\frac{12800}{9},
```

```math
CS_B=\frac{80^2}{2}=3200.
```

<strong>第五步：计算社会总剩余并核对。</strong>

没有外部性与固定成本时，社会总剩余由消费者剩余与生产者利润组成：

```math
TS=CS+\Pi.
```

所以：

```math
TS_M=800+1600=2400,
```

```math
TS_C=\frac{12800}{9}+\frac{12800}{9}
=\frac{25600}{9},
```

```math
TS_B=3200+0=3200.
```

也可以从总剩余函数反向验证。消费者对产出的总愿付价值减去总生产成本：

```math
TS(Q)=\int_0^Q(100-x)\,dx-20Q
=80Q-\frac{Q^2}{2}.
```

对它求导：

```math
\frac{dTS}{dQ}=80-Q.
```

社会最优产量是 $`Q^{SO}=80`$，恰好对应标准 Bertrand 的数量。因此在本题严格假设下，市场产量与社会总剩余由低到高是垄断、Cournot、Bertrand；企业总利润的排序却相反。<strong>不能用企业利润变动替代社会福利变动。</strong>

## 题 10｜四家企业的 Cournot 均衡：从双寡头推广到多企业

<strong>题目：</strong> 四家相同企业同时决定产量，逆需求为 $`P=120-2Q`$，每家的边际成本是 20、没有固定成本。计算各家均衡产量、总产量、价格和单家利润，并说明企业数增加为什么会压低价格。

<strong>答案：</strong> 每家产量为 10，总产量为 40，均衡价格为 40，每家利润为 200。

<strong>第一步：先写一般 $`n`$ 家企业的利润函数。</strong>

设每家产量为 $`q_i\ge0`$，市场总产量为：

```math
Q=\sum_{j=1}^{n}q_j.
```

一般线性逆需求为 $`P=a-bQ`$，各家边际成本同为 $`c`$。企业 $`i`$ 的利润为：

```math
\pi_i=(a-bQ-c)q_i.
```

把自己和其他企业的产量分开：

```math
\pi_i=
\left(a-c-bq_i-b\sum_{j\ne i}q_j\right)q_i.
```

<strong>第二步：对自己的产量求偏导。</strong>

其他企业产量全部固定，得到：

```math
\frac{\partial\pi_i}{\partial q_i}
=a-c-2bq_i-b\sum_{j\ne i}q_j.
```

二阶导数为 $`-2b<0`$，因此正产量区域的一阶条件为：

```math
2bq_i+b\sum_{j\ne i}q_j=a-c.
```

<strong>第三步：利用企业对称性联立。</strong>

各家面对相同需求和相同边际成本，考虑对称均衡 $`q_1=\cdots=q_n=q`$。这时其他 $`n-1`$ 家总产量为 $`(n-1)q`$，所以：

```math
2bq+b(n-1)q=a-c.
```

合并同类项：

```math
b(n+1)q=a-c
\quad\Longrightarrow\quad
q^{*}=\frac{a-c}{b(n+1)}.
```

因此：

```math
Q^{*}=\frac{n(a-c)}{b(n+1)}.
```

把 $`Q^{*}`$ 代回逆需求：

```math
P^{*}=a-bQ^{*}
=a-\frac{n(a-c)}{n+1}
=c+\frac{a-c}{n+1}.
```

<strong>第四步：代入本题数据。</strong>

题中 $`a=120`$、$`b=2`$、$`c=20`$、$`n=4`$，所以：

```math
q_i^{*}
=\frac{120-20}{2(4+1)}
=\frac{100}{10}=10.
```

总产量：

```math
Q^{*}=4\cdot10=40.
```

市场价格：

```math
P^{*}=120-2(40)=40.
```

单家利润：

```math
\pi_i^{*}=(40-20)\cdot10=200.
```

<strong>第五步：独立核对一家企业是否愿意改变产量。</strong>

其他三家各生产 10，企业 1 面对的其他企业总产量为 30，利润函数是：

```math
\pi_1(q_1\mid q_{-1}=30)
=(120-2(q_1+30)-20)q_1.
```

整理为：

```math
\pi_1(q_1\mid30)
=(40-2q_1)q_1=40q_1-2q_1^2.
```

求导得到 $`40-4q_1=0`$，恰好得到 $`q_1=10`$。其他三家对称，所以 (10,10,10,10) 确实构成纳什均衡。

<strong>第六步：解释企业数的影响。</strong>

一般公式为：

```math
P^{*}(n)=c+\frac{a-c}{n+1}.
```

在其他条件不变、$`a>c`$ 的情况下，企业数 $`n`$ 增加，第二项减小，均衡价格逐渐接近边际成本。若把企业数视为连续变量作比较静态：

```math
\frac{dP^{*}}{dn}
=-\frac{a-c}{(n+1)^2}<0.
```

现实中企业进入可能改变成本、产品差异或产能约束；上述单调关系是标准同质 Cournot 模型内的结论，而不是任何行业都适用的经验定律。

## 题 11｜成本不对称 Cournot：为什么不能预先假设产量相等

<strong>题目：</strong> 市场逆需求为 $`P=100-q_1-q_2`$，两家企业边际成本分别为 $`c_1=10`$、$`c_2=30`$，没有固定成本。求内部 Cournot 均衡并检验非负性，计算价格和双方利润。

<strong>答案：</strong> $`q_1^{*}=110/3`$、$`q_2^{*}=50/3`$、$`P^{*}=140/3`$；利润分别为 $`\pi_1^{*}=12100/9`$ 和 $`\pi_2^{*}=2500/9`$。

<strong>第一步：分别写利润函数，保留成本差异。</strong>

企业 1 的单位成本为 10：

```math
\pi_1=(100-q_1-q_2-10)q_1
=(90-q_1-q_2)q_1.
```

企业 2 的单位成本为 30：

```math
\pi_2=(100-q_1-q_2-30)q_2
=(70-q_1-q_2)q_2.
```

这里不能为了使用对称 Cournot 公式而把成本取平均，也不能预先令 $`q_1=q_2`$。两家企业面对的边际生产成本不同，最佳反应通常也不同。

<strong>第二步：分别对自身产量求导。</strong>

```math
\frac{\partial\pi_1}{\partial q_1}
=90-2q_1-q_2,
```

```math
\frac{\partial\pi_2}{\partial q_2}
=70-q_1-2q_2.
```

二阶导数都为 -2，因此在内部区域，最佳反应条件是：

```math
2q_1+q_2=90,\qquad
q_1+2q_2=70.
```

对应的完整非负产量最佳反应为：

```math
BR_1(q_2)=\max\left\{0,\frac{90-q_2}{2}\right\},
```

```math
BR_2(q_1)=\max\left\{0,\frac{70-q_1}{2}\right\}.
```

<strong>第三步：联立内部一阶条件。</strong>

从第一式得到 $`q_2=90-2q_1`$，代入第二式：

```math
q_1+2(90-2q_1)=70.
```

整理：

```math
-3q_1=-110
\quad\Longrightarrow\quad
q_1=\frac{110}{3}.
```

继续求另一家产量：

```math
q_2=90-2\cdot\frac{110}{3}
=\frac{270-220}{3}
=\frac{50}{3}.
```

<strong>第四步：检验非负性。</strong>

两个产量都大于零：

```math
\frac{110}{3}>0,\qquad\frac{50}{3}>0.
```

因此双方都处于内部区域，未触及非负产量约束；前面的内部一阶条件有效。代回两条最佳反应也分别得到相同的产量，所以这是 Cournot–Nash 均衡。

<strong>第五步：计算价格和利润。</strong>

```math
Q^{*}=\frac{110}{3}+\frac{50}{3}
=\frac{160}{3}.
```

```math
P^{*}=100-\frac{160}{3}
=\frac{140}{3}.
```

企业 1 的单位利润为：

```math
P^{*}-c_1=\frac{140}{3}-10
=\frac{110}{3},
```

故：

```math
\pi_1^{*}=\frac{110}{3}\cdot\frac{110}{3}
=\frac{12100}{9}.
```

企业 2 同理：

```math
P^{*}-c_2=\frac{140}{3}-30
=\frac{50}{3},
```

```math
\pi_2^{*}=\frac{50}{3}\cdot\frac{50}{3}
=\frac{2500}{9}.
```

成本更低的企业 1 生产更多、获得更高利润。值得注意的是，本题总产量仍是 $`160/3`$，与第 3 题两家成本都为 20 时相同。这是因为两家成本之和恰好一样：$`10+30=20+20`$。在两家都积极生产的线性 Cournot 模型里，总产量与成本之和有关，但市场份额和企业利润仍取决于各自成本。

## 题 12｜新增综合题：Stackelberg 先行动者为什么可以多生产

<strong>题目：</strong> 两家企业面临逆需求 $`P=100-q_1-q_2`$，单位成本均为 20。不同于 Cournot 同时决定产量，企业 1 先选择并承诺产量 $`q_1`$；企业 2 观察这一产量后选择 $`q_2`$。

求 Stackelberg 子博弈精炼均衡的产量、价格与利润，并与同时行动的 Cournot 均衡比较。

<strong>答案：</strong> Stackelberg 均衡为 $`q_1^{*}=40`$、$`q_2^{*}=20`$，总产量 60，市场价格 40；利润分别为 $`\pi_1^{*}=800`$、$`\pi_2^{*}=400`$。领导者的利润高于其在 Cournot 中的 $`6400/9`$，跟随者利润低于这一数值。

<strong>第一步：确定谁先行动、谁后行动。</strong>

企业 2 观察到企业 1 的产量之后才作决定，因此它是跟随者。解题时应先分析跟随者面对任意 $`q_1`$ 的最优选择，再让领导者预判这一反应。不能直接联立两家的同时行动最佳反应，因为那会把问题重新变回 Cournot。

<strong>第二步：求跟随者的完整最佳反应。</strong>

企业 2 的利润为：

```math
\pi_2=(100-q_1-q_2-20)q_2
=(80-q_1-q_2)q_2.
```

固定已观察到的 $`q_1`$，对 $`q_2`$ 求导：

```math
\frac{\partial\pi_2}{\partial q_2}
=80-q_1-2q_2.
```

令其为零：

```math
q_2=\frac{80-q_1}{2}.
```

因为 $`q_2\ge0`$ 且利润关于 $`q_2`$ 严格凹，完整最佳反应为：

```math
BR_2(q_1)
=\max\left\{0,\frac{80-q_1}{2}\right\}.
```

<strong>第三步：领导者把跟随者反应代入自己的利润。</strong>

先考虑 $`0\le q_1\le80`$，此时跟随者的最佳反应为 $`q_2=(80-q_1)/2`$。领导者的利润：

```math
\pi_1=(80-q_1-q_2)q_1.
```

代入跟随者的反应：

```math
\pi_1(q_1)
=\left(80-q_1-\frac{80-q_1}{2}\right)q_1.
```

括号内化简：

```math
80-q_1-\frac{80-q_1}{2}
=40-\frac{q_1}{2}.
```

所以：

```math
\pi_1(q_1)=40q_1-\frac{q_1^2}{2}.
```

<strong>第四步：领导者最优化并检查边界。</strong>

对 $`q_1`$ 求导：

```math
\frac{d\pi_1}{dq_1}=40-q_1.
```

令导数为零得到 $`q_1=40`$。二阶导数是 -1，且 $`40\in[0,80]`$，所以该点是本区间的利润最大值。

对于 $`q_1>80`$，跟随者最佳反应是 0，领导者利润变为 $`(80-q_1)q_1<0`$，不可能优于 $`q_1=40`$ 时的正利润。因此领导者的全局最优产量确实是：

```math
q_1^{*}=40.
```

<strong>第五步：依次求跟随者产量、价格与利润。</strong>

```math
q_2^{*}=BR_2(40)
=\frac{80-40}{2}=20.
```

```math
Q^{*}=40+20=60,\qquad
P^{*}=100-60=40.
```

企业 1 的利润：

```math
\pi_1^{*}=(40-20)\cdot40=800.
```

企业 2 的利润：

```math
\pi_2^{*}=(40-20)\cdot20=400.
```

<strong>第六步：与 Cournot 逐项比较。</strong>

| 指标 | Cournot 同时产量 | Stackelberg 先后产量 |
| --- | ---: | ---: |
| 企业 1 产量 | $`80/3`$ | 40 |
| 企业 2 产量 | $`80/3`$ | 20 |
| 市场总产量 | $`160/3`$ | 60 |
| 市场价格 | $`140/3`$ | 40 |
| 企业 1 利润 | $`6400/9`$ | 800 |
| 企业 2 利润 | $`6400/9`$ | 400 |

Stackelberg 领导者预先扩大产量，使跟随者在观察后减少自己的最优产量。领导者因此获得先动优势，而跟随者利润下降。这一结论依赖领导者产量能够被观察且可信地承诺；如果企业 1 之后可以随意更改产量，原来的逆向归纳求解就不再适用。

## 题 13｜新增综合题：Cournot 内点解出现负产量怎么办

<strong>题目：</strong> 两家企业同时竞争产量，市场逆需求为 $`P=100-q_1-q_2`$，边际成本分别为 $`c_1=20`$、$`c_2=90`$，两家均不能生产负产量。求全部纯策略 Cournot 均衡，解释为什么不能直接接受一阶条件的联立解。

<strong>答案：</strong> 唯一 Cournot 均衡是 $`q_1^{*}=40`$、$`q_2^{*}=0`$，价格 $`P^{*}=60`$，企业 1 利润 1600，企业 2 利润 0。若错误地强制两家都生产，会算出 $`q_2=-20`$，违反行动约束。

<strong>第一步：分别写两家利润。</strong>

企业 1 边际成本为 20：

```math
\pi_1=(100-q_1-q_2-20)q_1
=(80-q_1-q_2)q_1.
```

企业 2 边际成本为 90：

```math
\pi_2=(100-q_1-q_2-90)q_2
=(10-q_1-q_2)q_2.
```

<strong>第二步：先求内部一阶条件，观察问题出在哪里。</strong>

对企业 1 自身产量求导：

```math
80-2q_1-q_2=0
\quad\Longrightarrow\quad
2q_1+q_2=80.
```

对企业 2 求导：

```math
10-q_1-2q_2=0
\quad\Longrightarrow\quad
q_1+2q_2=10.
```

联立这两式可得：

```math
q_1=50,\qquad q_2=-20.
```

这是一个代数解，却不是合法的博弈行动组合。企业 2 的产量必须满足 $`q_2\ge0`$，所以不能把 $`(-20)`$ 当成生产数量继续计算价格或利润。

<strong>第三步：写出考虑非负约束的最佳反应。</strong>

两家利润对自身产量的二阶导数都是 -2，因而各自在非负可行区间上的最佳反应是：

```math
BR_1(q_2)=\max\left\{0,\frac{80-q_2}{2}\right\},
```

```math
BR_2(q_1)=\max\left\{0,\frac{10-q_1}{2}\right\}.
```

如果企业 1 产量大于 10，企业 2 的内部一阶条件会给出负产量。此时企业 2 的最佳反应变成不生产：

```math
q_1\ge10
\quad\Longrightarrow\quad BR_2(q_1)=0.
```

<strong>第四步：在企业 2 不生产的边界上重新求解。</strong>

设 $`q_2=0`$，则企业 1 的最佳反应为：

```math
BR_1(0)=\frac{80}{2}=40.
```

接着验证企业 2 面对 $`q_1=40`$ 是否确实选择零产量：

```math
BR_2(40)
=\max\left\{0,\frac{10-40}{2}\right\}
=\max\{0,-15\}=0.
```

因此：

```math
(q_1^{*},q_2^{*})=(40,0)
```

同时满足双方的完整最佳反应。企业 1 在对方停产时选择最优产量 40，企业 2 面对产量 40 的对手则宁愿不进入市场，所以这是纳什均衡。

<strong>第五步：计算价格和利润。</strong>

```math
Q^{*}=40,\qquad P^{*}=100-40=60.
```

```math
\pi_1^{*}=(60-20)\cdot40=1600,
\qquad
\pi_2^{*}=0.
```

企业 2 不生产的经济原因也很直观：即使它生产第一个极小单位，在企业 1 已经供应 40 单位时，市场价格接近 60，而企业 2 的边际成本却是 90，根本没有盈利空间。

<strong>第六步：把边界条件写成一般判断。</strong>

在市场 $`P=a-Q`$、低成本企业 1 成本为 $`c_1`$ 的情况下，如果企业 2 停产，企业 1 的最优产量是：

```math
q_1^{M}=\frac{a-c_1}{2}.
```

企业 2 面对这一产量选择零产量，需要它在零产量处的边际利润不大于零：

```math
a-c_2-q_1^{M}\le0.
```

代入 $`q_1^{M}`$：

```math
a-c_2-\frac{a-c_1}{2}\le0
\quad\Longleftrightarrow\quad
c_2\ge\frac{a+c_1}{2}.
```

本题有 $`a=100`$、$`c_1=20`$，右侧门槛为 60；企业 2 的成本 90 超过这一门槛，故它在均衡中退出生产。这个例子说明：<strong>求导得到的是内部候选值；当候选值违反约束时，应该回到完整最佳反应，而不是继续代入错误解。</strong>

## 题 14｜原课件投资协调博弈：超过 90% 的人投资才盈利

<strong>题目：</strong> 班级共有 20 人，每个人同时决定是否投资 10 元，不允许事前交流。若<strong>超过 90%</strong> 的人投资，则每个投资者净赚 5 元；否则每个投资者净亏 10 元。不投资者的收益恒为 0。

（1）确定项目成功所需的最低投资人数，并写出个人的支付函数。

（2）设其他 19 人中有 $`j`$ 人投资，求一个人的最佳反应；据此找出并证明全部纯策略纳什均衡，判断是否严格。

（3）分别讨论有 0、10、18、19、20 人投资时，项目是否成功、投资者个人收益和全班总收益，并判断两个均衡的帕累托关系。

（4）解释原课件讨论的“起初约 50% 投资”与“起初 95% 投资”两种课堂情形，为何可能演化出不同结果。与第一讲的门槛公共品博弈有何关键区别？

（5）若一位同学认为自己参与投资后项目成功的概率为 $`q`$，在什么条件下投资具有更高的期望收益？这个条件和“超过 90%”是否相同？

<strong>答案：</strong> （1）至少 19 人投资才成功。（2）当其他人至少有 18 人投资时，自己的唯一最佳反应为投资，否则为不投资；全部纯策略纳什均衡只有“20 人全不投”和“20 人全投”，且均为严格纳什均衡。（3）全投严格帕累托优于全不投。（4）初始参与率影响大家对成功的预期；本题未投资者不能分享成功收益，不同于可搭便车的公共品。（5）$`q>2/3`$ 时严格倾向投资，等于 $`2/3`$ 时无差异；它不是 90% 的参与人数门槛。

<strong>第一步：准确解释超过 90%。</strong>

20 人的 90% 是 18 人。但题目要求<strong>严格超过</strong>这个比例，所以 18 人投资仍失败，19 人才达到要求。记 $`m`$ 为包括自己在内的投资者总数，则：

```math
k=\lfloor0.9\times20\rfloor+1=19.
```

个人支付可以写为：

```math
u_i=
\begin{cases}
5,&\text{自己投资且 }m\ge19,\\
-10,&\text{自己投资且 }m\le18,\\
0,&\text{自己不投资}.
\end{cases}
```

题目所说的“净赚 5”意味着投资成功时最终利润是 +5，而非再减去投入本金后得到 −5。

<strong>第二步：固定其他 19 人，求个人最佳反应。</strong>

如果其他人中有 $`j`$ 人投资，自己投资后总人数是 $`j+1`$，因此：

| 其他人的投资人数 | 自己投资的收益 | 自己不投资的收益 | 唯一最佳反应 |
| --- | ---: | ---: | --- |
| $`0\le j\le17`$ | −10 | 0 | 不投资 |
| $`18\le j\le19`$ | +5 | 0 | 投资 |

临界点是其他人至少 18 人投资，而不是其他人至少 19 人投资。若恰好有 18 名其他人投资，自己加入后总数达到 19，项目就成功。

<strong>第三步：按总投资人数穷尽均衡情形。</strong>

| 总投资人数 $`m`$ | 能否找到有利的单方偏离？ | 是否为纳什均衡 |
| --- | --- | --- |
| $`m=0`$ | 一人单独加入只会损失 10，收益从 0 降至 −10 | 是，严格 |
| $`1\le m\le18`$ | 任意已投资者退出，可把收益从 −10 提升到 0 | 否 |
| $`m=19`$ | 唯一未投资者加入，可把收益从 0 提升到 +5 | 否 |
| $`m=20`$ | 任意已投资者退出，其个人收益从 +5 降至 0 | 是，严格 |

因此全部纯策略纳什均衡为：

```math
(N,N,\ldots,N)\qquad\text{和}\qquad(I,I,\ldots,I).
```

两者都严格。特别要注意：19 人投资时项目虽然成功，却<strong>不是</strong>纳什均衡，因为最后一名未投资者有动机加入。区分“项目成功”与“行动组合稳定”是本题的核心。

<strong>第四步：逐一计算人数情形与帕累托比较。</strong>

| 投资人数 $`m`$ | 投资比例 | 项目结果 | 每名投资者净收益 | 每名未投资者收益 | 总收益 $`W(m)`$ |
| ---: | ---: | --- | ---: | ---: | ---: |
| 0 | 0% | 未达到门槛 | 无投资者 | 0 | 0 |
| 10 | 50% | 失败 | −10 | 0 | −100 |
| 18 | 90% | 失败 | −10 | 0 | −180 |
| 19 | 95% | 成功 | +5 | 0 | 95 |
| 20 | 100% | 成功 | +5 | 无未投资者 | 100 |

全员不投资时，每位同学收益为 0；全员投资时，每位同学收益为 5。因此从全不投改为全投，所有人都严格变好，故全投<strong>严格帕累托优于</strong>全不投。但全不投仍是纳什均衡，因为一个人单独改变行动无法让项目成功。

<strong>第五步：解释课堂中不同初始比例的作用。</strong>

当约 50% 的人投资时，项目失败；已投资者看到损失，未来可能选择退出，更多人也会预期项目无法成功。当 95% 的人投资时，项目成功；剩下的一人若下一轮加入，自己也能获得 +5，从而可能走向全员投资。这说明同一个博弈可能因最初的共同预期和观察到的行为不同，朝不同均衡协调。

严格地说，原课件最先定义的是一次性同时行动博弈；对下一轮如何演化的描述依赖于参与者会根据结果调整决定的假设，<strong>不是</strong>原静态模型自动给出的唯一动态预测。事前沟通可能帮助协调共同预期，但没有强制执行力的沟通不能保证每个人都投资。

第一讲门槛公共品博弈的非贡献者在公共品成功提供时仍可能获得好处，因而要检查免费搭便车；本题规定未投资者始终收益为 0，所以项目成功后，未投资者反而有动力加入。两者的均衡结构不能互相照搬。

<strong>第六步：计算成功概率下的投资门槛。</strong>

若主观认为“自己投资后项目成功”的概率为 $`q`$，则：

```math
E[u_i(I)]=5q+(-10)(1-q)=15q-10,\qquad E[u_i(N)]=0.
```

于是：

```math
15q-10>0
\quad\Longleftrightarrow\quad
q>\frac{2}{3}.
```

$`q=2/3`$ 时两种行动的期望收益相等，$`q<2/3`$ 时不投资更好。这里 90% 指的是实际有多少人参与，$`2/3`$ 指的是个人相信项目成功的概率；例如“认为有 70% 的成功可能”绝不等于“认为会有 70% 的同学投资”。

相关规则、一般 $`n`$ 人的证明及课件例子见[第二讲笔记 §2.2](../notes/lecture-02-strategic-form-games.md)。

## 题 15｜原课件 Bertrand 四段最佳反应：为什么有时不存在最佳报价

<strong>题目：</strong> 两家企业销售完全同质的产品，同时决定价格，单位成本均为 $`c=20`$。若最低报价不超过 100，市场总需求为 $`D(p)=100-p`$；若价格高于 100，需求为零。同价时双方平分市场需求，低价企业获得全部需求，高价企业没有销量。价格先允许在非负实数范围内连续选择。

（1）写出企业 1 的利润分段函数，求其独占市场时的最优价格 $`p_m`$。

（2）依次令对手报价 $`p_2=15,20,30,65`$，分别求企业 1 的<strong>整个最佳反应集合</strong>。

（3）在 $`p_2=30`$ 时计算 $`p_1=29.9`$、$`29.99`$ 和 $`30`$ 的利润，并解释为何连续价格下没有真正的最佳反应。若报价只能是 $`0.01`$ 元的整数倍，最佳反应如何变化？

（4）求这个双寡头博弈的全部纯策略纳什均衡，并解释“面对某个价格没有最佳反应”为什么不等于“整个博弈不存在均衡”。

<strong>答案：</strong> （1）$`p_m=60`$。（2）最佳反应依次为 $`(15,+\infty)`$、$`[20,+\infty)`$、$`\varnothing`$ 和 $`\{60\}`$。（3）利润依次为 $`693.99`$、$`699.3999`$ 和 $`350`$；连续价格下上确界 $`700`$ 不可达到，报价单位为 $`0.01`$ 时最优报 $`29.99`$。（4）唯一纯策略纳什均衡为 $`(20,20)`$。

<strong>第一步：写出“比对手低价、同价、高价”三段利润。</strong>

```math
\pi_1(p_1,p_2)=
\begin{cases}
(p_1-20)\max\{100-p_1,0\},&p_1<p_2,\\
\dfrac{1}{2}(p_1-20)\max\{100-p_1,0\},&p_1=p_2,\\
0,&p_1>p_2.
\end{cases}
```

若拥有全部市场，利润在正需求区间为 $`f(p)=(p-20)(100-p)`$。直接求导：

```math
f'(p)=120-2p,\qquad f''(p)=-2<0.
```

因此 $`p_m=60`$，最大垄断利润 $`(60-20)(100-60)=1600`$。但<strong>企业是否能以 60 元取得全部市场</strong>，还要看对手是不是报得更高。

<strong>第二步：逐段求最佳反应，不能对所有情形直接套 $`p_m`$。</strong>

| 对手价格 $`p_2`$ | 最优报价集合 | 验证 |
| ---: | --- | --- |
| 15 | $`p_1>15`$ | 跟价或压价会以低于成本的价格销售，造成亏损；高于 15 时不销售，利润为零 |
| 20 | $`p_1\ge20`$ | 低于成本会亏损，等于或高于成本时利润均为零 |
| 30 | $`B_1(30)=\varnothing`$ | 必须低于 30 才能获得全部需求；低于 30 的报价越接近 30 越好，却没有最大的“严格低于 30” |
| 65 | $`B_1(65)=\{60\}`$ | 报 60 既低于 65、获得全市场，又等于最优垄断价格 |

特别注意：$`p_2=15`$ 时选择 $`p_1=18`$ 虽然也低于成本，但因为企业 1 报价高于对手，根本不会产生销量，所以并不亏损。<strong>价格低于成本与实际亏损不是同一个命题；必须同时检查销量。</strong>

<strong>第三步：计算连续压价与价格离散化。</strong>

```math
\begin{aligned}
\pi_1(29.9,30)&=(29.9-20)(100-29.9)=693.99,\\
\pi_1(29.99,30)&=(29.99-20)(100-29.99)=699.3999,\\
\pi_1(30,30)&=\frac{1}{2}(30-20)(100-30)=350.
\end{aligned}
```

对任何 $`20<p_1<30`$，都能再选一个位于 $`p_1`$ 与 30 之间的新报价并增加利润；但一旦报到 30，市场份额就从全部降为一半。因此：

```math
\sup_{p_1\ge0}\pi_1(p_1,30)
=\lim_{p_1\uparrow30}(p_1-20)(100-p_1)=700,
```

只是这个值<strong>没有任何报价能够达到</strong>。若要求报价为 $`0.01`$ 元的整数倍，则 29.99 是严格低于 30 的最大可行报价，同时本题中它优于同价、报高价或更低价，所以成为精确最佳反应。价格网格的改变使策略集合改变，不能用离散版本的答案反推连续模型的最佳反应集合非空。

<strong>第四步：检验整体纳什均衡。</strong>

若两家都报 20，每家零利润；单独涨价失去全部需求，利润仍为零；单独降价则在有销量时亏损。因此 $`(20,20)`$ 是均衡。

若两家同报高于成本且需求为正的价格，任一家稍微降价都能从半个市场变为整个市场，提高利润；若同报 100 或更高价格，则任一家可改报 60 获得正利润。若报价不同，较高价企业可能通过压到较低价以下争夺需求；当较低价恰好等于成本时，低价企业也可以上调到仍低于对手且高于成本的价格，赚取正利润；较低价低于成本时，当前卖货的企业可以提高报价以避免亏损。因此其他报价组合均非均衡。

<strong>最终结论：</strong> 唯一纯策略纳什均衡是 $`(20,20)`$。最佳反应在 $`p_2=30`$ 时为空，只说明没有一个报价能最大化“对手报 30”这一条件下的利润；它不妨碍价格组合 $`(20,20)`$ 相互成为最佳反应。详见[第二讲笔记 §5.1](../notes/lecture-02-strategic-form-games.md)。

## 题 16｜原课件双城镇居住模型：均衡与动态稳定为什么不同

<strong>题目：</strong> 按原课件第 66–73 页的设定，设有 10 名高个居民、10 名矮个居民，东、西两座城镇各最多居住 10 人。每人同时选镇；若一镇被 11 人选择，就从该镇 11 人中等概率随机调出一人到另一镇。为便于数值计算，设某人所在镇共有 $`k`$ 名与自己同类型居民（包括本人），其收益为：

```math
u(k)=
\begin{cases}
k/5,&0\le k\le5,\\
1.5-k/10,&5<k\le10.
\end{cases}
```

（1）分别求 $`u(3)`$、$`u(5)`$、$`u(7)`$、$`u(8)`$、$`u(10)`$；解释居民最喜欢哪种社会组成。

（2）初始东镇有 7 名矮个和 3 名高个，西镇有 7 名高个和 3 名矮个。计算东镇一名高个居民迁往西镇后的<strong>期望收益</strong>，判断其是否有利可图。

（3）证明“东镇全矮、西镇全高”的配置在题设随机调配规则下是纯策略纳什均衡，并讨论反向配置。

（4）两镇恰好各有 5 名高个和 5 名矮个，是否也是纳什均衡？为什么课件又说“充分混合的均衡不稳定”？以东镇 6 名高个、4 名矮个，西镇 4 名高个、6 名矮个为例，计算东镇一名矮个居民改选西镇后的期望收益，说明偏离如何自我强化。

<strong>答案：</strong> （1）依次为 $`0.6,1,0.8,0.7,0.5`$，最喜欢两类型各占一半。（2）迁移期望收益 $`8.3/11\approx0.7545`$，高于留下的 $`0.6`$，所以有利于迁移。（3）两个完全隔离的对称配置均为纯策略纳什均衡。（4）充分混合配置也可以是纳什均衡，但在受到小幅扰动后可能发生进一步迁移；给定 6:4 的扰动状态，少数矮个居民迁移后的期望收益为 $`9.4/11\approx0.8545`$，高于留下的 $`0.8`$。

<strong>第一步：把“更喜欢混合”写成可以计算的支付。</strong>

| 同类居民数 $`k`$ | 3 | 5 | 7 | 8 | 10 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 个人收益 $`u(k)`$ | 0.6 | 1.0 | 0.8 | 0.7 | 0.5 |

这里 $`u(5)=1`$ 比完全同类型的 $`u(10)=0.5`$ 高一倍；所以“发生隔离”绝不能直接解释成“居民偏好隔离”。

<strong>第二步：检查 7:3 初始状态下一次单方迁移的实际收益。</strong>

东镇的一名高个居民原先和其他 2 名高个一起生活，其收益为 $`u(3)=0.6`$。若他改选西镇，西镇暂时出现 8 名高个、3 名矮个，共 11 人。按题设的均匀随机规则，必须调出其中 1 人：

| 被随机调往东镇的人 | 概率 | 迁移发起者最终所在镇的高个总人数 | 发起者收益 |
| --- | ---: | ---: | ---: |
| 发起者本人 | $`1/11`$ | 东镇重新有 3 名高个 | $`u(3)=0.6`$ |
| 西镇原有的某名高个 | $`7/11`$ | 西镇仍有 7 名高个 | $`u(7)=0.8`$ |
| 西镇原有的某名矮个 | $`3/11`$ | 西镇有 8 名高个 | $`u(8)=0.7`$ |

因此：

```math
E[u\mid\text{改选西镇}]
=\frac{1}{11}(0.6)+\frac{7}{11}(0.8)+\frac{3}{11}(0.7)
=\frac{8.3}{11}\approx0.7545>0.6.
```

即使西镇并未达到高矮人数各半的最理想状态，迁移对这名少数居民仍有吸引力。西镇的少数矮个居民改选东镇，也能由对称性得到同样的激励。

<strong>第三步：验证两个隔离型纳什均衡。</strong>

先看东镇 10 名矮个、西镇 10 名高个。每人原收益均为 $`u(10)=0.5`$。任一名矮个居民尝试改选西镇时，西镇暂时变成 10 名高个加 1 名矮个；在 11 人中等概率调出 1 人：

若调出的是本人（概率 $`1/11`$），他回到原本全矮的东镇，仍得 $`0.5`$；若调出的是某名高个（概率 $`10/11`$），他留在西镇，成为唯一的矮个居民，只得 $`u(1)=0.2`$。所以：

```math
E[u\mid\text{偏离}]
=\frac{1}{11}\times0.5+\frac{10}{11}\times0.2
=\frac{2.5}{11}\approx0.2273<0.5.
```

这名矮个居民不会单独搬迁。对高个居民同理；将东、西镇对调也完全对称。因此课件列出的两个隔离配置都是纯策略纳什均衡。

<strong>第四步：检验混合状态和受到扰动后的激励。</strong>

两镇如果各有 5 名高个、5 名矮个，每人都获得 $`u(5)=1`$，已经是理论允许的最大支付。无人能通过单方偏离获得超过 1 的支付，因此该配置本身也是纳什均衡。<strong>不能把“不稳定”误写成“不是纳什均衡”。</strong>

但若受到外部扰动，东镇变为 6 高 4 矮，西镇 4 高 6 矮，东镇一名矮个居民的现有收益为 $`u(4)=0.8`$。他改选西镇，使西镇暂时成为 4 高 7 矮；再次随机调出 1 人：

```math
E[u\mid\text{改选西镇}]
=\frac{1}{11}u(4)+\frac{6}{11}u(6)+\frac{4}{11}u(7)
=\frac{0.8+6(0.9)+4(0.8)}{11}
=\frac{9.4}{11}\approx0.8545>0.8.
```

也就是说，<strong>严格的 50:50 混合状态可以满足静态纳什条件</strong>，但稍微偏向某类型之后，少数群体可能进一步向另一镇流动。课件说的“tipping point 50:50”是这种动力学反馈的直观阈值；完整收敛路径还要指定居民何时重新决策、每轮有多少人改变选择。本题既计算了单次偏离，也区分了静态均衡与动态稳定性。详见[第二讲笔记 §8.1](../notes/lecture-02-strategic-form-games.md)。

## 题 17｜Hotelling–Downs 选举：从选票分界线求完整最佳反应集合

<strong>题目：</strong> 两名候选人同时选政策位置 $`x_1,x_2\in[0,10]`$，选民理想政策点在 $`[0,10]`$ 上均匀分布，人人投给距离自己理想点最近的候选人。同距离时平分选票；候选人只关心最终获胜概率，赢得严格多数时胜率为 1，平票时胜率为 $`1/2`$。选民中位理想点 $`m=5`$。

（1）当候选人 2 选择 $`x_2=3`$ 时，求候选人 1 的<strong>全部最佳反应位置</strong>，并计算 $`x_1=6`$、$`7`$、$`8`$ 三种情况下的获胜概率。

（2）当 $`x_2=6`$、$`x_2=5`$ 时，分别求最佳反应集合。

（3）以一般的中位点 $`m`$ 和对手位置 $`x_2`$ 写出三个分段的最佳反应集合，求全部纯策略纳什均衡。

（4）解释为何此题的最佳反应是一个区间，而标准 Bertrand 价格竞争在某个区间反倒<strong>不存在</strong>最佳反应。

<strong>答案：</strong> （1）$`B_1(3)=(3,7)`$；对应 $`x_1=6,7,8`$ 的胜率分别为 $`1,1/2,0`$。（2）$`B_1(6)=(4,6)`$，$`B_1(5)=\{5\}`$。（3）一般分段表达见下文，唯一纯策略纳什均衡为 $`(m,m)`$，本题即 $`(5,5)`$。（4）候选人只关心是否赢，整个胜利区间给同样的最大收益；Bertrand 企业在压价区间内关心每一分钱的利润，向对手价格不断靠近会持续提高利润却永远无法达到上确界。

<strong>第一步：固定对手在中位点左侧，求选票分界线。</strong>

对手报 $`x_2=3`$，若候选人 1 选择 $`x_1>3`$，两人到选民理想点距离相等的位置是：

```math
z=\frac{x_1+3}{2}.
```

理想点大于 $`z`$ 的选民选候选人 1，理想点小于 $`z`$ 的选民选候选人 2。由于理想点均匀分布，候选人 1 要赢得超过一半的选民，必须满足 $`z<5`$。合并 $`x_1>3`$：

```math
3<x_1<7\qquad\Longrightarrow\qquad B_1(3)=(3,7).
```

代入三个候选位置验证：

| 候选人 1 的位置 | 选票分界线 | 候选人 1 得票比例 | 胜率 |
| ---: | ---: | ---: | ---: |
| 6 | 4.5 | 55% | 1 |
| 7 | 5 | 50% | $`1/2`$ |
| 8 | 5.5 | 45% | 0 |

这里 $`x_1=7`$ 是<strong>开区间的边界点</strong>，虽然双方政策都与中位点距离 2，但只能打平，不属于可确保获胜的最佳反应。

<strong>第二步：求对手在右侧与中位点上的最佳反应。</strong>

当 $`x_2=6>m`$，候选人 1 应该放在对手左侧，使两人的位置中点落在 5 的右边：

```math
x_1<6,\qquad\frac{x_1+6}{2}>5
\quad\Longleftrightarrow\quad 4<x_1<6.
```

当 $`x_2=5`$ 时，若候选人 1 偏离 5，无论向左还是向右，对手都留在中位点，得到严格多数；只有 $`x_1=5`$ 能打平。因此 $`B_1(5)=\{5\}`$。

<strong>第三步：给出课件第 77 页的分段函数，并验证均衡。</strong>

```math
B_1(x_2)=
\begin{cases}
\{x_1:x_2<x_1<2m-x_2\},&x_2<m,\\
\{m\},&x_2=m,\\
\{x_1:2m-x_2<x_1<x_2\},&x_2>m.
\end{cases}
```

若政策可选区间不是整个实数集合，应再与合法区间取交集。在此题中合法区间为 $`[0,10]`$，中位点 5 正好在区间中央，所以式中几个例子无须额外截断。

双方都选 5 时，单方离开 5 就会失去严格多数，故 $`(5,5)`$ 是纳什均衡。若双方同在非中位位置，任何一方都能向 5 靠近一些来获胜；若双方位置不同，落后的一方总能选择靠近 5 的适当位置取得严格多数。所以其他位置组合都不可能使双方互为最佳反应，唯一均衡是 $`(5,5)`$。

<strong>第四步：把“胜率阶梯”与“利润上确界”分开。</strong>

在此题中，候选人只要进入可获胜的开区间，就得到完全相同的最大支付 1；并不存在“再向某一点多挪 0.01 就更赚钱”的激励。Bertrand 企业则对利润金额敏感：在 $`c<p_2\le p_m`$ 时，越接近对手且保持更低价，利润越高，而到相同报价又只能平分市场。于是政治位置竞争可以有<strong>一整段最佳反应</strong>，同质品连续定价竞争却可能有<strong>空的最佳反应集合</strong>。详见[第二讲笔记 §8.3](../notes/lecture-02-strategic-form-games.md)。

## 本讲计算题的检查顺序

连续策略博弈的标准答题过程可以概括为：明确行动和时序，写出各方支付，固定对手求最佳反应，检查约束与二阶条件，联立或逆向归纳，代回计算支付，最后分析经济含义。

| 检查环节 | 必须写清楚的内容 | 最常见的失误 |
| --- | --- | --- |
| 行动与时序 | 选价格还是产量、同时还是先后、是否存在行动上限 | 把 Stackelberg 当 Cournot |
| 目标函数 | 自己的利润或效用如何依赖对手行动 | 把两家利润合并求导当作纳什均衡 |
| 一阶与二阶条件 | 固定其他人的行动，对自己变量求导 | 漏掉平方项求导的系数 2 |
| 约束与分段 | 负产量要截断为 0；满市场、零市场要单独讨论 | 把内部候选解当成全局最佳反应 |
| 均衡检验 | 将候选值逐个代回各方最佳反应 | 只得到联立方程的代数解 |
| 结果解释 | 价格、数量、个人利润及社会剩余分别计算 | 把利润、消费者剩余和社会福利混为一谈 |

在这组题里，Cournot 的产量最佳反应通常向下倾斜，合伙人努力与差异化定价的内部最佳反应向上倾斜。曲线斜率有助于理解战略替代与战略互补，但最终是否构成纳什均衡，仍由双方相互最佳反应的条件决定。
