# Lecture 03｜混合策略博弈：分层习题与完整解析

[本讲知识笔记](../notes/lecture-03-mixed-strategies.md) · [第二讲习题](lecture-02-exercises.md) · [学习目录](../README.md)

混合策略题不能只记住“令两种期望收益相等”这一句话。完整的计算需要先找纯策略均衡，再假设谁在随机化、每种行动使用什么概率，然后求出面对对手随机行动时的各个纯行动收益。最后还要检查概率是否位于合法区间、支持集外的行动有没有更高支付，以及是否存在一方纯策略、另一方混合等边界情况。

前 11 题保留原有题目并扩充推导，第 12、13 题分别训练单方混合的均衡集合和收益参数变化的比较静态。每题先给出结论，再解释公式从哪里来、怎样检验，以及容易混淆的概念。

## 题 1｜概念判断：混合策略、支持集与支配

<strong>题目：</strong> 判断下列命题的正误，并说明理由。

（1）混合策略纳什均衡要求每位参与人必须对所有纯行动分配正概率。

（2）若玩家 1 在均衡中以正概率使用 $`A`$ 和 $`B`$，则面对玩家 2 的均衡策略，$`A`$ 与 $`B`$ 带来的期望收益相同。

（3）一个纯行动若被某种混合策略严格支配，就不可能在任何纳什均衡中被以正概率使用。

（4）一个弱劣行动不可能出现在纳什均衡里。

<strong>答案：</strong> （1）错误；（2）正确；（3）正确；（4）错误。

<strong>（1）为什么混合策略不要求所有行动都使用？</strong>

混合策略是给可行纯行动分配概率。例如玩家拥有三个纯行动 $`A,B,C`$，一个混合策略可以写成：

```math
\sigma=(p_A,p_B,p_C),
\qquad
p_A,p_B,p_C\ge0,
\qquad
p_A+p_B+p_C=1.
```

三种行动不需要同时获得正概率。比如 $`(1/2,1/2,0)`$ 只在 $`A`$ 和 $`B`$ 之间随机化；$`(1,0,0)`$ 则等价于确定地选择 $`A`$，也属于退化混合策略。

概率严格大于零的行动组成<strong>支持集（Support）</strong>。对三个行动都赋正概率称为完全混合（Full-Support Mixing）；它只是混合策略的一种特殊情形，并不是任何混合均衡都必须满足的要求。

<strong>（2）为什么支持集内行动的期望收益必须相等？</strong>

设面对玩家 2 的策略，玩家 1 选 $`A`$ 的期望收益为 $`V_A`$，选 $`B`$ 的期望收益为 $`V_B`$。如果玩家 1 以概率 $`p`$ 选 $`A`$、以 $`1-p`$ 选 $`B`$，整体期望收益为：

```math
U_1(p)=pV_A+(1-p)V_B
=V_B+p(V_A-V_B).
```

假如 $`V_A>V_B`$，上式随 $`p`$ 增大而增加，玩家 1 最好把概率全部放在 $`A`$ 上，即 $`p=1`$。若 $`V_A<V_B`$，最好令 $`p=0`$。只有当：

```math
V_A=V_B
```

时，玩家 1 才可能在二者之间赋予严格正概率而不想改变自己的随机规则。

还要补充一项经常遗漏的条件：<strong>支持集内的行动不仅要相等，还必须达到所有可行纯行动中的最高期望收益。</strong>如果 $`A,B`$ 都得到 2，而未被使用的 $`C`$ 能得到 4，那么玩家 1 应该改选 $`C`$；单纯让 $`A,B`$ 无差异并不能构成均衡。

<strong>（3）为什么被混合策略严格支配的纯行动不能进入支持集？</strong>

假设纯行动 $`T`$ 被某个混合策略 $`\mu`$ 严格支配。含义是：不论对手采取什么纯行动，$`\mu`$ 的期望收益都严格高于 $`T`$ 的收益。因此面对对手的任意混合策略，$`\mu`$ 的期望收益仍严格更高。

如果玩家在某个所谓均衡中给 $`T`$ 分配正概率，就可以把这一部分概率移向 $`\mu`$，从而严格提高自己的期望收益，违反纳什均衡。因此严格被支配的纯行动不能被均衡以正概率使用。

注意“被某个纯行动严格支配”和“被某个混合策略严格支配”是不同的比较范围。后者允许使用多个纯行动组合成替代方案，第 6 题会说明为什么它可能比单纯比较两行更有力。

<strong>（4）弱被支配行动为什么仍可能出现？</strong>

弱支配只要求替代行动在每种对手选择下不差，并至少在一种选择下严格更好。假如对手在均衡中只使用双方收益相等的那些行动，被弱支配者就仍可能是最佳反应。

例如行玩家支付为：

| 行 / 列 | $`L`$ | $`R`$ |
| --- | ---: | ---: |
| $`U`$ | 1 | 1 |
| $`D`$ | 1 | 0 |

$`U`$ 弱支配 $`D`$，但面对 $`L`$ 时二者收益都是 1。若列玩家的收益设计使其在玩家 1 选 $`D`$ 时最佳反应为 $`L`$，则 $`(D,L)`$ 仍可能是纳什均衡。因此不能把所有弱被支配行动都直接排除。

## 题 2｜性别战：全部均衡、期望支付与协调概率

<strong>题目：</strong> 两人都希望参与同一项活动，但玩家 1 更偏好足球 $`S`$，玩家 2 更偏好芭蕾 $`B`$。支付矩阵为：

| 玩家 1 / 玩家 2 | 足球 $`S`$ | 芭蕾 $`B`$ |
| --- | --- | --- |
| 足球 $`S`$ | (2,1) | (0,0) |
| 芭蕾 $`B`$ | (0,0) | (1,2) |

求：（1）全部纯策略纳什均衡；（2）双方都严格混合的均衡；（3）混合均衡下双方的期望收益及选择同一活动的概率。

<strong>答案：</strong> 纯策略均衡为 $`(S,S)`$ 和 $`(B,B)`$；严格混合均衡中玩家 1 选 $`S`$ 的概率为 $`2/3`$，玩家 2 选 $`S`$ 的概率为 $`1/3`$；双方均衡期望收益都是 $`2/3`$，同行概率为 $`4/9`$。

<strong>第一步：先核对纯策略均衡。</strong>

玩家 1 面对玩家 2 的 $`S`$ 时，自己选 $`S`$ 得 2、选 $`B`$ 得 0，所以选 $`S`$；面对 $`B`$ 时，自己选 $`S`$ 得 0、选 $`B`$ 得 1，所以选 $`B`$。

玩家 2 面对玩家 1 的 $`S`$ 时，选 $`S`$ 得 1、高于选 $`B`$ 的 0；面对 $`B`$ 时，选 $`B`$ 得 2、高于选 $`S`$ 的 0。于是：

```math
BR_1(S)=\{S\},\qquad BR_1(B)=\{B\},
```

```math
BR_2(S)=\{S\},\qquad BR_2(B)=\{B\}.
```

两个最佳反应交点为 $`(S,S)`$ 与 $`(B,B)`$，且两者都是严格纯策略均衡。

<strong>第二步：给双方的随机行动定义不同的变量。</strong>

令 $`p`$ 为玩家 1 选择足球的概率，$`1-p`$ 为其选择芭蕾的概率；令 $`q`$ 为玩家 2 选择足球的概率，$`1-q`$ 为其选择芭蕾的概率：

```math
\sigma_1=(S:p,B:1-p),
\qquad
\sigma_2=(S:q,B:1-q).
```

假设两人都真正随机化，要求 $`0<p<1`$、$`0<q<1`$。这一假设只是用于寻找内部混合均衡，求得概率后还必须检查。

<strong>第三步：令玩家 1 对足球和芭蕾无差异，求玩家 2 的概率 $`q`$。</strong>

玩家 1 若确定选择足球，只有玩家 2 也选足球才有收益 2；若玩家 2 选芭蕾，收益为 0：

```math
EU_1(S)=2q+0(1-q)=2q.
```

玩家 1 若确定选择芭蕾，玩家 2 选足球时收益 0，选芭蕾时收益 1：

```math
EU_1(B)=0q+1(1-q)=1-q.
```

两种纯行动都要获得正概率，所以必须满足：

```math
2q=1-q
\quad\Longrightarrow\quad
3q=1
\quad\Longrightarrow\quad
q=\frac{1}{3}.
```

<strong>第四步：令玩家 2 无差异，求玩家 1 的概率 $`p`$。</strong>

玩家 2 若确定选足球，在玩家 1 选足球时得到 1，玩家 1 选芭蕾时得到 0：

```math
EU_2(S)=1p+0(1-p)=p.
```

玩家 2 若确定选择芭蕾，在玩家 1 选足球时收益 0，玩家 1 选芭蕾时收益 2：

```math
EU_2(B)=0p+2(1-p)=2(1-p).
```

令两种纯行动的期望收益相等：

```math
p=2(1-p)
\quad\Longrightarrow\quad
3p=2
\quad\Longrightarrow\quad
p=\frac{2}{3}.
```

两人的均衡混合策略为：

```math
\sigma_1^{*}=\left(\frac{2}{3},\frac{1}{3}\right),
\qquad
\sigma_2^{*}=\left(\frac{1}{3},\frac{2}{3}\right).
```

这里的概率顺序均为（足球，芭蕾）。特别注意：<strong>玩家 1 的无差异条件求出的是玩家 2 的概率 $`q`$，玩家 2 的无差异条件求出的是玩家 1 的概率 $`p`$。</strong>不能把两个结果互换。

<strong>第五步：验证混合概率合法，并计算期望收益。</strong>

$`p=2/3`$ 与 $`q=1/3`$ 都严格位于 (0,1) 内，满足双方真正混合的假设。对玩家 1，在玩家 2 的均衡策略下：

```math
EU_1(S)=2\cdot\frac{1}{3}=\frac{2}{3},
\qquad
EU_1(B)=1-\frac{1}{3}=\frac{2}{3}.
```

玩家 2 同理：

```math
EU_2(S)=\frac{2}{3},
\qquad
EU_2(B)=2\left(1-\frac{2}{3}\right)=\frac{2}{3}.
```

每位玩家面对对方的均衡概率，两个可行纯行动都达到同一个最高期望收益，所以没有人能通过改变自己的随机概率获益。

<strong>第六步：计算双方选择相同活动的概率。</strong>

双方随机行动独立。同行有两种互斥情况：都选足球，或者都选芭蕾。

两人都选足球的概率：

```math
\Pr(S,S)=pq
=\frac{2}{3}\cdot\frac{1}{3}
=\frac{2}{9}.
```

两人都选芭蕾的概率：

```math
\Pr(B,B)=(1-p)(1-q)
=\frac{1}{3}\cdot\frac{2}{3}
=\frac{2}{9}.
```

因此：

```math
\Pr(\text{同行})
=\frac{2}{9}+\frac{2}{9}
=\frac{4}{9}.
```

走散的概率则是 $`1-4/9=5/9`$。混合策略均衡保证双方没有单方更改概率的激励，但不保证当次抽中的行动一致。比较三个均衡可以看出，两个纯策略均衡实现了确定的协调，而混合均衡仍会产生协调失败。

## 题 3｜猜硬币：没有纯策略均衡时怎样求唯一混合均衡

<strong>题目：</strong> 玩家 1 希望双方选择相同面，玩家 2 希望双方选择不同面。支付为：

| 玩家 1 / 玩家 2 | 正面 $`H`$ | 反面 $`T`$ |
| --- | --- | --- |
| 正面 $`H`$ | (1,-1) | (-1,1) |
| 反面 $`T`$ | (-1,1) | (1,-1) |

求全部纳什均衡，解释为什么没有纯策略均衡，并计算均衡期望收益。

<strong>答案：</strong> 不存在纯策略纳什均衡；唯一混合策略均衡是双方独立地以 $`1/2`$ 概率选择正面、以 $`1/2`$ 概率选择反面；每人的均衡期望收益为 0。

<strong>第一步：逐格排除纯策略均衡。</strong>

如果选择相同的结果 $`(H,H)`$ 或 $`(T,T)`$，玩家 1 得 1，玩家 2 得 -1。玩家 2 只要单独换到另一面，就能把自己的收益从 -1 提高到 1。

如果选择不同的结果 $`(H,T)`$ 或 $`(T,H)`$，玩家 1 得 -1，玩家 2 得 1。此时玩家 1 只要单独改变行动，就能把自己的收益从 -1 提高到 1。

四个格子都存在有利单方偏离，所以不存在纯策略均衡。不能因此断言“没有任何纳什均衡”，因为有限博弈至少存在一个混合策略均衡。

<strong>第二步：设定概率，并展开玩家 1 的两种纯行动期望收益。</strong>

设玩家 1 选正面的概率为 $`p`$，玩家 2 选正面的概率为 $`q`$。玩家 1 如果固定选正面：

```math
EU_1(H)=1\cdot q+(-1)(1-q)
=2q-1.
```

如果固定选反面：

```math
EU_1(T)=(-1)q+1(1-q)
=1-2q.
```

玩家 1 真正随机化要求两个期望收益相同：

```math
2q-1=1-2q
\quad\Longrightarrow\quad
4q=2
\quad\Longrightarrow\quad
q=\frac{1}{2}.
```

<strong>第三步：展开玩家 2 的两种纯行动期望收益。</strong>

玩家 2 希望两人选择不同，因此它在相同格子得 -1、不同格子得 1。固定选择正面时：

```math
EU_2(H)=(-1)p+1(1-p)
=1-2p.
```

固定选择反面时：

```math
EU_2(T)=1p+(-1)(1-p)
=2p-1.
```

令两者相等：

```math
1-2p=2p-1
\quad\Longrightarrow\quad
4p=2
\quad\Longrightarrow\quad
p=\frac{1}{2}.
```

<strong>第四步：检查收益与单方偏离。</strong>

把 $`p=q=1/2`$ 代回任何一人的两种纯行动期望收益，均得到 0。例如：

```math
EU_1(H)=EU_1(T)
=2\cdot\frac{1}{2}-1=0.
```

由于玩家 1 面对玩家 2 的各半随机策略时，选择任何正面、反面概率都只能获得期望收益 0；玩家 2 也一样，所以双方没有有利单方偏离，构成混合策略纳什均衡。

它是唯一均衡的原因还需要解释：已证明没有纯策略均衡；如果只有一个玩家纯选某一面，对手必然严格偏好相应的最佳反应，随后纯选者又有严格偏离激励，因此不存在一方纯、一方严格混合的边界均衡。双方都混合时，上述两个无差异方程分别只有 $`1/2`$ 一个解。

<strong>第五步：理解均衡概率不是每次实际结果。</strong>

混合均衡中的 0 是事前的期望支付，某次实际对局仍然会出现 (1,-1) 或 (-1,1)。双方都以各半概率独立选择时，四个格子的发生概率均为 $`1/4`$，因此玩家 1 的期望收益：

```math
\frac{1}{4}(1)+\frac{1}{4}(-1)
+\frac{1}{4}(-1)+\frac{1}{4}(1)=0.
```

随机化的作用不是保证获胜，而是让对手无法利用自己的可预测行动规律。若玩家 1 永远选择正面，玩家 2 会固定选择反面；若玩家 1 采用各半概率，玩家 2 就无法通过偏向某一面改善期望收益。

## 题 4｜鹰鸽博弈：为什么存在两种纯均衡和一种混合均衡

<strong>题目：</strong> 两位玩家同时选择鹰（强硬）$`H`$ 或鸽（退让）$`D`$，收益如下。

| 玩家 1 / 玩家 2 | 鹰 $`H`$ | 鸽 $`D`$ |
| --- | --- | --- |
| 鹰 $`H`$ | (-2,-2) | (3,0) |
| 鸽 $`D`$ | (0,3) | (1,1) |

（1）求全部纯策略纳什均衡；（2）求双方选择鹰的混合概率；（3）计算混合均衡的期望收益。

<strong>答案：</strong> 两个纯策略均衡为 $`(H,D)`$、$`(D,H)`$；另有一个双方以 $`1/2`$ 概率选择鹰的严格混合均衡；混合均衡下每人期望收益为 $`1/2`$。

<strong>第一步：先求纯策略最佳反应。</strong>

如果对方选择鹰，自己选鹰得 -2、选鸽得 0，所以应该选鸽；如果对方选择鸽，自己选鹰得 3、选鸽得 1，所以应该选鹰。

双方的收益结构对称，因此：

```math
BR_1(H)=BR_2(H)=\{D\},
\qquad
BR_1(D)=BR_2(D)=\{H\}.
```

最佳反应交点是 $`(H,D)`$ 和 $`(D,H)`$。在两人都强硬的格子里，任何一方改为退让都可以从 -2 提高到 0；在两人都退让的格子里，任何一方改为强硬都可以从 1 提高到 3，因此另外两格不是均衡。

<strong>第二步：设玩家 1 选鹰概率为 $`p`$，玩家 2 选鹰概率为 $`q`$。</strong>

固定玩家 2 的随机概率 $`q`$，玩家 1 如果确定选鹰：

```math
EU_1(H)=(-2)q+3(1-q)
=3-5q.
```

如果确定选鸽：

```math
EU_1(D)=0q+1(1-q)
=1-q.
```

玩家 1 真正混合要求：

```math
3-5q=1-q
\quad\Longrightarrow\quad
2=4q
\quad\Longrightarrow\quad
q=\frac{1}{2}.
```

<strong>第三步：反过来求玩家 1 的概率。</strong>

固定玩家 1 选鹰概率 $`p`$，玩家 2 选鹰的期望收益也是 $`3-5p`$，选鸽的期望收益是 $`1-p`$。令二者相等：

```math
3-5p=1-p
\quad\Longrightarrow\quad p=\frac{1}{2}.
```

本题双方概率相等，是因为支付矩阵对称；遇到非对称博弈不能直接假设 $`p=q`$。

<strong>第四步：检验混合均衡并计算期望收益。</strong>

将 $`q=1/2`$ 代回玩家 1 的两种行动：

```math
EU_1(H)=3-5\cdot\frac{1}{2}
=\frac{1}{2},
```

```math
EU_1(D)=1-\frac{1}{2}=\frac{1}{2}.
```

玩家 2 同理，所以两人都对两种纯行动无差异。候选概率位于 (0,1) 内，支持集包含两种行动，且没有其他行动需要检查，因此构成内部混合均衡。

<strong>第五步：计算实际冲突的概率。</strong>

两人均选鹰时发生严重冲突。在独立随机化假设下：

```math
\Pr(H,H)=p q
=\frac{1}{2}\cdot\frac{1}{2}
=\frac{1}{4}.
```

双方都退让的概率同样是 $`1/4`$，一方强硬、另一方退让的概率合计为 $`1/2`$。虽然混合均衡下每人期望收益为 $`1/2`$，仍有四分之一的概率发生双方各损失 2 的冲突。混合策略的“无差异”只针对事前期望，而不意味着各种实际结果一样好。

## 题 5｜税务稽查：从无差异方程到处罚比较静态

<strong>题目：</strong> 稽查方选择检查 $`A`$ 或不检查 $`N`$，纳税人选择诚实 $`H`$ 或逃税 $`C`$。假设支付如下：

| 稽查方 / 纳税人 | 诚实 $`H`$ | 逃税 $`C`$ |
| --- | --- | --- |
| 检查 $`A`$ | (2,0) | (4,-10) |
| 不检查 $`N`$ | (4,0) | (0,4) |

（1）求混合均衡检查概率 $`p`$ 与诚实概率 $`q`$。（2）若查获逃税时纳税人收益改为 -20，其他支付不变，求新均衡。（3）解释处罚加重为什么可能伴随更低的均衡检查概率。

<strong>答案：</strong> 原均衡检查概率 $`p=2/7`$，诚实概率 $`q=2/3`$；处罚加重后检查概率变为 $`p'=1/6`$，诚实概率仍为 $`q'=2/3`$。

<strong>第一步：先排除纯策略均衡。</strong>

若纳税人诚实，稽查方检查得 2、不检查得 4，最佳反应是不检查；若稽查方不检查，纳税人诚实得 0、逃税得 4，最佳反应是逃税。

若纳税人逃税，稽查方检查得 4、不检查得 0，最佳反应是检查；若稽查方检查，纳税人诚实得 0、逃税得 -10，最佳反应又变为诚实。

四种情况形成最佳反应循环：

```math
(A,H)\rightarrow(N,H)\rightarrow(N,C)
\rightarrow(A,C)\rightarrow(A,H).
```

这里箭头表示某一方存在有利偏离，不代表现实行为一定按这一顺序变化。循环说明四个纯策略格子都无法使双方同时保持最佳反应，因此没有纯策略均衡。

<strong>第二步：定义概率，先让纳税人无差异。</strong>

令稽查方以概率 $`p`$ 检查，以 $`1-p`$ 不检查；纳税人以概率 $`q`$ 诚实，以 $`1-q`$ 逃税。

纳税人若确定诚实，不论查不检查，收益都是 0：

```math
EU_T(H)=0p+0(1-p)=0.
```

纳税人若确定逃税，遇到检查得到 -10，遇到不检查得到 4：

```math
EU_T(C)=(-10)p+4(1-p)
=4-14p.
```

若纳税人要在诚实与逃税之间真正混合，必须无差异：

```math
0=4-14p
\quad\Longrightarrow\quad
p=\frac{4}{14}=\frac{2}{7}.
```

注意 $`p`$ 是稽查方的检查概率，却要从<strong>纳税人的</strong>无差异条件中求得。

<strong>第三步：让稽查方无差异，求纳税人的诚实概率。</strong>

稽查方若确定检查，纳税人诚实时得到 2、逃税时得到 4：

```math
EU_A(A)=2q+4(1-q)
=4-2q.
```

稽查方若确定不检查，纳税人诚实时得到 4、逃税时得到 0：

```math
EU_A(N)=4q+0(1-q)=4q.
```

令检查与不检查的期望收益相等：

```math
4-2q=4q
\quad\Longrightarrow\quad
6q=4
\quad\Longrightarrow\quad
q=\frac{2}{3}.
```

所以原混合均衡是：

```math
\sigma_A=(A:\tfrac{2}{7},N:\tfrac{5}{7}),
\qquad
\sigma_T=(H:\tfrac{2}{3},C:\tfrac{1}{3}).
```

<strong>第四步：验证双方的均衡期望收益。</strong>

纳税人在该检查概率下面对诚实、逃税均得到 0：

```math
EU_T(C)=4-14\cdot\frac{2}{7}=0.
```

稽查方在纳税人的诚实概率下，检查和不检查均得到：

```math
EU_A(A)=4-2\cdot\frac{2}{3}
=\frac{8}{3},
```

```math
EU_A(N)=4\cdot\frac{2}{3}
=\frac{8}{3}.
```

两方都无差异，且概率严格位于 (0,1)，因此这是一个严格混合均衡。

<strong>第五步：将查获逃税时的处罚从 -10 改为 -20。</strong>

稽查方的四个支付数字没有变化，纳税人在诚实时仍然得到 0。变化的只有纳税人被检查且逃税时的收益。因此新逃税期望收益为：

```math
EU_T'(C)=(-20)p'+4(1-p')
=4-24p'.
```

新无差异条件：

```math
0=4-24p'
\quad\Longrightarrow\quad
p'=\frac{1}{6}.
```

稽查方的无差异条件仍是 $`4-2q'=4q'`$，所以：

```math
q'=\frac{2}{3}.
```

这表示处罚加重后，均衡检查频率从 $`2/7`$ 降到 $`1/6`$，而本模型中的诚实概率不变。

<strong>第六步：用一般参数解释为什么检查概率可能下降。</strong>

设未被查获的逃税净收益是 $`g>0`$，被查获逃税的收益为 $`-F`$，其中 $`F>0`$。诚实收益仍为 0。纳税人对诚实与逃税无差异时：

```math
0=-Fp+g(1-p)
=g-(F+g)p.
```

所以：

```math
p^{*}=\frac{g}{F+g}.
```

对处罚参数求导：

```math
\frac{dp^{*}}{dF}
=-\frac{g}{(F+g)^2}<0.
```

处罚越重，越小的检查概率就能使纳税人在诚实和逃税之间无差异。这是<strong>本题特定支付结构下的均衡比较静态</strong>，不能将它直接解释为现实中处罚加重会使逃税行为完全不变。现实中若风险偏好、处罚执行可信度、稽查成本或行动机会发生改变，均衡结构也可能不同。

## 题 6｜混合策略严格支配：纯行动不能支配，不代表混合策略也不能

<strong>题目：</strong> 下表只列出玩家 1 的支付，玩家 1 可以选择 $`T,M,B`$，玩家 2 可以选择 $`L,R`$。

| 玩家 1 / 玩家 2 | $`L`$ | $`R`$ |
| --- | ---: | ---: |
| $`T`$ | 1 | 1 |
| $`M`$ | 4 | 0 |
| $`B`$ | 0 | 3 |

（1）证明 $`T`$ 不被 $`M`$ 或 $`B`$ 中任一纯行动严格支配。（2）寻找在 $`M`$ 和 $`B`$ 间随机化且严格支配 $`T`$ 的混合策略，求概率范围。

<strong>答案：</strong> $`M`$ 与 $`B`$ 单独都不能严格支配 $`T`$；若以概率 $`r`$ 选择 $`M`$、以 $`1-r`$ 选择 $`B`$，则所有满足 $`1/4<r<2/3`$ 的混合策略都会严格支配 $`T`$。

<strong>第一步：逐列检查纯行动严格支配。</strong>

如果玩家 2 选 $`L`$，玩家 1 选择 $`T`$ 得 1，选 $`M`$ 得 4，选 $`B`$ 得 0。此时 $`M`$ 比 $`T`$ 好，但 $`B`$ 反而比 $`T`$ 差。

如果玩家 2 选 $`R`$，玩家 1 选择 $`T`$ 得 1，选 $`M`$ 得 0，选 $`B`$ 得 3。此时 $`B`$ 比 $`T`$ 好，但 $`M`$ 比 $`T`$ 差。

严格支配要求替代行动面对所有对手选择都更好，所以：

```math
u_1(M,R)=0<1=u_1(T,R),
```

```math
u_1(B,L)=0<1=u_1(T,L).
```

因此 $`M`$ 和 $`B`$ 都不能单独严格支配 $`T`$。

<strong>第二步：构造随机替代方案。</strong>

让玩家 1 以概率 $`r`$ 选择 $`M`$，以概率 $`1-r`$ 选择 $`B`$。这个随机策略记作 $`\mu=(M:r,B:1-r)`$。

若对手固定选 $`L`$，混合策略的期望收益是：

```math
EU_1(\mu,L)=4r+0(1-r)=4r.
```

若对手固定选 $`R`$：

```math
EU_1(\mu,R)=0r+3(1-r)=3-3r.
```

$`T`$ 面对任何一列的收益都为 1。要让 $`\mu`$ 严格支配 $`T`$，必须同时满足两列下的严格不等式：

```math
4r>1,\qquad 3-3r>1.
```

<strong>第三步：分别解不等式并求交集。</strong>

第一式给出：

```math
r>\frac{1}{4}.
```

第二式整理为：

```math
-3r>-2
\quad\Longrightarrow\quad
r<\frac{2}{3}.
```

又因为 $`r`$ 是概率，本来就应满足 $`0\le r\le1`$，故有效区间为：

```math
\boxed{\frac{1}{4}<r<\frac{2}{3}}.
```

两个端点不能包含，因为在 $`r=1/4`$ 时面对 $`L`$ 恰好只得 1，在 $`r=2/3`$ 时面对 $`R`$ 恰好只得 1，都只能满足非严格比较。

<strong>第四步：取一个具体概率验证。</strong>

选择 $`r=1/2`$，即 $`M`$ 与 $`B`$ 各使用一半概率。面对 $`L`$，期望收益为 $`4(1/2)=2>1`$；面对 $`R`$，期望收益为 $`3(1/2)=3/2>1`$。因此该混合策略确实在对手两种纯行动下都严格优于 $`T`$。

若对手自己以概率 $`q`$ 选 $`L`$，混合策略相对 $`T`$ 的期望优势为：

```math
q\big(4r-1\big)
+(1-q)\big(3(1-r)-1\big).
```

在刚得到的严格区间里，括号内两项都严格为正，所以对任意 $`q\in[0,1]`$，这个加权平均仍严格为正。这证明“对每个对手纯行动都严格更好”足以保证“对对手的任意混合策略也严格更好”。

本题并没有给出玩家 2 的收益，因此不能仅凭这张表求出完整纳什均衡；它要证明的是玩家 1 的纯行动 $`T`$ 不可能在任何均衡中获得正概率。

## 题 7｜二乘三支持集枚举：怎么保证没有漏掉均衡

<strong>题目：</strong> 下面是一个玩家 1 有两个纯行动、玩家 2 有三个纯行动的博弈。

| 玩家 1 / 玩家 2 | $`B`$ | $`S`$ | $`X`$ |
| --- | --- | --- | --- |
| $`B`$ | (4,2) | (0,0) | (0,1) |
| $`S`$ | (0,0) | (2,4) | (1,3) |

找出全部纳什均衡，并说明为什么在内部混合均衡中玩家 2 不会给 $`S`$ 分配正概率。

<strong>答案：</strong> 全部纳什均衡恰有三个：两个纯策略均衡 $`(B,B)`$、$`(S,S)`$，以及一个混合策略均衡：

```math
\sigma_1^{*}=(B:\tfrac{3}{4},S:\tfrac{1}{4}),
\qquad
\sigma_2^{*}=(B:\tfrac{1}{5},S:0,X:\tfrac{4}{5}).
```

<strong>第一步：先检查纯策略最佳反应。</strong>

玩家 1 面对玩家 2 选 $`B`$ 时，选 $`B`$ 得 4、选 $`S`$ 得 0；面对玩家 2 选 $`S`$ 时，选 $`B`$ 得 0、选 $`S`$ 得 2；面对玩家 2 选 $`X`$ 时，选 $`B`$ 得 0、选 $`S`$ 得 1。所以：

```math
BR_1(B)=\{B\},\quad
BR_1(S)=\{S\},\quad
BR_1(X)=\{S\}.
```

玩家 2 面对玩家 1 选 $`B`$ 时，自己的三种行动收益分别是 2、0、1，选 $`B`$ 最好；面对玩家 1 选 $`S`$ 时，收益分别是 0、4、3，选 $`S`$ 最好：

```math
BR_2(B)=\{B\},\qquad
BR_2(S)=\{S\}.
```

因此两个纯策略交点是 $`(B,B)`$ 与 $`(S,S)`$。本题还要寻找可能的混合均衡，不能在这里停止。

<strong>第二步：将玩家 2 三个行动的收益写成玩家 1 概率 $`p`$ 的函数。</strong>

设玩家 1 以概率 $`p`$ 选 $`B`$、以概率 $`1-p`$ 选 $`S`$。则玩家 2 若确定选列 $`B`$：

```math
V_2(B)=2p+0(1-p)=2p.
```

玩家 2 若确定选列 $`S`$：

```math
V_2(S)=0p+4(1-p)=4-4p.
```

玩家 2 若确定选列 $`X`$：

```math
V_2(X)=1p+3(1-p)=3-2p.
```

玩家 2 在任何候选混合均衡里，只有期望收益达到三者最大值的行动才能被放入支持集。

<strong>第三步：尝试玩家 2 在 $`B,X`$ 之间混合。</strong>

若玩家 2 同时给 $`B`$、$`X`$ 正概率，这两种列行动必须无差异：

```math
2p=3-2p
\quad\Longrightarrow\quad
4p=3
\quad\Longrightarrow\quad
p=\frac{3}{4}.
```

这时两种被使用的列行动都有期望收益：

```math
V_2(B)=V_2(X)=2\cdot\frac{3}{4}
=\frac{3}{2}.
```

没有被使用的列 $`S`$ 的收益是：

```math
V_2(S)=4-4\cdot\frac{3}{4}=1.
```

因为 $`1<3/2`$，玩家 2 没有动机从 $`B,X`$ 改到 $`S`$，所以支持集 $`\{B,X\}`$ 通过了支持集外行动检验。

<strong>第四步：求玩家 2 的混合概率，让玩家 1 无差异。</strong>

设玩家 2 选 $`B`$ 的概率为 $`q`$、选 $`X`$ 的概率为 $`1-q`$，而选 $`S`$ 的概率为 0。

玩家 1 如果确定选行 $`B`$，面对列 $`B`$ 获得 4，面对列 $`X`$ 获得 0，因此：

```math
EU_1(B)=4q+0(1-q)=4q.
```

玩家 1 如果确定选行 $`S`$，面对列 $`B`$ 获得 0，面对列 $`X`$ 获得 1，因此：

```math
EU_1(S)=0q+1(1-q)=1-q.
```

要让玩家 1 真正在 $`B,S`$ 之间混合，必须满足：

```math
4q=1-q
\quad\Longrightarrow\quad
5q=1
\quad\Longrightarrow\quad
q=\frac{1}{5}.
```

所以候选均衡为：

```math
\sigma_1^{*}=(\tfrac{3}{4},\tfrac{1}{4}),
\qquad
\sigma_2^{*}=(\tfrac{1}{5},0,\tfrac{4}{5}).
```

玩家 1 的两种行动收益均为 $`4/5`$；玩家 2 的 $`B,X`$ 收益均为 $`3/2`$，未使用的 $`S`$ 只有 1。两人都没有有利的单方偏离，因此这个候选解确实构成纳什均衡。

<strong>第五步：排除玩家 2 只混合 $`B,S`$ 的可能性。</strong>

若玩家 2 混合 $`B,S`$，必须有：

```math
V_2(B)=V_2(S)
\quad\Longrightarrow\quad
2p=4-4p
\quad\Longrightarrow\quad
p=\frac{2}{3}.
```

这时两个支持集内行动的共同收益是：

```math
V_2(B)=V_2(S)=\frac{4}{3}.
```

但支持集外的 $`X`$ 的收益为：

```math
V_2(X)=3-2\cdot\frac{2}{3}
=\frac{5}{3}>\frac{4}{3}.
```

玩家 2 会改选收益更高的 $`X`$，所以 $`\{B,S\}`$ 不能构成混合均衡的支持集。

<strong>第六步：排除玩家 2 只混合 $`S,X`$ 的可能性。</strong>

若玩家 2 真正混合 $`S,X`$，它可能面对的玩家 1 概率必须满足：

```math
V_2(S)=V_2(X)
\quad\Longrightarrow\quad
4-4p=3-2p
\quad\Longrightarrow\quad
p=\frac{1}{2}.
```

但当玩家 2 只在 $`S,X`$ 之间随机化时，玩家 1 选择行 $`B`$ 的支付恒为 0；选择行 $`S`$ 的支付则在列 $`S`$ 时为 2，在列 $`X`$ 时为 1，因此严格为正。于是玩家 1 的唯一最佳反应是纯选 $`S`$，即 $`p=0`$，这与 $`p=1/2`$ 矛盾。所以此支持集也不成立。

<strong>第七步：排除三列同时混合和其余边界情况。</strong>

如果玩家 2 对 $`B,S,X`$ 都分配正概率，三个列行动的期望收益必须相等。可是：

```math
V_2(B)=V_2(S)\ \Longrightarrow\ p=\frac{2}{3},
```

而：

```math
V_2(B)=V_2(X)\ \Longrightarrow\ p=\frac{3}{4}.
```

两者无法同时成立，因此不存在三列都以正概率使用的均衡。

还需检查“一方纯策略、另一方混合”的可能性：玩家 1 若纯选 $`B`$，玩家 2 的唯一最佳反应是 $`B`$；玩家 1 若纯选 $`S`$，玩家 2 的唯一最佳反应是 $`S`$。所以这里不会出现一方纯选、另一方严格混合的额外均衡。

因此完整均衡集合已经穷尽：两个纯策略均衡，以及前面得到的一个支持集为 $`\{B,X\}`$ 的混合均衡。支持集枚举真正困难的不是列方程，而是<strong>证明没有被使用的行动不能让任何人获益，并排除其他候选支持集</strong>。

## 题 8｜三人混合策略：为什么会出现概率乘积

<strong>题目：</strong> 三名玩家各有 $`A,B`$ 两个纯行动，分别以概率 $`p,q,r`$ 选择 $`A`$。已知三名玩家都真正混合时，对应的无差异条件为：

```math
qr=4(1-q)(1-r),
```

```math
pr=4(1-p)(1-r),
```

```math
pq=4(1-p)(1-q).
```

求对称、三人均严格混合的均衡概率，并解释为什么不能将三人问题简单照搬二人一次方程的做法。

<strong>答案：</strong> 满足这些无差异条件的严格混合概率为：

```math
\boxed{p=q=r=\frac{2}{3}}.
```

<strong>第一步：理解无差异方程里的乘积。</strong>

玩家 1 在决定自己选择什么行动时，必须考虑另外两人同时行动的不同情形。如果玩家 2 以概率 $`q`$ 选 $`A`$，玩家 3 以概率 $`r`$ 选 $`A`$，且两人独立随机化，那么：

```math
\Pr(A_2,A_3)=qr,
```

```math
\Pr(B_2,B_3)=(1-q)(1-r).
```

题目给出的第一条无差异关系，是某一组收益差异经整理后得到的 $`qr=4(1-q)(1-r)`$。它涉及两个对手的联合行动概率，因此是非线性方程。

这里“独立”很重要。如果三人通过共同的随机信号协调行动，联合概率未必等于边际概率的乘积，便不能直接使用这组方程。

<strong>第二步：先使用对称性。</strong>

题目要求对称解，即三名玩家采用相同的行动概率：

```math
p=q=r=x,\qquad 0<x<1.
```

三条方程会化为同一条：

```math
x^2=4(1-x)^2.
```

由于 $`0<x<1`$，可知 $`x>0`$ 且 $`1-x>0`$。对两侧取正平方根：

```math
x=2(1-x).
```

整理：

```math
x=2-2x
\quad\Longrightarrow\quad
3x=2
\quad\Longrightarrow\quad
x=\frac{2}{3}.
```

因此三人均以 $`2/3`$ 概率选择 $`A`$，以 $`1/3`$ 概率选择 $`B`$。

<strong>第三步：代回验证，而不是只报出结果。</strong>

将 $`p=q=r=2/3`$ 代入任一左边：

```math
qr=\frac{2}{3}\cdot\frac{2}{3}
=\frac{4}{9}.
```

右边：

```math
4(1-q)(1-r)
=4\cdot\frac{1}{3}\cdot\frac{1}{3}
=\frac{4}{9}.
```

其余两条对称，因此也成立。并且 $`2/3`$ 严格位于 (0,1) 内，符合三人都真正混合的假设。

<strong>第四步：能否证明严格混合解实际上必须对称？</strong>

在严格混合前提下，所有概率和它们的补数都大于零。第一条方程可以整理为：

```math
\frac{q}{1-q}\cdot\frac{r}{1-r}=4.
```

第二、三条分别是：

```math
\frac{p}{1-p}\cdot\frac{r}{1-r}=4,
\qquad
\frac{p}{1-p}\cdot\frac{q}{1-q}=4.
```

第一式和第二式相除，可得：

```math
\frac{q}{1-q}=\frac{p}{1-p}.
```

由于函数 $`z/(1-z)`$ 在 $`(0,1)`$ 上严格递增，说明 $`p=q`$。与第三条比较同理可得 $`q=r`$。因此即使一开始不假定对称，任何满足这组三条方程的严格混合解也必须有 $`p=q=r`$，随后唯一解就是 $`2/3`$。

<strong>第五步：区分概率方程与完整均衡分析。</strong>

本题明确指出这些是三名玩家全部严格混合时的无差异条件，而且每个人只有 $`A,B`$ 两个行动。在这个前提下，如果这些方程确实来自对应的收益比较，那么让各方无差异且概率合法，就足以证明三人都没有单方改变混合概率的收益。

但题目没有提供各个行动组合的原始支付表，因此无法计算每人的均衡期望收益，也无法找出可能存在的纯策略均衡或只有部分玩家混合的其他均衡。不能把“找到了唯一严格混合解”写成“找到了这个三人博弈的全部均衡”。

## 题 9｜零和博弈：无差异法、极小极大与博弈值

<strong>题目：</strong> 下表只给出玩家 1 的收益，玩家 2 在每格获得恰好相反的收益：

| 玩家 1 / 玩家 2 | $`L`$ | $`R`$ |
| --- | ---: | ---: |
| $`U`$ | 2 | -1 |
| $`D`$ | -2 | 3 |

求双方最优混合策略、玩家 1 的博弈值，并判断是否存在纯策略鞍点。

<strong>答案：</strong> 玩家 1 以概率 $`5/8`$ 选 $`U`$，玩家 2 以概率 $`1/2`$ 选 $`L`$；玩家 1 的博弈值为 $`1/2`$，玩家 2 的均衡期望收益为 $`-1/2`$；不存在纯策略鞍点。

<strong>第一步：用最大最小与最小最大排除纯策略鞍点。</strong>

玩家 1 希望最大化自己的收益，玩家 2 希望最小化玩家 1 的收益。若玩家 1 固定选 $`U`$，面对 $`L`$ 得 2、面对 $`R`$ 得 -1，最坏收益是 -1。若玩家 1 固定选 $`D`$，最坏收益是 -2。因此玩家 1 在纯策略下可保证的最大最小收益：

```math
\max\{-1,-2\}=-1.
```

玩家 2 若固定选 $`L`$，玩家 1 能在 $`U,D`$ 中择优得到 2；若固定选 $`R`$，玩家 1 最多得到 3。玩家 2 对玩家 1 支付能施加的最小最大上界：

```math
\min\{2,3\}=2.
```

因为 $`-1\ne2`$，两者之间存在差距，原矩阵没有纯策略鞍点。

<strong>第二步：定义混合概率。</strong>

设玩家 1 选择 $`U`$ 的概率为 $`p`$，选择 $`D`$ 的概率为 $`1-p`$。玩家 2 选择 $`L`$ 的概率为 $`q`$，选择 $`R`$ 的概率为 $`1-q`$。

求零和博弈的混合均衡，可以继续使用无差异法，但要记住玩家 2 的目标是<strong>最小化玩家 1 的支付</strong>。

<strong>第三步：让玩家 1 对两行无差异，解出玩家 2 的概率。</strong>

玩家 1 确定选择 $`U`$ 时：

```math
EU_1(U)=2q+(-1)(1-q)
=3q-1.
```

玩家 1 确定选择 $`D`$ 时：

```math
EU_1(D)=(-2)q+3(1-q)
=3-5q.
```

令两行相等：

```math
3q-1=3-5q
\quad\Longrightarrow\quad
8q=4
\quad\Longrightarrow\quad
q=\frac{1}{2}.
```

<strong>第四步：让玩家 2 对两列无差异，解出玩家 1 的概率。</strong>

玩家 2 获得的是玩家 1 支付的相反数。让玩家 2 对两列无差异，等价于让玩家 1 面对两列的期望收益相等。

当玩家 2 固定选 $`L`$，玩家 1 的期望收益是：

```math
V_L(p)=2p+(-2)(1-p)=4p-2.
```

当玩家 2 固定选 $`R`$：

```math
V_R(p)=(-1)p+3(1-p)=3-4p.
```

令两列产生相同的玩家 1 期望收益：

```math
4p-2=3-4p
\quad\Longrightarrow\quad
8p=5
\quad\Longrightarrow\quad
p=\frac{5}{8}.
```

因此双方混合策略为：

```math
\sigma_1^{*}=(U:\tfrac{5}{8},D:\tfrac{3}{8}),
\qquad
\sigma_2^{*}=(L:\tfrac{1}{2},R:\tfrac{1}{2}).
```

<strong>第五步：计算博弈值。</strong>

代入玩家 1 的行行动期望收益：

```math
v=EU_1(U)=3\cdot\frac{1}{2}-1
=\frac{1}{2}.
```

同样：

```math
EU_1(D)=3-5\cdot\frac{1}{2}
=\frac{1}{2}.
```

玩家 2 的均衡期望收益是 $`-v=-1/2`$，因为这是零和博弈。

<strong>第六步：从保障收益再验证一次。</strong>

如果玩家 1 固定使用 $`p=5/8`$，玩家 2 即使选择最不利于玩家 1 的列，玩家 1 仍能获得：

```math
V_L\left(\frac{5}{8}\right)
=4\cdot\frac{5}{8}-2
=\frac{1}{2},
```

```math
V_R\left(\frac{5}{8}\right)
=3-4\cdot\frac{5}{8}
=\frac{1}{2}.
```

所以玩家 1 的这个随机策略至少保证 $`1/2`$。另一方面，玩家 2 以 $`q=1/2`$ 随机化时，不论玩家 1 选哪一行，玩家 1 的收益都只能为 $`1/2`$，因此玩家 2 把玩家 1 的最高可能收益也压到 $`1/2`$。

双方保障与限制恰好一致，表明博弈值确实为 $`v=1/2`$。这就是零和博弈的极小极大思路与无差异方程之间的联系。

## 题 10｜不对称二乘二：两个均衡概率为什么不同

<strong>题目：</strong> 求下列博弈的全部纯策略纳什均衡，以及双方都使用两种行动的混合均衡。

| 玩家 1 / 玩家 2 | $`L`$ | $`R`$ |
| --- | --- | --- |
| $`U`$ | (3,1) | (0,0) |
| $`D`$ | (0,0) | (1,2) |

<strong>答案：</strong> 纯策略均衡为 $`(U,L)`$ 和 $`(D,R)`$；内部混合均衡中玩家 1 以 $`p=2/3`$ 概率选 $`U`$，玩家 2 以 $`q=1/4`$ 概率选 $`L`$；对应期望收益分别为 $`3/4`$ 和 $`2/3`$。

<strong>第一步：找纯策略均衡。</strong>

玩家 1 面对 $`L`$，选 $`U`$ 得 3、选 $`D`$ 得 0，故选 $`U`$；面对 $`R`$，选 $`U`$ 得 0、选 $`D`$ 得 1，故选 $`D`$。

玩家 2 面对 $`U`$，选 $`L`$ 得 1、高于选 $`R`$ 的 0；面对 $`D`$，选 $`R`$ 得 2、高于选 $`L`$ 的 0。因此 $`(U,L)`$ 与 $`(D,R)`$ 是两个纯策略纳什均衡，均为严格均衡。

<strong>第二步：设定概率，计算玩家 1 的两行期望收益。</strong>

令玩家 1 选 $`U`$ 的概率为 $`p`$，玩家 2 选 $`L`$ 的概率为 $`q`$。玩家 1 固定选 $`U`$ 的期望收益：

```math
EU_1(U)=3q+0(1-q)=3q.
```

玩家 1 固定选 $`D`$ 的期望收益：

```math
EU_1(D)=0q+1(1-q)=1-q.
```

若玩家 1 严格混合，要求：

```math
3q=1-q
\quad\Longrightarrow\quad
4q=1
\quad\Longrightarrow\quad
q=\frac{1}{4}.
```

<strong>第三步：计算玩家 2 的两列期望收益。</strong>

玩家 2 选 $`L`$ 的期望收益为：

```math
EU_2(L)=1p+0(1-p)=p.
```

玩家 2 选 $`R`$ 的期望收益为：

```math
EU_2(R)=0p+2(1-p)=2(1-p).
```

令两列无差异：

```math
p=2(1-p)
\quad\Longrightarrow\quad
3p=2
\quad\Longrightarrow\quad
p=\frac{2}{3}.
```

所以内部混合均衡：

```math
\sigma_1^{*}=(U:\tfrac{2}{3},D:\tfrac{1}{3}),
\qquad
\sigma_2^{*}=(L:\tfrac{1}{4},R:\tfrac{3}{4}).
```

<strong>第四步：检查概率和期望收益。</strong>

两个概率都严格处于 (0,1) 内，所以确实是双方都混合的策略。玩家 1 的期望收益：

```math
EU_1(U)=3\cdot\frac{1}{4}
=\frac{3}{4},
```

```math
EU_1(D)=1-\frac{1}{4}
=\frac{3}{4}.
```

玩家 2 的期望收益：

```math
EU_2(L)=\frac{2}{3},
\qquad
EU_2(R)=2\cdot\frac{1}{3}
=\frac{2}{3}.
```

由于双方支持集都包含自身全部两种行动，而且各自无差异，没有支持集外行动需要检查，因此这个混合策略组合确实是纳什均衡。

<strong>第五步：解释为什么 $`p`$ 和 $`q`$ 不相同。</strong>

玩家 1 对 $`(U,L)`$ 的收益为 3，玩家 2 在同一格子的收益只有 1；在 $`(D,R)`$ 处，两人收益分别为 1 和 2。两人的支付结构不对称，分别使对方无差异所需的概率也不同。不能因为这是一个二乘二协调博弈，就直接套用每人 50% 的随机概率。

## 题 11｜严格占优行动：为什么无差异方程可能根本不存在

<strong>题目：</strong> 下表只给出了行玩家的支付：

| 行玩家 / 列玩家 | $`L`$ | $`R`$ |
| --- | ---: | ---: |
| $`U`$ | 4 | 3 |
| $`D`$ | 1 | 2 |

不论列玩家自己的支付如何，是否可能存在双方都严格随机化的纳什均衡？

<strong>答案：</strong> 不可能。行玩家的 $`U`$ 严格支配 $`D`$，因此 $`D`$ 不会获得正的均衡概率。

<strong>第一步：不求概率，先比较支配关系。</strong>

如果列玩家选择 $`L`$，行玩家选 $`U`$ 得 4，选 $`D`$ 得 1，有：

```math
4>1.
```

如果列玩家选择 $`R`$，行玩家选 $`U`$ 得 3，选 $`D`$ 得 2，有：

```math
3>2.
```

所以不论列玩家如何行动，行玩家都严格偏好 $`U`$。这就是 $`U`$ 严格支配 $`D`$。

<strong>第二步：用概率方法再验证一次。</strong>

设列玩家以概率 $`q`$ 选择 $`L`$，以概率 $`1-q`$ 选择 $`R`$。行玩家固定选 $`U`$ 的期望收益为：

```math
EU_1(U)=4q+3(1-q)
=3+q.
```

固定选 $`D`$ 的期望收益为：

```math
EU_1(D)=1q+2(1-q)
=2-q.
```

两者之差：

```math
EU_1(U)-EU_1(D)
=(3+q)-(2-q)
=1+2q.
```

对任何合法概率 $`0\le q\le1`$，都有 $`1+2q\ge1>0`$。因此行玩家永远不会对 $`U,D`$ 无差异。

如果机械地求解 $`3+q=2-q`$，会得到：

```math
q=-\frac{1}{2},
```

但负概率不是可行策略。它表示我们关于“行玩家会同时使用 $`U,D`$”的支持集假设不成立，不能把 $`-1/2`$ 当作某种特殊混合均衡。

<strong>第三步：还能求出什么？</strong>

虽然无法仅凭行玩家支付判断列玩家究竟选 $`L`$ 还是 $`R`$，但可以确定：任何纳什均衡中，行玩家都必须纯选 $`U`$。列玩家在面对 $`U`$ 时采取自己的最佳反应；该最佳反应可能唯一，也可能有多个，取决于题目没有给出的列玩家支付。

因此本题展示的是一项排除法：<strong>严格支配检验往往比列无差异方程更早、更直接地排除不可能的混合支持集。</strong>

## 题 12｜新增综合题：为什么一个玩家纯策略、另一个玩家仍可以混合

<strong>题目：</strong> 两人同时行动，支付矩阵为：

| 玩家 1 / 玩家 2 | $`L`$ | $`R`$ |
| --- | --- | --- |
| $`U`$ | (2,1) | (2,1) |
| $`D`$ | (0,0) | (0,0) |

求全部纳什均衡，并解释为什么不可以把“混合策略均衡”理解成“两个人都必须随机化”。

<strong>答案：</strong> 玩家 1 必须纯选 $`U`$；玩家 2 可以以任意概率 $`q\in[0,1]`$ 在 $`L,R`$ 之间混合。因此全部均衡为：

```math
\sigma_1^{*}=(U:1,D:0),
\qquad
\sigma_2^{*}=(L:q,R:1-q),
\quad 0\le q\le1.
```

<strong>第一步：比较玩家 1 的两个行动。</strong>

面对玩家 2 的 $`L`$，玩家 1 选 $`U`$ 得 2、选 $`D`$ 得 0；面对 $`R`$ 也一样。无论玩家 2 选哪一列，都有：

```math
u_1(U,\cdot)=2>0=u_1(D,\cdot).
```

因此 $`U`$ 严格支配 $`D`$，任何均衡中玩家 1 都必须以概率 1 选 $`U`$。

<strong>第二步：在玩家 1 确定选 $`U`$ 时，分析玩家 2。</strong>

如果玩家 1 纯选 $`U`$，玩家 2 选 $`L`$ 得 1、选 $`R`$ 也得 1。因此：

```math
EU_2(L\mid U)=EU_2(R\mid U)=1.
```

玩家 2 对两列完全无差异。它可以纯选 $`L`$，也可以纯选 $`R`$，还可以使用任意概率随机化。

<strong>第三步：检验玩家 1 会不会因为玩家 2 随机化而改变想法。</strong>

令玩家 2 以概率 $`q`$ 选 $`L`$。玩家 1 选 $`U`$ 的期望收益：

```math
EU_1(U)=2q+2(1-q)=2.
```

玩家 1 选 $`D`$ 的期望收益：

```math
EU_1(D)=0q+0(1-q)=0.
```

对于任何 $`q\in[0,1]`$，玩家 1 都严格偏好 $`U`$，因此不会单方偏离。玩家 2 在玩家 1 纯选 $`U`$ 时也完全无差异，所以双方构成均衡。

<strong>第四步：区分均衡集合的端点与内部。</strong>

当 $`q=1`$ 时，玩家 2 纯选 $`L`$，得到纯策略均衡 $`(U,L)`$；当 $`q=0`$ 时，得到纯策略均衡 $`(U,R)`$。

当 $`0<q<1`$ 时，玩家 2 真正随机化，但玩家 1 仍然使用纯行动 $`U`$。因此它是“一方纯、一方混合”的均衡。这类题的均衡不是单个概率点，而是包含连续多个概率值的集合。若解题时只设双方都严格混合并要求四个纯行动全部无差异，就会遗漏整个均衡集合。

## 题 13｜新增综合题：检查成本变化，为什么改变的是诚实概率

<strong>题目：</strong> 仍考虑题 5 的税务稽查博弈，但现在稽查方只要选择检查就需要承担额外成本 $`k`$，无论纳税人是否逃税，这笔成本都会使稽查方的当次支付减少 $`k`$。纳税人的支付不变。

| 稽查方 / 纳税人 | 诚实 $`H`$ | 逃税 $`C`$ |
| --- | --- | --- |
| 检查 $`A`$ | $`(2-k,0)`$ | $`(4-k,-10)`$ |
| 不检查 $`N`$ | (4,0) | (0,4) |

设 $`0<k<4`$。（1）求严格混合均衡的检查概率 $`p`$ 和诚实概率 $`q`$。（2）当 $`k=1`$ 时计算两个概率。（3）说明检查成本增加究竟改变谁的均衡概率。

<strong>答案：</strong> 在 $`0<k<4`$ 内，严格混合均衡满足：

```math
p^{*}=\frac{2}{7},
\qquad
q^{*}=\frac{4-k}{6}.
```

当 $`k=1`$ 时，检查概率为 $`2/7`$，诚实概率为 $`1/2`$。检查成本提高会降低本模型中的均衡诚实概率，但在严格混合区间内不改变检查概率。

<strong>第一步：先判断支付变化影响了哪一个玩家的无差异条件。</strong>

检查成本 $`k`$ 只扣除稽查方选择检查时的收益，纳税人面对检查或不检查时的支付仍为原来的 0、-10 和 4。

如果稽查方以概率 $`p`$ 检查，纳税人诚实时始终得 0，逃税时的期望收益仍为：

```math
EU_T(C)=(-10)p+4(1-p)=4-14p.
```

因此使纳税人无差异的条件没有改变：

```math
0=4-14p
\quad\Longrightarrow\quad
p=\frac{2}{7}.
```

这说明纳税人的支付结构保持不变时，决定稽查方检查概率的无差异方程也保持不变。

<strong>第二步：重新计算稽查方的两种纯行动收益。</strong>

令纳税人诚实概率为 $`q`$。稽查方如果确定检查，面对诚实者得到 $`2-k`$，面对逃税者得到 $`4-k`$：

```math
EU_A(A)
=(2-k)q+(4-k)(1-q).
```

展开：

```math
EU_A(A)
=2q-kq+4-k-4q+kq
=4-k-2q.
```

若稽查方确定不检查，收益仍然为：

```math
EU_A(N)=4q+0(1-q)=4q.
```

<strong>第三步：令稽查方无差异，求新的诚实概率。</strong>

```math
4-k-2q=4q
\quad\Longrightarrow\quad
6q=4-k
\quad\Longrightarrow\quad
q=\frac{4-k}{6}.
```

当 $`0<k<4`$ 时，有 $`0<q<2/3<1`$；检查概率 $`p=2/7`$ 也位于 (0,1)，所以严格混合的概率假设有效。

<strong>第四步：代入数值并检验。</strong>

当 $`k=1`$：

```math
q=\frac{4-1}{6}=\frac{1}{2}.
```

稽查方检查时的期望收益是：

```math
EU_A(A)=4-1-2\cdot\frac{1}{2}=2.
```

不检查时的期望收益：

```math
EU_A(N)=4\cdot\frac{1}{2}=2.
```

纳税人面对检查概率 $`2/7`$ 时，诚实与逃税的期望收益仍都为 0，因此双方均无差异，确实构成混合均衡。

<strong>第五步：与题 5 的处罚变化作对照。</strong>

若改变纳税人的逃税处罚，改变的是纳税人的无差异条件，直接解出的是稽查方的均衡检查概率 $`p`$；若改变稽查方的检查成本，改变的是稽查方的无差异条件，直接解出的是纳税人的均衡诚实概率 $`q`$。

在本题规定的成本范围内：

```math
\frac{dq^{*}}{dk}=-\frac{1}{6}<0,
\qquad
\frac{dp^{*}}{dk}=0.
```

稽查成本越高，稽查方需要面对更多逃税者，才愿意维持原来的混合检查行为；因此均衡诚实概率下降。这里的“检查概率不变”是严格混合支持集和纳税人支付固定的共同结果。若 $`k`$ 超出给定范围，原来的概率公式可能到达边界，必须重新检查纯策略和其他支持集。

## 第三讲的完整解题核对

混合策略题的计算通常会遇到三个不同层次：第一，确认哪些纯策略结果已经是纳什均衡；第二，在给定支持集下用无差异条件求随机概率；第三，逐个排除不合法概率、收益更高的支持集外行动和可能被遗漏的边界均衡。

| 需要检查的内容 | 正确做法 | 典型错误 |
| --- | --- | --- |
| 概率定义 | 明确每个玩家的概率代表哪一个纯行动 | 把 $`p`$、$`q`$ 互换 |
| 期望收益 | 按对手每种行动的概率逐格加权 | 使用自己随机化概率计算自己的纯行动收益 |
| 无差异条件 | 让支持集内的纯行动取得相同的最高收益 | 只列等式，不检查其他行动 |
| 概率合法性 | 每个概率必须位于 $`[0,1]`$，真正混合要求严格位于内部 | 把负概率或大于 1 的结果当均衡 |
| 完整均衡集合 | 纯策略、双方混合、一方混合及其他支持集均须考虑 | 找到一个混合解就结束 |
| 期望收益与实际结果 | 使用概率加权计算事前期望，不能替代当次实现收益 | 把“无差异”理解成每格收益相等 |

第一讲的支付矩阵强调“相互最佳反应”；第三讲并没有更换纳什均衡的定义，而是把最佳反应从一个确定行动扩展到概率分布。随机化概率需要使对手无法通过改变自己的分布提高期望收益，这正是所有无差异方程背后的逻辑。
