# Lecture 9｜合作博弈：标准例题与完整解析

本练习覆盖联盟价值、超可加性、核心（Core）、Shapley 值、成本分摊以及核心与公平分配之间的区别。除非特别说明，以下均为具有可转移效用（TU）的特征函数博弈，$N=\{1,2,3\}$。

## 例题 1｜概念辨析

**题目。** 判断并解释：（1）合作博弈要求参与者一定会合作；（2）核心中的每个分配都必须有效率；（3）Shapley 值必然属于核心；（4）TU 博弈中的联盟价值可以在成员间转移。

**答案。** （1）错；（2）对；（3）错；（4）对。

**解析。** 合作博弈研究能够形成具有约束力的联盟时，合作收益如何分配，并不保证联盟一定形成。核心中的分配必须满足效率条件 $\sum_{i\in N}x_i=v(N)$，同时任何联盟 $S$ 都不愿因成员合计所得低于自身价值而退出，即 $\sum_{i\in S}x_i\ge v(S)$。Shapley 值按照平均边际贡献分配，满足效率、对称性、零贡献玩家和可加性，但一般不保证联盟稳定。TU 表示联盟产生的效用可通过货币等方式在成员间转移。

## 例题 2｜联盟与超可加性

**题目。** 三位参与者的联盟价值如下：

| 联盟 $S$ | $\varnothing$ | $\{1\}$ | $\{2\}$ | $\{3\}$ | $\{1,2\}$ | $\{1,3\}$ | $\{2,3\}$ | $N$ |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| $v(S)$ | 0 | 0 | 0 | 0 | 2 | 4 | 0 | 6 |

列出全部联盟，并判断该博弈是否超可加。

**答案。** 共 $2^3=8$ 个联盟，即表格所列八种。该博弈超可加。

**解析。** 超可加性要求对不相交的 $S,T$，有

```math
v(S\cup T)\ge v(S)+v(T).
```

单人联盟之间的合并价值分别为 $2,4,0$，均不小于 $0+0$。双人联盟与剩余单人联盟合并时，检查：$6\ge2+0$、$6\ge4+0$、$6\ge0+0$。与空联盟的合并恒成立。因此满足超可加性。**注意：** 超可加不等于一定存在非空核心。

## 例题 3｜列出并检验核心约束

**题目。** 设 $v(\{1\})=v(\{2\})=v(\{3\})=0$，$v(\{1,2\})=1$，$v(\{1,3\})=2$，$v(\{2,3\})=1$，$v(N)=3$。写出核心的完整约束，并判断 $x=(1,1,1)$、$y=(0,0,3)$ 是否属于核心。

**答案。** $x\in\operatorname{Core}(v)$；$y\notin\operatorname{Core}(v)$。

**解析。** 核心要求：

```math
\begin{aligned}
x_1+x_2+x_3&=3,\\
x_1,x_2,x_3&\ge0,\\
x_1+x_2&\ge1,\\
x_1+x_3&\ge2,\\
x_2+x_3&\ge1.
\end{aligned}
```

对于 $x=(1,1,1)$，总额为 3，各单人约束成立，三组双人所得分别为 $2,2,2$，均达到相应联盟价值，因此在核心中。对于 $y=(0,0,3)$，联盟 $\{1,2\}$ 只得到 $0<1$，两人有理由离开大联盟另行合作，因此不在核心中。

## 例题 4｜用不等式证明核心为空

**题目。** 三人单独行动的价值为 0，任意两人联盟的价值为 1，大联盟价值也为 1。证明核心为空。

**答案。** 核心为空。

**解析。** 若 $x$ 属于核心，则必须满足

```math
x_1+x_2+x_3=1,
```

且

```math
x_1+x_2\ge1,\qquad x_1+x_3\ge1,\qquad x_2+x_3\ge1.
```

把后三式相加，得到

```math
2(x_1+x_2+x_3)\ge3.
```

由效率条件，左边等于 2，推出 $2\ge3$，矛盾。因此不存在能够同时满足所有联盟要求的有效率分配。这个例子说明：**大联盟有总收益，并不意味着存在让所有潜在小联盟都满意的分法。**

## 例题 5｜三人博弈的 Shapley 值计算

**题目。** 对例题 2 的博弈，计算每位参与者的 Shapley 值，并检验分配是否位于核心。

**答案。** $\phi(v)=(3,1,2)$，且该分配位于核心。

**解析。** 三人博弈中，玩家 $i$ 的平均边际贡献为

```math
\phi_i(v)=\sum_{S\subseteq N\setminus\{i\}}
\frac{|S|!(3-|S|-1)!}{3!}
\bigl[v(S\cup\{i\})-v(S)\bigr].
```

其中空联盟和由另两人组成的双人联盟的权重各为 $1/3$，两个单人联盟的权重各为 $1/6$。依次计算：

```math
\begin{aligned}
\phi_1&=\tfrac13(0)+\tfrac16(2-0)+\tfrac16(4-0)+\tfrac13(6-0)=3,\\
\phi_2&=\tfrac13(0)+\tfrac16(2-0)+\tfrac16(0-0)+\tfrac13(6-4)=1,\\
\phi_3&=\tfrac13(0)+\tfrac16(4-0)+\tfrac16(0-0)+\tfrac13(6-2)=2.
\end{aligned}
```

检验效率：$3+1+2=6=v(N)$。检验个体合理性：$3,1,2\ge0$。检验联盟合理性：$\phi_1+\phi_2=4\ge2$，$\phi_1+\phi_3=5\ge4$，$\phi_2+\phi_3=3\ge0$。因此属于核心。

## 例题 6｜成本分摊博弈的核心

**题目。** 三个部门独立采购的成本分别为 $c(\{1\})=8$、$c(\{2\})=9$、$c(\{3\})=7$，联合成本为 $c(\{1,2\})=12$、$c(\{1,3\})=11$、$c(\{2,3\})=13$、$c(N)=15$。判断分摊向量 $a=(5,5,5)$ 和 $b=(7,7,1)$ 是否稳定。

**答案。** $a$ 稳定，$b$ 不稳定。

**解析。** 成本博弈的核心约束方向与收益博弈相反：总分摊等于大联盟成本；任何联盟的成员分摊总额**不能高于**该联盟自行行动的成本。

```math
\sum_{i\in N}a_i=c(N),\qquad
\sum_{i\in S}a_i\le c(S)\quad(\varnothing\ne S\subsetneq N).
```

对于 $a=(5,5,5)$，三人合计为 15；个人分摊 $5\le8,9,7$；两人合计均为 10，分别不超过 12、11、13，所以稳定。

对于 $b=(7,7,1)$，虽然合计仍为 15，且个人分摊不超独立成本，但部门 1、2 合计分摊 $7+7=14>c(\{1,2\})=12$。两部门自行组队能够节省 2，因此该分配不在成本核心中。

## 例题 7｜Shapley 值不一定在核心中

**题目。** 对例题 4 的对称博弈，计算 Shapley 值，并回答其是否在核心中。

**答案。** $\phi_1=\phi_2=\phi_3=1/3$，但不在核心中。

**解析。** 三位玩家在这个博弈中完全对称。由 Shapley 值的对称性和效率条件，每人分到 $1/3$。然而任意两人联盟所得仅为 $1/3+1/3=2/3<1$，都不能满足联盟合理性，因此 Shapley 分配不属于核心。实际上，例题 4 已证明这个博弈核心为空。**结论：公平性公理与联盟稳定性是两组不同的评价标准。**

## 例题 8｜按进入顺序理解 Shapley 值

**题目。** 三人独立或任意两人合作都不创造价值，只有三人全部加入才创造 6 单位收益，即 $v(N)=6$，其余所有联盟价值均为 0。利用排列法求 Shapley 值。

**答案。** $\phi(v)=(2,2,2)$。

**解析。** 三人共有 $3!=6$ 种等可能进入顺序。因为只有三人全部进入时价值才从 0 上升为 6，每一种顺序中，前两位进入者的边际贡献均为 0，**最后一位**进入者的边际贡献为 6。每个人在六种顺序中都有 $2!=2$ 次排在最后，所以其平均边际贡献为

```math
\phi_i=\frac{2\times6+4\times0}{6}=2.
```

三人各分 2，合计为 6。这里的 Shapley 值不是仅按“最后加入者最重要”分配，而是对所有可能加入顺序取平均。

## 考试检查表

做合作博弈题时，先判断题目给的是**收益分配**还是**成本分摊**。收益核心使用 $x(S)\ge v(S)$；成本核心使用 $x(S)\le c(S)$。求 Shapley 值时先计算各联盟的边际贡献及对应权重，再检验加总是否等于大联盟价值。**不能因为计算出了 Shapley 值，就直接声称它是核心分配。**

## 例题 9｜凸合作博弈与 Shapley 值的稳定性

**题目。** 三人 TU 博弈满足 $v(\varnothing)=0$、$v(\{i\})=0$、任意两人联盟价值均为 1、大联盟价值为 $v(N)=4$。（1）判断是否具有凸性；（2）计算 Shapley 值；（3）判断该分配是否属于核心。

**答案。** 该博弈为凸博弈，Shapley 值为 $(4/3,4/3,4/3)$，该值属于核心。

**解析。** 凸性要求随原联盟扩大，新成员的边际贡献不下降。对任意玩家 $i$，加入空联盟的边际贡献是 0；加入已有一名成员的联盟时价值从 0 变为 1，边际贡献是 1；加入已有两名成员的联盟时价值从 1 变为 4，边际贡献是 3。由于 $0\le1\le3$，满足凸性。

三人处于完全对称的位置，Shapley 值满足对称性及效率，因此各获 $4/3$。检验核心：三人合计 $3(4/3)=4$；每人得到 $4/3\ge v(\{i\})=0$；任何两人合计得到 $8/3\ge v(\{i,j\})=1$。全部条件成立。

**概念区分。** 凸性是关于联盟价值函数的结构性条件；核心是关于**某个具体分配**是否稳定的条件；Shapley 值是一条平均边际贡献分配规则。三者相关，但不属于同一个概念。
