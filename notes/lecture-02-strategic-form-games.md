# Lecture 02｜最佳反应与竞争：从连续决策到市场均衡

<strong>Strategic-Form Games II · Continuous Actions · Cournot · Bertrand · Hotelling · War of Attrition</strong>

[九讲总目录](../README.md) · [第一讲：策略式博弈](lecture-01-strategic-form-games.md) · [图解：市场竞争](../visuals/02-market-competition.md) · [第二讲习题与解析](../exercises/lecture-02-exercises.md)

第一讲的支付矩阵只有有限个格子，找最佳反应可以逐格比较。现实决策却常常是一段连续的数：企业生产多少件产品、定价多少、员工投入多少努力、候选人把政策立场定在哪里。此时每个人面对的已不是几个固定选项，而是一整个可行区间。

计算方法因此从比较数字变为分析函数，但博弈论的思路没有变：先把对方的决策看作给定，找到自己最有利的选择；再问每个人作出的选择能否同时成立。

本讲以这一方法研究合伙人努力、产量与价格竞争、市场位置选择和消耗战。几个模型看上去很不一样，真正造成结论差异的往往是<strong>行动变量、收益函数、约束和决策顺序</strong>。

## 1. 连续行动博弈：最佳反应不再是一个格子

设两名参与者分别选择 $`a_1`$ 和 $`a_2`$，玩家 1 的支付写成 $`u_1(a_1,a_2)`$。研究玩家 1 时，暂时把 $`a_2`$ 固定，解下面的最优化问题：

```math
BR_1(a_2)=\operatorname*{arg\,max}_{a_1\in A_1}u_1(a_1,a_2).
```

这里的 $`BR_1`$ 原则上是集合：最优行动可能有一个，也可能不止一个。若最优解唯一，我们常把它简写为一条函数曲线。玩家 2 同理。

双方都可以自由调整行动时，纯策略纳什均衡 $`(a_1^*,a_2^*)`$ 必须满足：

```math
a_1^*\in BR_1(a_2^*),\qquad
a_2^*\in BR_2(a_1^*).
```

这两个条件的意义不是两人分别达到“脱离对方的全局最优”，而是：<strong>在对方恰好采取均衡行动的情况下，自己没有单独改变行动的收益。</strong>

### 1.1 一阶条件只负责寻找内部候选解

若行动区间为 $`[0,K]`$，效用关于自己行动可微且严格凹，则解题要考虑三种情况：

| 最优解的位置 | 在凹函数假设下的判断 |
| --- | --- |
| 左端点 $`a_i=0`$ | $`\partial u_i/\partial a_i`$ 在 0 处不大于 0 |
| 内部 $`0<a_i<K`$ | 一阶导数等于 0 |
| 右端点 $`a_i=K`$ | $`\partial u_i/\partial a_i`$ 在 $`K`$ 处不小于 0 |

在讨论内点时，通常先令：

```math
\frac{\partial u_i(a_i,a_j)}{\partial a_i}=0,
\qquad
\frac{\partial^2 u_i(a_i,a_j)}{\partial a_i^2}<0.
```

第二个不等式保证收益关于自己行动向下弯曲。但如果一阶条件算出负产量、负价格或超过能力上限的努力水平，那个数并不是合法最佳反应，必须回到约束上判断。

### 1.2 两种典型关系：战略替代与战略互补

想象对手提高自己的行动水平，随后观察我方最佳反应怎么变：

当对手产量增加，我通常希望少生产一些；这种最佳反应朝相反方向移动的关系称为<strong>战略替代（Strategic Substitutes）</strong>。

当对手提高价格，我通常也可以提高价格而不至于失去太多顾客；这种最佳反应同方向移动的关系称为<strong>战略互补（Strategic Complements）</strong>。

只要内部最优解光滑且二阶导数不为 0，对一阶条件求导，可得到：

```math
\frac{d\,BR_i(a_j)}{d a_j}
=-\frac{\partial^2 u_i/\partial a_i\partial a_j}
{\partial^2 u_i/\partial a_i^2}.
```

分母对严格凹问题为负。因此，交叉二阶导数的符号决定最佳反应的斜率。这个判断将在合伙人努力、Cournot 和差异化价格竞争中反复出现。

## 2. 合伙人努力：对方越投入，我越愿意投入

假设两人共同经营一个项目，每人的努力水平为 $`s_i\in[0,4]`$。总产出是：

```math
Y=4(s_1+s_2+b s_1s_2),\qquad
0\le b\le\frac{1}{4}.
```

两人平分产出，每人独立承担平方型努力成本 $`s_i^2`$。因此：

```math
u_i(s_i,s_j)=2(s_i+s_j+b s_is_j)-s_i^2.
```

参数 $`b`$ 衡量协同程度。$`b=0`$ 时，一人的努力不改变另一人努力的边际回报；$`b>0`$ 时，两个人一起投入会带来额外产出。

固定 $`s_2`$，玩家 1 对自己的努力求导：

```math
\frac{\partial u_1}{\partial s_1}
=2+2bs_2-2s_1.
```

其二阶导数恒为 $`-2`$，故内部一阶条件给出：

```math
BR_1(s_2)=1+bs_2.
```

玩家 2 完全对称：

```math
BR_2(s_1)=1+bs_1.
```

由于 $`b\le 1/4`$ 且对方努力不超过 4，上述最佳反应在 $`[1,2]`$ 内，确实满足行动约束。两条向上倾斜的曲线说明：对方越努力，我多努力一单位的收益也越高。这不是要求两个人“相互模仿”，而是收益函数存在协同项 $`bs_1s_2`$ 的直接结果。

对称均衡满足 $`s_1=s_2=s`$，于是：

```math
s=1+bs
\quad\Longrightarrow\quad
s_1^*=s_2^*=\frac{1}{1-b}.
```

### 2.1 为什么均衡努力仍可能偏低

合伙人在选择努力时，只拿到新增产出的一半；另一半也会让伙伴受益。因此，个人选择未必把自己的全部社会贡献计算进去。

如果两人能够联合最大化总收益，规划者解决的是：

```math
\max_{0\le s_1,s_2\le4}
\left[4(s_1+s_2+bs_1s_2)-s_1^2-s_2^2\right].
```

对称的内部最优条件变为 $`4+4bs-2s=0`$，即：

```math
s^{SO}=\frac{2}{1-2b}.
```

在 $`0\le b<1/4`$ 下，这个解位于可行区间；当 $`b=1/4`$，社会最优刚好达到上界 4。比较个人均衡与社会最优，可以看到：

```math
\frac{1}{1-b}<\frac{2}{1-2b}.
```

例如，取 $`b=1/4`$，每人在纳什均衡下投入 $`4/3`$，而共同收益最大时每人投入 4。问题不在于参与者缺乏理性，而在于<strong>个人的边际收益与团队的边际收益不同</strong>。改变收益分成比例、设置可执行的努力奖励或重新设计产权安排，都可能改变这一差异；是否有效需要重新写出新的支付函数，不能直接从“加强合作”推出结论。

## 3. Cournot：企业同时选择产量

考虑两家企业生产同质产品。市场总产量越高，成交价格越低。令反需求函数为：

```math
P(Q)=a-bQ,\qquad
Q=q_1+q_2,\qquad
a>c\ge0,\quad b>0.
```

每生产一单位产品的成本为 $`c`$，暂不考虑固定成本。企业 1 的利润是：

```math
\pi_1(q_1,q_2)
=\big[a-b(q_1+q_2)-c\big]q_1.
```

企业 1 选择产量时，$`q_2`$ 被暂时视为固定。展开利润有助于看清边际收益：

```math
\pi_1=(a-c-bq_2)q_1-bq_1^2.
```

求一阶导数：

```math
\frac{\partial\pi_1}{\partial q_1}
=a-c-bq_2-2bq_1.
```

注意最后一项是 $`2bq_1`$，而不是 $`bq_1`$。提高自己产量会增加销量，同时压低自己原有产量的销售价格。后一个影响正是从竞争模型中不能省掉的部分。

若企业选择非负产量，则最佳反应为：

```math
BR_1(q_2)=
\max\left\{0,\frac{a-c-bq_2}{2b}\right\}.
```

类似地：

```math
BR_2(q_1)=
\max\left\{0,\frac{a-c-bq_1}{2b}\right\}.
```

在两家企业都生产正产量的区域，曲线的斜率为 $`-1/2`$。如果对手多生产两单位产品，我方最佳反应就减少一单位。这就是产量之间的战略替代。

两条最佳反应在正产量区域相交：

```math
q_1=\frac{a-c-bq_2}{2b},
\qquad
q_2=\frac{a-c-bq_1}{2b}.
```

整理得到 Cournot–Nash 均衡：

```math
q_1^*=q_2^*=\frac{a-c}{3b}.
```

因此：

```math
Q^*=\frac{2(a-c)}{3b},
\qquad
P^*=\frac{a+2c}{3},
\qquad
\pi_i^*=\frac{(a-c)^2}{9b}.
```

[图解中配有 Cournot 最佳反应曲线](../visuals/02-market-competition.md)。图上的均衡不是“各自找到最大产量”的交点，而是两家企业在对方产量已给定时所愿意生产的数量恰好一致。

### 3.1 用一组数字核对

令 $`P=100-Q`$，$`c=20`$。则：

```math
BR_1(q_2)=\max\left\{0,40-\frac{q_2}{2}\right\},
\qquad
BR_2(q_1)=\max\left\{0,40-\frac{q_1}{2}\right\}.
```

联立可得两家各生产 $`80/3`$，总产量为 $`160/3`$，价格为 $`140/3`$，各家利润为 $`6400/9`$。

若企业 2 已经生产 $`80/3`$，企业 1 在此基础上多生产或少生产，都会降低利润；企业 2 同理。因此这是纳什均衡，而不只是方程组的一个数学解。

### 3.2 比较静态：谁改变了均衡

由均衡公式直接可读出：市场需求截距 $`a`$ 增大时，单家均衡产量上升；边际成本 $`c`$ 增大时，产量下降；需求对数量越敏感（$`b`$ 越大），可支撑的均衡产量越小。

需要分清两种不同的分析：一家企业在对手产量已经固定时调整产量，是在其最佳反应曲线上移动；成本或市场需求变化，使最佳反应函数整体改变，则是曲线移动。考试画图题经常考察这个区别。

## 4. 从双寡头到多企业，以及不对称成本

若同质产品市场有 $`n`$ 家企业，并且各家边际成本同为 $`c`$，第 $`i`$ 家的利润写成：

```math
\pi_i=
\left[a-b\left(q_i+\sum_{j\ne i}q_j\right)-c\right]q_i.
```

内部一阶条件为：

```math
a-c-2bq_i-b\sum_{j\ne i}q_j=0.
```

对称均衡下所有企业产量相同，$`q_i=q`$，从而：

```math
q^*=\frac{a-c}{b(n+1)},
\qquad
Q^*=\frac{n(a-c)}{b(n+1)},
\qquad
P^*=c+\frac{a-c}{n+1}.
```

企业数增多，均衡价格逐渐接近边际成本；但对于任何有限的 $`n`$，只要成本低于需求截距，价格仍高于边际成本。这里的结论依赖企业对称、同时决策、同质产品及线性需求等具体假设。

### 4.1 成本不同，均衡不必对称

两家企业边际成本分别为 $`c_1`$ 和 $`c_2`$ 时，在两家都生产正产量的前提下：

```math
q_1^*=\frac{a-2c_1+c_2}{3b},
\qquad
q_2^*=\frac{a-2c_2+c_1}{3b}.
```

成本较低的一家通常生产更多，但不能仅凭公式就宣布两家都有正产量。

例如 $`P=100-Q`$，$`c_1=10`$，$`c_2=30`$，公式给出 $`q_1=110/3`$、$`q_2=50/3`$，均为正，内部解成立。

若把第二家成本改为 90，直接代入内部解会得到负的 $`q_2`$。产量不能为负，真正的均衡是：

```math
q_1^*=45,\qquad q_2^*=0,\qquad P^*=55.
```

验证方法是：企业 1 在企业 2 不生产时，以 $`q_1=(100-10)/2=45`$ 最大化自身利润；企业 2 面对 $`q_1=45`$ 时的边际利润起点为 $`100-45-90=-35<0`$，因此最佳反应确实是不生产。<strong>边界条件是经济模型的一部分，不能被求导步骤省略。</strong>

## 5. Bertrand：把决策变量换成价格

Cournot 模型里的企业直接决定卖多少，价格由总产量决定。如果改成两家同时报价，市场再按报价把顾客分配给企业，支付函数就变了。

先考虑最简单的 Bertrand 模型：产品完全同质、消费者选择低价卖家、两家单位成本相同且为 $`c`$、生产能力充足、没有转换成本。令市场在价格 $`p`$ 下的需求量为 $`D(p)`$。

两家同时公布价格时，企业 1 的销量是：

```math
D_1(p_1,p_2)=
\begin{cases}
D(p_1), & p_1<p_2,\\
\frac{1}{2}D(p_1), & p_1=p_2,\\
0, & p_1>p_2.
\end{cases}
```

利润则为 $`\pi_1=(p_1-c)D_1`$。这里的分段函数很重要：即使一分钱的降价，也可能使企业从拿到半个市场变成拿到整个市场。

在市场需求为正且有高于成本的可行交易价格时，唯一的纯策略均衡为：

```math
p_1^*=p_2^*=c.
```

为什么不是成本以上的某个共同价格？假设两家都报价 $`p>c`$，各拿一半市场。任一家把价格略微降到对方之下，只要降价足够小，就可以从半个市场转为整个市场，获得更高利润，因此原来的价格不是均衡。

如果两家都报价成本 $`c`$，独自降价会以低于成本出售，不能提高利润；独自涨价又会失去全部顾客，同样不能改善利润。于是没有企业愿意单独改价。

这个结论有时被称为 Bertrand 悖论：即使市场上只有两家企业，同质产品和充分价格竞争也能使价格等于边际成本。它不是“市场只要有两家公司就必然充分竞争”。只要改变产品差异、产能限制、搜索成本或成本结构，市场需求的分配方式就会变，均衡价格也可能高于成本。

### 5.1 同样的市场，为什么 Cournot 和 Bertrand 不同

| 比较 | Cournot 数量竞争 | 同质 Bertrand 价格竞争 |
| --- | --- | --- |
| 企业直接选什么 | 产量 $`q_i`$ | 价格 $`p_i`$ |
| 对手增加行动 | 往往减少自己的最优产量 | 高于对手报价可能丢掉整个市场 |
| 均衡价格 | 通常高于边际成本 | 等于边际成本 |
| 结论依赖 | 产量承诺和出清规则 | 同质、无产能约束、消费者逐价选择 |

表面上只改了一个决策变量，实际上也改变了消费者如何在企业间分配需求。判断模型时先写出销量如何由双方行动决定，比直接套用某个均衡公式可靠得多。

## 6. Stackelberg：先承诺产量，会怎样改变均衡

现在沿用 Cournot 的线性需求和成本，却让企业 1 先选择产量，企业 2 观察到后再决定自己的产量。企业 2 是跟随者，它对给定的 $`q_1`$ 作出最佳反应：

```math
q_2(q_1)=\frac{a-c-bq_1}{2b}.
```

在下面计算的均衡区域，两家产量均为正。企业 1 是先行动者，知道自己的产量会影响对方下一步的选择，所以它需要把跟随者的反应代入自身利润：

```math
\pi_1(q_1,q_2(q_1))
=\left[a-bq_1-b\frac{a-c-bq_1}{2b}-c\right]q_1
=\frac{1}{2}(a-c-bq_1)q_1.
```

对 $`q_1`$ 求导并令其为零，得到领导者产量。再代回跟随者反应：

```math
q_1^*=\frac{a-c}{2b},
\qquad
q_2^*=\frac{a-c}{4b}.
```

相应的市场结果是：

```math
Q^*=\frac{3(a-c)}{4b},
\quad
P^*=c+\frac{a-c}{4},
\quad
\pi_1^*=\frac{(a-c)^2}{8b},
\quad
\pi_2^*=\frac{(a-c)^2}{16b}.
```

以 $`P=90-q_1-q_2`$、$`c=0`$ 为例，可以把两个模型直接对比：

| 指标 | 同时生产：Cournot | 先后生产：Stackelberg |
| --- | ---: | ---: |
| 企业 1 产量 | 30 | 45 |
| 企业 2 产量 | 30 | 22.5 |
| 市场价格 | 30 | 22.5 |
| 企业 1 利润 | 900 | 1012.5 |
| 企业 2 利润 | 900 | 506.25 |

领导者提前多生产，使跟随者随后选择较少产量，自己获得较高利润。所谓先动优势并非因为“先行动总是更好”，而是因为前一步行动具有<strong>可观察且可信的承诺效果</strong>。如果企业 1 只是口头声称会生产 45，之后仍可随意改变产量，那么把这个问题当作 Stackelberg 博弈就不恰当。

这已经涉及先后行动与逆向归纳的逻辑。第四讲会从完整的扩展式博弈角度说明，为什么跟随者的最佳反应要先求、领导者的选择要后求。

## 7. Hotelling 线性城市：价格竞争为什么不一定把利润压到零

同质 Bertrand 模型中，便宜一点就能吸引全部消费者。但如果顾客偏好的产品特征不同，或者企业位于不同地点，最低价不一定对所有人最有吸引力。

设消费者均匀分布在长度为 1 的街道上，两家商店分别位于 0 和 1。商店提供相同的基础产品，消费者去不同商店需要承担不同的距离成本。用二次运输成本表示，位置为 $`x\in[0,1]`$ 的消费者从两家购买的净效用分别为：

```math
U_1(x)=v-p_1-tx^2,
\qquad
U_2(x)=v-p_2-t(1-x)^2,
\qquad t>0.
```

其中 $`v`$ 是购买的基础价值，$`p_i`$ 是价格，$`t`$ 表示距离造成的损失有多大。假设 $`v`$ 足够高，使每位消费者至少愿意从一家商店购买；还假设分界点落在 0 和 1 之间。

令两家商店对分界位置 $`x^*`$ 的消费者提供相同效用：

```math
v-p_1-t(x^*)^2
=v-p_2-t(1-x^*)^2.
```

展开并消掉共同项，得到：

```math
x^*=\frac{1}{2}+\frac{p_2-p_1}{2t}.
```

在消费者均匀分布、市场完全覆盖的条件下，$`x^*`$ 左边的顾客选择商店 1，右边选择商店 2，因此：

```math
D_1=\frac{1}{2}+\frac{p_2-p_1}{2t},
\qquad
D_2=\frac{1}{2}+\frac{p_1-p_2}{2t}.
```

这两个需求式子比“价格较低者拿走整个市场”平滑得多。一家商店涨价会流失一些顾客，但邻近自己的消费者仍可能愿意支付较高价格。

假设两家商店边际成本相同且为 $`c`$。商店 1 的利润：

```math
\pi_1(p_1,p_2)
=(p_1-c)\left(\frac{1}{2}+\frac{p_2-p_1}{2t}\right).
```

对价格求导：

```math
\frac{\partial\pi_1}{\partial p_1}
=\frac{1}{2}+\frac{p_2-2p_1+c}{2t}=0.
```

于是，在内部分界点成立的区域：

```math
BR_1(p_2)=\frac{c+t+p_2}{2},
\qquad
BR_2(p_1)=\frac{c+t+p_1}{2}.
```

两条最佳反应向上倾斜，斜率均为 $`1/2`$：对手提高价格，我方也倾向于提高价格。这与 Cournot 的负斜率恰好相反。

对称均衡为：

```math
p_1^*=p_2^*=c+t,
\qquad
D_1^*=D_2^*=\frac{1}{2},
\qquad
\pi_1^*=\pi_2^*=\frac{t}{2}.
```

比如 $`t=2`$、$`c=1`$，两家均衡定价为 3，每家获得一半顾客，每家利润为 1。即使只有两家企业，价格也高于成本：地理位置给企业带来了对邻近顾客的有限市场势力。

### 7.1 为什么“运输成本”也能表示产品差异

这里的街道可以是真实地理空间，也可以是一个抽象的偏好空间：左端是简洁型产品，右端是功能丰富型产品；或者两端代表不同设计风格。消费者的位置表示他们的理想产品特征，距离成本表示购买一个偏离自己偏好的产品所产生的损失。

因此，Hotelling 模型不只讨论开店选址，还能解释为什么差异化产品会削弱直接价格竞争。但目前我们固定了商店位置，只研究定价；<strong>企业同时选择位置和价格时，均衡结论需要重新求解</strong>，不能直接把 $`p=c+t`$ 套到任意位置上。

如果商店分别位于 $`z_1`$ 和 $`z_2`$，其中 $`z_1<z_2`$，在二次距离成本及内部分界点的条件下：

```math
x^*=
\frac{z_1+z_2}{2}
+\frac{p_2-p_1}{2t(z_2-z_1)}.
```

两家越靠近，消费者对价格差异通常越敏感。这个式子能够帮助理解位置和定价之间的联系，但位置不同也改变了两家企业各自的基础市场份额，不能只看分母而忽略整条需求函数。

### 7.2 把战略互补看得更清楚

不考虑地理位置时，也可以直接设两个差异化产品的需求为：

```math
D_1=A-p_1+\gamma p_2,
\qquad
D_2=A-p_2+\gamma p_1,
\qquad 0<\gamma<1.
```

在需求为正的内点区域，两家成本均为 $`c`$。企业 1 最大化 $`(p_1-c)D_1`$，得到：

```math
BR_1(p_2)=\frac{A+c+\gamma p_2}{2}.
```

这条曲线的斜率为 $`\gamma/2>0`$。不必记住某个特定数字，只要看出“对手提价使我的需求增加”，就能解释为什么我方的最优价格也可能上升。

## 8. 位置竞争与中位选民：同一条线可以代表不同问题

市场位置是消费者偏好的差异；选举位置则可以代表候选人的政策立场。两者都可以在一条线上建模，但各自的目标函数并不相同。

在最简单的中位选民模型中，选民的理想政策点分布在区间 $`[0,1]`$。两名候选人同时选择政策位置 $`x_A`$、$`x_B`$。每个选民投给距离自己偏好点更近的候选人；候选人以赢得选票为目标，双方在同一位置时平分选票。

设选民理想点的中位数为 $`m`$。如果选民偏好为单峰的，并且只有上述两个候选人、他们均以得票为目标，那么：

```math
x_A^*=x_B^*=m
```

是一个纳什均衡。

可以从偏离行为理解这一结论。若两名候选人都处于中位数，任何一名候选人单独向左或向右移动，都会把中位数及其一侧的多数选民留给不移动的对手。候选人没有通过单独改变位置赢得多数的办法。

如果选民偏好点恰好是 1 到 9 的九个整数，中位数是 5。在上述规则下，两名候选人都选择 5，是均衡；两人都处于最左端或最右端则不是。

现实选举涉及候选人能力、政治身份、参与投票、承诺可信性、党派认同和多个政策维度。中位选民定理解释的是一组严格条件下的定位激励，不能据此推断所有实际选举都会产生完全一致的中间政策。

### 8.1 从位置选择延伸到谢林隔离模型

同样的“位置”也可以指居住地。谢林（Schelling）隔离模型研究的并非两家企业争价格，也不是候选人争多数票，而是大量居民根据邻居构成决定是否搬迁。

假设每个居民只要求“周围有一定比例与自己相似的人”，甚至并不要求整个社区高度同质。居民一次次根据局部居住环境搬迁，可能使宏观上的群体分布逐渐分离。

这是一个很适合辨析的例子：<strong>个人偏好不必极端，群体结果也可能高度分化。</strong>不过，具体是否发生隔离、隔离程度多大，取决于迁移规则、住房空缺、邻域定义和异质性阈值。若研究动态过程，还必须区分某一时点的最优搬迁行为与长期稳定状态。

## 9. 消耗战：为什么有人一直不愿退出

想象两家企业争夺一项排他许可。价值为 $`v_i>0`$ 的奖品最终只给坚持到最后的一方；持续争夺每单位时间给参与者带来 1 单位成本。双方在开始时各自承诺一个退出时间 $`t_i\ge0`$。

若玩家 1 在玩家 2 之前退出，即 $`t_1<t_2`$，玩家 1 失去奖品且承担等待成本 $`t_1`$；玩家 2 在时间 $`t_1`$ 赢得奖品，也要承担这段时间的成本。支付为：

```math
u_1(t_1,t_2)=-t_1,
\qquad
u_2(t_1,t_2)=v_2-t_1.
```

若玩家 2 先退出，则：

```math
u_1(t_1,t_2)=v_1-t_2,
\qquad
u_2(t_1,t_2)=-t_2.
```

同一时刻退出的结算需要额外规定，下面考虑的是一人先退出、另一人后退出的纯策略情形。

### 9.1 纯策略均衡的逻辑

若两人都在正时间之后退出，一方必然先退出。对于先退出的一方，如果最终要输，那么在时间 0 退出可以避免此前白白承担的等待成本。因此，在纯策略均衡里，输家不会选择严格正的退出时间。

假设玩家 1 在时间 0 退出，玩家 2 承诺坚持到 $`t_2>0`$。玩家 2 获得奖品且无需实际等待，因为对手立即退出。玩家 1 如果打算改为比 $`t_2`$ 更晚退出，则赢得奖品的净收益为 $`v_1-t_2`$。为了使玩家 1 不愿这样做，必须有：

```math
v_1-t_2\le0
\quad\Longleftrightarrow\quad
t_2\ge v_1.
```

对称地，玩家 2 可以立即退出，只要玩家 1 承诺的退出时间至少达到 $`v_2`$。

因此，不考虑同时退出带来的边界细节，典型纯策略均衡可写为：

```math
(t_1^*,t_2^*)=(0,t_2),\quad t_2\ge v_1;
\qquad
(t_1^*,t_2^*)=(t_1,0),\quad t_1\ge v_2.
```

例如奖品对玩家 1 价值 3、对玩家 2 价值 5，则 $`(0,4)`$ 是纯策略均衡：玩家 1 不愿为了价值 3 的奖品付出至少 4 的争夺成本，玩家 2 也不愿单独放弃已经可以立刻得到的奖品。反过来，$`(6,0)`$ 也是纯策略均衡。

这个结果不意味着比赛一定持续到承诺的退出时间。若有人在 0 时刻退出，实际等待就立刻结束。承诺时间决定的是<strong>如果对方坚持不退，我准备承受多大成本</strong>。

### 9.2 对称消耗战的一种混合均衡

若双方奖品价值相同 $`v`$，采用连续随机退出时间，也可以构造对称混合策略均衡。设对手退出时间的分布函数为 $`F(t)`$、密度为 $`f(t)`$。

我方承诺在时间 $`t`$ 退出时，若对手先退，我获得奖品；两人实际承担的等待成本是双方退出时间中的较小者。由此可写出预期支付：

```math
U(t)=vF(t)-\int_0^t[1-F(s)]\,ds.
```

若要使所有被随机选中的退出时间都同样合算，要求一阶导数为零：

```math
U'(t)=vf(t)-[1-F(t)]=0.
```

于是对手的瞬时退出概率率（hazard rate）为：

```math
\frac{f(t)}{1-F(t)}=\frac{1}{v}.
```

配合 $`F(0)=0`$，可得指数分布：

```math
F(t)=1-e^{-t/v},\qquad t\ge0.
```

这是一个颇有意思的对照：纯策略分析中，至少有一人立即退出；混合策略分析中，两人都可能等待随机长度的时间。指数分布是这一组对称、线性等待成本和完全信息假设下的特定结果，并不是所有消耗战的通用退出规律。

## 10. 均衡、社会最优和市场福利不是一个概念

从合伙人努力可以看到，个人最优反应未必产生团队总收益最大值。在市场竞争中，这个差别还可以用消费者剩余和总剩余明确衡量。

继续考虑反需求 $`P=a-bQ`$、恒定边际成本 $`c<a`$。在没有外部性且不考虑固定成本的标准设定下，消费者剩余为需求曲线下方、市场价格上方的面积：

```math
CS=\frac{1}{2}(a-P)Q=\frac{1}{2}bQ^2.
```

行业总利润为 $`\Pi=(P-c)Q`$。所以总剩余：

```math
TS=CS+\Pi=(a-c)Q-\frac{b}{2}Q^2.
```

使总剩余最大化时：

```math
\frac{dTS}{dQ}=a-c-bQ=0
\quad\Longrightarrow\quad
Q^{SO}=\frac{a-c}{b},\qquad P^{SO}=c.
```

这一社会最优产量同时也是标准完全竞争下的交易量。

### 10.1 垄断、双寡头与 Bertrand 的定量比较

垄断者通过 $`\max_Q[a-bQ-c]Q`$ 决定产量，解为：

```math
Q^M=\frac{a-c}{2b},\qquad
P^M=\frac{a+c}{2}.
```

对比双寡头 Cournot 与同质 Bertrand，可得到：

| 市场结构 | 总产量 | 价格 | 总剩余 |
| --- | --- | --- | --- |
| 垄断 | $`(a-c)/(2b)`$ | $`(a+c)/2`$ | $`3(a-c)^2/(8b)`$ |
| 两家 Cournot | $`2(a-c)/(3b)`$ | $`(a+2c)/3`$ | $`4(a-c)^2/(9b)`$ |
| 同质 Bertrand | $`(a-c)/b`$ | $`c`$ | $`(a-c)^2/(2b)`$ |

当 $`P=100-Q`$、$`c=20`$ 时，算出更直观的数字：

| 指标 | 垄断 | 两家 Cournot | 同质 Bertrand |
| --- | ---: | ---: | ---: |
| 总产量 | 40 | $`160/3`$ | 80 |
| 价格 | 60 | $`140/3`$ | 20 |
| 消费者剩余 | 800 | $`12800/9`$ | 3200 |
| 企业总利润 | 1600 | $`12800/9`$ | 0 |
| 总剩余 | 2400 | $`25600/9`$ | 3200 |

垄断利润高，不代表社会总剩余高；消费者剩余也不能被拿来等同于企业利润。市场结构比较中的效率结论还依赖不变边际成本、市场全覆盖规则、无外部性等条件。前面 Hotelling 模型中的距离成本本身就是一种真实的消费者损失，如果计算社会福利就不能忽略它。

## 11. 从最佳反应曲线能看到什么，不能看到什么

Cournot 模型的最佳反应向下倾斜，合伙人努力与差异化价格竞争的最佳反应向上倾斜。用图判断均衡时，先把两个玩家的最佳反应画在同一坐标系里，再找交点即可；如果只有一条最佳反应曲线，不能单独确定纳什均衡。

画图还要留意坐标轴。例如横轴为企业 1 产量、纵轴为企业 2 产量时：

```math
q_1=\frac{a-c-bq_2}{2b}
```

是企业 1 的最佳反应，但画在 $`(q_1,q_2)`$ 平面上时，往往需要把它改写为 $`q_2=(a-c)/b-2q_1`$。因此，<strong>同一条经济意义上的最佳反应，斜率数值会随坐标轴上的变量安排而变化</strong>。不能看到一条线斜率为 $`-2`$ 就断言模型推导的 $`-1/2`$ 错了。

另一个常被忽略的区别是<strong>均衡与调整过程</strong>。最佳反应交点定义纳什均衡，但不能单凭存在交点，就证明企业从任意初始状态出发反复调整产量一定会走向该点。收敛还涉及更新顺序、调整速度和最佳反应曲线的局部性质。

对于本讲的线性 Cournot 模型，如果两家交替根据对手上一轮产量选择最佳反应，内点附近每次响应的斜率绝对值为 $`1/2`$，因而通常能够收敛。但“最佳反应动态是否稳定”与“是否满足纳什均衡条件”是两个不同的问题。

## 12. 如何判断一道题应该用什么模型

给定一道企业竞争或位置选择题，不应先看到“有两家企业”就直接代 Cournot 公式。先读四项信息：究竟在选择价格还是数量；选择是否同时；市场需求如何分配；边际成本、能力约束或距离成本是什么。

例如同样有两家生产相同产品的企业：

| 题目条件 | 首先考虑的模型 | 应写出的关键关系 |
| --- | --- | --- |
| 同时决定产量，总产量决定价格 | Cournot | $`P(Q)`$ 与 $`\pi_i(q_i,q_j)`$ |
| 先生产的一家承诺产量，另一家观察后生产 | Stackelberg | 跟随者反应 $`BR_2(q_1)`$ |
| 同时决定同质产品价格，无产能约束 | Bertrand | 低价者吸收需求的分段函数 |
| 同时定价，顾客偏好或位置不同 | Hotelling / 差异化价格竞争 | 无差异消费者与需求分配 |
| 两方争夺独占收益，持续等待有成本 | 消耗战 | 先退出与后退出的支付 |
| 两名候选人争取单峰偏好的选民 | 中位选民模型 | 选民分布与得票规则 |

若题目只给“企业 1 选择产量，企业 2 也选择产量”，但没有说明双方能否观察对方行动，不能轻易把它当成 Stackelberg。反过来，若题目明确规定先后顺序，直接联立双方同时行动最佳反应求交点也就答错了均衡概念。

### 12.1 一份可复用的完整解题过程

先明确每个人的行动集，并将自身利润或效用写成双方行动的函数。随后固定对手的行动，求自己的最优选择；若行动连续，检查导数、二阶条件和边界。对同时行动博弈，联立双方最佳反应；对先后行动博弈，先求后行动者的最佳反应，再代入先行动者目标函数。

得到候选解后，需要把它代回最初的约束和利润函数。最后回答三个不同问题：均衡行动是什么，均衡下各方得到多少，以及这些结果为何随模型假设改变。写到这里，一道完整的博弈论计算题才算真正结束。

## 13. 本讲练习的使用顺序

建议先做[第二讲习题与解析](../exercises/lecture-02-exercises.md)中的合伙人努力、Cournot 和 Bertrand 题。它们能检验是否掌握“对对手行动求条件最优”这一基本方法。

接着做线性城市和消耗战，训练从效用比较推导市场份额、从退出激励判断均衡。最后做多企业 Cournot、成本不对称与社会福利题，检查自己能否辨认公式的适用前提，而不只是代数运算。
