## 1. 最佳反应与纳什均衡：从支付矩阵走向函数

上一讲通过逐格比较支付寻找最佳反应；当企业选择的价格、产量或努力水平是连续变量时，同样的思想表现为**最佳反应函数**（best-response function）。

```math
BR_i(a_{-i})=\arg\max_{a_i\in A_i}u_i(a_i,a_{-i}).
```

纳什均衡 $`a^{*}`$ 必须满足 $`a_i^{*}\in BR_i(a_{-i}^{*})`$，也就是**每个人的选择同时是面对别人选择的最优反应**。若两人的最佳反应可以画成曲线，交点是均衡；若最优反应是集合而非单个数，应使用最佳反应对应（correspondence）。

对于可微的连续决策，常用一阶条件 $\partial u_i/\partial a_i=0$ 求内部最优解，但必须检查二阶条件和边界约束。特别是产量不能为负、价格常有成本下界，不能机械地把所有一阶解当成均衡。

## 2. 合伙人努力博弈：为什么个人努力通常不足

两名合伙人选择努力 $s_i\in[0,4]$。企业总产出为 $4(s_1+s_2+bs_1s_2)$，收益各分一半，每人付出努力成本 $s_i^2$，其中 $0\le b\le1/4$。因此

```math
u_1=2(s_1+s_2+bs_1s_2)-s_1^2,\qquad u_2=2(s_1+s_2+bs_1s_2)-s_2^2.
```

对 $s_1$ 求导得到 $2+2bs_2-2s_1=0$，所以 $BR_1(s_2)=1+bs_2$；对称地 $BR_2(s_1)=1+bs_1$。联立得

```math
\boxed{s_1^{*}=s_2^{*}=\frac1{1-b}}.
```

若由整体规划者最大化 $u_1+u_2$，对称的社会最优努力则为 $\boxed{s^{SO}=2/(1-2b)}$。在上述参数区间内，该值不超过努力上限 4。由于个人付出的额外努力还让另一人获益，却无法独占增量价值，个人均衡努力小于社会最优。这是**正外部性与搭便车**的一种形式。

## 3. 古诺双寡头（Cournot）：同时选择产量

两个企业生产同质产品，反需求为

```math
P(Q)=a-bQ,\quad Q=q_1+q_2,\quad a>c,\ b>0,
```

边际成本均为 $c$，两企业同时选择 $q_i\ge0$。企业 1 的利润为

```math
\pi_1=(a-c-bq_1-bq_2)q_1.
```

对 $q_1$ 求导，$a-c-2bq_1-bq_2=0$。考虑产量非负边界，最佳反应为

```math
BR_1(q_2)=\max\left\{0,\frac{a-c-bq_2}{2b}\right\},\qquad BR_2(q_1)=\max\left\{0,\frac{a-c-bq_1}{2b}\right\}.
```

在对称内部均衡下：

```math
\boxed{q_1^{*}=q_2^{*}=\frac{a-c}{3b}},\qquad
\boxed{Q^{*}=\frac{2(a-c)}{3b}},\qquad
\boxed{P^{*}=\frac{a+2c}{3}}.
```

每家企业的利润为 $`\boxed{\pi_i^{*}=(a-c)^2/(9b)}`$。对比垄断，古诺均衡产量较大、价格较低；对比完全竞争，古诺价格一般高于边际成本。

**例题：** $P=100-Q$、$c=20$，有 $BR_1(q_2)=(80-q_2)/2$，联立得到 $q_1=q_2=80/3$，总产量 $160/3$，价格 $140/3$，每家利润 $6400/9$。

## 4. 伯特兰双寡头（Bertrand）：同时选择价格

仍是两家具有**相同边际成本 $c$、同质商品、没有产能限制**的企业，但现在同时选择价格 $p_i$。消费者向低价企业购买；价格相同则平分需求。在标准模型中，唯一纯策略均衡为

```math
\boxed{p_1^{*}=p_2^{*}=c}.
```

理解这个结果应分两步：若两家定价都高于 $c$，任何一家略微降价就能争夺全部市场，从而使原价格组合不稳定；若某家定价低于成本，则亏损，不会是最优选择。$p_1=p_2=c$ 时无法通过单方降价获得正利润，单方涨价又会失去订单。

**古诺与伯特兰不能只用“一个选产量、一个选价格”来死记**。均衡差异来自行动变量与需求分配机制的变化。在品牌差异、产能约束、搜索成本等条件下，伯特兰价格不一定降到边际成本。

| 比较 | Cournot | 标准 Bertrand |
| --- | --- | --- |
| 决策变量 | 产量 $q_i$ | 价格 $p_i$ |
| 企业如何竞争 | 提高本企业产量会压低市场价 | 略低于对手报价可争夺市场 |
| 对称均衡 | $q_i=(a-c)/(3b)$ | $p_i=c$ |
| 主要假设 | 同质产品、同时定量 | 同质产品、无限产能、同时定价 |

## 5. 线性城市：水平差异与定价均衡

在区间 $[0,1]$ 均匀分布消费者，企业 1 位于 0、企业 2 位于 1。若消费者位置为 $x$，其购买两家的效用分别为

```math
U_1=v-p_1-tx^2,\qquad U_2=v-p_2-t(1-x)^2,\quad t>0.
```

令无差异消费者 $`x^{*}`$ 满足 $U_1=U_2$，可得

```math
\boxed{x^{*}=\frac12+\frac{p_2-p_1}{2t}}.
```

若所有消费者都购买、且无差异点位于内部，企业 1 的需求份额为 $`x^{*}`$，企业 2 为 $`1-x^{*}`$。设边际成本均为 $c$：

```math
\pi_1=(p_1-c)\left(\frac12+\frac{p_2-p_1}{2t}\right).
```

由一阶条件可得 $BR_1(p_2)=(c+t+p_2)/2$；对称地 $BR_2(p_1)=(c+t+p_1)/2$。因此

```math
\boxed{p_1^{*}=p_2^{*}=c+t},\qquad\boxed{D_1=D_2=1/2}.
```

这是**固定两端位置、二次交通成本、市场完全覆盖**下的价格均衡。产品越有差异、消费者跨店成本越高，企业越能保持正的加价。它不能直接推广成“Hotelling 模型的所有均衡价格都是 $c+t$”。

## 6. 消耗战（War of Attrition）：为什么会拖延

两方争夺一个价值分别为 $v_1,v_2>0$ 的奖品，同时承诺何时退出，记为 $t_1,t_2\ge0$。先退出者得不到奖品，却承担等待成本；后退出者获得奖品，但也支付此前的等待成本。假设时间成本率为 1、退出时间可连续选择。

若 $t_1<t_2$，玩家 1 的收益为 $-t_1$，玩家 2 的收益为 $v_2-t_1$；平局规则按题目另设。纯策略均衡的典型形式是：

```math
\boxed{(t_1,t_2)=(0,t_2),\ t_2\ge v_1}\qquad\text{或}\qquad\boxed{(t_1,t_2)=(t_1,0),\ t_1\ge v_2}.
```

一方立刻退出，另一方表示愿意等待至少达到对手奖品估值的时间，对手不愿略微延长等待来争夺奖品。注意这描述的是**事先承诺退出时间的策略式模型**；若允许每个时点重新决策，应进一步使用动态博弈和混合退出时刻分析。

## 7. 严格支配、弱支配及迭代删除

严格支配意味着一个行动在对手所有选择下都更差，所以可直接删除；重复删除严格被支配行动称为 IESDS。有限博弈中，严格支配行动的删除不应被用于排除任何纳什均衡。弱支配只保证不差且在至少一种情况严格更好，**弱劣行动仍可能出现在均衡中**，不可以不检查地随意删掉。

## 8. 中位选民与选址博弈

在两候选人争夺多数票、选民更喜欢距离自己理想政策最近的候选人、理想位置分布存在唯一中位数 $m$、竞选人只关心胜选等假设下，两个候选人均选择中位选民位置是自然的均衡预测。因为偏离中位位置一般会使对手获得超过半数的支持。

同一逻辑可用于解释产品定位趋同、企业门店选址集中，但真实选址还涉及租金、拥挤、差异化、竞争数量和消费需求密度。线性城市中的**价格竞争**与中位选民模型中的**位置竞争**是两个不同决策问题，不能把二者的均衡条件混用。

另有群体选择居住区的模型：如果个人效用受到本区同类人群占比影响，即使每个人仅有相对温和的同类偏好，也可能通过反复迁移产生整体聚集或隔离。其原因是**局部最佳反应的反馈**，不代表所有参与人都有强烈排斥意愿。

## 9. 计算题方法

连续博弈统一按“写支付函数 → 对自己的决策求最大值 → 求最佳反应 → 联立 → 验证边界”完成。若问题含图，应标注横纵坐标分别属于哪个玩家、最佳反应的方向与交点；若含社会最优，则应独立最大化社会目标，不能仅把纳什均衡叫做最优方案。

## 10. 从企业利润扩展到消费者剩余与社会福利

产量竞争题如果只计算两家企业的均衡利润，就还没有回答**不同竞争制度对整个市场是否有利**。在线性需求 $P=a-bQ$、常数边际成本 $c$、无固定成本且市场充分竞争的设定下，消费者剩余和总剩余分别是

```math
CS=\frac12(a-P)Q=\frac12bQ^2,
```

```math
TS=CS+\sum_i\pi_i=(a-c)Q-\frac12bQ^2.
```

可分别代入垄断、双寡头古诺、标准伯特兰的市场总产量进行比较：

| 市场结构 | 总产量 $Q$ | 市场价格 $P$ |
| --- | --- | --- |
| 单一垄断企业 | $(a-c)/(2b)$ | $(a+c)/2$ |
| 对称双企业 Cournot | $2(a-c)/(3b)$ | $(a+2c)/3$ |
| 标准同质品 Bertrand | $(a-c)/b$ | $c$ |

在这些**特定假设**下，产量从垄断到古诺再到伯特兰逐步增加，消费者剩余和社会总剩余也相应提高。但企业利润变化的方向与社会福利变化不相同。现实市场若存在固定成本、差异化、产能限制或动态创新，不能据此断言“价格越低，在所有情形下社会福利都越高”。

## 11. 从双寡头推广到 n 家企业的 Cournot 竞争

设市场反需求为 $P=a-bQ$，共有 $n$ 家成本相同的企业，边际成本为 $c<a$，总产量为所有企业产量之和。企业 i 选择 $q_i$，利润为

```math
\pi_i=(a-c-bq_i-bQ_{-i})q_i.
```

在内部最优解中，对自己的产量求导，而不是对整个市场产量求导：

```math
\frac{\partial\pi_i}{\partial q_i}
=a-c-2bq_i-bQ_{-i}=0.
```

对称均衡令所有企业生产相同产量，由 $Q_{-i}=(n-1)q_i$ 得到

```math
\boxed{q_i^{*}=\frac{a-c}{b(n+1)}},\qquad
Q^{*}=\frac{n(a-c)}{b(n+1)},\qquad
P^{*}=c+\frac{a-c}{n+1}.
```

企业数增加时，在这些假设下每家产量与价格加成下降、市场总产量上升；当企业数趋于无穷大，价格趋近边际成本。这个结果并不适用于存在明显规模经济或固定成本导致企业数内生变化的所有市场。

## 12. 非对称成本时为什么不能直接套对称公式

若两家企业成本分别为 $c_1,c_2$，仍有 $P=a-b(q_1+q_2)$，则各自的最佳反应必须保留对方产量：

```math
BR_1(q_2)=\max\left\{0,\frac{a-c_1-bq_2}{2b}\right\},\qquad
BR_2(q_1)=\max\left\{0,\frac{a-c_2-bq_1}{2b}\right\}.
```

先求联立内部解，**再检验产量是否非负**。当成本差距很大时，高成本企业的候选产量可能为负，这意味着内部一阶条件不适用，需回到含零产量的边界最优解。不能把负产量作为答案，也不能将两个不同成本简单平均后代入对称公式。
