**Cooperative Games, the Core and the Shapley Value**

## 1. 合作博弈研究的是什么

前面几讲主要研究各参与人独立选择行动后形成什么均衡；合作博弈（cooperative game）强调**参与人能否形成具有约束力的联盟，以及联盟创造的收益或承担的成本应该怎样分配**。它尤其适合联合采购、共享仓储、合资研发、联合运输和多部门成本分摊等问题。

合作博弈中的两个关键问题并不相同：**稳定性**——有没有小联盟愿意单独退出；**公平或贡献归属**——联盟价值应如何分配。核心（Core）主要回答前者，Shapley 值主要回答后者。

## 2. 特征函数与可转移效用（TU）

设参与人集合为 $`N=\{1,\ldots,n\}`$，任意子集 $`S\subseteq N`$ 称为联盟（coalition）；所有人组成的联盟 $`N`$ 称为大联盟（grand coalition）。可转移效用合作博弈写为

```math
\boxed{(N,v)},\qquad v:2^N\to\mathbb R,\quad v(\varnothing)=0.
```

$`v(S)`$ 是联盟 $`S`$ 独立行动时最多能创造的总价值；可转移效用表示联盟内部可用支付、转账等方式重新分配总收益。若价值并不能任意转移，例如成员只在乎不可交易的环境质量、政策结果或个别名额，就不能直接套用 TU 模型，应考虑非可转移效用（NTU）框架。

**示例：** 三家公司分别具备研发、咨询和销售能力，各自独立收益为 $`v(1)=17`$、$`v(2)=15`$、$`v(3)=18`$（单位：万元）；双方联盟收益为 $`v(12)=35`$、$`v(13)=38`$、$`v(23)=36`$；三方共同合作收益 $`v(123)=56`$。这些 $`2^3=8`$ 个联盟价值（含空联盟）共同定义了一个 TU 博弈。

## 3. 利润博弈、成本博弈与两种常用性质

**利润博弈**中联盟数值越大越好，例如联合研发后可获得的收益。**成本博弈**通常记为 $`(N,c)`$，$`c(S)`$ 表示联盟 $`S`$ 独自完成项目所需的最小成本，数值越小越好。

超可加性（superadditivity）针对互不相交联盟 $`S,T`$：

```math
v(S\cup T)\ge v(S)+v(T).
```

它意味着联合行动至少不损失两组单独行动的总价值。单调性（monotonicity）针对 $`S\subseteq T`$：

```math
v(S)\le v(T).
```

它意味着联盟增加成员不会使总价值下降。这两个条件并不完全等同；尤其在允许负的单人成员价值等一般 TU 模型中，不能仅由一个条件就不加证明地推另一个。

## 4. 联盟结构、有效性与个体理性

一个联盟结构是对参与人集合 $`N`$ 的划分。例如 $`N=\{1,2,3,4\}`$ 时，$`\{\{1,2\},\{3,4\}\}`$ 代表两个两人联盟，而 $`\{\{1,2,3,4\}\}`$ 代表大联盟。

若大联盟形成，收益分配向量为 $`x=(x_1,\ldots,x_n)`$。**有效性**（efficiency）要求全部价值恰好分完：

```math
\boxed{\sum_{i\in N}x_i=v(N)}.
```

**个体理性**（individual rationality）要求每人至少得到单独行动价值：

```math
\boxed{x_i\ge v(\{i\})}.
```

同时满足两者的分配称为可归责分配或 imputation。有效分配不一定对所有人有吸引力；例如总收益很高，但若某人拿得比单独经营少，就缺少参加联盟的动机。

## 5. 核心（Core）：没有联盟想集体退出

仅要求每人“不如单干差”还不够：两家企业可能合在一起获得比目前两人份额之和更高的收益。核心要求对**所有可能联盟**保持联盟理性：

```math
\boxed{\mathrm{Core}(v)=\left\{x\in\mathbb R^n:\sum_{i\in N}x_i=v(N),\ \sum_{i\in S}x_i\ge v(S)\ \forall S\subseteq N\right\}}.
```

为何不等号是 $`\ge`$？若某个联盟 $`S`$ 的现有合计分配 $`x(S)`$ 小于其单独创造价值 $`v(S)`$，该联盟可以退出大联盟，把更多收益分给自己的成员，所以原方案不稳定。

**经典三人例题：** 令 $`v(i)=0`$、$`v(12)=1`$、$`v(13)=2`$、$`v(23)=1`$、$`v(123)=3`$。核心必须满足

```math
\begin{cases}x_1+x_2+x_3=3,\\x_1,x_2,x_3\ge0,\\x_1+x_2\ge1,\\x_1+x_3\ge2,\\x_2+x_3\ge1.\end{cases}
```

例如 $`(1,1,1)`$ 满足所有不等式，因此属于核心；$`(0,1,2)`$ 虽然有效且个人份额非负，但联盟 $`\{1,3\}`$ 的分配和为 2，恰好达到其独立价值，同样可行；$`(0,0,3)`$ 的 $`x_1+x_2=0<1`$，不属于核心。

**成本博弈要反转不等号**。若 $`x_i`$ 表示成员分摊的成本，核心要求

```math
\boxed{\sum_{i\in N}x_i=c(N),\qquad\sum_{i\in S}x_i\le c(S)\quad\forall S\subseteq N.}
```

某联盟当前支付成本若超过其自行建设所需成本，就有动力退出；所以成本分摊不能超过联盟的独立实施成本。

## 6. 核心有时为空

并非每个合作博弈都存在稳定分配。设三个人单独行动价值为 0，每个两人联盟可创造价值 1，三人大联盟价值也仅为 1。

若核心存在，需要 $`x_1+x_2+x_3=1`$ 且 $`x_1+x_2\ge1`$、$`x_1+x_3\ge1`$、$`x_2+x_3\ge1`$。三个两人联盟约束相加得 $`2(x_1+x_2+x_3)\ge3`$，即 $`2\ge3`$，矛盾。故核心为空。

这说明“组成大联盟能创造价值”并不能保证各成员都能接受同一套不被小联盟挑战的分配方案。

## 7. Shapley 值：平均边际贡献

Shapley 值不通过寻找“无人愿意退出”的集合，而是通过考虑参与人按不同先后顺序加入联盟时的**边际贡献**进行分配。对于 $`n`$ 人 TU 博弈：

```math
\boxed{\phi_i(v)=\sum_{S\subseteq N\setminus\{i\}}\frac{|S|!(n-|S|-1)!}{n!}\left[v(S\cup\{i\})-v(S)\right].}
```

其中 $`v(S\cup\{i\})-v(S)`$ 是玩家 $`i`$ 加入既有联盟 $`S`$ 所带来的价值增量；系数是随机排列中恰好由 $`S`$ 在其之前加入的概率。因此 Shapley 值也等于“所有 $`n!`$ 种加入顺序下边际贡献的平均值”。

### 7.1 三人计算捷径

当 $`n=3`$ 时，对于玩家 1：

```math
\phi_1=\frac13 v(1)+\frac16\{[v(12)-v(2)]+[v(13)-v(3)]\}+\frac13[v(123)-v(23)].
```

玩家 2、3 对称更换下标即可。这个公式对应：自己第一个加入的概率 $`1/3`$；第二个加入的每种前序联盟权重 $`1/6`$；最后加入的概率 $`1/3`$。

### 7.2 数值例题

设 $`v(i)=0`$，$`v(12)=2`$，$`v(13)=4`$，$`v(23)=0`$，$`v(123)=6`$。则

```math
\phi_1=\frac{2+4}{6}+\frac{6-0}{3}=\boxed{3},
```

```math
\phi_2=\frac{2+0}{6}+\frac{6-4}{3}=\boxed{1},
```

```math
\phi_3=\frac{4+0}{6}+\frac{6-2}{3}=\boxed{2}.
```

因此 $`\boxed{\phi=(3,1,2)}`$，三人的份额之和为 6，符合总价值有效分配。可以进一步分别检验该向量是否属于核心，二者不是同一概念。

## 8. Shapley 的四个公理

**效率（efficiency）**：所有玩家的 Shapley 值之和为 $`v(N)`$。

**对称性（symmetry）**：如果两个玩家对所有其他联盟的边际贡献完全相同，他们获得相同的分配。

**零贡献玩家（null player）**：若玩家加入任何联盟都不增加其价值，即 $`v(S\cup\{i\})=v(S)`$，则 $`\phi_i=0`$。

**可加性（additivity）**：对具有相同玩家集合的两个合作博弈 $`v,w`$，有 $`\phi(v+w)=\phi(v)+\phi(w)`$。

这四个公理刻画出一个唯一的 Shapley 分配规则，但**Shapley 值不保证一定属于核心**。核心可以是空集或一个连续集合；Shapley 值始终给出一个确定的向量。两者回答的规范问题不同。

## 9. 求解合作博弈的标准顺序

题目给出全部联盟价值后，先检查是否 TU 利润或成本博弈；确定大联盟价值；若求核心则写有效性和所有非平凡联盟约束并求可行集；若求 Shapley 值则按每个玩家的边际贡献、权重求和；最后检查总和等于 $`v(N)`$，并单独检验所求分配是否稳定。

常见错误包括：把成本核心写成 $`\ge`$；漏掉两人联盟约束；把 Shapley 值等同于均分；将“核心非空”误当成 Shapley 一定属于核心；把联盟特征函数的值 $`v(S)`$ 与某成员个人分配 $`x_i`$ 混淆。

## 10. 凸博弈：什么时候 Shapley 值一定稳定

一般合作博弈的 Shapley 值不保证在核心中。但若博弈具有**凸性（convexity，也称超模性）**，则 Shapley 值属于核心。凸性可以表达为：对任意 $`S\subseteq T\subseteq N\setminus\{i\}`$，

```math
v(S\cup\{i\})-v(S)
\le
v(T\cup\{i\})-v(T).
```

这表示一个新成员加入较大联盟时的**边际贡献不低于**加入较小联盟时的边际贡献。它比单纯“合并联盟不损失价值”的超可加性要求更强。

例如三人的单独价值均为 0，任意两人联盟价值为 1，三人联盟价值为 4。某人从空联盟加入的边际贡献为 0；加入已含一人的联盟时贡献为 1；加入已有两人的联盟时贡献为 $`4-1=3`$。边际贡献随原联盟扩大而递增，因此满足凸性。

对称性与效率性给出 Shapley 值

```math
\phi(v)=\left(\frac43,\frac43,\frac43\right).
```

检验核心：个人分配 $`4/3\ge0`$，任意两人合计 $`8/3\ge1`$，全体合计 $`4=v(N)`$；所以它同时满足效率与联盟稳定性。

**判断次序不能倒置**：证明一个具体 Shapley 向量属于核心，只需检验全部核心约束；若想引用“凸博弈的 Shapley 值属于核心”这一定理，则应先检验凸性，不能从“当前例子恰好在核心”反推博弈必然凸。

## 11. 核心为空时：最小核心（Least Core）

一些合作博弈无法找到让所有联盟都满意的精确分配。此时可以容许每个联盟的稳定性约束存在不超过 $`\varepsilon`$ 的缺口，并使这一最大缺口尽可能小。对收益型 TU 博弈，常见的**最小核心**问题为

```math
\min\ \varepsilon
\quad\text{使得}\quad
\sum_{i\in N}x_i=v(N),\quad
\sum_{i\in S}x_i\ge v(S)-\varepsilon
\quad(\varnothing\ne S\subsetneq N).
```

考虑一个三人多数联盟博弈：单人联盟价值 0，任意两人联盟价值 1，三人联盟价值也为 1。若存在核心，任意两人都需要至少分到 1。将三个两人联盟约束相加，左侧为 $`2(x_1+x_2+x_3)=2`$，右侧却为 3，矛盾；因此核心为空。

若每个两人联盟允许缺口 $`\varepsilon`$，则

```math
2(x_1+x_2+x_3)\ge3(1-\varepsilon)
\quad\Longrightarrow\quad
\varepsilon\ge\frac13.
```

取平均分配 $`x_1=x_2=x_3=1/3`$，任意两人合计 $`2/3`$，恰好实现 $`\varepsilon=1/3`$。所以最小核心的最优缺口为 $`1/3`$，而不是说核心突然变成非空。它量化了**在无法使所有联盟完全满意时，至少必须容忍多大的联盟不满程度**。

## 12. 收益分配与成本分摊的对偶

收益博弈的核心要求任何联盟实际所得不低于单独行动创造的价值；成本分摊博弈则要求任何联盟承担的总成本**不高于**自己单独完成任务的成本。两者不等号方向相反，是因为一类强调“至少拿多少”，另一类强调“至多付多少”。

对于对称成本问题，还可以先用 Shapley 值的对称性与效率性快速得到均分，再**单独验算核心约束**。Shapley 值是一条分摊规则，核心是稳定性集合；即使数值恰好相同，也不能把二者定义混为一谈。
