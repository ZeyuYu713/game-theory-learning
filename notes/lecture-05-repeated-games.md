# Lecture 05｜重复博弈：未来如何改变今天的选择

<strong>Repeated Games · Finite and Infinite Horizons · Trigger Strategies · Discounting · Folk Theorem</strong>

[九讲目录](../README.md) · [第四讲：扩展式博弈](lecture-04-extensive-form-games.md) · [图解：合作与惩罚状态](../visuals/05-repeated-games.md) · [第五讲习题与解析](../exercises/lecture-05-exercises.md)

两家企业今天相遇，可能明天还要在同一个市场竞争；供应商完成本期订单后，还希望下个月继续获得采购；两个人今天是否守约，也可能影响对方未来是否愿意合作。重复博弈研究的正是这种关系：<strong>在当前行动可能影响未来对待方式时，眼前的最佳选择是否会发生改变。</strong>

重复不必然导致合作。若未来毫无价值，今天的决策仍然只由当期支付决定；若惩罚只是口头威胁，到了要执行的时候又对惩罚者自己不利，也不能成为可靠的合作机制。本讲需要明确的不是“如何让参与者愿意合作”这样抽象的问题，而是一个可以计算的比较：当前偏离能多赚多少，未来因此会损失多少。

## 1. 阶段博弈与重复博弈不是同一层问题

每一期反复进行的原始博弈叫阶段博弈（Stage Game）。整个重复互动及其历史依赖策略共同构成重复博弈（Repeated Game），有时也称 Supergame。

以一组对称的囚徒困境支付为例：

| 玩家 1 / 玩家 2 | 合作 C | 背叛 D |
| --- | --- | --- |
| 合作 C | (2,2) | (0,3) |
| 背叛 D | (3,0) | (1,1) |

如果对手合作，自己背叛得到 3，比合作的 2 更高；如果对手背叛，自己背叛仍得 1，比合作的 0 更高。因此 D 严格支配 C，阶段博弈的唯一纳什均衡是 $`(D,D)`$，双方各得 1。

然而，若双方连续很多期都选 C，每期各得 2。与每期互相背叛相比，这看起来对双方都更有利。问题是：既然每一期都能通过单方背叛把自己的当期收益提高到 3，为什么有人会愿意坚持合作？

不能用“双方都希望合作”直接回答。一个人的合作愿望与维持合作的激励条件是两回事。要使合作成为均衡，必须让当前违约的好处不超过未来违约后果造成的损失。

### 1.1 重复博弈中的策略是一份条件计划

在一次性囚徒困境中，说“我选择 C”就足以描述一个纯行动。重复博弈中的策略则需要说明：第一期做什么，第二期根据第一期发生的事情做什么，以及此后每一种历史下又做什么。

设 $`h^{t-1}`$ 表示在第 $`t`$ 期之前，所有已经发生并且能够观察到的行动历史。玩家 $`i`$ 的本期策略可记为：

```math
s_i^t(h^{t-1})\in A_i.
```

例如，玩家可以规定“第一期合作，此后只要过去没有任何人背叛就继续合作；一旦发生过背叛就永远背叛”。这是一份完整的、依赖历史的策略。它与“我打算一直合作”不同：后者没有回答发现对方背叛时会怎么办。

重复博弈沿用了第四讲的扩展式思想。一个完整策略必须在可能发生的各种后续历史下规定行动，而不只是描述最终的均衡路径。

### 1.2 三种经常出现的策略

无条件背叛（Always Defect）规定每一期都选 D，与此前发生的事情无关。

冷酷触发（Grim Trigger）从 C 开始，只要没有观察到背叛就维持 C；只要任何一方背叛过一次，双方以后永久选择 D。这种策略记住的是“是否曾经发生过背叛”。

以牙还牙（Tit-for-Tat，TFT）第一期选 C，之后每一期复制对手上一期的行动。它只使用最近一轮的行动信息，因此在对方恢复合作时也有机会恢复合作，但有时会形成轮流报复。

这些策略都可以被清楚描述，却不代表它们在任何收益结构下都属于子博弈精炼纳什均衡。是否真的稳定，还要计算偏离收益。

## 2. 如何比较跨期收益：折现因子

先假定各期收益可以相加，但未来收益比当前收益权重低。设 $`\delta\in[0,1)`$ 为每跨过一期的折现因子，第 $`t`$ 期支付为 $`u_i^t`$。从第一期看，玩家 $`i`$ 的无限期折现总收益为：

```math
V_i=\sum_{t=1}^{\infty}\delta^{t-1}u_i^t
=u_i^1+\delta u_i^2+\delta^2u_i^3+\cdots.
```

$`\delta=0`$ 表示只有本期收益有权重；$`\delta`$ 接近 1 则表示未来收益衰减较慢。它可以反映对未来的重视程度，也可以在特定模型中综合时间价值与关系持续的可能性。折现因子的经济含义必须结合题目设定。

若每期收益都等于 $`r`$，可直接使用等比数列：

```math
V=r+r\delta+r\delta^2+\cdots=\frac{r}{1-\delta}.
```

如果本期先得到 5，下一期起每期都得到 1，则：

```math
V=5+\delta+\delta^2+\cdots
=5+\frac{\delta}{1-\delta}.
```

这一式子中的 5 只出现一次，不能把它错误地变成未来每一期都有的收益。

### 2.1 周期性收益为什么出现平方折现

若支付从本期开始交替为 $`a,b,a,b,\ldots`$，折现总收益为：

```math
V=a+\delta b+\delta^2a+\delta^3b+\cdots
=\frac{a+\delta b}{1-\delta^2}.
```

分母出现 $`1-\delta^2`$，是因为同一个支付水平每隔两期才重复一次。比如收益为 $`3,0,3,0,\ldots`$，则总收益为 $`3/(1-\delta^2)`$，不是 $`3/(1-\delta)`$。

以后研究 TFT 的报复循环时，正是用这个公式计算长期收益。

### 2.2 归一化折现收益

有些教材将折现总收益乘以 $`1-\delta`$，定义归一化折现收益：

```math
\bar V_i=(1-\delta)\sum_{t=1}^{\infty}\delta^{t-1}u_i^t.
```

如果每期都得 3，折现总收益为 $`3/(1-\delta)`$，归一化收益恰好为 3。对固定的 $`\delta<1`$，两者只相差正的常数，因此不会改变某个玩家对不同策略的偏好次序和均衡判断。

但计算题必须明确正在使用哪种收益口径。一个答案是 $`15`$、另一个是 $`3`$，不一定相互矛盾；当 $`\delta=0.8`$ 且每期都得 3，前者是折现总收益，后者是归一化收益。

## 3. 有限期重复囚徒困境：为什么合作会被倒推掉

让前面的囚徒困境重复三期，并假设双方都知道确切的总期数、能够观察各期行动、完全了解支付结构。

从最后一期开始看。第三期结束后不会再有下一期可以奖励合作或惩罚背叛，因此第三期的决策就是一个独立的阶段博弈。不论过去怎样，每个人都严格偏好 D，所以第三期只能出现 $`(D,D)`$。

再退到第二期。玩家已经知道第三期无论第二期发生什么都会选 D，所以第二期的合作不可能换来第三期的额外合作收益。既然未来支付不受第二期合作影响，第二期仍按阶段博弈的最优行动选择 D。

相同推理继续传回第一期，得到：

```math
(D,D)\quad\text{在第 }1,2,3\text{ 期均出现}.
```

每位玩家三期的折现总收益是：

```math
V_i=1+\delta+\delta^2.
```

注意这里不是 $`1/(1-\delta)`$，因为游戏明确只有三期。

这种“从最后一期向前推回第一期”的逻辑，与第四讲最后通牒和多阶段博弈使用的逆向归纳完全一致。参与者不能只说“如果现在背叛，以后我就惩罚你”，还必须说明未来真的到达惩罚期时，自己为什么仍愿意执行惩罚。

### 3.1 有限期重复一定不能合作吗

不能这样概括。这里阶段博弈只有一个纳什均衡，而且总期数是共同知识。最后一期的唯一均衡固定下来，才使前一期无法通过改变未来均衡来奖惩当前行动。

如果阶段博弈有多个均衡，后面的某一期可以根据早期行为进入不同的阶段均衡。即使未来没有无限多期，较好的未来均衡也可能奖励当期合作，较差的未来均衡则可能惩罚当期偏离。

如果玩家并不确定对手类型、总期数有不确定性，或者某些当期行动影响未来进入市场的机会，游戏也就不再是这里的简单有限重复模型，不能直接照搬上述结论。

## 4. 有限两期也可能有合作：多个阶段均衡的作用

考虑一个每人可选 C、D、P 的阶段博弈，支付为：

| 玩家 1 / 玩家 2 | C | D | P |
| --- | --- | --- | --- |
| C | (-1,-1) | (-10,0) | (-15,-10) |
| D | (0,-10) | (-9,-9) | (-15,-10) |
| P | (-10,-15) | (-10,-15) | (-12,-12) |

先观察两个格子。$`(D,D)`$ 是阶段纳什均衡：面对 D，任何一方选择 D 得 -9，改选 C 或 P 都得 -10。$`(P,P)`$ 也是阶段纳什均衡：面对 P，选择 P 得 -12，改选 C 或 D 都得 -15。

两者都是可信的阶段均衡，但前者给每人 -9，后者给每人 -12。于是可以考虑只重复两期的策略：第一期双方选择 C；若第一期双方都确实选择 C，第二期转到较好的均衡 $`(D,D)`$；只要第一期任何一方偏离，第二期转到较差的均衡 $`(P,P)`$。

第二期的两个续局都确实是阶段纳什均衡，因此没有人到了第二期还想单独破坏既定续局。剩下需要检查的是第一期的激励。

两人都遵守第一期 C 时，每人的总收益为：

```math
V_C=-1-9\delta.
```

若我方在对方选 C 时改为 D，本期收益从 -1 提高到 0，但第二期会转为 $`(P,P)`$，因此：

```math
V_D=0-12\delta.
```

不偏离要求：

```math
-1-9\delta\ge-12\delta
\quad\Longleftrightarrow\quad
\delta\ge\frac{1}{3}.
```

如果第一期改选 P，本期面对对方 C 只得 -10，第二期仍落入较差均衡，不如遵守合作。因此在 $`\delta\ge1/3`$ 时，这份两期策略构成 SPNE。

本例与经典有限囚徒困境的区别不在于“惩罚态度更强”，而在于第二期确实有两个可执行的阶段均衡，可用于对第一期行动作出奖惩。

## 5. 无限重复囚徒困境与冷酷触发

现在令前述 $`(2,2),(0,3),(3,0),(1,1)`$ 的囚徒困境无限重复，双方采用冷酷触发策略：最初合作，只要过去双方都合作就继续合作；一旦有人背叛，以后永远选择 D。

按照这份策略，如果迄今没有人背叛，每期合作都能得到 2，因此从当前时点开始的收益为：

```math
V_C=2+2\delta+2\delta^2+\cdots
=\frac{2}{1-\delta}.
```

假设对手本期依旧合作，而我方现在突然背叛。当前支付从 2 提高到 3；但由于偏离已经被观察到，从下一期起双方永久进入 $`(D,D)`$，我方以后每期只能得到 1。偏离总收益是：

```math
V_D=3+\delta+\delta^2+\cdots
=3+\frac{\delta}{1-\delta}.
```

为了让当前合作至少和当前背叛一样合算，需要：

```math
\frac{2}{1-\delta}
\ge3+\frac{\delta}{1-\delta}.
```

将两边乘以正数 $`1-\delta`$：

```math
2\ge3(1-\delta)+\delta
=3-2\delta
\quad\Longleftrightarrow\quad
\delta\ge\frac{1}{2}.
```

折现因子低于一半，当前背叛的收益优势大于未来合作收益损失；折现因子达到一半或更大，永久惩罚足以抵消当前诱惑。

### 5.1 惩罚不是说出来就会执行

还要检查另一种历史：假设过去已经出现过背叛，双方进入永久惩罚阶段。此时无论对手当前选择什么，按照冷酷触发它都选择 D。

面对对手的 D，我选择 D 得 1，改为 C 只得 0；而且无论当前是否改选 C，触发条件都不会解除，未来仍是 $`(D,D)`$。因此在已经触发惩罚的任何历史之后，继续背叛仍是最佳反应。

合作历史与惩罚历史都通过检验，所以在这组支付结构和完全观察行动的设定下，双方冷酷触发策略构成 SPNE 当且仅当：

```math
\delta\ge\frac{1}{2}.
```

[图解中的两状态模型](../visuals/05-repeated-games.md)可以帮助理解：冷酷触发的“合作状态”允许转向永久惩罚状态，而惩罚一旦开始就不再返回。收益条件决定合作状态是否稳定；阶段博弈的最佳反应条件决定惩罚状态是否稳定。

## 6. 把数字改成参数：一般囚徒困境的阈值

对于对称囚徒困境，通常用四个字母表示单期支付：

| 符号 | 本方与对手的行动 | 本方支付 |
| --- | --- | --- |
| $`T`$，Temptation | 我方 D、对方 C | 单方背叛收益 |
| $`R`$，Reward | 双方 C | 合作收益 |
| $`P`$，Punishment | 双方 D | 相互背叛收益 |
| $`S`$，Sucker | 我方 C、对方 D | 单方合作低收益 |

典型囚徒困境满足 $`T>R>P>S`$。这保证 D 严格支配 C，同时双方都合作又比双方都背叛更好。

在冷酷触发策略下，每期合作的收益为 $`R`$；若本期单方背叛，则本期得 $`T`$，以后每期进入双方背叛的阶段均衡、得到 $`P`$：

```math
V_C=\frac{R}{1-\delta},
\qquad
V_D=T+\frac{\delta P}{1-\delta}.
```

不偏离条件化简为：

```math
\begin{aligned}
R&\ge T(1-\delta)+\delta P,\\
\delta(T-P)&\ge T-R,\\
\delta&\ge\frac{T-R}{T-P}.
\end{aligned}
```

这个分数可以直接从经济意义理解。分子 $`T-R`$ 是当前背叛比合作多得的收益；分母 $`T-P`$ 决定了背叛后的损失与短期诱惑的相对关系。也可以把相同条件写成：

```math
T-R\le\frac{\delta}{1-\delta}(R-P).
```

右边更直观：如果维持合作，未来每一期比永久相互背叛多得 $`R-P`$，这些未来差额折算到今天，就是违约可能失去的价值。<strong>只有这笔未来损失不小于当前偏离的额外收益，合作才具有自我约束力。</strong>

例如 $`T=5,R=3,P=2,S=0`$，阈值为 $`(5-3)/(5-2)=2/3`$。若合作支付从 3 提升为 4，其余保持不变，则阈值下降到 $`1/3`$。这不是因为玩家变得更有道德，而是继续合作的收益提高、背叛相对不再那么划算。

## 7. 一次偏离原理：为什么不需要枚举所有未来计划

重复博弈的完整策略为每一种历史都规定了后续行动。只要可以一直重复，就存在大量复杂的偏离方式：今天背叛、明天合作；以后每隔三期背叛一次；或者遇到某个历史再临时改变策略。逐一列举这些计划几乎不可能。

对标准的折现重复博弈，若阶段行动有限、收益有界且满足适当连续性条件，可以使用一次偏离原理（One-shot Deviation Principle）。它的含义是：要判断候选策略是否在每一个子博弈中最优，足以检查任一玩家在任意历史之后，只改变当前这一期的行动、此后重新遵循原策略，是否能够提高收益。

为什么一次偏离足够？可以先想有限期的情形。如果存在一份多期偏离计划比原策略好，可以从这份偏离计划最后一次与原策略不同的行动开始，逐步比较该行动是否有利。若每个单独行动改动都不可能提高收益，就无法通过有限串联改动获得更高的最终收益。对于有界支付和折现因子小于 1 的无限期情形，足够遥远的收益影响可以变得任意小，再利用相应连续性条件处理无限尾部。

这个思路让计算变得可行，但不能把它误写成“只需要检查第一期一次偏离”。必须检查的是<strong>任何可能历史之后</strong>的一次偏离。

对于冷酷触发，候选策略实质上只有两个状态：从未背叛过的合作状态，以及已经触发的永久惩罚状态。检查这两种状态就涵盖了所有历史。

对于 TFT，未来行为取决于双方上一期的行动组合。上一期可能是 $`(C,C),(C,D),(D,C),(D,D)`$，这四种状态各自可能产生不同的偏离激励。因此只检查从第一期开始双方合作的路径远远不够。

若参与者观察不到彼此的实际行动，只看到某种噪声信号，节点可能组成信息集，不能不加修改地把完美监测下的 SPNE 一次偏离表套上去。那时还要分析信念、信号和相应的信息集。

## 8. 以牙还牙（TFT）：为什么合作路径上有效仍可能不是 SPNE

继续使用阶段支付：

| 玩家 1 / 玩家 2 | C | D |
| --- | --- | --- |
| C | (2,2) | (0,3) |
| D | (3,0) | (1,1) |

双方 TFT 的规则是：第一期 C，以后每期复制对手上一期行动。两人在一直合作的路径上，每期都得 2；本期单方背叛时可得 3，但下一期对手会报复 D，而自己复制对手上一期的 C，于是只能选 C、得 0。再下一期双方角色反转，报复循环可能继续。

从此前一直合作的状态 $`(C,C)`$ 出发，遵守 TFT 的收益仍为 $`2/(1-\delta)`$；若本期改选 D，实际支付序列变为：

```math
3,0,3,0,\ldots
```

偏离收益为：

```math
V_D=\frac{3}{1-\delta^2}.
```

合作不偏离要求：

```math
\frac{2}{1-\delta}\ge\frac{3}{1-\delta^2}
\quad\Longleftrightarrow\quad
2(1+\delta)\ge3
\quad\Longleftrightarrow\quad
\delta\ge\frac{1}{2}.
```

若只计算这一条，我们可能误以为 TFT 只要玩家足够有耐心就能成为 SPNE。但还要检查另外三种上一期结果。

### 8.1 其他历史之后的行动

假设上一期是 $`(C,D)`$，即玩家 1 上期合作、玩家 2 上期背叛。按照 TFT，本期玩家 1 选 D，玩家 2 选 C。若继续遵守，玩家 1 今后的支付是 $`3,0,3,0,\ldots`$。

但是玩家 1 也可以在本期单独改为 C。由于玩家 2 本期已经按 TFT 选 C，当前就恢复 $`(C,C)`$；两人下一期继续复制对方的 C，之后可一直合作。于是本期不报复的收益反而是 $`2/(1-\delta)`$。

为了让玩家 1 愿意继续按 TFT 报复，必须有：

```math
\frac{3}{1-\delta^2}\ge\frac{2}{1-\delta}
\quad\Longleftrightarrow\quad
\delta\le\frac{1}{2}.
```

它与合作状态要求的 $`\delta\ge1/2`$ 正好朝相反方向。这种冲突来自两个不同的激励：从合作状态出发，玩家需要足够重视未来才能抵抗背叛诱惑；从报复循环出发，过于重视未来的玩家反而更想主动打破循环、恢复合作。

剩余两个状态可以用相同办法验证：

| 上一期结果 | 本期按 TFT 行动 | 玩家 1 的遵守收益 | 改变当前行动后的收益 | 无偏离要求 |
| --- | --- | --- | --- | --- |
| $`(C,C)`$ | $`(C,C)`$ | $`2/(1-\delta)`$ | $`3/(1-\delta^2)`$ | $`\delta\ge1/2`$ |
| $`(C,D)`$ | $`(D,C)`$ | $`3/(1-\delta^2)`$ | $`2/(1-\delta)`$ | $`\delta\le1/2`$ |
| $`(D,C)`$ | $`(C,D)`$ | $`3\delta/(1-\delta^2)`$ | $`1/(1-\delta)`$ | $`\delta\ge1/2`$ |
| $`(D,D)`$ | $`(D,D)`$ | $`1/(1-\delta)`$ | $`3\delta/(1-\delta^2)`$ | $`\delta\le1/2`$ |

玩家 2 的条件因支付对称而相同。四种历史下的条件同时成立，只有：

```math
\delta=\frac{1}{2}.
```

因此在这组具体支付中，双方使用 TFT 构成 SPNE 当且仅当折现因子恰好等于一半。

这不是对 TFT 的一般否定。TFT 常被讨论，是因为它容易理解、能够回应对手行动，而且有恢复合作的可能；但它在某个特定收益矩阵里是否满足每个历史之后的最优性，仍是一道需要计算的问题。不能把冷酷触发的折现条件直接移植过来。

## 9. 惩罚只持续有限期，合作还能维持吗

永久惩罚能够产生较强威慑，但也意味着双方一旦发生一次背叛，此后再无恢复合作的机会。可以考虑另一种制度：正常状态下双方选 C；若有人在正常状态偏离，则接下来双方共同背叛 K 期，之后重新回到合作状态。

为了让这份策略能够被验证，还需要把惩罚状态规定完整：惩罚期双方都执行 D；惩罚期内单方改选 C 不会提前结束或缩短惩罚；惩罚期结束后按预先约定恢复合作。若有新的正常期背叛，再开启一段新的 K 期惩罚。

考虑一般囚徒困境支付 $`T,R,P,S`$。从正常合作状态出发，遵守合作时，下一期及以后都获得 R；若本期背叛，则先获得 T，随后 K 期获得 P，再恢复 R。

把每一期列出来更直观：

```math
V_C=\frac{R}{1-\delta},
```

```math
V_D=T+P\sum_{t=1}^{K}\delta^t
+\frac{R\delta^{K+1}}{1-\delta}.
```

两者相减并整理，不偏离条件是：

```math
(R-P)\sum_{t=1}^{K}\delta^t\ge T-R.
```

左边是惩罚 K 期造成的折现损失，右边是本期背叛的即时收益增量。这条式子也显示出惩罚长度和耐心的关系：当 $`R>P`$，增加 K 会增加预期损失；在其他条件相同的情况下，折现因子较高的玩家更在意这些未来损失。

### 9.1 两期惩罚的数值例子

取 $`T=5,R=3,P=1,S=0`$。当 $`K=2`$ 时：

```math
V_C=\frac{3}{1-\delta},
\qquad
V_D=5+\delta+\delta^2+\frac{3\delta^3}{1-\delta}.
```

要求 $`V_C\ge V_D`$，可整理为：

```math
2(\delta+\delta^2)\ge2,
\qquad
\delta^2+\delta-1\ge0.
```

在 $`0<\delta<1`$ 内，得到：

```math
\delta\ge\frac{\sqrt{5}-1}{2}\approx0.618.
```

若只惩罚一期，正常期条件变成 $`2\delta\ge2`$，对所有 $`\delta<1`$ 都不成立；若允许无限期惩罚，条件则趋向冷酷触发的 $`\delta\ge1/2`$。

这些比较说明的是合作状态的激励，还需验证惩罚是否会执行。在这里，惩罚期对手选择 D，自己继续选择 D 是阶段博弈的严格最佳反应；而且单方改选 C 不会缩短惩罚，因此惩罚期间也没有有利的一次偏离。在这样完整规定的状态转移下，上述阈值可以支持 SPNE。

如果换成一种让惩罚者自己承担额外成本的处罚方式，或者惩罚期一方能通过偏离提早解除处罚，就不能仅凭合作路径的计算宣布整个策略可信。

## 10. 玩家耐心不同：双方要分别满足自己的条件

对称的囚徒困境可以用同一组 $`T,R,P,S`$ 和一个共同折现因子表示双方。但在许多合作关系中，双方可能有不同的短期诱惑、不同的未来收益，也可能对长期关系有不同重视程度。

设玩家 $`i`$ 在目标合作状态下每期获得 $`R_i`$，单方背叛当期获得 $`T_i`$，进入永久惩罚后每期获得 $`P_i`$，折现因子为 $`\delta_i`$。若永久惩罚对所有参与者都可信，玩家 $`i`$ 不背叛的条件是：

```math
\delta_i\ge\frac{T_i-R_i}{T_i-P_i}.
```

每个人都必须满足自己的不等式。

例如，一方的支付为 $`T_1=5,R_1=3,P_1=1`$，要求 $`\delta_1\ge1/2`$；另一方的支付为 $`T_2=4,R_2=3,P_2=1`$，只需 $`\delta_2\ge1/3`$。若两人分别有折现因子 0.6 和 0.4，都满足约束，合作可以被冷酷触发支持；若第二人的折现因子只有 0.2，另一人再耐心也无法单独保证双方合作。

这与静态博弈中“每个玩家都必须没有有利单方偏离”的条件完全一致。重复博弈只是把偏离收益从一个时期扩展成一条跨期收益流。

## 11. 关系可能终止时的有效折现因子

无限期模型不一定意味着现实中双方肯定永远交易。可以假设每期结束后，合作关系以概率 $`\rho`$ 延续到下一期；玩家对下一期收益的纯时间折现因子为 $`\beta`$。

若关系能否延续与本期行动、此前历史独立，并且终止后没有额外支付，那么下一期收益同时受到时间折现和关系生存概率影响。两者合成的有效折现因子为：

```math
\delta_{\mathrm{eff}}=\beta\rho.
```

于是，冷酷触发的合作条件变成：

```math
\beta\rho\ge\frac{T-R}{T-P}.
```

例如 $`T=5,R=3,P=1,S=0`$，阈值为一半。如果 $`\beta=0.9`$，就要求：

```math
\rho\ge\frac{1/2}{0.9}=\frac{5}{9}\approx0.556.
```

关系延续概率为 0.5 时，有效折现因子 $`0.45`$，不足以维持冷酷触发合作；延续概率为 0.7 时，有效折现因子 $`0.63`$，合作条件得到满足。

这一结论解释了一种常见现象：即使双方并不短视，如果预计关系很快结束，未来的合作奖励和惩罚也可能失去威慑。反过来，如果终止概率取决于是否背叛，或者交易结束后仍有可计算的声誉损失，就要重新写转移概率与后续收益，而不能继续机械使用 $`\beta\rho`$。

## 12. 不是每次行动都能被看见：监测结构的影响

前面各类触发策略都默认参与者能观察到对方真实选择了 C 还是 D。这被称为完美监测（Perfect Monitoring）。只有知道背叛是否发生，玩家才能准确按照历史决定何时开始惩罚。

如果只能看到一个含噪声的结果，例如订单延误、交付质量下降或市场份额变化，就可能出现两种情况：对方实际上合作，坏结果却被错误解释为背叛；对方已经背叛，观察到的信号却仍然正常。

在这种环境中，冷酷触发过于敏感可能导致长期合作关系因一次误报而永久终止；但惩罚不够敏感，又可能让真实偏离缺乏威慑。

要认真分析此类问题，应明确公开信号或私人信号的概率分布，求出不同行动对信号发生概率的影响，再在相应信息结构下定义均衡。只有公共信号时常可以讨论公共策略与公共完美均衡（Perfect Public Equilibrium）；如果每个人看到的信号不同，还涉及私人监测和信念更新。

这不改变重复博弈的基本问题——今日偏离与未来代价如何比较——但会改变未来代价如何被触发和执行。不能把有噪声的现实信号直接当成准确的行动历史。

## 13. 民间定理：重复博弈可以有多少种均衡结果

在囚徒困境里，我们只尝试支持双方一直合作这一条路径。但重复博弈更一般的问题是：如果参与者足够重视未来，是否可以利用后续奖惩支持其他原本不是阶段纳什均衡的行动组合？

民间定理（Folk Theorem）研究的就是可持续收益集合。不同版本有不同的观察、折现和可实施性条件；它们大体说明，未来互动足够重要时，重复博弈可能支持远多于阶段博弈均衡的长期结果。

先讨论一个易于证明的情形。假设某阶段博弈有一个纳什均衡 $`a^{NE}`$，其中玩家 $`i`$ 每期得到 $`w_i`$。现在有一个希望持续执行的公开可观察行动组合 $`a^*`$，使每位玩家得到 $`v_i>w_i`$。当其他玩家执行 $`a^*`$ 时，玩家 $`i`$ 单方面改变行动，最多能把本期收益提高到：

```math
g_i=\max_{a_i\in A_i}u_i(a_i,a_{-i}^*).
```

约定如下触发策略：没有人偏离时，每期都执行 $`a^*`$；一旦有人偏离，此后永远执行阶段纳什均衡 $`a^{NE}`$。

遵守目标行动的长期收益是：

```math
V_i^C=\frac{v_i}{1-\delta}.
```

本期偏离后，玩家 $`i`$ 先获得最多 $`g_i`$，以后每期只得 $`w_i`$，所以：

```math
V_i^D=g_i+\frac{\delta w_i}{1-\delta}.
```

不偏离条件整理为：

```math
\delta\ge\frac{g_i-v_i}{g_i-w_i}.
```

只要每位玩家都满足相应条件，且惩罚阶段的 $`a^{NE}`$ 是可信的阶段纳什均衡，那么这条目标路径就能由相应的触发策略支持为 SPNE。

### 13.1 用一组数字判断能否支持目标合作

假设双方在目标行动组合下每期各得 4，在某个可用作惩罚的阶段均衡中各得 1，且任一玩家单方偏离目标组合时，本期最多得 7。

遵守目标行动：

```math
V_C=\frac{4}{1-\delta}.
```

本期单方偏离：

```math
V_D=7+\frac{\delta}{1-\delta}.
```

因此：

```math
\frac{4}{1-\delta}\ge7+\frac{\delta}{1-\delta}
\quad\Longleftrightarrow\quad
\delta\ge\frac{1}{2}.
```

这个例子与囚徒困境冷酷触发的计算结构相同，说明该机制并不局限于 C、D 两个行动，也不局限于某一张支付矩阵。

### 13.2 可行收益与个体理性

不能把民间定理解读为“只要无限重复，任何收益都可能是均衡”。首先，目标收益必须可行：它应能由阶段行动组合、这些组合的时间轮换或在允许的条件下由随机化实现。其次，参与者不能被迫长期接受低于其适当保障水平的收益；否则他可以选择某种偏离方式，避免陷入不利安排。

在更一般的民间定理中，常讨论可行并满足个体理性约束的收益向量。保障水平、公共监测、私人信息、折现条件与可用惩罚方式都会影响可支持集合。前面通过“偏离后永远执行某个阶段纳什均衡”得到的是一种清楚可验证的充分机制，并不声称囊括所有民间定理的条件。

### 13.3 原课件第 24–25 页：把完美民间定理写成严格的命题

原课件将这部分称为 <strong>The (Perfect) Folk Theorem</strong>。它首先说明：无限次重复囚徒困境中的冷酷触发不仅可以维持 $`(C,C)`$，还可以推广到任意有限玩家阶段博弈中某些<strong>优于阶段纳什均衡</strong>的行动组合。

设阶段博弈为 $`G`$，共有 $`N`$ 名玩家，行动集合为 $`A_i`$，单期收益为 $`u_i(a)`$。为使每一期的最优偏离都存在，先考虑有限行动集、有限且有界的收益，并假设每期行动被其他人准确观察、各期使用相同的折现因子 $`0\le\delta<1`$。

取阶段博弈的一个纳什均衡 $`\sigma^*`$。记在此均衡下每名玩家的单期收益为 $`w_i=u_i(\sigma^*)`$。再取一个准备在无限重复博弈中长期执行的行动组合 $`\sigma`$，其单期收益为 $`v_i=u_i(\sigma)`$。原课件要求对<strong>每一位玩家</strong>都有严格不等式：

```math
v_i=u_i(\sigma)>u_i(\sigma^*)=w_i,
\qquad i=1,\ldots,N.
```

在这组设定下，存在一个 $`\bar\delta<1`$，使得对全部 $`\delta\in[\bar\delta,1)`$，下面的触发策略构成重复博弈的子博弈精炼纳什均衡（SPNE）：

```math
s_i(h^t)=
\begin{cases}
\sigma_i,&\text{此前每一期全体均执行目标组合 }\sigma,\\
\sigma_i^*,&\text{此前曾有人偏离目标组合 }\sigma.
\end{cases}
```

初始期执行 $`\sigma_i`$；无偏离的历史继续执行 $`\sigma_i`$；一旦观察到任何偏离，所有玩家从<strong>下一期开始</strong>永久执行阶段均衡 $`\sigma^*`$。请注意：原课件的记号 $`\sigma`$ 是<strong>目标行动组合</strong>，$`\sigma^*`$ 是<strong>惩罚用阶段纳什均衡</strong>，不要将星号误解为“合作更优的行动”。

这是一个<strong>可构造的充分性定理</strong>：它说明满足以上条件时至少能找到一种 SPNE 来支持目标路径；它并没有说所有 SPNE 都必须使用这种永久惩罚，也没有声称只有优于某个阶段纳什均衡的收益才能被重复博弈支持。

### 13.4 原课件第 26 页：先证明惩罚阶段可信

要证明完整策略构成 SPNE，就必须在<strong>每一种可能历史之后</strong>验证没有玩家愿意单独偏离。历史可以先划分成两个状态：从未发现偏离的“目标状态”，以及已经发生过偏离的“永久惩罚状态”。

先看惩罚状态。由于策略规定此后每期都执行阶段均衡 $`\sigma^*`$，玩家 $`i`$ 若遵守，得到：

```math
V_i^P=\frac{w_i}{1-\delta}.
```

若玩家 $`i`$ 在某一惩罚期擅自选择 $`a_i'`$，其他玩家仍执行 $`\sigma_{-i}^*`$，当前最多获得 $`u_i(a_i',\sigma_{-i}^*)`$。因为 $`\sigma^*`$ 本身是阶段纳什均衡，必有：

```math
u_i(\sigma_i^*,\sigma_{-i}^*)
\ge u_i(a_i',\sigma_{-i}^*)
\qquad\text{对任意 }a_i'.
```

偏离不会解除已经触发的永久惩罚，因此未来支付流完全相同；今天也无法通过改行动提高收益。<strong>这就是惩罚可信的根本原因。</strong>如果把惩罚写成一个并非阶段纳什均衡的行动组合，惩罚者自己可能从下一期起就不愿执行，它便不能直接用于本证明。

### 13.5 原课件第 26 页：再证明目标状态没有有利的一次偏离

未发生过偏离时，玩家 $`i`$ 遵守目标组合，每期得到 $`v_i`$，折现总收益为：

```math
V_i^C=v_i+\delta v_i+\delta^2v_i+\cdots
=\frac{v_i}{1-\delta}.
```

当其余玩家本期仍选择 $`\sigma_{-i}`$ 时，玩家 $`i`$ 若偏离为某个 $`a_i'\ne\sigma_i`$，本期收益为 $`u_i(a_i',\sigma_{-i})`$，以后从下一期开始执行永久惩罚，因此：

```math
V_i^D(a_i')=u_i(a_i',\sigma_{-i})
+\delta\frac{w_i}{1-\delta}.
```

不发生有利偏离，要求 $`V_i^C\ge V_i^D(a_i')`$。消去正的 $`1-\delta`$ 后：

```math
\begin{aligned}
\frac{v_i}{1-\delta}
&\ge u_i(a_i',\sigma_{-i})+\frac{\delta w_i}{1-\delta},\\
v_i&\ge(1-\delta)u_i(a_i',\sigma_{-i})+\delta w_i,\\
\delta\bigl(u_i(a_i',\sigma_{-i})-w_i\bigr)
&\ge u_i(a_i',\sigma_{-i})-v_i.
\end{aligned}
```

这正是课件第 26 页给出的收益不等式。为避免对不盈利的偏离错误地除以负数，更稳妥的做法是先定义<strong>最佳单期偏离收益</strong>：

```math
g_i=\max_{a_i\in A_i}u_i(a_i,\sigma_{-i}).
```

由于自己也可以选择原行动 $`\sigma_i`$，所以 $`g_i\ge v_i`$；又因为假设 $`v_i>w_i`$，因此有 $`g_i-w_i>0`$，分母符号确定。这时所有偏离约束等价于最强的一条约束：

```math
\boxed{\delta\ge\delta_i^*
=\frac{g_i-v_i}{g_i-w_i}}.
```

如果 $`g_i=v_i`$，说明目标行动本身已经是玩家 $`i`$ 对其他目标行动的最佳反应，其门槛为 $`\delta_i^*=0`$；如果 $`g_i>v_i>w_i`$，则 $`0<\delta_i^*<1`$。要让<strong>所有玩家</strong>都没有有利偏离，必须取：

```math
\boxed{\bar\delta=\max_{i=1,\ldots,N}
\frac{g_i-v_i}{g_i-w_i}<1}.
```

只要 $`\delta\ge\bar\delta`$，目标状态满足一次偏离约束；而惩罚状态已经因为阶段纳什均衡性质而可信。根据前面第 7 节解释的一次偏离原理，在有限行动、收益有界、折现且可准确观察历史的重复博弈中，以上两类状态都没有有利的一次偏离，就足以推出整个触发策略在每个子博弈内为纳什均衡，即构成 SPNE。

证明中最关键的逻辑不是“大家重视未来，所以会合作”，而是三个可以逐项检验的事实：$`\sigma^*`$ 确实是阶段均衡；$`v_i>w_i`$ 对每个玩家成立；折现因子足以让任何玩家的当前最佳偏离收益，都不超过遵守目标策略的长期价值。

### 13.6 一般阶段博弈的数值计算：最不耐心的玩家决定门槛

考虑下面的阶段收益矩阵，行动 $`C`$、$`D`$ 分别代表合作与背叛，但两人的收益并不对称：

| 玩家 1／玩家 2 | $`C`$ | $`D`$ |
| --- | ---: | ---: |
| $`C`$ | $`(4,5)`$ | $`(0,9)`$ |
| $`D`$ | $`(7,0)`$ | $`(1,2)`$ |

对双方而言，给定对手选择 $`C`$ 或 $`D`$，自己都严格偏好 $`D`$；因此阶段博弈的唯一纳什均衡为 $`\sigma^*=(D,D)`$，支付向量 $`w=(1,2)`$。选 $`\sigma=(C,C)`$ 作为持续目标，每期支付为 $`v=(4,5)`$，两人均严格优于惩罚支付。

如果单独背叛目标组合，玩家 1 得 $`g_1=7`$，玩家 2 得 $`g_2=9`$。于是：

```math
\begin{aligned}
\delta_1^*&=\frac{7-4}{7-1}=\frac{1}{2},\\
\delta_2^*&=\frac{9-5}{9-2}=\frac{4}{7},\\
\bar\delta&=\max\left\{\frac{1}{2},\frac{4}{7}\right\}
=\boxed{\frac{4}{7}}.
\end{aligned}
```

例如当 $`\delta=0.55`$ 时，玩家 1 已经愿意遵守目标，但玩家 2 仍可通过单期背叛获利；只有 $`\delta\ge4/7`$ 时，双方都满足激励约束。判断多玩家重复博弈时，<strong>不能因为某一位玩家的折现条件满足，就宣布整个策略构成 SPNE</strong>。这组矩阵在[第五讲习题第 15 题](../exercises/lecture-05-exercises.md)中进一步做了完整的偏离和续局收益检验。

### 13.7 原课件第 26–27 页的两个适用边界

<strong>混合目标策略的可核验性。</strong>原课件第 26 页特别提醒：如果目标 $`\sigma`$ 是混合策略，参与者的随机化必须能够在事后核验。原因在于观察到一个纯行动，并不自动告诉其他人这个行动是否按照约定概率抽取。例如约定某人以 60% 概率选 $`A`$、40% 概率选 $`B`$，实际观察到 $`A`$，无法仅凭这一期结果断定他是否偏离了概率 60%。要把“改变混合分布”作为可触发的违约，必须另外指定可公开验证的随机化、公共随机设备或足以检测偏离的监测规则。<strong>纯行动目标可以直接检验行动偏离；私人混合分布不能这样套用。</strong>

<strong>更广义的可行—个体理性版本。</strong>原课件第 27 页提及另一些民间定理：在适当条件下，重复博弈可以支持某些满足可行性、且每人收益高于其 min-max 保障水平的收益向量。这里的可行集合可能包括不同阶段行动收益的凸组合：

```math
F=\operatorname{co}\{u(a):a\in A\}.
```

如果允许混合行动，玩家 $`i`$ 的 min-max 水平通常写为：

```math
\underline v_i
=\min_{\alpha_{-i}}
\max_{\alpha_i}
\mathbb E[u_i(\alpha_i,\alpha_{-i})].
```

这个数是“其余玩家针对玩家 $`i`$ 选择最严厉的行动分布后，玩家 $`i`$ 仍能做最佳反应得到多少”，不能简单替换成任意某个阶段纳什均衡收益 $`w_i`$。同时，<strong>可行且超过 min-max 水平</strong>是这类更一般定理中的收益目标条件；要推出 SPNE 仍须满足相应版本对信息、公共监测、惩罚构造、可行收益集合维度及折现因子的要求。原课件第 25–26 页已经证明的是前述<strong>阶段纳什均衡永久惩罚版本</strong>，并未给出所有 min-max 版本的完整证明。

考试中如果要求“陈述并证明原课件的完美民间定理”，就先写 $`v_i>w_i`$、两状态触发策略、惩罚可信性、目标状态的单期偏离比较和 $`\bar\delta`$；若题目改问“民间定理的一般经济含义”，再讨论可行收益、个体理性和不同定理版本。不要直接把两个层次的假设、证明和结论合并成一句“任何可行收益都可由无限重复支持”。

## 14. 应用到重复 Cournot：产量竞争中的长期激励

第二讲研究过两家企业同时选择产量的 Cournot 博弈。若企业每期都会再次进入同一个市场，可以把它看成一个重复阶段博弈，检验是否存在其他长期可持续的产量组合。

设市场价格为：

```math
P=100-q_1-q_2,
```

两家企业边际成本均为 20。一次性 Cournot 均衡下，每家生产 $`80/3`$，价格为 $`140/3`$，每家利润为：

```math
\pi_i^{NE}=\frac{6400}{9}\approx711.11.
```

作为一个比较基准，若双方将总产量控制在垄断最优数量 40，并平均分担产量，则各生产 20，价格为 60，每家利润为：

```math
\pi_i^C=(60-20)\times20=800.
```

这一目标组合使双方每期都比静态 Cournot 均衡多获得利润，但它本身不是阶段纳什均衡。若另一家生产 20，我方的利润函数为：

```math
\pi_i(q_i,20)
=[100-q_i-20-20]q_i
=(60-q_i)q_i.
```

使利润最大的单方产量为 $`q_i=30`$，此时：

```math
\pi_i^D=(60-30)\times30=900.
```

也就是说，在另一家维持 20 的情况下，我方有动力把产量从 20 提高到 30，本期额外赚取 100。要维持长期较低的目标产量，就需要未来后果抵消这一短期诱惑。

假设每期产量可被准确观察，双方从目标产量 20 开始；只要有人偏离目标产量，未来永久回到阶段 Cournot 均衡。由于每一期的 Cournot 均衡本身就是最佳反应组合，因此后续惩罚是可信的。

按前面的通用公式，合作条件为：

```math
\delta\ge
\frac{900-800}{900-\frac{6400}{9}}
=\frac{9}{17}
\approx0.529.
```

当折现因子足够高，这组历史依赖策略可以支持双方每期各生产 20 的路径。若低于该阈值，单方增加当期产量所带来的收益超过了以后回到 Cournot 均衡所造成的损失。

与静态 Cournot 模型相比，重复博弈并没有改变每一期的需求函数和成本函数，而是扩大了一个行动的后果：现在多生产一单位，不只影响本期价格，还可能改变以后每一期对方的产量策略。

这一例子也便于辨认两个不同的问题。计算静态 Cournot 均衡时，联立本期最佳反应；计算重复博弈的合作阈值时，要先确定目标产量、最有利的单方偏离及可信惩罚收益，再把它们放进跨期激励约束。

## 15. 共同已知的有限期限与有限期中的声誉

第三节的有限期囚徒困境得出每期背叛，是基于双方都知道总共只有多少期，也都知道对方在阶段博弈中具有怎样的支付和理性选择规则。

如果一方不确定另一方是否属于“即使眼前吃亏也会坚持惩罚”的类型，合作行为就可能传递类型信息，并影响对方对未来行动的判断。在此类具有不完全信息的有限期模型里，较理性的玩家也可能暂时维持合作，以免过早暴露自己的激励结构或改变对方信念。

但这已经不是“固定支付、共同已知类型、完全信息”的简单重复囚徒困境，而属于重复博弈与贝叶斯博弈结合的问题。分析时需要写出可能的类型、先验概率、历史观察和后验信念。仅仅说“现实中人们会顾及声誉”，不足以证明原模型的逆向归纳结果错误。

同样，若总期数本身不确定，例如每期都有机会继续交易，模型就可能转化成前面讨论的随机终止关系。是否能支持合作，取决于它如何改变未来收益的重要性，而不是简单在已知有限期问题后面加一句“双方可能还会再见”。

## 16. 题目求解中最需要分清的几件事

首先确认阶段博弈的支付与均衡。冷酷触发惩罚往往依赖某个阶段纳什均衡，因为到了惩罚阶段后，参与者仍然必须愿意执行指定行动。若没有先求阶段博弈，就很难判断未来惩罚是否可信。

其次确认总期限和信息结构。已知共同有限期、无限期、随机终止期限、可以观察全部行动或只能观察噪声信号，这些条件都会改变候选策略的合理性。不能把有限期的逆向归纳和无限期的触发阈值当成同一道题来做。

然后写出完整策略，包括正常合作状态、惩罚何时开始、惩罚持续多久、何时恢复合作，以及偏离发生在惩罚期时会怎样处理。只写“合作，违约则惩罚”通常不足以验证 SPNE。

计算时，把遵守目标策略的折现总收益记为 $`V_C`$，把当前最有利偏离且随后按候选续局行动的收益记为 $`V_D`$。列出 $`V_C\ge V_D`$ 并求折现因子的范围，再检查其他所有历史下是否存在有利的一次偏离。

| 题目情形 | 先使用的工具 | 特别注意 |
| --- | --- | --- |
| 阶段博弈唯一 NE、已知重复有限期 | 末期逆向归纳 | 不能凭“重复”推断前期合作 |
| 阶段博弈存在多个 NE、有限期重复 | 检查不同可信续局 | 奖惩必须使用后续真正的均衡 |
| 无限期、冷酷触发 | 等比数列与一次偏离 | 同时检查合作和永久惩罚状态 |
| 无限期、TFT | 周期收益与四种历史 | 不能只检查初始合作路径 |
| K 期惩罚后恢复 | 有限期损失之和 | 写清惩罚期间的偏离处理 |
| 每期可能终止 | 有效折现因子 | 延续概率是否独立于行动 |
| 多名玩家或非对称支付 | 逐人写激励约束 | 每个人都必须满足自己的条件 |

对考试来说，最容易混淆的是支付流的时间位置。例如本期背叛得 5、下期开始每期得 1，应写为 $`5+\delta/(1-\delta)`$；如果只惩罚两期，后面恢复合作，必须在第三期之后重新把合作收益加回来，不能把有限惩罚当成永久惩罚。

还要分清阶段均衡与重复均衡。阶段均衡描述给定某一期行动时的相互最佳反应；重复均衡研究的是对整个历史依赖策略进行单方偏离是否有利。重复博弈的合作路径可以不是阶段纳什均衡，但支撑这条路径的奖惩机制仍必须在对应后续历史下有合理激励。

[第五讲习题与详细解析](../exercises/lecture-05-exercises.md)覆盖有限期倒推、多个阶段均衡、冷酷触发、TFT 四状态、有限 K 期惩罚、随机终止与民间定理条件。有关合作状态和惩罚状态的转换，可结合[第五讲图解](../visuals/05-repeated-games.md)阅读。下面将两类最容易被同一个折现公式误导的问题继续推导：<strong>一般支付下 TFT 的四状态检验</strong>，以及<strong>已知耐心程度时反过来设计最少惩罚期数</strong>。

## 17. TFT 的一般参数检验：为什么有时根本不存在可行的折现因子

前面第 8 节使用 $`T=3,R=2,P=1,S=0`$ 的特殊矩阵，算出双方 TFT 恰好在 $`\delta=1/2`$ 构成 SPNE。不要把这个结果推广成“只要折现因子等于一半，TFT 总能成为均衡”。真正决定结论的是四种历史下的激励约束能否同时成立。

考虑对称囚徒困境，假设 $`T>R>P>S`$，双方每一期都能准确观察上期行动，初始采用合作 $`C`$，此后每期无条件复制对手上一期的行动。我们分别检验玩家 1 在任何可能历史之后只改变<strong>本期一次行动</strong>、以后又恢复 TFT 的收益。由于阶段支付对称，对玩家 2 的检验将得到相同的条件。

### 17.1 两条可能持续下去的收益流

如果上一期是 $`(C,C)`$，按 TFT 的双方本期继续合作。玩家 1 遵守的折现总收益为 $`R/(1-\delta)`$；若本期独自改为 D，以后恢复 TFT，会出现 $`T,S,T,S,\ldots`$ 的支付循环：

```math
V_{CC}^{\mathrm{follow}}=\frac{R}{1-\delta},\qquad
V_{CC}^{\mathrm{deviate}}=\frac{T+\delta S}{1-\delta^2}.
```

合作状态不偏离要求：

```math
\begin{aligned}
\frac{R}{1-\delta}&\ge\frac{T+\delta S}{1-\delta^2},\\
R(1+\delta)&\ge T+\delta S,\\
\delta(R-S)&\ge T-R,\\
\boxed{\delta\ge a:=\frac{T-R}{R-S}}.
\end{aligned}
```

如果上一期是 $`(C,D)`$，本期按 TFT 玩家 1 应报复，选择 D，获得 $`T,S,T,S,\ldots`$；若临时改成 C，本期双方就变回 $`(C,C)`$，之后永久合作。这次要让玩家 1 愿意<strong>继续报复</strong>，必须满足相反方向的条件：

```math
\begin{aligned}
\frac{T+\delta S}{1-\delta^2}&\ge\frac{R}{1-\delta},\\
\boxed{\delta\le a:=\frac{T-R}{R-S}}.
\end{aligned}
```

这两条约束必须同时成立，因此<strong>仅比较合作与报复这两种历史</strong>，就已经需要 $`\delta=a`$。这种等号条件来源于两个相反的激励：当前合作时要抵住背叛诱惑，而已经开始报复循环时又不能想单方恢复合作。

### 17.2 另外两个历史给出第二个临界值

如果上一期是 $`(D,C)`$，本期玩家 1 按 TFT 应选 C，对手应选 D。遵守后支付流为 $`S,T,S,T,\ldots`$，折现总收益 $`(S+\delta T)/(1-\delta^2)`$；若本期改选 D，当期就进入 $`(D,D)`$，之后永久得到 P，因此偏离收益为 $`P/(1-\delta)`$。遵守约束是：

```math
\begin{aligned}
\frac{S+\delta T}{1-\delta^2}&\ge\frac{P}{1-\delta},\\
S+\delta T&\ge P(1+\delta),\\
\boxed{\delta\ge b:=\frac{P-S}{T-P}}.
\end{aligned}
```

如果上一期是 $`(D,D)`$，本期遵守 TFT 得到 $`P,P,P,\ldots`$；本期单方改成 C，则形成 $`S,T,S,T,\ldots`$ 的交替循环。避免这一偏离，又得到：

```math
\frac{P}{1-\delta}\ge\frac{S+\delta T}{1-\delta^2}
\quad\Longleftrightarrow\quad
\boxed{\delta\le b:=\frac{P-S}{T-P}}.
```

把四个状态的条件放在一起：

| 上一期的行动结果 | 本期 TFT 规定 | 本期偏离后形成的主要路径 | 不偏离要求 |
| --- | --- | --- | --- |
| $`(C,C)`$ | $`(C,C)`$ | $`T,S,T,S,\ldots`$ | $`\delta\ge a`$ |
| $`(C,D)`$ | $`(D,C)`$ | 恢复长期 $`(C,C)`$ | $`\delta\le a`$ |
| $`(D,C)`$ | $`(C,D)`$ | 永久 $`(D,D)`$ | $`\delta\ge b`$ |
| $`(D,D)`$ | $`(D,D)`$ | $`S,T,S,T,\ldots`$ | $`\delta\le b`$ |

故对于上述对称、完全监测、确定性 TFT 策略组合，四状态检验的<strong>必要且充分条件</strong>是：

```math
\boxed{\delta=a=b\in[0,1),\qquad
a=\frac{T-R}{R-S},\quad b=\frac{P-S}{T-P}.}
```

这里的两个临界值不一定相等。比如取 $`T=5,R=3,P=1,S=0`$，就得到 $`a=2/3`$、$`b=1/4`$，不可能找出同一个 $`\delta`$ 同时等于两者。<strong>这组收益下，无论参与者多么耐心，双方都执行 TFT 都不能成为 SPNE</strong>。但冷酷触发仍可在 $`\delta\ge1/2`$ 时支持合作，说明“某个具体的历史依赖策略不构成均衡”和“合作不可能被任何策略支持”是不同命题。

相反，前面课堂型支付 $`(3,2,1,0)`$ 恰好得到 $`a=b=1/2`$，所以 TFT 仅在 $`\delta=1/2`$ 时构成 SPNE。[习题 17](../exercises/lecture-05-exercises.md)将两组支付与冷酷触发、两期惩罚放在同一道题中逐项比较。

## 18. 反向设计惩罚：已知折现因子，至少惩罚多少期？

考试可能不再问“给定 K 期惩罚，求最小 $`\delta`$”，而改问“给定 $`\delta`$，需要多少期惩罚才足以阻止背叛”。这是同一条激励约束的不同未知量；如果只会求二次方程的正根，遇到这类题就容易卡住。

沿用 $`T=5,R=3,P=1,S=0`$ 的囚徒困境，正常状态双方合作，发现违约后从下一期开始执行 K 期 $`(D,D)`$，然后恢复合作；惩罚期间个别玩家选择 C 不改变剩余惩罚期限。正常状态不偏离要求：

```math
(R-P)\sum_{t=1}^{K}\delta^t\ge T-R
\quad\Longleftrightarrow\quad
\boxed{\sum_{t=1}^{K}\delta^t\ge1}.
```

### 18.1 固定折现因子后逐期检验

如果 $`\delta=0.6`$，只惩罚一期时损失折现值为 $`0.6`$，不足以补偿当前背叛多得的单位化收益 1；惩罚两期时为 $`0.6+0.6^2=0.96<1`$；惩罚三期时为 $`0.6+0.6^2+0.6^3=1.176\ge1`$。所以最短惩罚长度是<strong>三期</strong>。

为什么不能把三期写成“本期就算第一期”？因为当前违约时已经获得 $`T=5`$，处罚承诺从<strong>下一期</strong>才开始兑现；因此第一期惩罚乘 $`\delta`$，第三期惩罚乘 $`\delta^3`$。如果将惩罚从本期算起，会错误地高估处罚威慑力。

### 18.2 把逐期试算改成通用整数公式

对于 $`0<\delta<1`$，有限几何级数为：

```math
\sum_{t=1}^{K}\delta^t
=\frac{\delta(1-\delta^K)}{1-\delta}.
```

在本题收益下，要求：

```math
\frac{\delta(1-\delta^K)}{1-\delta}\ge1
\quad\Longleftrightarrow\quad
\delta^K\le\frac{2\delta-1}{\delta}.
```

如果 $`\delta\le1/2`$，任何有限 K 都不足以使左侧的损失和达到 1；$`\delta=1/2`$ 时无限惩罚的极限恰好等于 1，但每个有限 K 都严格小于 1。若 $`1/2<\delta<1`$，右侧严格位于 0 与 1 之间，两边取自然对数。由于 $`\ln\delta<0`$，除以这个负数时必须把不等号反向，得到：

```math
K\ge\frac{\ln[(2\delta-1)/\delta]}{\ln\delta}.
```

因此最小整数惩罚长度为：

```math
\boxed{K_{\min}
=\left\lceil\frac{\ln[(2\delta-1)/\delta]}{\ln\delta}\right\rceil,
\qquad 1/2<\delta<1.}
```

这个式子只适用于上述具体支付和处罚状态；对于其他 $`T,R,P`$，应重新从 $`(R-P)\sum_{t=1}^{K}\delta^t\ge T-R`$ 出发。计算得到接近整数的浮点数时，应代回有限和验证，而不是仅凭显示器的四舍五入决定最小 K。

### 18.3 交易可能结束时，先改折现因子，再算期数

如果关系每期以概率 $`\rho`$ 独立延续，时间折现因子为 $`\beta`$，则用于预期收益流比较的有效折现因子是 $`\delta_{\mathrm{eff}}=\beta\rho`$，前提是关系延续概率不受行动影响，且关系终止时没有额外终止收益。

例如 $`\beta=0.9,\rho=0.6`$，有效折现为 $`0.54`$；三期惩罚的折现损失单位和为 $`0.54+0.54^2+0.54^3=0.989064<1`$，四期则增加 $`0.54^4=0.08503056`$，超过 1，因此至少惩罚四期。若 $`\rho=0.55`$，有效折现只有 $`0.495<1/2`$，即使永久惩罚也不足以支持合作，当然不存在有限 K 的解。

以上所有计算仍需核对惩罚状态：对手执行 D 时，自己执行 D 获得 $`P=1>S=0`$，且一次改选 C 不会改变惩罚剩余时间，所以惩罚是可信的。[习题 18](../exercises/lecture-05-exercises.md)将阈值、整数 K、随机终止和惩罚期一次偏离放在同一组问题中检验。
