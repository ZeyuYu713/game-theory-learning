## 1. 为什么“知道对手会理性决策”仍然不够

两家企业准备进入同一市场。企业 A 的生产成本是确定的，企业 B 可能拥有低成本技术，也可能使用较昂贵的传统设备。B 知道自己的成本，A 却只能根据公开信息判断两种情况出现的概率。即使 A 完全相信 B 会最大化利润，也无法提前确定 B 的产量，因为 B 的最优决策取决于 A 不知道的成本。

这种不确定性与“随机乱选策略”不同。B 对自己的成本并不需要随机猜测，它可能确定地按照成本类型选择行动；A 所面对的随机性，来自对 B 私人类型的无知。

在完全信息博弈中，参与人共同知道其他参与人的行动集合和支付函数等模型要素。在不完全信息（incomplete information）博弈中，至少有一个参与人不知道影响收益或决策的某些特征，通常包括成本、估值、风险偏好、能力、质量等。

需要区分两个经常混淆的概念：

| 概念 | 不知道什么 | 一个典型例子 |
| --- | --- | --- |
| 不完全信息（incomplete information） | 对手的某些类型、支付参数或相关特征 | 我不知道竞争企业是高成本还是低成本 |
| 不完美信息（imperfect information） | 行动历史中的某些事实 | 两家企业同时报价，提交时都看不到对方本轮报价 |

一个博弈完全可能同时具有这两种性质。例如双方同时出价，而且彼此不知道对方估值。不完全信息关注“对手是什么类型”，不完美信息关注“行动过程中谁知道发生了什么”。两者不能因为中文名称相近就视为同义词。

## 2. Harsanyi 转换：把未知的支付参数变成自然选择的类型

### 2.1 自然先决定类型

Harsanyi 的处理方法是把私人信息明确写入博弈。用一个没有个人战略利益的虚拟参与人“自然”（Nature）在决策之前按照概率分布抽取类型，再规定各参与人能够观察到什么。

例如企业 B 的边际成本为

```math
c_B\in\{20,40\},
\qquad
\Pr(c_B=20)=0.6,\quad
\Pr(c_B=40)=0.4.
```

自然抽取的成本对 B 可见，对 A 不可见，但两个企业都知道以上类型集合与概率。这里“概率是共同知识”并不意味着企业 A 知道具体抽中了哪一种成本。

更一般地，玩家 $`i`$ 的类型记为 $`\theta_i\in\Theta_i`$。类型的联合概率分布为 $`p(\theta_1,\ldots,\theta_n)`$。对于有限行动和有限类型，可以将贝叶斯博弈表示为

```math
G=\left(N,(A_i)_{i\in N},(\Theta_i)_{i\in N},p,(u_i)_{i\in N}\right).
```

其中 $`u_i(a_1,\ldots,a_n;\theta_1,\ldots,\theta_n)`$ 表示行动与类型给定后的收益。在更一般的模型中，玩家的可行动作也可能随自身类型变化。

### 2.2 联合分布与条件信念

若类型独立，玩家知道自己的类型，也不会改变对别人类型的概率判断。例如

```math
\Pr(\theta_j=H\mid\theta_i=L)
=\Pr(\theta_j=H).
```

如果类型相关，这个等式就不一定成立。设两家企业面临相同的地区需求冲击，观察到自己的订单异常增加，可能提高对竞争对手也处于旺季的判断。此时必须使用条件概率

```math
p(\theta_{-i}\mid\theta_i),
```

而不是一律使用无条件先验概率。题目如果只给出联合概率表，求解前应先算出每种类型对应的条件信念。

## 3. 策略为什么必须是“类型到行动”的完整规则

普通静态博弈中，一名玩家的一项纯策略通常就是一个可选行动。贝叶斯博弈中，玩家在知道自身类型后行动，因此策略必须回答“如果我是每一种类型，会做什么”：

```math
s_i:\Theta_i\longrightarrow A_i.
```

假设一家企业只有两种成本类型 $`L,H`$，每种类型可以选择投资 $`I`$ 或不投资 $`N`$。它的纯策略一共有四种：

| 完整策略 | 低成本类型 $`L`$ | 高成本类型 $`H`$ |
| --- | --- | --- |
| $`(I,I)`$ | 投资 | 投资 |
| $`(I,N)`$ | 投资 | 不投资 |
| $`(N,I)`$ | 不投资 | 投资 |
| $`(N,N)`$ | 不投资 | 不投资 |

因此，“企业选择投资”在没有说明类型时，通常不是这个不完全信息模型中的完整纯策略。对于两种类型、每种类型各有两种行动的参与人，纯策略数量是 $`2^2=4`$，而不是 2。

如果每种类型有 $`k`$ 个可选行动，共有 $`m`$ 个类型，则在行动集合相同的情况下，完整纯策略数为 $`k^m`$。不需要每道题都列出所有策略，但必须明白求解的对象是一个完整的条件规则。

还要区分“类型随机”与“行动混合”。例如有 60% 的人属于低成本类型，这是自然抽取的概率；某个低成本类型在知道自己成本以后，以 70% 的概率选择投资，则是该类型的混合策略。这是两层不同的不确定性，不能把它们的概率互相替代。

## 4. 贝叶斯纳什均衡：对每种类型分别检验最优反应

### 4.1 从普通纳什均衡推到 BNE

普通纳什均衡要求：给定其他玩家的策略，每名玩家都无法通过单方面改变策略提高收益。贝叶斯纳什均衡（Bayesian Nash equilibrium，BNE）保留了这条逻辑，只是玩家不知道对手的真实类型，因此必须根据自己掌握的信息计算期望收益。

在有限类型、有限行动的模型中，给定其他玩家的完整策略 $`s_{-i}^{*}`$，玩家 $`i`$ 对每一种可能的自身类型 $`\theta_i`$ 都应满足

```math
\boxed{
s_i^{*}(\theta_i)\in
\arg\max_{a_i\in A_i}
\sum_{\theta_{-i}}
p(\theta_{-i}\mid\theta_i)
u_i\!\left(
a_i,s_{-i}^{*}(\theta_{-i});
\theta_i,\theta_{-i}
\right)
}.
```

如果是连续类型，求和相应地改为积分；如果使用混合策略，期望还要对对手的随机行动取平均。

这条定义可以按自然语言理解：假设我已经知道自己是哪一种类型，但不知道其他人的真实类型；我以条件概率推测其他类型出现的机会，并相信他们按照各自类型的均衡策略行动；在这种情况下，我当前选择的行动必须是最好的。

其中最容易遗漏的是“对每种类型”。如果一个候选策略能让低成本企业满意，但高成本企业有动机偷偷改成另一种行动，它就不是 BNE。

### 4.2 事前期望、类型条件期望与事后收益

贝叶斯博弈常用三个时间视角描述收益。

事前（ex ante）：自然还没有决定、或玩家尚不知道自己的类型时，对所有可能类型取期望。

中期或类型已知时（interim）：玩家知道自己的类型，仍不知道其他人的类型，按照条件信念计算期望收益。BNE 的最优反应通常在这个层面检验。

事后（ex post）：所有类型和行动都已确定，可以计算实际支付。一个策略在每种已实现状态下都最优，是比贝叶斯最优更强的要求；BNE 一般不需要满足这一点。

例如某人已经知道自己的成本是 40，就应比较“成本为 40 时的投资与不投资”，而不是拿两种成本平均之后替这个高成本类型决定行动。

## 5. 不完全信息市场进入：一张支付矩阵已经不够

考虑两家企业的市场进入问题。在位企业（玩家 1）知道自己的成本类型，进入者（玩家 2）不知道。在位企业可以建设新产能 $`B`$ 或不建设 $`D`$；进入者可以进入 $`In`$ 或不进入 $`Out`$。双方同时决定，因此进入者不能观察在位企业本轮是否建设。

在位企业的高成本类型 $`H`$ 出现概率为 $`p`$，低成本类型 $`L`$ 出现概率为 $`1-p`$。支付按“在位企业、进入者”的顺序书写。

高成本类型的支付矩阵：

| 在位企业 / 进入者 | 进入 $`In`$ | 不进入 $`Out`$ |
| --- | --- | --- |
| 建设 $`B`$ | $`(0,-1)`$ | $`(2,0)`$ |
| 不建 $`D`$ | $`(2,1)`$ | $`(3,0)`$ |

低成本类型的支付矩阵：

| 在位企业 / 进入者 | 进入 $`In`$ | 不进入 $`Out`$ |
| --- | --- | --- |
| 建设 $`B`$ | $`(3,-1)`$ | $`(5,0)`$ |
| 不建 $`D`$ | $`(2,1)`$ | $`(3,0)`$ |

### 5.1 先求知情者的类型依赖最佳反应

如果在位企业是高成本类型 $`H`$，不论进入者选择什么，它都更愿意不建设。进入者进入时，$`D`$ 带来 2、$`B`$ 带来 0；进入者退出时，$`D`$ 带来 3、$`B`$ 带来 2。因此对于 $`H`$ 类型，$`D`$ 严格占优。

如果在位企业是低成本类型 $`L`$，建设产能在进入者进入时带来 3，高于不建的 2；在进入者退出时带来 5，高于不建的 3。因此对于 $`L`$ 类型，$`B`$ 严格占优。

于是玩家 1 的完整策略必定是

```math
\boxed{s_1(H)=D,\qquad s_1(L)=B}.
```

注意这里没有求概率平均值。玩家 1 知道自己的类型，所以两个类型分别比较自己的支付即可。

### 5.2 再求不知道类型的进入者的最佳反应

进入者不知道当前面对哪种类型，但已经知道它们各自会怎么做：高成本类型不建设、低成本类型建设。

进入时，如果遇到 $`H`$ 类型，进入者获得 1；如果遇到 $`L`$ 类型，进入者获得 $`-1`$。所以

```math
\begin{aligned}
EU_2(In)
&=p\times1+(1-p)\times(-1)\\
&=2p-1.
\end{aligned}
```

不进入时收益为零：

```math
EU_2(Out)=0.
```

比较二者便得到

```math
\begin{cases}
p>\frac{1}{2}, & \text{Enter};\\
p<\frac{1}{2}, & \text{Out};\\
p=\frac{1}{2}, & \text{indifferent}.
\end{cases}
```

例如 $`p=0.7`$，进入的期望收益为 0.4，所以完整的纯策略 BNE 为

```math
\boxed{\left((H:D,\ L:B),\ In\right)}.
```

若 $`p=0.3`$，进入的期望收益为 $`-0.4`$，BNE 改为 $`((H:D,\ L:B),Out)`$。若 $`p=0.5`$，进入者在两种行动之间无差异，可以选择任意混合概率；在位企业两种类型的严格占优策略仍然不变。

这个例子说明一件事：在位企业的类型依赖策略可以保持不变，但进入者仅仅因为对类型的先验概率不同，就会改变均衡行动。贝叶斯博弈研究的正是这种“隐藏特征如何改变理性决策”。

## 6. 贝叶斯法则：看见信号之后，原来的概率还能直接用吗

前面的进入者没有观察到关于成本的额外信号。如果进入者能先获得一份技术调查报告，报告未必完全准确，却会改变进入判断。

设 $`H`$ 表示“在位企业是高成本类型”，进入者最初认为

```math
\Pr(H)=0.3,\qquad \Pr(L)=0.7.
```

调查报告可能显示信号 $`S`$，其准确性为

```math
\Pr(S\mid H)=0.8,\qquad
\Pr(S\mid L)=0.1.
```

第一个概率表示高成本企业出现这一信号的概率，第二个概率表示低成本企业被错误标记的概率。进入者观察到信号后，需要计算的是反方向的概率 $`\Pr(H\mid S)`$，它通常不等于 0.8。

根据贝叶斯法则：

```math
\begin{aligned}
\Pr(H\mid S)
&=\frac{\Pr(S\mid H)\Pr(H)}
{\Pr(S\mid H)\Pr(H)+\Pr(S\mid L)\Pr(L)}\\
&=\frac{0.8\times0.3}{0.8\times0.3+0.1\times0.7}\\
&=\frac{24}{31}\approx0.774.
\end{aligned}
```

在没有调查报告时，进入者判断高成本概率为 0.3，低于前面进入门槛 0.5，因此不会进入；观察到信号 $`S`$ 后，高成本后验概率提高到约 0.774，进入成为最优行动。

如果报告没有出现信号 $`S`$，后验为

```math
\Pr(H\mid \neg S)
=\frac{0.2\times0.3}
{0.2\times0.3+0.9\times0.7}
=\frac{2}{23}\approx0.087.
```

此时仍不会进入。两种信号产生不同的后验信念，并可能引起不同的策略选择。

这里采用了“报告在行动选择之前产生且不受当期建设行动影响”的信息结构，因此可以把报告作为外生信号。如果报告是企业自己有策略地发布的，或企业可以选择是否披露，信号就可能传递战略信息，需要进一步研究信号博弈中的发送者激励。

### 6.1 怎样判断一份信号有没有信息含量

若 $`\Pr(S\mid H)=\Pr(S\mid L)`$，说明两种类型同样容易产生 $`S`$，观察它不会改变先验概率。若两项概率差异很大，信号的区分能力通常更强，但后验仍受先验概率影响。

条件概率的方向必须写清楚：

| 概率 | 解释 |
| --- | --- |
| $`\Pr(S\mid H)`$ | 已知高成本，报告出现信号的概率 |
| $`\Pr(H\mid S)`$ | 已知报告出现信号，实际高成本的概率 |
| $`\Pr(H)`$ | 没看到报告之前的高成本先验概率 |

做题时最安全的办法是先画出“类型 → 信号”的概率树，再用“某条路径的联合概率 ÷ 该信号出现的总概率”求后验。

## 7. 真正的混合 BNE：不同类型可能以不同概率参与公共品供给

上面的市场进入题中，知情者具有严格占优行动，类型策略相对容易确定。贝叶斯博弈也可能出现需要认真求解的混合均衡，而且混合概率必须针对具体类型。

考虑两名参与人各自决定是否承担一次公共品建设任务。只要至少一人出资，两人都得到收益 3；如果无人出资，收益都是 0。出资者还要承担自己的成本。

每人的私人成本是低成本 $`c_L=2`$ 或高成本 $`c_H=4`$，两类各以概率 $`1/2`$ 独立出现。每个人知道自己的成本，但不知道对方成本。行动是出资 $`C`$ 或不出资 $`N`$，两人同时选择。

高成本类型如果出资，无论对方怎样行动，都获得 $`3-4=-1`$；如果不出资，收益至少为 0。因此高成本类型必然不出资。

低成本类型如果出资，公共品必定建成，自己的收益为 $`3-2=1`$。如果不出资，只有对方出资时才能获得收益 3。

假设双方使用相同的类型依赖混合策略：低成本类型以概率 $`s`$ 出资，高成本类型从不出资。站在其中一名低成本参与人看来，对方出资的总概率为

```math
\Pr(C_{-i})=\frac{1}{2}s.
```

所以低成本类型选择不出资的期望收益为

```math
EU_L(N)=3\times\frac{s}{2}=\frac{3s}{2},
```

出资的期望收益始终为

```math
EU_L(C)=1.
```

如果低成本类型确实要在 $`C`$ 和 $`N`$ 之间混合，就必须对两种行动无差异：

```math
1=\frac{3s}{2}
\quad\Longrightarrow\quad
\boxed{s=\frac{2}{3}}.
```

因此存在一个对称的混合 BNE：

```math
\boxed{
\Pr(C\mid L)=\frac{2}{3},
\qquad
\Pr(C\mid H)=0
}.
```

验证也很直接。高成本类型出资必亏，不愿偏离；低成本类型面对对方的均衡策略，出资与不出资的收益同为 1，确实可以混合。

注意“低成本类型以 $`2/3`$ 概率出资”并不意味着总体出资概率为 $`2/3`$。随机抽取一名参与人，其出资的事前概率为

```math
\Pr(C)=\frac{1}{2}\times\frac{2}{3}+\frac{1}{2}\times0=\frac{1}{3}.
```

两人独立，因而公共品最终至少由一人出资的概率为

```math
\Pr(\mathrm{provided})=1-\left(1-\frac{1}{3}\right)^2
=\frac{5}{9}.
```

这个模型还可能存在非对称均衡；此处求的是对称混合 BNE。它同时展示了两种概率：自然选择类型的概率 $`1/2`$，以及某种类型在给定信息下自主混合行动的概率 $`2/3`$。两者的含义和计算位置都不同。

## 8. 不完全信息 Cournot：一个企业不知道另一个企业的成本

Cournot 模型在前两讲的静态博弈内容中已经出现。完全信息版本中，两家企业都知道对方的成本，可以根据竞争对手的产量求最佳反应，最后联立求解。现在只改一个条件：企业 1 知道自己的成本，但不知道企业 2 属于哪一种成本类型。

设市场逆需求函数为

```math
P=a-q_1-q_2.
```

企业 1 的单位成本为 $`C`$，这是共同知识。企业 2 的单位成本只有两个可能值：

```math
\begin{cases}
C_L, & \text{with probability }\theta,\\
C_H, & \text{with probability }1-\theta,
\end{cases}
\qquad C_L<C_H.
```

企业 2 在决定产量前知道自己的成本；企业 1 只知道两种类型及其概率。两家同时选择产量，企业 1 选择一个数 $`q_1`$，企业 2 的完整策略则要给出两个数：

```math
\boxed{(q_1,q_L,q_H)}.
```

这里 $`q_L`$ 是企业 2 低成本时的产量，$`q_H`$ 是高成本时的产量。不能让企业 2 在已经知道真实成本后，还按两种成本的平均值去决定自己生产多少。

### 8.1 企业 1 的利润最大化

企业 1 不知道对方最终生产多少，但它知道两种类型各自将选择的产量。由于逆需求函数是线性的，企业 1 的期望利润为

```math
\begin{aligned}
\mathbb E[\pi_1]
&=\theta(a-q_1-q_L-C)q_1\\
&\quad +(1-\theta)(a-q_1-q_H-C)q_1\\
&=[a-C-q_1-\theta q_L-(1-\theta)q_H]q_1.
\end{aligned}
```

令预期竞争产量

```math
\bar q_2=\theta q_L+(1-\theta)q_H.
```

那么

```math
\mathbb E[\pi_1]=(a-C-q_1-\bar q_2)q_1.
```

在产量为正的内部解情形，对 $`q_1`$ 求一阶条件：

```math
\frac{\partial\mathbb E[\pi_1]}{\partial q_1}
=a-C-2q_1-\bar q_2=0.
```

因此企业 1 的最佳反应是

```math
\boxed{q_1=\frac{a-C-\bar q_2}{2}}.
```

这个式子与完全信息 Cournot 的形式类似，只是原来确定的竞争对手产量改成了按类型加权的预期产量。能够这样简化，依赖当前线性需求及风险中性、确定本企业产量等假设；不能不加分析地推广到所有非线性收益模型。

### 8.2 企业 2 的两种类型分别最大化利润

企业 2 知道自身成本，因此低成本类型的问题是

```math
\max_{q_L\geq0}
(a-q_1-q_L-C_L)q_L.
```

对应内部最优条件 $`a-q_1-C_L-2q_L=0`$。同样，高成本类型的问题给出另一条最佳反应：

```math
\boxed{q_L=\frac{a-C_L-q_1}{2}},
\qquad
\boxed{q_H=\frac{a-C_H-q_1}{2}}.
```

注意两个类型对企业 1 的产量 $`q_1`$ 有相同判断，但由于自身成本不同，选择的最优产量不同。

### 8.3 联立三个最佳反应

先计算企业 2 的预期产量。定义预期成本为

```math
\bar C=\theta C_L+(1-\theta)C_H.
```

则

```math
\begin{aligned}
\bar q_2
&=\theta\frac{a-C_L-q_1}{2}
+(1-\theta)\frac{a-C_H-q_1}{2}\\
&=\frac{a-\bar C-q_1}{2}.
\end{aligned}
```

代回企业 1 的最佳反应：

```math
\begin{aligned}
q_1
&=\frac{a-C-\frac{1}{2}(a-\bar C-q_1)}{2},\\
4q_1&=a-2C+\bar C+q_1,\\
3q_1&=a-2C+\bar C.
\end{aligned}
```

于是

```math
\boxed{q_1^{*}=\frac{a-2C+\bar C}{3}}.
```

再代回两种类型的最佳反应，可以写成

```math
\boxed{q_L^{*}=\frac{a-C_L-q_1^{*}}{2}},
\qquad
\boxed{q_H^{*}=\frac{a-C_H-q_1^{*}}{2}}.
```

也可把 $`q_1^{*}`$ 展开成只含外生参数的形式：

```math
\begin{aligned}
q_L^{*}
&=\frac{a-2C_L+C}{3}
-\frac{(1-\theta)(C_H-C_L)}{6},\\
q_H^{*}
&=\frac{a-2C_H+C}{3}
+\frac{\theta(C_H-C_L)}{6}.
\end{aligned}
```

这些公式假定三个产量都严格为正。如果成本太高，公式计算出负产量，经济上不能直接接受，应把 $`q_i\geq0`$ 的约束加入最优反应，分情形重新求解边界均衡。

### 8.4 完整算一道数字题

设 $`a=90`$，企业 1 成本 $`C=30`$，企业 2 低成本 20、高成本 40，概率各为 $`1/2`$。

首先有

```math
\bar C=\frac{1}{2}(20)+\frac{1}{2}(40)=30.
```

企业 1 的最优产量为

```math
q_1^{*}=\frac{90-2(30)+30}{3}=20.
```

企业 2 两种类型分别生产

```math
q_L^{*}=\frac{90-20-20}{2}=25,
\qquad
q_H^{*}=\frac{90-40-20}{2}=15.
```

所以完整 BNE 是

```math
\boxed{(q_1^{*},q_L^{*},q_H^{*})=(20,25,15)}.
```

还可以按类型计算市场价格和利润，验证这个结果的经济含义：

| 企业 2 的真实类型 | $`q_1`$ | $`q_2`$ | 市场价格 $`P`$ | 企业 1 利润 | 企业 2 利润 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 低成本 20 | 20 | 25 | 45 | 300 | 625 |
| 高成本 40 | 20 | 15 | 55 | 500 | 225 |

例如遇到低成本对手时，价格为 $`90-20-25=45`$，企业 1 的利润是 $`(45-30)\times20=300`$；遇到高成本对手时，价格上升到 55，企业 1 的利润为 500。因此企业 1 在报价之前的期望利润为 $`0.5(300)+0.5(500)=400`$。

这一例子很适合检查“平均成本”与“类型依赖策略”的差别。企业 1 的均衡产量恰好等于把企业 2 的成本设为 30 后求得的完全信息产量 20；但企业 2 实际并不永远生产 20，而是成本低时生产 25、成本高时生产 15。这种数值巧合来自模型的线性结构，不能据此认为“把类型取平均”就是求 BNE 的通用方法。

## 9. 第一价格密封拍卖：出价既影响胜率，也影响成交后的利润

拍卖是贝叶斯博弈最常见的应用之一。买家清楚自己对商品的估值，但通常不知道其他买家的估值，所以每个人的出价既反映自身价值，也取决于对竞争强度的判断。

先讨论最简单的独立私人价值拍卖。两名竞标者风险中性，各自估值 $`v_i`$ 独立服从 $`U[0,1]`$。两人同时提交密封报价，最高报价者获得物品，并支付自己报出的价格；未中标者不支付、收益为零。先忽略平局，因为连续估值和严格递增的对称报价策略下，平局概率为零。

### 9.1 为什么不能直接报真实估值

假设一名竞标者的估值是 $`v=0.8`$。如果他总是报 0.8，即使中标，也没有任何净收益。稍微降低报价可能减少中标概率，但在赢的时候能留下一部分收益。第一价格拍卖需要权衡这两种效果。

猜测两位竞标者采用相同的线性策略

```math
b(t)=\frac{t}{2}.
```

现在站在估值为 $`v`$ 的某一位竞标者角度，假设对手遵守这一规则。若自己出价 $`b\in[0,1/2]`$，只有当对手估值 $`t<2b`$ 时才赢。由于 $`t`$ 服从均匀分布，

```math
\Pr(\mathrm{win}\mid b)=2b.
```

中标后净收益为 $`v-b`$，所以期望收益为

```math
\begin{aligned}
EU(b\mid v)
&=(v-b)\Pr(\mathrm{win}\mid b)\\
&=(v-b)2b\\
&=2vb-2b^2.
\end{aligned}
```

对出价求导：

```math
\frac{\partial EU}{\partial b}
=2v-4b.
```

一阶条件给出 $`b=v/2`$，二阶导数为 $`-4<0`$，因此是该区间的最大值。若出价超过 $`1/2`$，中标概率已经达到 1，再提高报价只会减少收益；若出价为负或超过自身估值，也不会改善最优结果。

因此面对对手的 $`b(t)=t/2`$，每一种私人估值 $`v`$ 的最佳反应也是

```math
\boxed{b^{*}(v)=\frac{v}{2}}.
```

双方都按照这条规则出价时，每一种类型都不想偏离，所以这构成对称 BNE。这种低于真实估值的报价称为出价压低（bid shading）。

比如估值为 0.8 的人出价 0.4，赢的概率为 0.8，中标后的净收益为 0.4，期望收益为 0.32。真实报价 0.8 虽然确保中标，却让中标后的净收益降为零，显然不是更优策略。

### 9.2 竞标者不止两个人会怎样

假设有 $`n`$ 名风险中性竞标者，私人估值独立服从 $`U[0,1]`$，且规则仍为第一价格密封拍卖。对称均衡报价函数为

```math
\boxed{b(v)=\frac{n-1}{n}v}.
```

可以用偏离检验理解它。假设其他 $`n-1`$ 人都采用这一规则，估值为 $`v`$ 的人暂时按照估值 $`z`$ 的规则报价，即报 $`(n-1)z/n`$。要赢就必须所有其他人的估值都不超过 $`z`$，中标概率为 $`z^{n-1}`$，因此

```math
EU(z\mid v)
=\left(v-\frac{n-1}{n}z\right)z^{n-1}.
```

对于内部选择，一阶导数为

```math
\frac{\partial EU}{\partial z}
=(n-1)z^{n-2}(v-z).
```

导数在 $`z<v`$ 时为正，在 $`z>v`$ 时为负，因此最优选择是 $`z=v`$，即遵守猜测的策略。边界情况也与这一最优选择一致。

当 $`n=2`$ 时回到 $`b=v/2`$；当 $`n=5`$ 时变为 $`b=4v/5`$。竞标人数增多，压低出价的幅度减小，因为过低出价更容易被其他竞标者超过。

这条通式依赖独立、同分布、均匀估值、风险中性和对称递增报价策略。若估值分布改变，仍能建立期望收益最大化问题，但一般不能把 $`(n-1)/n`$ 当成固定系数直接使用。

## 10. 第二价格密封拍卖：支付规则为什么会改变最优策略

第二价格密封拍卖与第一价格拍卖只有一处不同：最高报价者依然中标，但只需要支付第二高报价，而不是自己的报价。

设某名竞标者对物品的真实估值为 $`v`$，其他竞标者中的最高报价为 $`m`$。若他中标，支付额为 $`m`$，净收益是 $`v-m`$；若他不中标，收益为零。

可以逐个比较。

如果 $`v>m`$，中标带来正收益，理想行动是使自己的报价超过 $`m`$。如果 $`v<m`$，中标会亏损，理想行动是不超过 $`m`$。如果两者相等，赢和输在货币收益上无差异。

报出真实估值 $`b=v`$，恰好能够在所有可能的 $`m`$ 下实现上述选择。因此在标准私人价值、准线性效用且没有预算约束或外部效应的环境中，

```math
\boxed{b(v)=v}
```

是弱占优策略。这里“弱占优”表示任何其他报价都不会在所有对手报价下更好，而不是说真实报价在每一种状态下都严格领先。

例如估值为 80，其他人的最高报价为 65。报 80 可以赢并支付 65，净收益 15。报 100 在这个具体情形中也会赢并支付 65，看起来并没有损失；但如果其他人的最高报价改成 90，报 100 就会以 90 赢得一件只值 80 的商品，净亏 10。报 80 则会自动退出这笔不划算的交易。

第一价格拍卖和第二价格拍卖的差异可以概括为：在第一价格拍卖里，自己的报价影响胜负，也影响中标后的付款；在第二价格拍卖里，自己的报价主要决定是否中标，一旦中标，付款由他人的最高报价决定。

需要留意，第二价格拍卖真实报价的弱占优性不要求私人估值一定是均匀分布，也不必通过求最佳反应才成立。不过一旦买家对物品价值存在共同不确定性、预算限制、串通或外部效应，标准结论就可能不再适用。

### 10.1 原课件第 64–65 页：拍卖收入等价定理及其证明

第一价格拍卖中，竞标者为了留下中标利润，通常会报出低于估值的价格；第二价格拍卖中，真实报价却是弱占优策略。两种机制的报价明显不同，那么卖家从中获得的收入是否也不同？原课件第 64–65 页介绍的<strong>收入等价定理（Revenue Equivalence Theorem）</strong>回答了这个问题。

该定理不能简化为“任何拍卖都一样”。它比较的是一类满足特定信息、分配和支付条件的拍卖，结论首先涉及<strong>给定私人估值时的事前期望支付</strong>，然后才能对估值取平均，得到卖家总收入的期望。

#### 10.1.1 定理的适用条件与结论

考虑 $`n\ge2`$ 名竞标者争夺一件不可分物品。每位竞标者 $`i`$ 知道自己对物品的私人估值 $`v_i`$，各人的估值独立、同分布，公共累积分布函数为 $`F`$，估值位于 $`[0,\bar v]`$。所有人风险中性，收益等于物品带来的估值减去支付额。令拍卖规则为 $`A`$，假定它满足：

1. <strong>标准拍卖与相同分配规则。</strong> 出价最高者赢得物品；在比较的对称递增均衡中，估值最高者中标。不存在改变这一分配规则的保留价或额外限制。
2. <strong>独立同分布的私人估值。</strong> 一个人是否中标，可由其他 $`n-1`$ 名竞标者的估值分布计算；竞争对手之间不具有原模型以外的估值相关性。
3. <strong>风险中性与对称、递增的均衡出价策略。</strong> 在对称递增策略下，自己的出价次序和估值次序一致。下面为展示课件的一阶条件证明，进一步采用连续、可微以及相关区间内严格递增的常规情形。
4. <strong>相同的支付边界条件。</strong> 估值为 0 的竞标者的期望支付为 0，即 $`m_A(0)=0`$。

在这些条件下，不论标准拍卖 $`A`$ 的具体支付规则怎样，只要处于相应的对称递增均衡，<strong>估值为 $`v`$ 的竞标者具有相同的期望支付函数 $`m(v)`$</strong>，因此卖家的期望总收入也相同。这是一项关于均衡期望支付的结论，<strong>不要求不同机制下的实际出价相同、每次成交价格相同，或每个估值实现下的收入相同</strong>。

#### 10.1.2 第一步：从私人估值计算获胜概率

固定竞标者 1，令其他 $`n-1`$ 名竞标者的最高私人估值为：

```math
Y=\max\{v_2,v_3,\ldots,v_n\}.
```

如果竞标者 1 的估值为 $`v`$，在对称严格递增的均衡策略下，他获胜当且仅当其他所有人的估值都低于 $`v`$。独立性意味着这 $`n-1`$ 个事件的概率可以相乘，所以：

```math
G(v)=\Pr(Y\le v)=\prod_{j=2}^{n}F(v)=\boxed{F(v)^{n-1}}.
```

连续型估值下平局的概率为 0，因此这里使用 $`<`$ 还是 $`\le`$ 不改变获胜概率。若 $`F`$ 有密度 $`f`$，对 $`G`$ 求导得到：

```math
g(v)=G'(v)=(n-1)F(v)^{n-2}f(v).
```

这里的 $`G(v)`$ 是<strong>最高对手估值的累积分布函数，同时也是本人的中标概率</strong>；$`g(v)`$ 是该随机变量的密度，不能直接将二者都写成单个竞标者的分布 $`F`$。

#### 10.1.3 第二步：把偏离报价写成效用函数

设某拍卖机制 $`A`$ 的对称均衡报价函数为 $`\beta_A(v)`$。为了检查一种类型为 $`v`$ 的竞标者是否愿意偏离，让他暂时不按真实类型对应的出价行动，而是报出类型 $`x`$ 在均衡中会报出的价格 $`\beta_A(x)`$。

因为其他人仍遵守递增策略，自己这样报价的获胜概率是 $`G(x)`$。记 $`m_A(x)`$ 为出价 $`\beta_A(x)`$ 所带来的<strong>不计自身估值、包括胜负各状态在内的期望支付</strong>。风险中性下，偏离后的期望效用为：

```math
U_A(x;v)=vG(x)-m_A(x).
```

这个公式有两部分。$`vG(x)`$ 是得到物品的期望价值，$`m_A(x)`$ 是拍卖规则所确定的预期期望付款。对第一价格拍卖，后者通常等于中标概率乘自己的报价；对第二价格拍卖，后者等于中标概率乘中标时支付的对手最高报价的条件期望。定理并不预先规定两者相等，而是要<strong>从均衡最优性推导相等</strong>。

#### 10.1.4 第三步：利用贝叶斯纳什均衡的一阶条件

既然 $`\beta_A`$ 是均衡报价策略，对每个内部估值 $`v`$ 而言，按该类型对应的报价行动，即选择 $`x=v`$，必须优于选择其他 $`x`$。在可微的内部解中有：

```math
\left.\frac{\partial U_A(x;v)}{\partial x}\right|_{x=v}=0.
```

对 $`U_A(x;v)`$ 求导时，$`v`$ 是该竞标者真实且固定的私人估值，只有假装报告的 $`x`$ 在变化：

```math
\frac{\partial U_A(x;v)}{\partial x}
=v g(x)-m_A'(x).
```

在均衡对应点 $`x=v`$，得到：

```math
vg(v)-m_A'(v)=0
\quad\Longrightarrow\quad
\boxed{m_A'(v)=vg(v)}.
```

注意这里<strong>不是</strong>对 $`vG(v)-m_A(v)`$ 直接求总导数并令其为零：真实类型 $`v`$ 本身不是决策变量。正确顺序是固定 $`v`$，先对假设的报价类型 $`x`$ 求偏导，再代入最优条件 $`x=v`$。

#### 10.1.5 第四步：利用零估值支付条件，积分确定唯一支付函数

沿着估值从 0 到 $`v`$ 积分：

```math
m_A(v)-m_A(0)=\int_0^v t g(t)\,dt.
```

根据课件的边界条件 $`m_A(0)=0`$：

```math
\boxed{m_A(v)=\int_0^v t g(t)\,dt}.
```

由于 $`g=G'`$，对积分做分部积分，还可写成：

```math
m_A(v)=vG(v)-\int_0^v G(t)\,dt.
```

而从最高对手估值的条件分布出发，又得到：

```math
m_A(v)=G(v)\,\mathbb E[Y\mid Y<v].
```

最后这个表达与课件前面第一价格和第二价格拍卖的预期支付公式直接衔接。最重要的是：<strong>最终表达式只含估值分布 $`F`$、竞标人数 $`n`$ 和零点支付条件，没有出现拍卖规则 $`A`$ 的具体形式。</strong> 因此任意两种满足上述条件的标准拍卖 $`A`$ 和 $`B`$，均有：

```math
m_A(v)=m_B(v)=\int_0^v t g(t)\,dt.
```

收入等价还可从类型 $`v`$ 的均衡期望效用检验。因为 $`u(v)=vG(v)-m(v)`$：

```math
u(v)=\int_0^v G(t)\,dt.
```

也就是说，在定理条件下，同一估值的竞标者在不同标准机制中的<strong>期望效用</strong>同样一致。这是支付等价与配置等价共同得到的推论，不代表竞标者在各机制中承担的价格风险也完全一样。

#### 10.1.6 第五步：从个人支付得到卖家期望收入

个人期望支付函数 $`m(v)`$ 把“我的估值已知为 $`v`$”作为条件。对卖家来说，尚未观察竞标者的实际私人估值，必须再按 $`F`$ 对 $`v`$ 取平均。假设所有竞标者对称，则卖家总收入的期望为：

```math
\mathbb E[R_A]
=\sum_{i=1}^n\mathbb E[m_A(V_i)]
=n\int_0^{\bar v}m_A(v)f(v)\,dv.
```

由于各标准拍卖具有相同 $`m_A(v)`$，其期望卖家收入自然相同。但一次具体拍卖中，第一价格拍卖的成交价是赢家自己的报价，第二价格拍卖的成交价是第二高报价；具体实现的收入完全可能不同。

#### 10.1.7 例子：$`n`$ 人估值独立均匀分布

取 $`V_i\sim U[0,1]`$，则 $`F(v)=v`$，因此：

```math
G(v)=v^{n-1},\qquad
g(v)=(n-1)v^{n-2}.
```

代入收入等价支付公式：

```math
\begin{aligned}
m(v)
&=\int_0^v t(n-1)t^{n-2}\,dt\\
&=(n-1)\int_0^v t^{n-1}\,dt\\
&=\boxed{\frac{n-1}{n}v^n}.
\end{aligned}
```

与第一价格拍卖核对：均衡报价 $`\beta_I(v)=(n-1)v/n`$；以概率 $`v^{n-1}`$ 中标并支付自己的报价，得到：

```math
m_I(v)=v^{n-1}\frac{n-1}{n}v=\frac{n-1}{n}v^n.
```

与第二价格拍卖核对：真实报价 $`\beta_{II}(v)=v`$；中标时支付最高对手估值 $`Y`$，而均匀分布下：

```math
\mathbb E[Y\mid Y<v]=\frac{n-1}{n}v.
```

因此：

```math
m_{II}(v)=v^{n-1}\mathbb E[Y\mid Y<v]
=\frac{n-1}{n}v^n=m_I(v).
```

例如三名竞标者、某人估值为 0.6，中标概率是 $`0.6^2=0.36`$。第一价格拍卖的均衡出价为 $`0.4`$，所以该人的事前期望支付为 $`0.36\times0.4=0.144`$；第二价格拍卖时他报 0.6，但只有中标才付款，且在中标条件下平均支付也是 0.4，故期望支付同样为 0.144。<strong>两种机制的报价不同，期望支付相同。</strong>

最后对均匀估值 $`v\in[0,1]`$ 积分，计算整个拍卖的卖家期望收入：

```math
\begin{aligned}
\mathbb E[R]
&=n\int_0^1\frac{n-1}{n}v^n\,dv\\
&=(n-1)\frac{1}{n+1}\\
&=\boxed{\frac{n-1}{n+1}}.
\end{aligned}
```

两名竞标者时，卖家期望收入是 $`1/3`$；三名竞标者时为 $`1/2`$。后一结果也可以直接用第二价格拍卖的第二高估值的期望来核对。

#### 10.1.8 哪些条件变化后，不能直接援用收入等价

<strong>风险厌恶：</strong>第一价格拍卖中的价格和盈利风险可能改变最佳报价，因此基于线性效用写出的 $`U_A=vG-m_A`$ 不再适用。<strong>估值相关或竞标者不对称：</strong>中标概率不一定仍是共同的 $`F(v)^{n-1}`$，即使存在均衡也不能直接套用同一支付公式。<strong>保留价或其他配置规则改变：</strong>估值最高者不一定总能获得商品，不能再假设不同拍卖的中标概率函数完全一样。<strong>最低类型的预期支付不同：</strong>即使导数关系相同，积分常数不同也会使期望支付出现差异。<strong>共同价值或预算约束：</strong>类型和效用结构发生变化，前述独立私人价值证明不再直接成立。

因此，判断一题能否使用收入等价定理，应该先检查<strong>价值模型、胜率规则、风险偏好、均衡的单调性和最低类型支付</strong>，再计算支付。第七讲习题第 18 题给出了从定理证明到均匀分布数值结果的完整训练。

## 11. 私人价值与共同价值：为什么拍卖会出现“赢家的诅咒”

独立私人价值模型中，一件商品对我的价值是 $`v_i`$，我自己知道它，不需要因为别人出价而改变对 $`v_i`$ 的判断。例如同一幅画对不同收藏家的审美价值不同。

共同价值（common value）模型则不同：物品有一个对所有人相同、但在竞价前未知的实际价值，各人只拿到带噪声的私人估计。矿产勘探权就是典型例子：地下真正有多少矿石对所有中标者都一样，但各投标人的勘探信号可能不同。

如果每个人简单按照自己的估计报价，最高价者往往是估计最乐观的人。赢得拍卖本身就是一个信息事件——它说明其他人的报价、进而可能说明其他人的信号并不高。中标者若忽略这个条件信息，可能系统性高估物品的真实价值。这种现象被称为赢家的诅咒（winner's curse）。

因此共同价值拍卖中的决策应考虑

```math
\mathbb E[V\mid S_i,\mathrm{win}],
```

而不只是 $`\mathbb E[V\mid S_i]`$。这里的 $`V`$ 是未知的共同价值，$`S_i`$ 是竞标者自己观察到的估值信号。两项条件期望不同，意味着不能直接照搬私人价值第二价格拍卖的真实估值报价规则。

这也展示了贝叶斯博弈中一个重要的特点：观察到的“我赢了”本身就可能改变我对状态的判断。信息不仅来自正式公布的检测报告，也可能来自战略互动所产生的结果。

## 12. 逆向选择：交易对象的类型会因价格而改变

前面的贝叶斯博弈通常先给定类型概率，再让参与人行动。但交易市场还有一个更深的问题：潜在交易者会根据自己掌握的私人信息决定是否参与，因此真正进入市场的人群不一定仍保持原来的类型比例。

考虑二手设备市场，设备有高质量 $`H`$ 和低质量 $`L`$ 两种类型，事前概率各为 $`1/2`$。卖家了解设备质量，买家在交易前不能准确辨别。

| 质量类型 | 卖家的最低可接受价格 | 买家的最高愿付价格 |
| --- | ---: | ---: |
| 高质量 $`H`$ | 70 | 100 |
| 低质量 $`L`$ | 20 | 40 |

单独观察每一种质量，都有潜在的交易剩余：高质量为 $`100-70=30`$，低质量为 $`40-20=20`$。因此“交易失败”不一定意味着设备毫无经济价值，而可能是信息结构妨碍了达成协议。

### 12.1 如果统一价格为 60

高质量卖家最低愿收 70，因此不愿按 60 出售；低质量卖家最低愿收 20，愿意按 60 出售。

买家即使原来相信两种质量各占一半，在知道卖家的参与决策之后，也会发现真正愿意按 60 出售的只有低质量卖家。于是待售设备的条件质量判断应改为

```math
\Pr(L\mid \mathrm{listed\ at\ }60)=1.
```

买家对当前待售设备的估值因此是 40，而不是原先的平均估值

```math
\frac{1}{2}(100)+\frac{1}{2}(40)=70.
```

既然估值 40 小于价格 60，买家不会购买。这是一个在给定价格下无法完成交易的例子。

### 12.2 如果统一价格为 35

高质量卖家仍然不愿出售，低质量卖家愿意出售；但买家知道待售设备是低质量，估值为 40，大于价格 35，因此可以成交。

价格变化在这里引起了两件事：它改变了哪种卖家愿意出售，也改变了买家对待售商品的后验质量判断。不能把“事前所有设备中高质量的比例”和“已决定挂牌设备中高质量的比例”混为一谈。

这个例子说明逆向选择（adverse selection）的机制。它只比较了两个给定价格下的参与和交易决策；若题目要求求市场均衡，就还需要规定谁定价、买家数量、是否允许讨价还价以及市场竞争方式。

### 12.3 逆向选择与道德风险并不相同

逆向选择通常发生在契约或交易之前，关键是参与人的某些既有特征不能被另一方观察。例如投保人比保险公司更了解自己的事故风险。

道德风险（moral hazard）通常关注契约建立后，某方的行动不能被完全观察或监督，例如投保之后是否仍然谨慎驾驶。前者偏向隐藏类型，后者偏向隐藏行动。两者可能同时存在，但建模时不能用一个概率参数混过去。

## 13. 信息的价值：更多信息是否总会让参与人受益

如果其他人的策略固定不变，而且一个额外的私人信号完全免费、可以选择忽略，那么对某个决策者而言，信息不会降低其最优期望收益。因为他收到信号后，至少仍可照旧采用没有信号时的行动。

但博弈中的信息环境变化常常会改变对手的反应。例如市场公布各企业成本信息后，竞争对手会重新优化产量；谈判中公开保留价格，可能使另一方调整报价；拍卖中公开估值线索，可能改变所有人的竞标行为。此时比较的是两个不同信息结构下的均衡，而不是仅仅给某个人一条可以自由忽略的私人消息。

所以“私人、免费、可忽略的额外信息不会降低固定环境下的最优值”与“信息公开后某人的均衡收益可能下降”并不矛盾。前者固定了其他人的策略；后者允许战略互动随信息一起改变。

分析信息披露政策时，应明确谁获得信息、是否共同知道、信息是否可验证，以及获得信息之后哪些参与人能够重新选择策略。仅比较信号准确率或预测误差，并不能直接判断博弈中的收益变化。

## 14. 贝叶斯博弈与动态贝叶斯博弈的边界

本讲主要研究：自然先确定类型，玩家在知道各自信息后选择行动，均衡要求每种类型在自己的条件信念下都没有获益偏离。市场进入、同时产量竞争、密封投标都可以放入这一框架。

如果行动不再同时完成，而是出现“先观察一方的行动，再决定自己怎么做”，问题会增加新的要求。

例如低成本企业和高成本企业先决定是否降价，外部投资人观察降价后再决定是否注资。如果不同类型的企业都可能降价，投资人就必须在观察降价后形成后验信念；而企业在选择降价时，也会预期投资人如何理解自己的行为。这时单纯列出静态 BNE 往往不足以描述序贯决策。

后续的动态贝叶斯博弈将引入信号发送、类型模仿、信念更新、池化与分离，以及完美贝叶斯均衡（PBE）。本讲先把类型、条件期望和类型依赖最佳反应打牢，是理解那些模型的前提。

## 15. 如何完整写出一道 BNE 题的解答

面对不完全信息题目，不妨先在草稿纸上写四句话：谁知道什么？不知道的人以什么概率相信对手是哪种类型？每种类型分别可以采取什么行动？拒绝某个候选策略之后，是否有任何一种类型能赚得更多？

接下来把它们落实为数学计算。先列全类型集合与概率，必要时计算条件分布；给每种知情者类型分别写收益函数；对不知道真实类型的玩家，按照均衡候选策略求条件期望收益；联立所有参与人的最佳反应条件，并检查边界和无差异情形。

常见失误包括：

| 失误 | 正确处理 |
| --- | --- |
| 把类型概率直接当成某一类型的混合行动概率 | 分别写清自然抽取类型与玩家自主随机行动的概率 |
| 用一个“平均类型”的行动代替完整策略 | 每一种私人类型都要满足自己的最优反应 |
| 不区分 $`\Pr(S\mid H)`$ 与 $`\Pr(H\mid S)`$ | 按贝叶斯法则从似然和先验求后验 |
| 只求出知情者策略就宣称得到 BNE | 还需验证其他参与人的期望收益最佳反应 |
| 忽略在无差异点可能存在混合均衡 | 将两种行动的期望收益设为相等，并检查混合概率范围 |
| 把第一价格拍卖的折价规则用于第二价格拍卖 | 先核对赢家支付自己的报价还是次高报价 |
| 直接套用内部 Cournot 产量公式 | 若结果为负，应重新处理非负产量约束 |

最后还要检查答案的完整性。若玩家 1 有两种私人成本类型，答案不能只写“玩家 1 投资”，而应写明 $`s_1(L)`$ 与 $`s_1(H)`$；若玩家 2 混合进入和退出，则要给出其混合概率；若模型包含可观察信号，则要说明行动前使用的是哪一个后验分布。
