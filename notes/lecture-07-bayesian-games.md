# Lecture 7｜贝叶斯博弈：类型、信念与不完全信息竞争

<strong>Bayesian Games and Bayesian Nash Equilibrium</strong>

## 1. 信息不完全与行动不可观察不是一回事

在完全信息博弈中，各人的支付函数、行动集合等结构为共同知识。不完全信息（incomplete information）意味着至少有某人不知道别人的某些相关特征，例如成本水平、产品质量、支付偏好或行动能力。

不完美信息（imperfect information）则指在某个行动节点不能确定先前发生了什么。一个完全信息博弈也可以具有不完美信息，例如两人虽然都知道支付矩阵，却同时决定是否投资。<strong>贝叶斯博弈主要处理“我不确定对手是什么类型”这一问题。</strong>

## 2. 类型、自然与 Harsanyi 转换

玩家 $`i`$ 的私人类型记为 $`\theta_i\in\Theta_i`$，可能代表成本、估值或能力。自然（Nature）首先按照共同知道的概率分布 $`p(\theta_1,\ldots,\theta_n)`$ 确定类型；玩家观察自己的类型，但未必观察对手类型。每人根据所拥有的信息选择行动。

贝叶斯博弈可写为

```math
G=(N,(A_i),(\Theta_i),p,(u_i)).
```

最重要的概念变化是：<strong>策略不再只是一项行动，而是从私人类型到行动的映射</strong>：

```math
s_i:\Theta_i\longrightarrow A_i.
```

例如一家企业的成本可能是低 $`L`$ 或高 $`H`$，则策略“低成本时扩产，高成本时保守生产”是一项完整策略；仅写“扩产”没有回答高成本类型怎么做。

## 3. 贝叶斯纳什均衡（BNE）

给定自己的类型 $`\theta_i`$，参与人以条件信念 $`p(\theta_{-i}\mid\theta_i)`$ 计算行动的条件期望收益。贝叶斯纳什均衡要求每一种类型选择的行动都最优：

```math
s_i^{*}(\theta_i)\in\arg\max_{a_i\in A_i}\sum_{\theta_{-i}}p(\theta_{-i}\mid\theta_i)u_i\bigl(a_i,s_{-i}^{*}(\theta_{-i}),\theta_i,\theta_{-i}\bigr).
```

和普通纳什均衡相比，其核心并没有改变——仍然排除有利单方偏离；区别在于需要<strong>分别检验每一种可能的私人类型</strong>，并使用该类型的条件概率对不知道的状态取期望。

## 4. 典型例题：不完全信息下的市场进入

在位企业（玩家 1）成本可能较高 $`H`$ 或较低 $`L`$，其私人信息对进入者不可见。高成本的先验概率为 $`p`$，低成本概率为 $`1-p`$。两家同时决策：在位企业建设新产能 $`B`$ 或不建 $`D`$；进入者进入 $`In`$ 或退出 $`Out`$。

<strong>高成本类型 $`H`$：</strong>

| 在位企业 / 进入者 | $`In`$ | $`Out`$ |
| --- | --- | --- |
| 建设 $`B`$ | $`(0,-1)`$ | $`(2,0)`$ |
| 不建 $`D`$ | $`(2,1)`$ | $`(3,0)`$ |

<strong>低成本类型 $`L`$：</strong>

| 在位企业 / 进入者 | $`In`$ | $`Out`$ |
| --- | --- | --- |
| 建设 $`B`$ | $`(3,-1)`$ | $`(5,0)`$ |
| 不建 $`D`$ | $`(2,1)`$ | $`(3,0)`$ |

高成本类型无论进入者怎么选，都偏好不建 $`D`$；低成本类型无论如何都偏好建设 $`B`$。于是，在位企业的类型依赖策略为 $`s_1(H)=D,s_1(L)=B`$。

进入者若进入，遇到高成本企业可得 1、遇到低成本企业可得 $`-1`$，期望收益为

```math
EU_2(In)=p\cdot1+(1-p)(-1)=2p-1,\qquad EU_2(Out)=0.
```

因此

```math
\boxed{p>1/2\Rightarrow In;\quad p<1/2\Rightarrow Out;\quad p=1/2\Rightarrow\text{两行动无差异}}.
```

完整 BNE 必须同时包括在位企业对两种类型的行动和进入者的行动。例如 $`p=0.7`$ 时，$`((H:D,L:B),In)`$ 是 BNE。

## 5. 贝叶斯法则：获得信息后如何调整信念

设事件 $`H`$ 表示“高质量”、$`E`$ 表示“获得某项检测信号”。贝叶斯公式为

```math
\boxed{\Pr(H\mid E)=\frac{\Pr(E\mid H)\Pr(H)}{\Pr(E\mid H)\Pr(H)+\Pr(E\mid L)\Pr(L)}}.
```

例如高质量先验概率为 $`0.4`$；高质量时通过检测的概率为 $`0.8`$，低质量时通过概率为 $`0.2`$。观测到通过后，高质量的后验概率为

```math
\Pr(H\mid E)=\frac{0.8\cdot0.4}{0.8\cdot0.4+0.2\cdot0.6}=\boxed{\frac{8}{11}\approx0.727}.
```

<strong>先验（prior）是观测前的概率；后验（posterior）是观测后按信号修正的概率。</strong> 注意后验不是单纯的“信号命中率”$`0.8`$，它还与基础概率和误报率有关。

## 6. 不完全信息 Cournot：一方成本是私人信息

市场逆需求 $`P=a-(q_1+q_2)`$，企业 1 成本 $`C`$ 为共同知识；企业 2 成本为 $`C_L`$（概率 $`\theta`$）或 $`C_H`$（概率 $`1-\theta`$），且 $`C_L<C_H`$，成本类型只有企业 2 知道。策略写成一个三元组

```math
\boxed{(q_1,q_L,q_H)},
```

其中企业 2 的低成本与高成本类型分别生产 $`q_L,q_H`$。设 $`\bar C=\theta C_L+(1-\theta)C_H`$。企业 1 的最佳反应基于预期产量 $`E[q_2]=\theta q_L+(1-\theta)q_H`$：

```math
q_1=\frac{a-C-E[q_2]}{2},\quad q_L=\frac{a-C_L-q_1}{2},\quad q_H=\frac{a-C_H-q_1}{2}.
```

当三个产量均为正的内部解成立时，联立得

```math
\boxed{q_1^{*}=\frac{a-2C+\bar C}{3}},
```

```math
\boxed{q_L^{*}=\frac{a-2C_L+C}{3}-\frac{(1-\theta)(C_H-C_L)}{6}},
```

```math
\boxed{q_H^{*}=\frac{a-2C_H+C}{3}+\frac{\theta(C_H-C_L)}{6}}.
```

这一模型突出一个概念：企业 1 不能假设对方“生产一个平均成本类型对应的确定产量”，而应面对两种类型各自的最优生产和加权的预期竞争压力。若某些公式给出负产量，需要重新考虑 $`q\ge0`$ 的边界均衡。

## 7. 公开品、拍卖与信息价值

私人缴费成本的公共品博弈中，每人知道自己的成本 $`c_i`$，不知道其他人的成本，因而最优行动可能采取阈值策略：低成本类型参加、高成本类型退出。阈值由“边际加入收益”等于“私人缴费成本”的无差异方程求出。

拍卖同样是典型贝叶斯博弈：出价由自己的估值决定，但竞争对手估值未知，理性投标需根据估值分布推测竞标强度。不同规则（第一价格、第二价格、公开竞价）并不共享同一出价均衡。

在战略互动中，更多信息也<strong>未必总提高个人均衡收益</strong>：信息公开可能改变别人的最佳反应，从而降低自己的议价地位或竞争优势。评价信息价值时，不能只固定其他人行为不变来计算直接收益。

## 8. BNE 的统一求解流程

先列全类型空间及先验概率；然后对每一种类型分别写行动和支付；再根据其他类型策略求条件期望收益，推导最优反应；最后联立并验证每个类型都不愿单独偏离。

易错点包括：把私人类型写成“所有人都看得到”；只求一个平均行动而不写完整类型策略；把先验与后验混用；用普通 NE 的单一行动代替类型依赖策略；忽略零概率事件或边界产量。

## 9. 经典拓展：两人第一价格密封拍卖

考虑两个风险中性竞标者，各自私人估值 $`v_i`$ 独立服从 $`U[0,1]`$，每人同时提交密封报价；<strong>出价最高者赢得物品，并支付自己的报价</strong>，未中标者收益为 0。设对手采用严格递增的报价规则 $`b(t)=t/2`$。

估值为 $`v`$ 的竞标者若报价 $`b\in[0,1/2]`$，赢过对手的条件是 $`t<2b`$。因为 $`t\sim U[0,1]`$，中标概率为 $`2b`$，期望收益为

```math
EU(b\mid v)=(v-b)\,2b.
```

求导可得

```math
\frac{\partial EU}{\partial b}=2v-4b=0
\quad\Longrightarrow\quad
\boxed{b^{*}(v)=\frac{v}{2}}.
```

二阶导数为 $`-4<0`$；对于更高出价 $`b\ge1/2`$，中标概率达到 1，再加价只会降低净收益。由此验证，两位竞标者都使用 $`b(v)=v/2`$ 互为最佳反应，形成对称贝叶斯纳什均衡。

这道题体现<strong>出价压低（bid shading）</strong>：估值越高，愿意报的价也越高，但第一价格拍卖的报价低于真实估值，以保留中奖后的净收益。与之相反，在标准独立私人价值、准线性效用的<strong>第二价格密封拍卖</strong>中，真实报价是弱占优策略。两个结论对应的支付规则不同，不能混用。

## 10. 逆向选择：价格会改变愿意参与交易的类型

不完全信息市场中，不能总是使用<strong>交易前的先验平均质量</strong>评价成交商品，因为不同类型可能对同一价格作出不同的参与决策。考虑高质量商品 $`H`$、低质量商品 $`L`$：卖家的保留价值分别为 70 和 20，买家对应估值分别为 100 和 40，先验两类各占 $`1/2`$。

如果市场给定价格 $`p=60`$，高质量卖家不会出售（$`60<70`$），低质量卖家愿意出售（$`60>20`$）。买家理性地预见这种类型选择后，会将<strong>实际挂牌出售的商品</strong>判断为低质量，因此成交后的价值是 40，而不是先验平均估值 70。由于 $`40<60`$，买家也不会接受交易。

若价格为 $`p=35`$，只有低质量卖家愿意出售，买家愿意以 35 购买价值 40 的商品，交易可以发生。这个例子说明了<strong>逆向选择（adverse selection）</strong>：价格不仅分配盈余，也会改变交易样本中的质量构成。以上比较是对给定价格的条件行为分析，若允许卖家自由定价或竞价，还需要额外求解完整市场均衡。

## 11. 第一价格与第二价格拍卖为何不同

第一价格拍卖：最高出价者赢且支付<strong>自己的报价</strong>，提高报价虽然增加胜率，但也提高中标成本，所以通常需要在获胜概率与净收益之间权衡。

第二价格密封拍卖：最高出价者赢但支付<strong>第二高报价</strong>。在标准独立私人价值、无预算约束且没有外部效应的模型中，真实报价具有弱占优性。若他人最高报价为 $`m`$，估值为 $`v`$ 的人只需比较是否值得以价格 $`m`$ 购买：当 $`v>m`$ 时应赢；当 $`v<m`$ 时应输。报出 $`v`$ 恰好使胜负决策与这条规则一致，不需要先猜对手的分布。

这个论证不能直接用于共同价值拍卖、存在预算约束或支付规则改变的环境；尤其<strong>第二价格真实报价</strong>不意味着<strong>第一价格真实报价</strong>。
