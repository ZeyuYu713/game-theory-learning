## 1. 为什么动态不完全信息需要“策略＋信念”

静态贝叶斯博弈中，各人面对不知道的类型直接最大化期望收益。动态博弈还多了一个层次：<strong>先行动者的行为会向后行动者透露私人信息，后行动者需要依照观察更新信念，然后作出最优行动。</strong>

例如企业知道自己技术能力强弱，先决定是否进行昂贵的市场进入准备；竞争对手只看得到准备行动、看不到真实能力。对手应怎样判断对方实力？实力不同的企业又会怎样选择准备行动？这正是信号博弈（signaling game）。

## 2. 类型、信息集、行为策略与信念系统

自然先选择类型 $`\theta`$，知情方观察自己的类型后选择信号 $`m`$，不知情方观察信号再选择反应 $`a`$。信息集把后行动者无法区分的历史归为一组；它不能无理由地假装自己知道真实类型。

<strong>行为策略</strong>（behavioral strategy）在每个信息集规定一个行动概率分布；<strong>信念系统</strong> $`\mu`$ 则在每个信息集规定其对不同可能历史或类型的概率判断。一份候选动态均衡通常写成<strong>策略与信念的组合</strong> $`(\beta,\mu)`$，称为评估（assessment）。

若某信号实际在均衡路径上以正概率出现，观察它之后应通过 Bayes 法则更新信念：

```math
\boxed{\Pr(\theta\mid m)=\frac{\Pr(m\mid\theta)\Pr(\theta)}{\sum_{\theta'}\Pr(m\mid\theta')\Pr(\theta')}}.
```

这里 $`\Pr(m\mid\theta)`$ 由各类型的发送策略决定，$`\Pr(\theta)`$ 是自然给出的先验。

## 3. 两个均衡条件：序贯理性与信念一致性

<strong>序贯理性</strong>（sequential rationality）要求：在每个信息集，不论它是否在均衡路径上发生，当期行动都必须是给定其信念与后续策略的最佳反应。

<strong>信念一致性</strong>（belief consistency）要求：信念能够由策略生成的概率合理解释。在均衡路径上，Bayes 法则给出可检验的约束；路径外信息集的信念如何限制，则是不同精炼概念的关键区别。

弱序贯均衡／弱完美贝叶斯均衡（weak sequential equilibrium, weak PBE）的标准表述通常要求序贯理性和<strong>路径上</strong>的 Bayes 一致性；路径外信念可能较自由。严格意义的<strong>序贯均衡</strong>（sequential equilibrium）还要求存在一列趋近候选行为策略的完全混合策略，其 Bayes 信念也趋近所给信念。这样路径外信念必须能被小概率“扰动”合理近似，不能随意捏造。

在有限、具有完美回忆的扩展式博弈中，序贯均衡比普通纳什均衡更强，通常也满足子博弈精炼要求。不要把“仅指定某个终局结果”当作完整的序贯均衡：<strong>必须同时报告全部相关行动与信念。</strong>

## 4. 信号博弈的三种结构

在两类发送者 $`H,L`$ 的模型中：

<strong>分离均衡（separating equilibrium）</strong>：不同类型发不同信号，例如 $`H`$ 选高教育、$`L`$ 选零教育；收到对应信号时，接收者可以反推出类型。

<strong>混同均衡（pooling equilibrium）</strong>：不同类型发相同信号，例如都选零教育；该信号本身无法帮助区分类型，接收者的路径上信念仍为先验。

<strong>半分离／半混同均衡（semi-separating / semi-pooling）</strong>：至少一种类型混合发送信号，接收者从信号中获取部分信息，但不能完全判断类型。

判定均衡需要分别检查发送者各类型是否想模仿别的类型、接收者在每个信号后的反应是否最优，以及信念是否一致。

## 5. Spence 劳动力市场信号模型

工人能力为高类型 $`H`$ 或低类型 $`L`$，$`H>L>0`$；企业不知道能力，工人知道。工人先选择教育年限 $`e\ge0`$，企业看到 $`e`$ 后在竞争中按预期生产率报价工资。教育不直接提高生产率，而是对两种类型具有不同成本：高能力成本 $`e/H`$，低能力成本 $`e/L`$。

设分离路径中低类型选择 $`e_L=0`$，高类型选择 $`e_H=e^{*}>0`$；企业看到 $`e^{*}`$ 时给工资 $`H`$，看到 $`0`$ 时给 $`L`$。分离稳定需要两个模仿约束。

高类型不愿假装低类型：

```math
H-\frac{e^{*}}{H}\ge L\quad\Longrightarrow\quad e^{*}\le H(H-L).
```

低类型不愿假装高类型：

```math
L\ge H-\frac{e^{*}}{L}\quad\Longrightarrow\quad e^{*}\ge L(H-L).
```

因此支持这种分离结果的教育信号区间为

```math
\boxed{L(H-L)\le e^{*}\le H(H-L)}.
```

<strong>数值例题：</strong> $`H=4,L=2`$，则 $`4\le e^{*}\le8`$。选 $`e^{*}=6`$ 时，高类型得到 $`4-6/4=2.5`$，比伪装低类型拿 2 更好；低类型伪装高类型只能得到 $`4-6/2=1<2`$，因而不模仿。此例的教育成本在于区分能力，而不是直接创造额外生产率。

## 6. 混同均衡与路径外信念

如果高低两类工人都选择相同教育 $`e^{*}`$，企业在该信号上的后验等于先验。设高能力先验概率为 $`\pi`$，工资为

```math
\bar w=\pi H+(1-\pi)L.
```

若企业对所有未在均衡路径上的其他教育水平都相信工人是低类型，从而给工资 $`L`$，则支持混同的必要约束由低类型给出：

```math
\bar w-\frac{e^{*}}{L}\ge L\quad\Longleftrightarrow\quad\boxed{e^{*}\le\pi L(H-L)}.
```

该不等式描述的是<strong>特定路径外信念支持的弱精炼结果</strong>。为什么要特别交代路径外信念？因为企业可能看到异常高教育时却坚信它来自低类型，这种信念未必符合更强的精炼准则。因此混同均衡是否保留，取决于所采用的均衡概念与信念限制。

## 7. 廉价交流（Cheap Talk）：消息为何未必可信

如果发送消息没有直接成本，且双方偏好不一致，发送者可能夸大真实状态。一个经典模型是：真实需求状态 $`w\sim U[0,1]`$；知情委员会 $`C`$ 知道 $`w`$ 并发送消息；决策者 $`F`$ 最终确定支出 $`f`$。双方支付为

```math
u_F=-(f-w)^2,\qquad u_C=-(f-w-c)^2,\quad c>0.
```

决策者想让 $`f`$ 等于真实需求 $`w`$，委员会却希望支出比实际需求高 $`c`$。因此完全真实、精确揭示 $`w`$ 的策略通常无法稳定：如果决策者无条件相信报告，委员会有动力报得更高。

### 7.1 空谈均衡（Babbling Equilibrium）

委员会始终发送同一消息，决策者忽略该消息，选择状态分布均值 $`f=1/2`$。消息不携带信息，因此发送者没有必要因改变消息而获益，形成空谈均衡。

### 7.2 部分信息传递：两档消息

允许委员会分别在 $`[0,w_1)`$ 和 $`[w_1,1]`$ 发两种消息；决策者接到消息后，最优选择为区间均值 $`f_1=w_1/2`$ 与 $`f_2=(w_1+1)/2`$。处于边界 $`w_1`$ 的发送者必须对两种消息无差异，其理想支出为两种实际支出的中点：

```math
w_1+c=\frac{f_1+f_2}{2}\quad\Longrightarrow\quad\boxed{w_1=\frac{1}{2}-2c}.
```

要使两档区间非空，需要 $`c<1/4`$。当偏好分歧足够小时，免费消息也可能传递<strong>粗粒度的真实信息</strong>；当分歧过大，信息传递会退化。对于更多消息档数，区间宽度满足相邻差增加 $`4c`$ 的递推关系，体现利益分歧限制可传递的信息精度。

## 8. 求解信号博弈的标准顺序

先列类型及先验，再写每个类型的发送策略、接收者看到各信号后的行动。对于路径上信号，用 Bayes 法则计算后验；根据后验求接收者最佳反应；随后逐类型检查发送者是否想模仿或改发其他信号；最后说明路径外信念，以及采用的是弱 PBE 还是更严格的序贯均衡。

常见错误是认为“看到信号就知道类型”；只验证接收者、不检查发送者模仿；不写路径外信念；用 Nash 均衡标准代替所有信息集上的序贯理性；把成本信号与廉价消息混为一谈。

## 9. 一道完整的分离均衡例题

发送者有高类型 $`H`$ 与低类型 $`L`$，先验各为 $`1/2`$。发送者先选择发信号 $`s=1`$ 或不发信号 $`s=0`$；接收者看到信号后选择“投资”或“不投资”。投资给接收者的收益：面对 $`H`$ 时为 $`3`$，面对 $`L`$ 时为 $`-1`$；不投资收益为 0。

不论类型，发送者只要获得投资便得到收益 $`2`$，否则得到 0，但发信号的成本因类型而异：$`c_H(1)=0.5`$、$`c_L(1)=3`$，且 $`c_H(0)=c_L(0)=0`$。

考虑候选分离策略：$`H`$ 发信号，$`L`$ 不发；接收者看到 $`1`$ 后投资、看到 $`0`$ 后不投资。因为两种信号都以正概率出现，Bayes 法则确定路径上信念为

```math
\mu(H\mid s=1)=1,\qquad\mu(H\mid s=0)=0.
```

接收者在 $`s=1`$ 后投资的收益为 $`3>0`$，在 $`s=0`$ 后投资的收益为 $`-1<0`$，所以其行动序贯理性。再检查发送者：

| 类型 | 遵守分离策略的收益 | 模仿另一类型的收益 | 是否有利可图 |
| --- | ---: | ---: | --- |
| $`H`$ | $`2-0.5=1.5`$ | $`0`$ | 否 |
| $`L`$ | $`0`$ | $`2-3=-1`$ | 否 |

双方均无获益偏离，信念也与均衡路径一致，所以这是一个<strong>分离型完美贝叶斯均衡（PBE）</strong>。这里的信号不是因为它本身创造生产率，而是因为<strong>不同类型支付信号成本的差异</strong>使模仿对低类型不划算。

## 10. 同一个信号模型中的混同均衡与路径外信念

沿用上例：$`H,L`$ 先验各为 $`1/2`$；接收者投资时面对 $`H`$ 得 3、面对 $`L`$ 得 $`-1`$，不投资得 0；发送者获得投资的毛收益为 2。发送信号 $`s=1`$ 对高类型的成本是 $`0.5`$，对低类型的成本是 3，选择 $`s=0`$ 没有成本。

现在考虑两种类型<strong>都选择 $`s=0`$</strong> 的混同候选策略。均衡路径上，接收者看到 $`s=0`$ 后的后验保持为先验 $`1/2`$。如果记当前信息集上高类型的概率为 $`\mu`$，投资的期望收益为

```math
EU(\text{投资}\mid\mu)=3\mu-1(1-\mu)=4\mu-1.
```

因此接收者的最佳反应阈值是：$`\mu>1/4`$ 时投资，$`\mu<1/4`$ 时不投资，等于 $`1/4`$ 时无差异。观察到 $`s=0`$ 后，$`\mu=1/2`$，必定投资。

尚未在均衡路径上出现的 $`s=1`$ 属于<strong>路径外信息集</strong>。例如指定信念 $`\mu(H\mid s=1)=0`$，则接收者看到这一信号后不投资。此时两个类型遵守策略均得 2；若单方偏离至 $`s=1`$，高类型得 $`-0.5`$、低类型得 $`-3`$，都不愿偏离。所以：

| 信息集或类型 | 候选均衡规定 |
| --- | --- |
| 类型 $`H`$、$`L`$ | 均发送 $`s=0`$ |
| 见 $`s=0`$ 的接收者 | 后验 $`1/2`$，选择投资 |
| 见 $`s=1`$ 的接收者 | 后验 0，选择不投资 |

上述策略与信念组成一个<strong>混同型 PBE</strong>。这表明同一组支付参数可能同时支持混同和分离均衡。路径外信念不由 Bayes 法则直接确定；需要明确采用的均衡精炼标准，才可能进一步限制这类信念。注意此处给出的是一个有效的路径外信念构造，并不声称只有这一种信念可以支持混同。

## 11. PBE 检查顺序：先接收者，后发送者

每一种候选信号策略都应经过四步：写出完整发送策略；为每种可能信号指定接收者行动及其信念；用 Bayes 法则约束路径上信念、用期望收益确定接收者的最优行动；最后逐类型比较发送者留在原信号与偏离其他信号的净收益。

<strong>信念合理</strong>不等于<strong>策略激励相容</strong>。尤其不能只因为后验概率是 0 或 1，就宣布分离均衡成立；低类型模仿高类型的净收益，以及高类型改用低成本信号的机会，都必须列式检验。
