## 1. 动态贝叶斯博弈比静态 BNE 多了什么

一家公司准备寻找外部融资。管理层知道项目质量，投资人不知道。管理层先决定是否主动披露一份成本很高的技术审查报告，投资人观察到报告是否出现，然后决定投资。高质量项目可能更容易通过审查，低质量项目也可能模仿这一行为。

投资人的决策不能只依赖项目质量的事前概率。他还会想：如果项目确实是高质量，管理层为什么愿意披露？如果是低质量，是否也有动力披露？更进一步，管理层选择披露时，也会预判投资人如何理解这一行为。

这与 Lecture 07 的静态贝叶斯博弈有两方面联系。两者都有私人类型、概率信念和类型依赖的策略；不同的是，这里先行动者的行动会成为后行动者可以观察的信号，而后行动者对类型的判断又反过来决定先行动者的策略激励。

因此，一个动态不完全信息均衡需要同时回答三个问题：

1. 每种私人类型会采取什么行动？
2. 观察到每种可能的行动后，其他参与人相信是哪种类型的概率是多少？
3. 在这些信念和后续策略下，所有人在每个可能的决策节点上是否愿意按照既定策略行动？

第三个问题之所以强调“每个可能的节点”，是因为有些信号可能在均衡路径上不会出现，但一旦意外出现，投资人仍必须采取一个合理的应对行动。那些看似不会发生的后续决策，可能决定最初的信号是否值得发送。

## 2. 先把信息结构写成一个信号博弈

最常用的两人信号博弈可以写成以下顺序。自然首先抽取发送者的私人类型 $`\theta\in\{H,L\}`$，高类型概率为 $`p`$，低类型概率为 $`1-p`$。发送者观察自己的类型后，选择信号 $`m\in M`$。接收者能够观察信号，但不能直接观察类型，随后选择行动 $`a\in A`$。双方收益由类型、信号和接收者行动共同决定：

```math
u_S(\theta,m,a),\qquad u_R(\theta,m,a).
```

这里的发送者不一定是主动说话的人。教育年限、产品保修、降价、资本投入、审计报告和押金，都可能成为可观察信号。信号也不必是语言，它只要能被另一方观察并用于推断私人类型即可。

### 2.1 策略必须覆盖所有类型与所有可观察信号

发送者的纯策略规定每种类型发什么信号，例如

```math
s_S(H)=1,\qquad s_S(L)=0.
```

接收者的纯策略规定看到每种信号后做什么，例如

```math
s_R(1)=\mathrm{Invest},\qquad
s_R(0)=\mathrm{Reject}.
```

后者不能只写“投资”，因为接收者的行动取决于自己看到的信号。即使信号 $`m=1`$ 在候选均衡中从不会出现，也要给出收到它后的反应。

行为策略（behavioral strategy）允许在每个信息集随机选择行动。若发送者高类型以 80% 概率发信号 1，就可以记为

```math
\sigma_S(1\mid H)=0.8.
```

这里的 0.8 不是高类型出现的先验概率，而是高类型已经确定后，发送者选择该信号的条件概率。

### 2.2 接收者的信息集与信念

假设接收者看到 $`m=1`$，他仍无法直接区分“高类型发了 1”和“低类型发了 1”这两段历史。这两种可能历史属于同一个信息集。

接收者必须给这个信息集附上一个概率判断：

```math
\mu(H\mid m=1).
```

如果高低类型都可能发送 1，并且该信号出现的总体概率为正，那么贝叶斯法则给出

```math
\boxed{
\mu(H\mid 1)=
\frac{
p\,\sigma_S(1\mid H)
}{
p\,\sigma_S(1\mid H)
+(1-p)\,\sigma_S(1\mid L)
}
}.
```

例如 $`p=0.3`$，高类型发 1 的概率为 0.8，低类型发 1 的概率为 0.2，则

```math
\mu(H\mid 1)=
\frac{0.3(0.8)}{0.3(0.8)+0.7(0.2)}
=\frac{12}{19}\approx0.632.
```

观察前高类型概率是 0.3，观察后提高到约 0.632。不能把“高类型发送信号的概率 0.8”直接当成“发送信号后为高类型的概率”。

## 3. 完美贝叶斯均衡（PBE）究竟要求什么

动态贝叶斯博弈的候选解通常写成一组策略和信念：

```math
(\sigma,\mu).
```

这组对象称为评估（assessment）。策略描述每个人在各自信息集上如何行动；信念描述人在到达信息集后，如何对无法区分的历史赋予概率。

### 3.1 序贯理性

序贯理性（sequential rationality）要求每个人在每个信息集都作出最优选择。对于接收者而言，这意味着看到某个信号后，不能因为这个信号“本来不该出现”，就任意规定一个对自己明显不利的行动。

如果接收者投资时面对高类型的收益为 3，面对低类型的收益为 $`-1`$，拒绝投资收益为 0，那么当高类型后验概率为 $`\mu`$ 时，

```math
\begin{aligned}
EU_R(\mathrm{Invest}\mid\mu)
&=3\mu-1(1-\mu)\\
&=4\mu-1,\\
EU_R(\mathrm{Reject}\mid\mu)&=0.
\end{aligned}
```

所以

```math
\begin{cases}
\mu>\frac{1}{4}, & \mathrm{Invest},\\
\mu<\frac{1}{4}, & \mathrm{Reject},\\
\mu=\frac{1}{4}, & \text{either action or a mixture}.
\end{cases}
```

这条阈值条件将在后面几个例子中反复使用。当信念等于 $`1/4`$ 时，接收者对两种行动无差异，因此可以混合；如果信念严格高于或低于门槛，就不能随意混合。

发送者也必须满足序贯理性。对每一种私人类型，既定信号产生的收益必须不低于改发其他信号、并引起接收者对应反应时的收益。这就是信号模型的激励相容约束。

### 3.2 信念一致性

第二类要求是信念与策略相容。只要某个信息集在候选均衡下以正概率到达，该处信念就必须根据贝叶斯法则由先验和策略推出。这不是可以任意挑选的参数。

如果某个信息集在候选均衡下到达概率为零，贝叶斯公式的分母也为零，无法直接给出后验。我们把这样的信息集称为路径外信息集（off-path information set）。

在通常教学采用的弱 PBE 表述中，路径外信念可以较自由地指定，但指定之后接收者仍须按照该信念作出最优反应，而且发送者不得因相应的路径外反应而愿意偏离。也就是说，信念可以有选择空间，策略却不能脱离激励约束。

对于更严格的序贯均衡（sequential equilibrium），还要求信念能由一列趋近候选策略的完全混合扰动策略产生的贝叶斯信念取极限。这是额外的“一致性”要求。PBE 在不同教材中存在弱、强等表述差异；写题时应遵循课程对均衡概念的定义，不要把所有精炼概念当成完全同一个东西。

### 3.3 NE、SPNE、PBE 的用途有什么不同

| 均衡概念 | 主要检验对象 | 对本讲问题的局限或作用 |
| --- | --- | --- |
| Nash equilibrium（NE） | 初始策略互为最佳反应 | 可能依靠不合理的路径外威胁支撑 |
| Subgame-perfect NE（SPNE） | 每个子博弈中仍是纳什均衡 | 若接收者的信息集跨越不同类型节点，常常无法将它单独构造成真子博弈 |
| Perfect Bayesian equilibrium（PBE） | 每个信息集上的策略最优性，以及信念与策略的一致性 | 适合显式追踪信号和后验判断 |
| Sequential equilibrium（SE） | 序贯理性与完全混合扰动极限的一致性 | 进一步限制路径外信念的形成方式 |

在具有完美回忆的有限扩展式博弈中，序贯均衡是对子博弈精炼要求的进一步强化。对于本讲常见的两类型信号博弈，直接写出策略与后验信念，通常比试图只用 SPNE 判断结果更清楚。

## 4. 分离、混同与半分离：先看信号能透露多少信息

设发送者有 $`H,L`$ 两种类型，可以选择 $`m=0`$ 或 $`m=1`$。

分离均衡（separating equilibrium）是不同类型选择不同信号，例如 $`H\to1`$、$`L\to0`$。如果两种类型先验概率都为正，且按这种纯策略行动，则观察到 1 的接收者知道发送者为 $`H`$，观察到 0 的接收者知道发送者为 $`L`$。这时路径上后验为 1 或 0。

混同均衡（pooling equilibrium）是两种类型选择同一信号，例如 $`H\to0`$、$`L\to0`$。由于两种类型都发 0，观察到 0 并不能区分类型，后验仍为先验。相反，信号 1 从不出现，接收者看到它之后的判断就涉及路径外信念。

半分离或半混同均衡（semi-separating / semi-pooling equilibrium）允许至少一种类型混合发送信号。观察到某个信号时，接收者可能只能把高类型概率从 0.2 更新到 0.4，而无法把它精确判断为 0 或 1。

这三类描述的是<strong>不同类型的发送行为与信息传递程度</strong>，还不是均衡存在的证明。证明必须进一步检查接收者的最优反应、发送者各类型的偏离激励和必要的贝叶斯更新。

## 5. 一个贯穿本讲的投资信号模型

下面先固定一组支付参数，分别求分离和混同 PBE。这组参数也对应[本讲练习](../exercises/lecture-08-exercises.md)中的典型题目。

自然以相同概率抽取高类型 $`H`$ 和低类型 $`L`$，发送者知道类型。发送者可以选择发信号 $`s=1`$ 或不发信号 $`s=0`$；接收者观察信号后决定是否投资。

接收者投资时，高类型带来收益 3，低类型带来收益 $`-1`$；不投资时收益为 0。发送者不论类型，只要获得投资，就得到毛收益 2；若接收者不投资，毛收益为 0。

信号 1 需要付出类型依赖成本：

```math
c_H(1)=0.5,\qquad c_L(1)=3.
```

信号 0 对两种类型都不产生成本。因此发送者净收益可以写为

```math
u_S(\theta,s,a)
=2\mathbf1\{a=\mathrm{Invest}\}-c_{\theta}(s).
```

这里 $`\mathbf1\{\cdot\}`$ 是指示函数：条件成立取 1，不成立取 0。

发送者与接收者的收益不能混着算。发送者只关心能否得到投资以及发送信号的成本；接收者要根据类型与后验判断投资是否值得。

## 6. 分离型 PBE：高类型发信号，低类型不发

考虑以下候选策略：

```math
s_S(H)=1,\qquad s_S(L)=0.
```

接收者看到 $`s=1`$ 就投资，看到 $`s=0`$ 就不投资。

### 6.1 先求接收者的信念

由于两种类型先验均为 $`1/2`$，而高类型必然发 1、低类型必然发 0，两个信号在均衡下都以正概率出现。贝叶斯更新给出

```math
\mu(H\mid s=1)=1,\qquad
\mu(H\mid s=0)=0.
```

接收者看到 1 时，投资的期望收益为 3，高于不投资的 0；看到 0 时，投资的期望收益为 $`-1`$，低于不投资的 0。因此接收者两个信息集上的行动都最优。

### 6.2 再检查发送者的模仿激励

高类型按照约定发送 1，可以得到投资，净收益为

```math
u_H(1)=2-0.5=1.5.
```

如果高类型偏离为 0，接收者会按照信号 0 的既定反应拒绝投资，高类型得到 0。因此 $`1.5>0`$，高类型不愿偏离。

低类型按照约定发送 0，接收者不投资，收益为 0。如果低类型模仿高类型发送 1，虽然能获得投资，但须承担成本 3，净收益为

```math
u_L(1)=2-3=-1.
```

因为 $`0>-1`$，低类型也不愿偏离。

把两个偏离检验放在一起：

| 发送者类型 | 遵守分离策略 | 改发另一种信号 | 最优行动 |
| --- | ---: | ---: | --- |
| $`H`$ | $`1.5`$ | $`0`$ | 发 1 |
| $`L`$ | $`0`$ | $`-1`$ | 发 0 |

所以候选策略满足发送者激励相容，接收者行动序贯理性，后验信念也符合贝叶斯法则，构成一个分离型 PBE。这个模型中，信号没有直接提高项目质量；它能区分类型，是因为低类型模仿成本过高。

另外，因为两个可观察信号都在均衡下以正概率出现，本例没有需要额外指定的接收者路径外信号信息集。这使分离型候选的验证相对直接。

## 7. 同样的支付，为什么还可能出现混同型 PBE

仍然使用第 5 节的参数，但考虑另一个候选策略：高、低两种类型都发送 $`s=0`$。接收者见 0 后投资，见 1 后不投资。

### 7.1 路径上的信念不能任意指定

两种类型都发送 0，接收者见到 0 后仍认为高类型概率是

```math
\mu(H\mid s=0)=\frac{1}{2}.
```

投资的期望收益为

```math
3\times\frac{1}{2}-1\times\frac{1}{2}=1>0.
```

所以接收者在均衡路径上选择投资是最优的。

### 7.2 路径外信念如何支撑这一结果

由于均衡中没有类型发送 1，信号 1 是路径外信号。考虑指定

```math
\mu(H\mid s=1)=0.
```

按该信念，接收者相信意外出现的信号 1 来自低类型，投资的收益为 $`-1`$，因此见 1 后拒绝投资。接收者在这个路径外信息集上的行动仍然是自己的最佳反应。

对发送者而言，遵守发送 0 可以得到投资，收益为 2。若高类型偏离为 1，接收者将拒绝投资，高类型反而支付 0.5 的成本，收益为 $`-0.5`$。若低类型偏离为 1，收益为 $`-3`$。两个类型均不偏离。

因此

```math
\begin{cases}
s_S(H)=s_S(L)=0,\\
s_R(0)=\mathrm{Invest},\quad s_R(1)=\mathrm{Reject},\\
\mu(H\mid0)=1/2,\quad\mu(H\mid1)=0
\end{cases}
```

是一组混同型弱 PBE。

与分离结果相比，混同均衡中接收者会投资两类项目，因为共同信号没有揭示类型，而先验下投资的期望收益为正。高类型虽然可以付出较小成本制造信号，但在当前混同均衡中，它已经免费获得投资，单独发送信号反而没有收益。

需要区别两个问题：“混同型 PBE 是否存在？”与“所有合理的精炼概念是否只保留它？”这里证明的是在指定路径外信念下它可以构成弱 PBE，并没有证明该信念唯一，也不意味着任何混同结果都能够通过更强的精炼检验。

## 8. 半分离均衡：发送者与接收者为什么会同时混合

前两个例子中的发送者使用纯策略。现在换一组参数，看看如何计算真正的混合信号均衡。

仍是高低两种类型、两种信号和投资决策，但把先验改为

```math
\Pr(H)=0.2,\qquad\Pr(L)=0.8.
```

接收者投资面对高类型获利 3、面对低类型亏损 1，不投资得 0；发送者获得投资的毛收益为 2。发送信号 1 对高类型没有成本，对低类型成本为 1；发送 0 无成本。

考虑这样的候选结构：高类型总发 1；低类型以概率 $`r`$ 发 1、以概率 $`1-r`$ 发 0；接收者见 1 后以概率 $`\beta`$ 投资，见 0 后不投资。

### 8.1 先让低类型愿意混合

低类型发 0 时一定不获投资，净收益为 0。发 1 时，接收者以概率 $`\beta`$ 投资，预期毛收益为 $`2\beta`$，但要支付成本 1，所以净收益为

```math
EU_L(1)=2\beta-1.
```

如果低类型要在两种信号之间真正混合，就必须无差异：

```math
2\beta-1=0
\quad\Longrightarrow\quad
\boxed{\beta=\frac{1}{2}}.
```

### 8.2 再让接收者愿意混合

接收者见到信号 1 后，高类型的后验为

```math
\mu(H\mid1)
=\frac{0.2\times1}{0.2\times1+0.8r}.
```

接收者要在投资与不投资之间混合，就必须满足投资期望收益为零，即 $`4\mu-1=0`$，所以 $`\mu=1/4`$：

```math
\frac{0.2}{0.2+0.8r}
=\frac{1}{4}.
```

解得

```math
0.2=0.05+0.2r
\quad\Longrightarrow\quad
\boxed{r=\frac{3}{4}}.
```

### 8.3 验证所有人的最优反应

低类型在发 1 与发 0 之间无差异，因而可以按 $`r=3/4`$ 混合；高类型发 1 的期望收益为 $`2\beta=1`$，发 0 不获投资、收益为 0，所以高类型确实愿意发 1。

信号 0 只可能由低类型发送，故 $`\mu(H\mid0)=0`$，接收者拒绝投资最优。信号 1 下后验为 $`1/4`$，投资收益恰好为零，所以接收者可以按 $`\beta=1/2`$ 混合。

于是得到一个半分离型 PBE：

```math
\boxed{
\begin{aligned}
\sigma_S(1\mid H)&=1,\\
\sigma_S(1\mid L)&=\frac{3}{4},\\
\sigma_R(\mathrm{Invest}\mid1)&=\frac{1}{2},\\
\sigma_R(\mathrm{Invest}\mid0)&=0.
\end{aligned}
}
```

这里不能把“低类型发送 1 的概率 $`3/4`$”误解成“观察 1 后为低类型的概率 $`3/4`$”。实际上观察 1 后高类型概率为 $`1/4`$，低类型概率也恰好为 $`3/4`$，两项数值相等只是当前参数设置导致的巧合，计算逻辑完全不同。

这一例子揭示混合 PBE 的一般求解技巧：<strong>让发送者无差异，求接收者的混合概率；让接收者无差异，结合贝叶斯公式反求发送者的混合概率。</strong> 最后再逐类型验证其余纯策略是否确实最优。

## 9. Spence 教育信号：教育为什么可能只是为了证明能力

教育往往具有提升技能的实际价值，但信号理论提出了另一个可能的作用：教育也能向不知情的雇主传递劳动者的私人能力信息。

为了把“生产率提升”和“信息传递”区分开，考虑一个简化的 Spence 模型。劳动者能力为高类型 $`H`$ 或低类型 $`L`$，其中 $`H>L>0`$。劳动者知道自己的能力，企业不知道。劳动者先选择教育水平 $`e\geq0`$，企业看到教育之后，在竞争性劳动市场中支付与预期生产率一致的工资。

假定教育本身不直接提高生产率，但会产生成本，且高能力劳动者完成同样教育更容易：

```math
c_H(e)=\frac{e}{H},\qquad
c_L(e)=\frac{e}{L}.
```

由于 $`H>L`$，相同教育水平下有 $`e/H<e/L`$。劳动者效用为工资减去教育成本：

```math
u_{\theta}(e)=w(e)-\frac{e}{\theta}.
```

企业在观察教育水平以后支付多少工资，取决于它形成的后验信念。若完全相信工人为高类型，则工资为 $`H`$；若完全相信是低类型，则工资为 $`L`$。

### 9.1 设想一种分离方案

假设低类型选择零教育 $`e_L=0`$，高类型选择某个正教育水平 $`e_H=e^{*}>0`$。雇主据此识别类型，并分别支付

```math
w(0)=L,\qquad w(e^{*})=H.
```

要让这种行为成为均衡，必须考虑两种类型是否会冒充另一类型。

高类型遵守分离方案时得到

```math
H-\frac{e^{*}}{H}.
```

如果它改选零教育，工资变为 $`L`$，教育成本也为零。因此高类型不偏离的条件为

```math
H-\frac{e^{*}}{H}\geq L,
```

整理得到

```math
\boxed{e^{*}\leq H(H-L)}.
```

另一方面，低类型遵守方案时得到工资 $`L`$，没有教育成本。如果低类型模仿高类型选择 $`e^{*}`$，企业会误以为它是高类型而支付 $`H`$，但低类型须承担更高的教育成本 $`e^{*}/L`$。低类型不模仿的条件为

```math
L\geq H-\frac{e^{*}}{L},
```

即

```math
\boxed{e^{*}\geq L(H-L)}.
```

两条激励约束合在一起：

```math
\boxed{
L(H-L)\leq e^{*}\leq H(H-L)
}.
```

下界来自低类型不愿模仿，上界来自高类型不愿为了信号付出过高成本。区间之所以存在，正是因为两种类型取得相同教育信号的成本不同。

### 9.2 用数字检验

取 $`H=4`$、$`L=2`$。可支持分离的教育水平区间为

```math
4\leq e^{*}\leq8.
```

例如选 $`e^{*}=6`$。高类型遵守分离时，净收益为 $`4-6/4=2.5`$；如果改选零教育，只能得到工资 2。低类型遵守方案时得到 2；如果冒充高类型，净收益仅为 $`4-6/2=1`$，还不如原来。

但是做到这一步，还需要说明非均衡路径上其他教育水平如何被雇主理解。因为教育选择是连续的，劳动者不仅可以在 0 与 6 之间选，还可以选 1、5.9、7 等。一个支持性的弱 PBE 信念和工资安排是：雇主仅在看到 6 时认定高类型并给工资 4；看到 0 或其他未在路径上的教育水平时认为是低类型并给工资 2。对任何类型而言，改选其他正教育水平只会得到工资 2 并产生教育成本，因此不会构成有利偏离。

这个细节很重要：两条模仿约束是检验分离的核心，但对于具有连续信号空间的完整动态博弈，还要补上所有其他可能信号后的信念和反应，才能严格说明 PBE。

### 9.3 信号可能存在社会成本

在这个模型中，教育不直接增加生产率。工人为了证明自己能力而付出教育成本，企业借此改善类型识别，但社会并没有因为教育本身产生额外产出。如果类型能够无成本地验证，高类型就不必付出这笔信号成本。

这并不等于现实中的教育没有提高技能的作用，而是强调：当一种行动既能改善能力又能传递能力信息时，需要在模型中分别刻画两种机制，不能把全部教育回报都解释成生产率提升。

## 10. Spence 混同均衡：为什么所有人可能选择相同教育

仍考虑 $`H>L>0`$，设高类型先验概率为 $`\pi`$。现在假设两种类型都选择同一个教育水平 $`e^{*}`$。雇主观察到这个共同信号后无法区分能力，因此竞争性工资按平均生产率确定：

```math
\bar w=\pi H+(1-\pi)L.
```

为了检验这种混同候选，考虑一种支持性的路径外信念：对于任何偏离共同教育水平的其他教育选择，雇主都判断劳动者为低类型，并支付工资 $`L`$。

对于低类型，遵守共同教育方案的净收益为

```math
\bar w-\frac{e^{*}}{L}.
```

若偏离到零教育且这一教育不在均衡路径上，就可以拿到工资 $`L`$ 并省去教育成本。低类型不偏离的必要条件为

```math
\bar w-\frac{e^{*}}{L}\geq L,
```

所以

```math
\boxed{e^{*}\leq\pi L(H-L)}.
```

高类型相应的条件为

```math
\bar w-\frac{e^{*}}{H}\geq L,
```

得到 $`e^{*}\leq\pi H(H-L)`$。由于 $`H>L`$，高类型条件较弱，因此限制混同教育水平的是低类型。

例如 $`H=4`$、$`L=2`$、$`\pi=1/2`$，共同工资为 3。低类型必须满足 $`3-e^{*}/2\geq2`$，即

```math
\boxed{0\leq e^{*}\leq2}.
```

当两种类型都选择 $`e^{*}=2`$ 时，低类型得到 2，若偏离至零教育并被视为低类型，也得到 2；高类型得到 2.5，偏离至零教育只得到 2。若两种类型都选择 0，则在上述路径外信念下，同样可以形成混同。

上述证明依赖于雇主对非常规教育水平的信念。它表明这些教育选择能够在特定弱 PBE 设定下得到支持，并不表示所有信念限制更强的均衡概念都会接受这些混同结果。比较分离与混同时，要先明确所使用的精炼条件。

## 11. 路径外信念能有多“随意”：一个直观准则例子

上面两组混同结果可能让人产生疑问：既然接收者可以在某个从不出现的信号后相信“发送者一定是低类型”，是否任何不合理的结果都能通过悲观信念维持？

在弱 PBE 中确实可能出现许多依赖路径外信念的均衡。因此博弈论提出了进一步筛选均衡的精炼准则，例如 Cho–Kreps 直观准则（Intuitive Criterion）。它的基本思路是：如果某一类型无论接收者如何回应，都不可能通过某项偏离获益，那么观察到这项偏离时，接收者不应仍把它归因于这一类型，从而挫败其他可能获益的类型。

用第 5 节的投资信号参数，仅将高类型先验概率改为 $`p=0.2`$。此时如果两种类型都发送 0，接收者看到 0 后投资的期望收益为

```math
3(0.2)-1(0.8)=-0.2<0.
```

所以接收者选择不投资。假设对于未出现的信号 1，接收者规定信念 $`\mu(H\mid1)=0`$，并同样不投资。发送者遵守发送 0 时都得到 0；高类型改发 1 后既无法获得投资，还支付成本 0.5，得 $`-0.5`$；低类型偏离后得 $`-3`$。这确实构成一个弱 PBE。

但进一步想：如果接收者观察到信号 1 后选择投资，高类型偏离的净收益是 $`2-0.5=1.5`$，高于原来的 0；低类型即使获得投资，净收益也是 $`2-3=-1`$，仍低于原来的 0。

所以低类型无论接收者如何回应都不会因发 1 而获益，高类型却有可能获益。直观准则据此排除低类型作为该信号的合理解释，使接收者在观察 1 后推断其来自高类型并选择投资。高类型于是有动力偏离，原来的混同结果不能通过这个精炼检验。

这里需要区分两件事：弱 PBE 允许某种路径外信念支撑均衡，并不保证该信念能通过所有更强的精炼准则；同时，直观准则对这个例子的排除也不意味着它会排除所有混同均衡。精炼条件的结论取决于实际支付与谁有可能从偏离中获益。

## 12. 廉价交流：为什么说真话不一定是均衡

前面的教育、审查等信号通常需要付出类型依赖成本。廉价交流（cheap talk）则研究另一种情况：发送消息本身没有直接成本，也不改变可行资源分配，但接收者可能根据消息采取行动。

一个典型情境是公司内部的预算建议。业务部门知道真实需求，财务部门必须决定预算金额；业务部门希望预算比实际需求高一些，而财务部门希望尽量贴近真实需求。

设真实需求状态 $`w`$ 均匀分布于 $`[0,1]`$。发送者（委员会）观察到 $`w`$，向接收者（决策者）发送一条免费消息。接收者看到消息后选择支出水平 $`f`$。

接收者希望 $`f`$ 尽量接近真实需求，其效用为

```math
u_F=-(f-w)^2.
```

发送者希望支出比真实需求高 $`c>0`$，其效用为

```math
u_C=-(f-w-c)^2.
```

接收者的理想行动为 $`f=w`$，发送者的理想行动为 $`f=w+c`$。两者偏好方向相近，但总存在一个偏差。

### 12.1 为什么完全如实报告不容易成立

假设发送者直接汇报 $`w`$，接收者每次都完全相信并选择 $`f=w`$。这套策略能让接收者满意，却不符合发送者的激励。

如果某个发送者观察到状态 $`w=0.4`$，他最希望的支出是 $`0.4+c`$。如果虚报一个略高的状态，接收者就会选择更高支出，使发送者的效用提高。因此在偏差 $`c>0`$ 的模型中，毫无约束的完全真实报告通常不是稳定均衡。

要注意，消息不可信并不意味着消息完全没有信息。它可能只透露需求高低的大致区间。

### 12.2 空谈均衡（Babbling Equilibrium）

最简单的均衡是发送者始终发同一条消息，或者虽然发送不同消息但这些消息与状态无关。接收者知道消息没有信息含量，因此保持原来的均匀先验，并选择使平方误差期望最小的均值：

```math
\boxed{f^{*}=\mathbb E[w]=\frac{1}{2}}.
```

接收者不随消息改变支出，发送者便无法通过改变消息影响结果，因此没有有利的消息偏离。这构成一个空谈均衡。

在空谈均衡中，不存在有用的信息传递，但并不要求发送者“诚实”或“不诚实”：只要消息对接收者行动没有影响，消息本身就丧失了区分状态的作用。

## 13. 廉价交流也可能传递部分信息：两档消息的完整推导

假设发送者把需求分成低、高两个区间。当真实状态位于 $`[0,w_1)`$ 时发低需求消息，位于 $`[w_1,1]`$ 时发高需求消息。

接收者知道这种消息划分，因此收到低需求消息后，会相信真实状态在 $`[0,w_1)`$ 内均匀分布；收到高需求消息后，会相信状态在 $`[w_1,1]`$ 内均匀分布。

因为接收者的损失是平方误差，其条件最优行动等于对应区间的条件均值：

```math
f_1=\frac{w_1}{2},
\qquad
f_2=\frac{w_1+1}{2}.
```

现在检查发送者是否真愿意按照该分界发送消息。对于状态远低于 $`w_1`$ 的发送者，低支出 $`f_1`$ 更接近其理想值；对于远高于 $`w_1`$ 的发送者，高支出 $`f_2`$ 更合意。在临界状态 $`w=w_1`$，发送者必须对两种消息无差异。

他的理想支出为 $`w_1+c`$。在平方损失下，当理想支出恰好位于 $`f_1`$ 和 $`f_2`$ 的中点时，两种行动给出的效用相同：

```math
w_1+c=\frac{f_1+f_2}{2}.
```

将条件均值代入：

```math
\begin{aligned}
w_1+c
&=\frac{1}{2}
\left(\frac{w_1}{2}+\frac{w_1+1}{2}\right)\\
&=\frac{2w_1+1}{4}.
\end{aligned}
```

整理得

```math
\boxed{w_1=\frac{1}{2}-2c}.
```

这不仅是一个代数等式，还要求两个消息区间都有正长度，也就是 $`0<w_1<1`$。在本模型 $`c>0`$ 下，得到

```math
\boxed{0<c<\frac{1}{4}}.
```

如果 $`c=0.1`$，则

```math
w_1=0.5-0.2=0.3,
```

两条消息分别表示需求位于 0 到 0.3 之间、或位于 0.3 到 1 之间。接收者收到两条消息后的最优支出分别是

```math
\boxed{f_1=0.15,\qquad f_2=0.65}.
```

位于分界点 $`w_1=0.3`$ 的发送者理想支出为 0.4，它恰好是 0.15 和 0.65 的中点。低于 0.3 的发送者更愿意导致支出 0.15，高于 0.3 的发送者更愿意导致支出 0.65，因而这套区间划分是激励相容的。

### 13.1 能不能划分更多消息档

设共有 $`K`$ 个区间，依次记其长度为 $`\ell_1,\ell_2,\ldots,\ell_K`$。在同一个平方损失与均匀分布模型中，相邻区间边界发送者的无差异条件给出

```math
\boxed{\ell_{k+1}=\ell_k+4c}.
```

因为区间长度总和必须为 1，所以

```math
\begin{aligned}
1
&=\sum_{k=1}^{K}\ell_k\\
&=K\ell_1+2cK(K-1).
\end{aligned}
```

要让每个区间都有正长度，需要 $`\ell_1>0`$，即

```math
\boxed{c<\frac{1}{2K(K-1)}}
\qquad (K\geq2).
```

例如当 $`c=0.1`$ 时，两档消息满足门槛 $`0.1<1/4`$，可以存在；三档消息的门槛是 $`1/12\approx0.0833`$，已经小于 0.1，因此该模型中不存在具有三个正长度区间的此类单调分区均衡。

这说明偏好差异越大，可以稳定传递的信息往往越粗略。完全真实报告、区间消息和空谈不是简单的“可信/不可信”二选一，而是不同精度的信息传递结构。

## 14. 信号、筛选和廉价交流分别在解决什么问题

企业主动进行认证、求职者先选择教育、卖家先提出保修条款，都可以理解为知情方先采取可观察行动的信号问题。若低质量类型模仿高质量类型要付出更高成本，信号可能实现分离。

筛选（screening）则通常由不知情方先设计一个菜单，让知情方根据私人类型自我选择。例如保险公司设计高保费低免赔额和低保费高免赔额两份合同，高风险与低风险投保人可能因为自身事故概率不同而选择不同合同。筛选模型需要检验各类型在合同菜单中的自选择激励，而不能只观察最后谁选了哪份合同。

廉价交流则强调消息本身没有直接成本，因而它的可信度主要取决于发送者与接收者的偏好是否足够接近。它可以产生部分信息传递，也可能完全退化为空谈。

三类模型都涉及私人信息，但行动顺序和激励来源不同，不能用“看到行为就知道类型”一句话概括。尤其在策略性发送消息的环境中，贝叶斯更新必须使用<strong>类型在均衡下发送消息的概率</strong>；不能只套用一个外部检测设备的固定准确率。

## 15. 一道动态贝叶斯题应怎样写完整解答

先写出自然选择的类型、先验分布，以及谁在何时观察到哪些信息。接着按时间顺序列出发送者策略、接收者每种可能信号后的策略，并明确是纯策略还是混合策略。

然后固定一个候选结构，例如分离、混同或半分离。对于均衡路径上有正概率出现的每个信号，使用贝叶斯法则求后验；对于不会出现的信号，说明需要指定什么路径外信念，并据此求接收者的最优行动。

最后对发送者每种类型逐一比较“遵守候选策略”与“偏离到其他信号”的净收益。对于连续信号或连续教育水平，还须检查不在两个候选信号之内的其他可行行动。对于混合均衡，先用无差异条件求混合概率，再验证其他行动不会带来更高收益。

| 常见错误 | 应检查的地方 |
| --- | --- |
| 只写发送者发什么信号，不写接收者在其他信号后的行动 | 接收者的完整策略必须覆盖每个信息集 |
| 看到某个信号后，直接宣布发送者一定是高类型 | 按发送策略与先验计算后验，除非真正实现分离 |
| 只验证接收者理性，忘记低类型会模仿高类型 | 必须写出每种发送者类型的激励相容约束 |
| 把路径外信念误当成 Bayes 公式的计算结果 | 到达概率为零的节点不能直接使用分母为零的 Bayes 更新 |
| 接收者严格偏好投资，却仍写“以 50% 概率投资” | 只有对投资与不投资无差异时才能在两行动间混合 |
| 检验了两种教育水平，却忽略其他教育水平 | 连续信号空间需要覆盖所有有可能获益的偏离 |
| 把弱 PBE、序贯均衡和直观准则称为同一个概念 | 说明各自对路径外信念施加了何种约束 |

可以结合[本讲练习与解析](../exercises/lecture-08-exercises.md)复算信号后验、教育信号区间、廉价交流两档分界、分离与混同型 PBE；再用[图解：信号博弈](../visuals/08-signaling-games.md)检查自己是否把类型、信号、接收者信息集和后验概率放在了正确的时间位置。
