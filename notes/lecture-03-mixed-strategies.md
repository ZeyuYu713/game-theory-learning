# Lecture 03｜混合策略：当可预测本身成为弱点

<strong>Mixed Strategies · Indifference · Support · Inspection Games · Minimax</strong>

[九讲目录](../README.md) · [第二讲：连续行动与市场竞争](lecture-02-strategic-form-games.md) · [图解：无差异概率](../visuals/03-mixed-strategies.md) · [第三讲习题与解析](../exercises/lecture-03-exercises.md)

前两讲主要让每个参与者选择一个确定的行动。即使这些选择最终构成纳什均衡，对手也知道我在均衡下会做什么。但在猜硬币、点球、巡逻、抽查等情境中，行动一旦完全可预测，就可能立即被对方利用。于是，有时我们要研究的不是“最终选哪一个”，而是“以怎样的概率选择不同的行动”。

混合策略并不要求参与者缺乏判断，也不意味着策略不重要。恰恰相反，随机概率也必须由收益比较决定。数学上的主要变化是：玩家不只比较纯行动的支付，还要比较<strong>面对对手随机行动时，每种纯行动能够获得的期望支付</strong>。

## 1. 一个人为何愿意随机选择

先考虑一个极简的二人游戏。甲、乙各有正面和反面两个行动；甲希望双方选择相同，乙希望双方选择不同。甲猜对得 1，猜错得 -1；乙的收益恰好相反。

如果甲永远选择正面，乙只要永远选择反面就能获益；甲改为永远反面，乙又会改选正面。这里不存在一个双方都愿意坚持的纯行动组合。

假设甲事先采用一套私人的随机规则，有一半机会选择正面，一半机会选择反面。乙即使知道这套规则，也无法仅凭规则预测甲这一轮的实际结果。乙选正面和选反面的期望收益恰好相同。反过来，只有乙也使用适当的随机规则，甲才愿意坚持自己的随机化方式。

要区分两件事：<strong>对手知道你的概率分布</strong>，与<strong>对手在同一轮行动前观察到你随机抽中的结果</strong>。混合策略均衡通常允许前者，却不能把后者偷偷加入模型；如果随机结果可以提前被观察，博弈的信息结构就已经改变。

## 2. 混合策略到底是什么

设玩家 $`i`$ 有 $`m`$ 个纯行动：

```math
A_i=\{a_{i1},a_{i2},\ldots,a_{im}\}.
```

混合策略（Mixed Strategy）就是定义在这些行动上的概率分布：

```math
\sigma_i=(p_{i1},p_{i2},\ldots,p_{im}),
\qquad
p_{ik}\ge0,\qquad
\sum_{k=1}^{m}p_{ik}=1.
```

例如，两种行动 A、B 对应 $`(0.7,0.3)`$，表示以 70% 的概率执行 A，以 30% 的概率执行 B。$`(1,0)`$ 仍然是混合策略的一个特殊情形，只不过它没有实际随机性，称为退化混合策略。

一个策略中概率严格大于零的行动构成它的<strong>支持集（Support）</strong>。策略 $`(0.7,0.3,0)`$ 的支持集只有前两个行动，第三个不在支持集内。支持集和行动集合不同：一个人有资格选择三种行动，不代表均衡时必须给三种行动都分配概率。

对于两个有限行动玩家，独立随机化时：

```math
U_1(\sigma_1,\sigma_2)
=\sum_{a_1\in A_1}\sum_{a_2\in A_2}
\sigma_1(a_1)\sigma_2(a_2)u_1(a_1,a_2).
```

这里出现的乘积来自两人的随机化彼此独立。比如甲选 A 的概率为 0.7、乙选 L 的概率为 0.4，那么同时出现 A 和 L 的概率为 $`0.7\times0.4=0.28`$。不能在没有说明共同随机信号或关联机制的情况下，把两个概率相乘规则任意改掉。

混合策略纳什均衡要求：其他人的概率分布不变时，任何人都无法通过更改自己的概率分布提高期望收益。有限玩家、有限纯行动的策略式博弈至少存在一个这样的均衡；它可能是纯策略，也可能包含真正的随机化。这一存在性结论通常称为纳什存在定理。

## 3. 无差异条件从哪里来

这是混合策略中最值得花时间理解的一步。假设甲只有 U、D 两个纯行动，乙以概率 $`q`$ 选 L，其余时候选 R。乙的随机化给定后，甲若选 U，可获得期望收益 $`V_U(q)`$；若选 D，可获得 $`V_D(q)`$。

现在甲决定自己以概率 $`p`$ 选 U，$`1-p`$ 选 D。甲的总体期望收益是：

```math
U_1(p,q)=pV_U(q)+(1-p)V_D(q)
=V_D(q)+p[V_U(q)-V_D(q)].
```

把 $`q`$ 暂时固定，这个式子对 $`p`$ 是一条直线。直线的斜率是两种纯行动的期望收益差：

```math
\frac{\partial U_1}{\partial p}
=V_U(q)-V_D(q).
```

如果 $`V_U(q)>V_D(q)`$，甲把 $`p`$ 提高到 1 最有利；如果 $`V_U(q)<V_D(q)`$，把 $`p`$ 降到 0 最有利。只有在：

```math
V_U(q)=V_D(q)
```

的时候，甲选择任意 $`p\in[0,1]`$ 都得到同样的期望收益，才可能真正在 U、D 之间随机化。

于是，一个常见误区就可以用微积分说清楚：<strong>不是因为甲把自己的概率选为某个数字，甲的两种行动才变得一样好。令甲无差异的是乙的概率 $`q`$。</strong>甲的概率 $`p`$ 又必须从乙的无差异条件中反过来求得。

在两人均严格随机化的均衡中，每个人都在用自己的概率让对方没有理由改变行动。两个无差异条件同时成立，均衡概率才确定。

[这里有两条纯行动期望收益直线的图解](../visuals/03-mixed-strategies.md)。曲线交点表示对方的某个混合概率使我无差异，而不是说任何两条收益线交叉都会自动构成整个博弈的均衡。

### 3.1 支持集外的行动为什么也要比较

若甲有 U、M、D 三个行动，某个候选策略只在 U 与 M 之间随机化，那么至少要验证两件事：首先 U、M 的期望收益相等；其次 D 的期望收益不高于它们。

仅验证前一项并不够。假如 U、M 都能获得 2，但 D 能获得 5，那么甲只需改选 D 就能获益。所谓无差异条件，准确说是：<strong>所有被实际使用的行动必须同样好，而且都达到最高收益。</strong>

支持集外行动可以与支持集内行动并列最优，均衡时不必给它正概率。正概率是支持集的定义，不是每一个最佳反应都必须被使用的规定。

## 4. 二乘二博弈的一般解法

设行玩家（甲）选择 U 或 D，列玩家（乙）选择 L 或 R，支付矩阵为：

| 甲 / 乙 | L | R |
| --- | --- | --- |
| U | $`(a,e)`$ | $`(b,f)`$ |
| D | $`(c,g)`$ | $`(d,h)`$ |

令甲选 U 的概率为 $`p`$，乙选 L 的概率为 $`q`$。

甲在两个纯行动之间的期望收益：

```math
V_U(q)=qa+(1-q)b,
\qquad
V_D(q)=qc+(1-q)d.
```

若甲真正混合，两者必须相等：

```math
qa+(1-q)b=qc+(1-q)d.
```

整理得：

```math
q=\frac{d-b}{a-b-c+d}.
```

乙的两个纯行动则分别获得：

```math
W_L(p)=pe+(1-p)g,
\qquad
W_R(p)=pf+(1-p)h.
```

要使乙真正混合，令两者相等：

```math
p=\frac{h-g}{e-f-g+h}.
```

两条公式只是对无差异方程的整理，并不比原方程更有内容。遇到具体数字时，直接写出四个期望收益反而更不容易出错。

公式还隐含了适用条件。首先，相应分母不能为零；其次，如果我们假设两人都使用两个行动，就必须有 $`0<p<1`$、$`0<q<1`$。若计算得到 $`q=-1/3`$，这不是“负概率的均衡”，而是说明假定的支持集不成立。

当分母为零，应该回到原方程。可能是两种行动在任何对手概率下都无差异，也可能是永远不可能无差异。直接说“无解”或者把分母为零的情况丢掉，都会遗漏某些退化博弈的均衡。

### 4.1 一个玩家纯策略、另一个玩家混合，也可能是均衡

看下面的支付表：

| 甲 / 乙 | L | R |
| --- | --- | --- |
| U | (2,1) | (2,1) |
| D | (0,0) | (0,0) |

甲始终更喜欢 U。若甲选择 U，乙面对 L 和 R 都得到 1，无论怎样随机化都一样好。因此对于任意 $`q\in[0,1]`$，下列组合都是纳什均衡：

```math
\sigma_1=(U:1,D:0),
\qquad
\sigma_2=(L:q,R:1-q).
```

当 $`0<q<1`$ 时，这是一方纯策略、一方真正随机化的均衡。它说明“求混合纳什均衡”不能自动等同于“求一个双方都严格混合的解”。

## 5. 猜硬币：没有纯策略均衡时，随机化如何制约对手

设甲希望两枚硬币同面，乙希望不同面。支付（甲，乙）如下：

| 甲 / 乙 | 正面 H | 反面 T |
| --- | --- | --- |
| 正面 H | (1,-1) | (-1,1) |
| 反面 T | (-1,1) | (1,-1) |

先不要急着列方程。检查四个格子就会发现：若两枚硬币同面，乙想改变；若不同面，甲想改变。任何纯行动组合都不能让两人同时满意，因此没有纯策略纳什均衡。

令甲出正面的概率为 $`p`$，乙出正面的概率为 $`q`$。甲面对乙的混合策略时：

```math
V_H(q)=q-(1-q)=2q-1,
\qquad
V_T(q)=-q+(1-q)=1-2q.
```

甲无差异要求 $`2q-1=1-2q`$，得到 $`q=1/2`$。

乙面对甲的混合策略时：

```math
W_H(p)=-p+(1-p)=1-2p,
\qquad
W_T(p)=p-(1-p)=2p-1.
```

乙无差异要求 $`1-2p=2p-1`$，得到 $`p=1/2`$。最终均衡为：

```math
\sigma_1^*=\sigma_2^*
=\left(\frac{1}{2},\frac{1}{2}\right),
\qquad
U_1^*=U_2^*=0.
```

即便甲知道乙使用各半的概率，它也无法通过偏向某一面获益。这正是随机化的均衡作用：让对手即使知道自己的选择规则，也找不到可以利用的偏差。

对于这一题，双方都用均匀概率是精确的均衡结论。换成其他收益矩阵，混合概率未必是二分之一。不能把“混合策略”简单理解为“所有行动等概率”。

## 6. 性别战：混合均衡存在，但协调仍可能失败

两人希望一起参加活动。甲更喜欢足球 S，乙更喜欢芭蕾 B。只要双方去同一个地方都比走散好：

| 甲 / 乙 | 足球 S | 芭蕾 B |
| --- | --- | --- |
| 足球 S | (2,1) | (0,0) |
| 芭蕾 B | (0,0) | (1,2) |

从最佳反应判断，$`(S,S)`$ 和 $`(B,B)`$ 都是纯策略均衡。甲乙能对去哪儿形成一致预期时，任何一方单独改选都会从正收益变成零，所以没有偏离动机。

如果无法事先协调，双方还可能采取独立随机策略。设甲选 S 的概率为 $`p`$，乙选 S 的概率为 $`q`$。

甲如果确定选 S，期望收益为 $`2q`$；如果确定选 B，期望收益为 $`1-q`$。令二者相等：

```math
2q=1-q
\quad\Longrightarrow\quad
q=\frac{1}{3}.
```

乙如果确定选 S，期望收益为 $`p`$；如果确定选 B，期望收益为 $`2(1-p)`$：

```math
p=2(1-p)
\quad\Longrightarrow\quad
p=\frac{2}{3}.
```

因此，第三个均衡是：

```math
\sigma_1^*=
\left(S:\frac{2}{3},B:\frac{1}{3}\right),
\qquad
\sigma_2^*=
\left(S:\frac{1}{3},B:\frac{2}{3}\right).
```

甲选足球的概率大于乙选足球的概率，与双方对足球的偏好相符；但两人的混合概率并非直接由自己的偏好强弱决定，而是互相满足对方的无差异条件。

均衡下两人各得 $`2/3`$ 的期望收益。实际能同行的概率为：

```math
\Pr(\mathrm{same})
=\frac{2}{3}\cdot\frac{1}{3}
+\frac{1}{3}\cdot\frac{2}{3}
=\frac{4}{9}.
```

这意味着走散的概率还有 $`5/9`$。所以混合均衡回答的是双方在无法改变对方规则时是否愿意改变自己的规则，并没有保证协调成功。与两个纯策略均衡相比，这个混合均衡在协调效率上明显较低。

## 7. 鹰鸽博弈：双方都不愿让步，也都不愿正面冲突

把“强硬争夺”称为鹰 H，把“避让”称为鸽 D。假设收益如下：

| 甲 / 乙 | 鹰 H | 鸽 D |
| --- | --- | --- |
| 鹰 H | (-2,-2) | (3,0) |
| 鸽 D | (0,3) | (1,1) |

对方选鹰时，我选鸽可得 0，强硬争夺只能得 -2；对方选鸽时，我选鹰可得 3，选鸽只有 1。因此存在两个纯策略均衡：$`(H,D)`$ 和 $`(D,H)`$。

如果双方对称地随机化，设乙选鹰概率为 $`q`$。甲选鹰的期望收益：

```math
V_H(q)=-2q+3(1-q)=3-5q.
```

选鸽的期望收益：

```math
V_D(q)=0q+1(1-q)=1-q.
```

无差异条件 $`3-5q=1-q`$ 给出 $`q=1/2`$。对称性又给出甲的混合概率 $`p=1/2`$。因此：

```math
\sigma_1^*=\sigma_2^*
=\left(H:\frac{1}{2},D:\frac{1}{2}\right),
\qquad
U_1^*=U_2^*=\frac{1}{2}.
```

与猜硬币不同，本例既有两个纯策略均衡，也有一个严格混合均衡。需要分别报告，不能因为找到混合概率就把纯策略均衡遗漏。

还有一个容易混淆的问题：在这个混合均衡下，甲选鹰和选鸽的期望收益相同，但不代表每次两种行动实现的收益相同。真正发生 $`(H,H)`$ 时，双方还是都会损失 2。<strong>“无差异”指事前期望，不是事后结果。</strong>

## 8. 税务稽查：处罚与检查频率为什么可能反向变化

考虑一项简化的税务检查制度。稽查方选择检查 A 或不检查 N，纳税人选择诚实 H 或逃税 C。先用一组假设支付研究双方激励：

| 稽查方 / 纳税人 | 诚实 H | 逃税 C |
| --- | --- | --- |
| 检查 A | (2,0) | (4,-10) |
| 不检查 N | (4,0) | (0,4) |

这里每个格子的第一项是稽查方收益，第二项是纳税人收益。数字只是定义模型的假设，不是实际税务部门的行为数据。

先检查是否有纯策略均衡。若纳税人诚实，稽查方宁愿不检查，因为 4 大于 2；若不检查，纳税人宁愿逃税，因为 4 大于 0；若纳税人逃税，稽查方又宁愿检查，因为 4 大于 0；但被检查时，纳税人宁愿诚实，因为 0 大于 -10。最佳反应形成循环，所以没有纯策略纳什均衡。

令检查概率为 $`p`$、诚实概率为 $`q`$。纳税人诚实时收益固定为零，逃税时：

```math
U_T(H)=0,
\qquad
U_T(C)=-10p+4(1-p)=4-14p.
```

纳税人在 H、C 之间随机化，要求：

```math
0=4-14p
\quad\Longrightarrow\quad
p^*=\frac{2}{7}.
```

稽查方检查时的期望收益是 $`2q+4(1-q)=4-2q`$，不检查时是 $`4q`$。因此：

```math
4-2q=4q
\quad\Longrightarrow\quad
q^*=\frac{2}{3}.
```

均衡下稽查方的检查概率为 $`2/7`$，纳税人诚实概率为 $`2/3`$。检查概率是从纳税人的无差异条件求出的；诚实概率来自稽查方的无差异条件。如果把这两个方向写反，后面的比较静态分析也会错。

### 8.1 加重处罚，为什么均衡检查概率反而降低

假设检查发现逃税时，纳税人收益从 -10 降为 -20，其他格子不变。纳税人逃税的期望收益改为：

```math
U_T(C)=-20p+4(1-p)=4-24p.
```

新的无差异条件是 $`4-24p=0`$，所以：

```math
p'=\frac{1}{6}.
```

稽查方的四个支付没有发生变化，仍需纳税人以 $`q=2/3`$ 的概率诚实，才能对检查与不检查无差异。

这样，处罚加重，模型中的均衡检查概率从 $`2/7`$ 降到 $`1/6`$，而诚实概率保持不变。这个结果初看反直觉，原因却很具体：处罚越严厉，越低的被查获概率就足以让纳税人不愿偏向逃税。

不妨把“被查获收益”写成 $`-F`$，把未被查获逃税的收益写成 $`g>0`$。纳税人无差异时：

```math
0=-Fp+g(1-p)
\quad\Longrightarrow\quad
p^*=\frac{g}{F+g}.
```

因此：

```math
\frac{dp^*}{dF}=-\frac{g}{(F+g)^2}<0.
```

这个导数说明的是<strong>给定其余支付不变时，均衡检查概率随处罚强度怎样变化</strong>，并不证明现实中加重处罚不会减少逃税。现实结果还可能受到风险偏好、稽查能力、逃税机会、执行成本以及处罚可信度影响。数学模型只能对自己写入的机制负责。

### 8.2 为什么不能凭“行玩家收益变了”判断行玩家概率怎样变

设只有稽查方的支付发生变化，例如提高检查成本，纳税人的支付完全不变。纳税人无差异方程没有变化，因此决定检查概率 $`p`$ 的方程仍旧是原来的；相反，决定诚实概率 $`q`$ 的稽查方无差异条件可能改变。

这揭示了二人二行动混合均衡比较静态的一般性质：<strong>一方的收益参数直接进入让该方无差异的方程，而这个方程通常解出的是对方的随机概率。</strong>当然，若参数变化太大，原先的严格混合支持集可能不再成立，就必须重新检查边界和纯策略均衡。

## 9. 零和博弈：无差异法与极小极大法之间的关系

零和博弈（Zero-Sum Game）里，乙得到的收益总是甲收益的相反数。乙不是在最大化一个独立设计的支付函数，而是在尽量压低甲的支付。因此它还可以从“最坏情况保障”理解。

考虑甲的支付矩阵，乙的支付为对应数字取负：

| 甲 / 乙 | L | R |
| --- | ---: | ---: |
| U | 2 | -1 |
| D | -2 | 3 |

纯策略下，甲若选 U，最坏会得 -1；若选 D，最坏会得 -2，因此甲的最大最小保障收益为 -1。乙若选 L，甲最多可得 2；若选 R，甲最多可得 3，因此乙能压低的最小最大支付为 2。

两者不同，说明没有纯策略鞍点。允许双方随机化后，保障收益可能上升、对手可以施加的上界可能下降。

设甲选 U 的概率为 $`p`$，乙选 L 的概率为 $`q`$。甲面对乙随机化时：

```math
V_U(q)=2q-(1-q)=3q-1,
\qquad
V_D(q)=-2q+3(1-q)=3-5q.
```

令两者相等：

```math
3q-1=3-5q
\quad\Longrightarrow\quad
q^*=\frac{1}{2}.
```

乙面对甲随机化时，比较甲在两列的期望收益即可，因为乙希望甲收益尽量低：

```math
W_L(p)=2p-2(1-p)=4p-2,
\qquad
W_R(p)=-p+3(1-p)=3-4p.
```

令两列相等：

```math
4p-2=3-4p
\quad\Longrightarrow\quad
p^*=\frac{5}{8}.
```

均衡下，甲的期望收益为 $`1/2`$，乙为 $`-1/2`$。这一数值称为零和博弈的博弈值（Value of the Game）。

### 9.1 验算：为什么 $`5/8`$ 是甲的保障策略

如果甲以概率 $`5/8`$ 选 U，不论乙固定选择 L 还是 R，甲的期望收益都是：

```math
W_L\left(\frac{5}{8}\right)
=W_R\left(\frac{5}{8}\right)
=\frac{1}{2}.
```

乙改为任意混合策略也不会把这个支付压到 $`1/2`$ 以下，因为混合后的值只是两列支付的加权平均。

同理，乙以概率 $`1/2`$ 选择 L 时，甲无论选 U 还是 D，都只得到 $`1/2`$；甲改成任意混合策略也不能超过它。两个方向合在一起，就解释了为何这是零和博弈的极小极大均衡。

有限零和博弈的极小极大定理保证，允许混合策略时，上述最大最小值与最小最大值相等。不要把它推广到所有非零和博弈：性别战中的双方并不是在最大化和最小化同一笔支付。

## 10. 支持集枚举：从二乘二走向二乘三

二乘二博弈的内部均衡只需解两组无差异方程。但一旦有玩家拥有三个行动，我们必须先猜它实际会随机使用哪些行动，然后检验这一猜测。

考虑下面的支付矩阵：

| 甲 / 乙 | B | S | X |
| --- | --- | --- | --- |
| B | (4,2) | (0,0) | (0,1) |
| S | (0,0) | (2,4) | (1,3) |

先从纯策略入手。双方分别选择 B 时，都没有单独改选的好处；双方分别选择 S 时，也同样如此。因此 $`(B,B)`$ 与 $`(S,S)`$ 是两个纯策略均衡。

下面研究是否存在真正的混合均衡。甲只有两个行动，设它选 B 的概率为 $`p`$。乙三个行动的期望收益为：

```math
W_B(p)=2p,
\qquad
W_S(p)=4(1-p),
\qquad
W_X(p)=p+3(1-p)=3-2p.
```

假设乙只在 B 与 X 之间随机化。要让乙同时愿意使用这两种行动，需要：

```math
2p=3-2p
\quad\Longrightarrow\quad
p=\frac{3}{4}.
```

此时乙选择 B 或 X 都得 $`3/2`$；没有进入支持集的 S 只得 1。于是乙确实没有理由改选 S，支持集外检验通过。

接着设乙选 B 的概率为 $`q`$、选 X 的概率为 $`1-q`$。甲选 B 时得到 $`4q`$；甲选 S 时得到 $`1-q`$。让甲无差异：

```math
4q=1-q
\quad\Longrightarrow\quad
q=\frac{1}{5}.
```

由此得到混合均衡：

```math
\sigma_1^*=
\left(B:\frac{3}{4},S:\frac{1}{4}\right),
\qquad
\sigma_2^*=
\left(B:\frac{1}{5},S:0,X:\frac{4}{5}\right).
```

验算甲的两种行动均得 $`4/5`$，乙支持集内的 B、X 均得 $`3/2`$，未使用的 S 只得 1；因此双方都没有有利单方偏离。

### 10.1 为什么还要排除其他支持集

若乙使用 B、S，则无差异要求 $`2p=4(1-p)`$，给出 $`p=2/3`$。但这时乙未使用的 X 得到 $`5/3`$，高于 B 和 S 的 $`4/3`$，所以这个支持集不可能构成均衡。

若乙使用 S、X，则要求 $`4(1-p)=3-2p`$，得到 $`p=1/2`$。但只要乙确实给 S、X 正概率，甲选 S 的支付严格高于选 B 的支付，甲就不会保持 $`p=1/2`$，同样失败。

若乙三个行动都使用，就需 $`2p=4(1-p)=3-2p`$，这三个等式无法同时成立。再结合前面已找到的纯策略均衡，本例一共有三个均衡：两个纯策略和一个支持集为 $`\{B,X\}`$ 的非纯均衡。

题目的难点不在于多解一个方程，而在于明白一个支持集需要通过三道检查：内部正概率、内部无差异、外部不更优。三个条件缺一不可。

## 11. 被混合策略严格支配的行动

第一讲介绍过纯行动之间的支配关系。现在随机策略也成为可选行动，就不能只问“有没有某一个纯行动支配它”，还要问“有没有一种概率组合在任何对手选择下都更好”。

下表只给出甲的支付：

| 甲 / 乙 | L | R |
| --- | ---: | ---: |
| T | 1 | 1 |
| M | 4 | 0 |
| B | 0 | 3 |

没有哪个单独的纯行动能严格支配 T。M 遇到 R 时只得 0，B 遇到 L 时也只得 0，都不如 T 的 1。

但假设甲以概率 $`r`$ 选 M、以概率 $`1-r`$ 选 B。面对乙选 L，这一混合策略的收益为 $`4r`$；面对 R，收益为 $`3(1-r)`$。

要在两种情况下都严格超过 T，必须：

```math
4r>1,\qquad 3(1-r)>1.
```

也就是：

```math
\frac{1}{4}<r<\frac{2}{3}.
```

例如 $`r=1/2`$ 时，混合策略面对 L 得 2，面对 R 得 $`3/2`$，两种情况下都优于 T。乙如果自身也混合，两个收益仍是上述纯列收益的加权平均，因此混合策略对乙的任意策略都严格更好。

只要某纯行动被另一可行策略严格支配，它就不可能在纳什均衡中获得正概率。理由是：如果仍给它正概率，玩家总能把这部分概率转移给严格更好的策略，提高期望收益。

### 11.1 弱支配不能像严格支配那样随意删除

设甲的收益和乙的收益如下：

| 甲 / 乙 | L | R |
| --- | --- | --- |
| U | (1,1) | (1,0) |
| D | (1,1) | (0,0) |

对甲来说，U 面对 L 和 D 一样好，面对 R 严格好，所以 D 被 U 弱支配。可是 $`(D,L)`$ 仍是纳什均衡：乙面对 D 喜欢 L，甲面对 L 选择 U、D 均能得到 1，并无严格改进。

严格支配意味着无论对手如何混合都劣于另一策略；弱支配允许某些对手策略下完全持平。这点差别足以让弱劣行动在均衡中仍可能出现。

因此，对于“求全部纳什均衡”的题目，删去严格劣势行动通常是安全的；删除弱劣行动则可能丢失原博弈的某些均衡。如果题目要求讨论迭代删除弱劣策略，必须清楚说明删除顺序和保留的均衡集合。

## 12. 三人混合策略：无差异方程不再是一次函数

在二人二行动博弈中，某人面对对手的概率 $`q`$，每个纯行动的期望收益都是 $`q`$ 的一次函数。增加参与者后，情况有一点变化：一个人的期望收益需要对其他所有人的行动组合加权，因此可能出现多个概率的乘积。

考虑三个玩家，每人选择 A 或 B。规则如下：如果我选择 A，且另外两人都选择 A，我得到 1；如果我选择 B，且另外两人都选择 B，我得到 4；其余情况下，我得到 0。这个游戏鼓励三人协调，但三人一起选择 B 的收益比一起选择 A 高。

设玩家 1、2、3 选 A 的概率分别为 $`p,q,r`$。对于玩家 1，选择 A 的期望收益是另外两人同时选 A 的概率：

```math
V_1(A)=qr.
```

选择 B，则只有另外两人同时选 B 才获得 4：

```math
V_1(B)=4(1-q)(1-r).
```

玩家 1 若严格混合，要求：

```math
qr=4(1-q)(1-r).
```

对玩家 2、3 分别写出同样的条件：

```math
pr=4(1-p)(1-r),
\qquad
pq=4(1-p)(1-q).
```

若寻找对称严格混合均衡，可设 $`p=q=r=x`$，得到：

```math
x^2=4(1-x)^2.
```

由于 $`0<x<1`$，两边开方时取非负值：

```math
x=2(1-x)
\quad\Longrightarrow\quad
x=\frac{2}{3}.
```

所以三人都以 $`2/3`$ 的概率选 A，$`1/3`$ 的概率选 B 时，每人对 A、B 无差异。此时期望收益为 $`4/9`$。

不过，这个游戏还存在全体选 A 和全体选 B 两个纯策略均衡。三人全部选 A 时，任何一人独自改选 B 都只能得到 0，低于保持 A 的 1；全体选 B 时，独自改选 A 同样只能得到 0，低于保持 B 的 4。

三人题的写法因此不是机械地把二人公式多写一遍。首先明确别人行动组合的概率如何计算，再为每名实际随机化的玩家列出一条无差异方程，最后检查纯策略、边界支持集和概率合法性。

## 13. 独立随机化与共同信号：一个值得区分的延伸

回到性别战。严格混合均衡中，甲选择足球的概率为 $`2/3`$，乙选择足球的概率为 $`1/3`$。他们各自独立地随机决定去哪儿，于是走散的概率达到 $`5/9`$。

假设换一种制度：两人事先约定由一个公共、可信的随机信号决定活动。例如抛一枚公正硬币，正面双方都去看足球，反面双方都去看芭蕾。在这个方案下，二人始终同行。每人的期望收益为：

```math
U_1=U_2=\frac{1}{2}\times2+\frac{1}{2}\times1
=\frac{3}{2}.
```

这个数高于原来独立混合策略均衡的 $`2/3`$。但不能因此说原来的混合均衡算错了：<strong>两套制度允许的信息与随机化方式不同。</strong>

独立随机化下，每个人私下抽取行动，双方的联合概率等于各自概率的乘积。公共信号方案下，随机信号同时决定两个行动，选择结果可以相关。若公开信号建议双方去足球，任何一人独自改去芭蕾都会从正收益变成 0；信号建议芭蕾时同理。因此，在这个例子中遵循信号是稳定的。

这种允许共同推荐信号的分析可以引向相关均衡（Correlated Equilibrium）。它拓宽了策略之间的概率关联方式，但不是把原本独立的混合策略概率随意改成联合概率。相关均衡所允许的信号、建议以及偏离条件，都需要作为博弈的一部分明确写出。

对于组织协调问题，这个区别非常实际：单靠个人“随机试一试”，可能持续发生错配；允许公开抽签或共同遵守的规则，就能减少错配。相应的制度能否执行，则是模型之外需要另外判断的问题。

## 14. 怎样理解均衡中的概率和期望支付

数学模型里的混合概率可以有几种不同解释。它可以是玩家实际使用的随机行动规则，也可以表示其他玩家对其行动的概率预测。重复许多次时，某种稳定随机规则也可能对应观察到的长期选择频率；在一些群体模型里，概率还会被用来表示采取不同策略的人群比例。

这些解释在特定条件下能够彼此联系，却不是同一回事。单次二人博弈中的随机规则，并不等于参与者在每一轮都必须有意识地掷硬币；看到现实数据中 60% 的参与者选择某行动，也不能仅凭这个比例判定它是混合纳什均衡。还需要知道收益结构，以及每个人是否有改变自身选择的激励。

另一个细节是概率与支付的单位。假设求得甲选 U 的概率为 $`p=0.6`$，甲在均衡下的期望支付为 3。前者回答“选 U 的频率”，后者回答“按照均衡随机策略行动时的平均收益”。二者没有直接的大小关系，不能写成“甲的均衡收益是 0.6”。

随机策略还使效用函数的表示方式变得重要。对于只有确定结果的偏好比较，单调变换通常不改变行动排序；但对于混合策略下的期望效用，任意非线性单调变换可能改变玩家对风险组合的评价，从而改变均衡概率。若采用期望效用框架，保留同样的风险偏好比较通常要求使用正仿射变换。

### 14.1 为什么本讲不直接推广到一切连续行动博弈

本章的无差异推导以有限行动和概率向量为主要对象。在无限行动模型中，混合策略可能是连续概率分布，支持集也可能是一整段区间。此时不能再把每个可能行动列成有限张表，均衡存在性和最优性检验都需要额外的数学条件。

第二讲的消耗战就是一个例子。退出时间可以取任意非负实数，采用连续混合策略时需要求退出时间的分布函数，而不是解两个简单的一次方程。它仍然遵循“支持集中的行动应同样合算”的思想，但处理方法有所不同。

#### 14.1.1 原课件第 33 页：无限行动博弈的混合策略均衡判定

有限博弈中，每人只有有限个纯行动，混合策略是一个有限维概率向量。例如三个行动的混合概率可以写成 $`(0.2,0.5,0.3)`$。但如果玩家可以选择区间 $`[0,1]`$ 中任意实数，就有不可数多个纯行动；这时混合策略是定义在行动集合上的<strong>概率分布</strong>，既可能有离散概率点，也可能有连续密度，甚至是两者的混合。

设玩家 $`i`$ 的可行行动集合为 $`A_i`$，候选混合策略组合为 $`\alpha^*=(\alpha_i^*,\alpha_{-i}^*)`$。为避免将“对手行动的随机性”和“自己行动的随机性”混在一起，先定义玩家 $`i`$ 如果固定选择纯行动 $`a_i`$、对手遵守候选策略时的期望收益：

```math
g_i(a_i;\alpha_{-i}^*)
=\mathbb E_{a_{-i}\sim\alpha_{-i}^*}
\bigl[u_i(a_i,a_{-i})\bigr].
```

再记玩家 $`i`$ 自己也遵守候选混合策略时的期望收益为：

```math
V_i=U_i(\alpha_i^*,\alpha_{-i}^*)
=\int_{A_i}g_i(a_i;\alpha_{-i}^*)\,d\alpha_i^*(a_i).
```

在有关期望收益存在且可积的常规前提下，课件给出的无限行动博弈混合纳什均衡刻画可写为以下两项条件，对每个参与人 $`i`$ 都必须成立。

原课件这一页的第二个英文要点出现了“finite games ... does not apply in finite games”的前后重复。结合该页标题、前一条有限与无限的对比，以及随后“概率分配在行动集合而非单个行动上”的解释，其实际要表达的应是：<strong>有限行动模型中逐点使用正概率的写法不能原样照搬到无限行动模型</strong>。下面直接给出不依赖这处措辞的正式数学条件。

<strong>条件一：不存在收益更高的纯策略偏离。</strong>

```math
\boxed{
g_i(a_i;\alpha_{-i}^*)\le V_i
\quad\text{对所有 }a_i\in A_i.
}
```

也就是说，只要对手维持 $`\alpha_{-i}^*`$，玩家 $`i`$ 无论临时改选哪个确定行动，都不可能超过原候选策略的期望收益。若存在某个 $`a_i'`$ 满足 $`g_i(a_i';\alpha_{-i}^*)>V_i`$，候选策略便不是纳什均衡。

<strong>条件二：自己的混合策略不给严格低收益行动集合分配正概率。</strong>

先定义严格低收益行动构成的集合：

```math
D_i=\{a_i\in A_i:g_i(a_i;\alpha_{-i}^*)<V_i\}.
```

要求：

```math
\boxed{\alpha_i^*(D_i)=0.}
```

这条条件并非要求每个最优行动都获得正概率。它的意思是：玩家实际随机选到<strong>严格不如候选期望收益</strong>的行动的总概率必须为零。所有分配了正概率质量的行动，除去一个概率为零的例外集合，必须达到最高期望收益。

严格说，在期望收益可积的情况下，条件一已经足以判定“没有任何混合偏离可以提高收益”。原因是任意其他混合分布 $`\beta_i`$ 对纯行动的收益取加权平均，仍然不可能超过上界 $`V_i`$：

```math
\int_{A_i}g_i(a_i;\alpha_{-i}^*)\,d\beta_i(a_i)\le V_i.
```

同时，候选策略本身取得了平均收益 $`V_i`$，且条件一保证所有单项收益不超过 $`V_i`$；于是它不可能给严格低于 $`V_i`$ 的行动集合分配正概率，否则平均值也会严格低于 $`V_i`$。因此，在上述可积条件下，条件二实际上可以从条件一和 $`V_i`$ 的定义推出。课件并列写出两项，是为了把<strong>禁止有利偏离</strong>和<strong>混合概率只能落在最优行动上（几乎处处）</strong>这两层含义分别说明。

#### 14.1.2 连续分布为什么要使用“概率为零的集合”，而不是逐点概率

有限行动博弈里，通常说“如果行动 $`a`$ 被赋予正概率，它必须是最佳反应”。这一说法在有限维概率向量中很直观。但对连续均匀分布 $`U[0,1]`$ 来说，任意一个指定的点 $`a`$ 都满足：

```math
\Pr(X=a)=0.
```

这不代表分布没有使用任何行动；它把总概率 1 分配在整个区间上。真正需要检验的是<strong>某一类严格劣于最优值的行动组成的集合</strong>是否获得了正概率，而不是逐点检查某个行动有无正概率。

例如两名玩家都从 $`[0,1]`$ 选择实数，每人的收益只取决于自己是否选择零：

```math
u_i(a_i,a_{-i})=
\begin{cases}
0,&a_i=0,\\
1,&0<a_i\le1.
\end{cases}
```

假设双方都使用连续均匀分布 $`U[0,1]`$。由于选中单点 $`0`$ 的概率为零，每人的候选期望收益为 $`V_i=1`$。对任意纯行动 $`a_i>0`$，偏离后的收益仍是 1；改选 $`a_i=0`$ 只得 0，因此无人可以严格提高期望收益。严格低收益行动集合就是 $`D_i=\{0\}`$，而均匀分布满足 $`\alpha_i^*(D_i)=0`$。所以这是一个混合策略纳什均衡。

在这个特意构造的不连续支付例子中，均匀分布的拓扑支持集包括端点 0，但 0 本身不是最佳反应；这并不违反课件条件，因为该单点获得的概率仍为零。因此不能在<strong>任意不连续无限行动博弈</strong>中武断声称“拓扑支持集上的每个点都必定最优”。正确的通用表述是：严格低收益行动集合的概率为零。在具有适当连续性的模型里，才可以进一步得到通常使用的支持集逐点最优结论。

#### 14.1.3 为什么有限博弈一定有混合均衡，无限博弈却未必有

有限参与人、有限纯行动的标准博弈具有混合策略纳什均衡存在性结论。但无限行动博弈不能只靠“允许随机化”就保证存在均衡：策略集合是否包含边界、支付是否连续、最优行动能否取到，都会影响存在性。

考虑两名玩家的行动集合均为开区间 $`A_i=(0,1)`$，各人的收益为 $`u_i(a_i,a_{-i})=a_i`$。无论对手如何行动，玩家都希望把自己的数字选得更接近 1，但又永远不能选到 1。

若玩家 $`i`$ 使用任意混合策略 $`\alpha_i`$，其期望收益记为 $`m_i=\mathbb E_{\alpha_i}[a_i]`$。因为所选数字总严格小于 1，必有 $`m_i<1`$。玩家可以单方面改选确定数字：

```math
a_i'=\frac{m_i+1}{2}\in(0,1),
\qquad a_i'>m_i.
```

这给出严格有利的纯行动偏离。因此<strong>无论候选策略是纯策略还是连续混合分布，都不可能构成纳什均衡</strong>。这个反例的重点是行动集合没有包含可实现的最优边界 1，而不是“连续行动模型一概没有均衡”。

实际做无限行动博弈题时，先明确候选概率分布和各纯行动的期望收益函数 $`g_i`$，再求候选值 $`V_i`$，最后依照原课件两条条件检查纯行动偏离以及严格低收益集合的概率。若题目允许连续密度，应将单点概率和区间概率分开处理。对应的[第三讲习题第 14 题](../exercises/lecture-03-exercises.md)给出完整计算。

## 15. 解题时怎样把所有均衡找全

面对一个新的支付矩阵，首先从纯策略开始。把每一列里行玩家的最大支付和每一行里列玩家的最大支付分别标出来，两方标记重合的格子就是纯策略纳什均衡。这一步往往可以直接发现多个均衡，也能初步看出哪几种行动可能进入混合支持集。

随后检查严格支配。严格被支配的行动不可能以正概率出现在均衡中，因此可以先排除。对于剩下的行动，若双方各只有两种，便可设 $`p,q`$ 并列两组无差异方程；行动数更多时，则需要枚举候选支持集。

求出概率之后，不要立即停笔。应把结果代回每种纯行动的期望收益，确认支持集中的行动都得到相同的最高支付，未使用的行动也没有更高收益。若有玩家实际上只给一个行动正概率，还必须检查“一个人纯策略、另一个人混合”的边界情况。

最后计算均衡期望支付。如果题目还问协调概率、被查获概率、双方都强硬的概率等联合事件，要利用双方实际行动的联合分布计算。对于本章标准的独立混合策略，联合概率是相应边际概率的乘积。

| 题目表现 | 应先检查的地方 |
| --- | --- |
| 算出的概率小于 0 或大于 1 | 支持集假设可能不成立；回到最佳反应 |
| 无差异方程出现 $`0=0`$ | 存在退化情形；检查是否有一整段均衡概率 |
| 两个行动无差异，第三个收益更高 | 当前支持集无效 |
| 求出了混合概率，但题目问“全部均衡” | 仍需列出纯策略及边界混合均衡 |
| 一方行动被严格支配 | 该行动在任何均衡中都不能获得正概率 |
| 一方行动只被弱支配 | 不可据此排除所有含该行动的均衡 |

为了检验是否真正理解了本章，可以独立完成三个问题：在性别战中为什么甲的足球概率由乙的无差异条件决定；在税务稽查中为什么加大处罚改变的是检查概率；在二乘三博弈中为什么两个行动同样好仍不一定能够进入支持集。把这三件事说清楚，再做复杂的计算题通常就不会陷入盲目代公式。

配套的[第三讲习题与完整解析](../exercises/lecture-03-exercises.md)包含性别战、猜硬币、鹰鸽、税务稽查、混合支配、二乘三支持集、三人混合与零和博弈。若需要结合图形理解概率交点，可以回到[混合策略图解](../visuals/03-mixed-strategies.md)。以下再把两类常见的边界难题单独展开，作为完成本章后的强化训练。

## 16. 进阶但很实用：均衡为什么有时不是一个点，而是一整段概率

前面的二乘二例题经常有一组唯一的内部混合概率，所以容易形成一种印象：写两条无差异方程，解出 $`p,q`$，就完成了求均衡。实际上，一旦存在<strong>收益并列、弱支配或者无差异方程退化</strong>，均衡可能是一整个连续集合。此时最稳妥的方法不是继续硬套分式公式，而是把两个玩家的<strong>最佳反应对应关系</strong>分别写出来，再求交集。

### 16.1 一个具体的二乘二矩阵

考虑下列阶段收益，每格第一个数字属于行玩家：

| 行玩家／列玩家 | $`L`$ | $`R`$ |
| --- | ---: | ---: |
| $`U`$ | $`(3,1)`$ | $`(1,2)`$ |
| $`D`$ | $`(1,2)`$ | $`(2,2)`$ |

设 $`p=\Pr(U)`$，$`q=\Pr(L)`$。不要急着假设两个人都混合。先计算行玩家选择纯行动 $`U`$ 或 $`D`$ 的期望收益：

```math
\begin{aligned}
V_U(q)&=3q+1(1-q)=1+2q,\\
V_D(q)&=1q+2(1-q)=2-q.
\end{aligned}
```

求差得到 $`V_U-V_D=3q-1`$。所以行玩家的全部最佳反应是：

```math
BR_{\mathrm{row}}(q)=
\begin{cases}
D,&0\le q<1/3,\\
\{U,D\}\text{ 及二者任意混合},&q=1/3,\\
U,&1/3<q\le1.
\end{cases}
```

注意在 $`q=1/3`$ 时，行玩家<strong>可以</strong>选择任意混合概率，但不是说“必须选 $`p=1/2`$”。两个行动收益相等意味着所有混合权重都同样好；最终能否形成纳什均衡还要看列玩家会如何回应。

列玩家选 $`L`$ 的期望收益是 $`1p+2(1-p)=2-p`$，选 $`R`$ 的期望收益恒为 $`2`$，因此：

```math
BR_{\mathrm{col}}(p)=
\begin{cases}
R,&0<p\le1,\\
\{L,R\}\text{ 及二者任意混合},&p=0.
\end{cases}
```

这一结果背后的意思是：只要行玩家有正概率选 $`U`$，列玩家就严格更喜欢 $`R`$；只有行玩家确定选 $`D`$，列玩家才对 $`L,R`$ 无差异。

### 16.2 按两种情形取最佳反应交集

假设 $`p>0`$。根据列玩家的最佳反应，必有 $`q=0`$；但是 $`q=0`$ 时行玩家只能最优地选 $`D`$，要求 $`p=0`$。这与假设矛盾，因此任何均衡都不能有 $`p>0`$。

于是只剩 $`p=0`$，即行玩家确定选 $`D`$。此时列玩家对 $`L,R`$ 无差异，任意 $`q\in[0,1]`$ 对列玩家来说都是最佳反应；然而行玩家愿意继续选 $`D`$ 的条件是 $`q\le1/3`$。综合双方条件，完整均衡集合为：

```math
\boxed{\{(p,q):p=0,\quad 0\le q\le1/3\}}.
```

其中 $`q=0`$ 对应纯策略均衡 $`(D,R)`$；$`0<q\le1/3`$ 则是行玩家纯选 $`D`$、列玩家在 $`L,R`$ 间随机化的均衡。行玩家均衡期望收益为 $`2-q`$，会随 $`q`$ 改变；列玩家始终得到 2。因此<strong>不同均衡可以具有不同收益</strong>，并没有一条一般规则要求同一个博弈的所有纳什均衡支付相同。

### 16.3 为什么弱支配行动仍能被使用

对于列玩家，$`R`$ 面对行玩家选 $`U`$ 时支付 2、高于 $`L`$ 的 1；面对 $`D`$ 时两者都得 2。所以 $`L`$ 被 $`R`$ <strong>弱支配</strong>，却并未被严格支配。

当均衡中的行玩家确定选 $`D`$ 时，列玩家选 $`L`$ 和 $`R`$ 的收益恰好相同；因此列玩家可以以正概率选一个弱劣行动 $`L`$，但不能偏离获益。若提前把所有弱劣行动都删掉，就会只留下 $`(D,R)`$，遗漏 $`q\in(0,1/3]`$ 的全部均衡。与此不同，<strong>严格被支配</strong>的行动在任何纳什均衡中都不能有正概率。

本例的求解顺序可以记作：<strong>列出两个纯行动的收益函数 → 写分段最佳反应 → 从边界 $`p=0`$ 入手找交集 → 验证整个区间 → 再讨论弱支配</strong>。对应的[习题 15](../exercises/lecture-03-exercises.md)把每一步改写成可直接在考试中使用的标准答案。

## 17. 把税务稽查的无差异方程翻译成可理解的经济机制

再看一个经常“计算正确、解释却写反”的场景。纳税人可以诚实申报 $`H`$ 或逃税 $`E`$；稽查机关可以检查 $`I`$ 或不检查 $`N`$。为突出激励关系，把诚实申报时纳税人的净增量收益设为 0，逃税未被查到得到 $`B>0`$，被查到损失 $`F>0`$。稽查成本为 $`c>0`$，抓到逃税可获得直接收益 $`R`$，未检查逃税造成损失 $`L`$。支付如下：

| 纳税人／稽查机关 | 检查 $`I`$ | 不检查 $`N`$ |
| --- | ---: | ---: |
| 诚实 $`H`$ | $`(0,-c)`$ | $`(0,0)`$ |
| 逃税 $`E`$ | $`(-F,R-c)`$ | $`(B,-L)`$ |

这里 $`R`$ 与 $`F`$ 是不同玩家的收益参数，不必在数值上相等；本节研究的是明确给定的模型，而不是对现实税收制度的完整描述。

先设 $`x=\Pr(E)`$、$`q=\Pr(I)`$。<strong>纳税人要不要随机逃税，取决于机关检查概率 $`q`$</strong>：诚实得到 0，逃税期望收益为 $`B-q(B+F)`$。两者相等时：

```math
\boxed{q^*=\frac{B}{B+F}}.
```

<strong>机关要不要随机检查，取决于纳税人逃税概率 $`x`$</strong>：检查期望收益为 $`xR-c`$，不检查为 $`-xL`$，二者相等时：

```math
xR-c=-xL
\quad\Longrightarrow\quad
\boxed{x^*=\frac{c}{R+L}}.
```

当 $`B,F>0`$ 且 $`0<c<R+L`$ 时，这两个概率都严格位于 0 与 1 之间。在该参数范围内，四个纯行动格子均有玩家想偏离，因此这组内部混合概率构成唯一纳什均衡。

例如取 $`B=4,F=6,R=5,L=3,c=2`$，则 $`q^*=0.4`$，$`x^*=0.25`$。提高罚款 $`F`$ 到 12，纳税人的无差异门槛会变成 $`q^*=0.25`$，而 $`x^*=0.25`$ 暂时不变。提高检查成本 $`c`$ 到 4，则逃税概率变成 $`x^*=0.5`$，而检查概率仍为 0.4。

这不是说“加重处罚一定导致现实中的检查率下降”，而是<strong>在本例的完全混合均衡、其余参数不变的条件下</strong>，罚款改变纳税人对检查概率的要求，检查成本改变机关对逃税概率的要求。更完整的数值代入、纯均衡排除和 $`c\ge R+L`$ 的边界分析见[习题 16](../exercises/lecture-03-exercises.md)。
