## 二、同一个答案，为什么还要采用另一种算法

<strong>均衡的数值与均衡的证明是两回事。</strong> 例如第二讲 Cournot 题可以联立求解产量，但仍需检验每家利润关于自身产量凹、产量非负，以及在对手均衡产量下确实是最佳反应。独立核算程序通过反复更新最佳反应，检查其是否收敛到文中的同一个交点；这是对代数求解结果的另一条计算路径。

<strong>路径上的行动合理不等于动态博弈的完整策略合理。</strong> 第四讲市场进入题必须分别验证普通 NE 与 SPNE，第五讲重复博弈必须检查惩罚状态。只有初始合作时没有人想偏离，并不能推出 TFT 或其他历史依赖策略在所有可能历史后仍合理。

<strong>信念和联盟约束不能用单个平均值代替。</strong> 第八讲信号题要同时检验接收者行动与发送者各类型的偏离；第九讲即使 Shapley 分配总和等于大联盟价值，也仍要测试每个两人联盟能否退出获益。

## 四、如何重新运行核算

在仓库根目录运行：

```bash
node scripts/check-docs.mjs
node scripts/normalize-math.mjs --check
node scripts/verify-exercises.mjs
```

第三条命令直接独立计算本页表格列出的十组模型，若有数值不一致则中止并报告对应检查项。它不依赖笔记中写好的最终数字做中间计算，因此适合在调整教材例题参数或重新编写答案后回归核对。
