## 二、六组最容易混淆的知识点

| 看到的题目现象 | 不能直接得出的结论 | 应该实际检查什么 |
| --- | --- | --- |
| 两家企业生产相同产品 | “一定是 Cournot” | 是同时定<strong>产量</strong>，还是同时定<strong>价格</strong>；行动是否有先后 |
| 某个格子总收益最高 | “这一定是纳什均衡” | 固定对手选择后，双方有无获益的<strong>单方偏离</strong> |
| 混合策略计算出一个概率 | “已找到全部混合 NE” | 概率是否在合法区间、支持集外是否更优、是否有纯策略或边界均衡 |
| 树上出现先行动与后行动 | “直接逆推每个节点即可” | 后行动者能否观察该节点；若是同一信息集，需先解<strong>续局博弈</strong> |
| 重复博弈初始合作不值得背叛 | “这份策略已经是 SPNE” | 惩罚实施时是否仍最优；不同历史状态是否都满足激励约束 |
| 算出 Shapley 值且总额等于联盟价值 | “分配一定稳定” | 所有子联盟获得的金额是否至少达到其单独合作价值，即是否处于核心 |

特别需要分清<strong>完全信息</strong>和<strong>完美信息</strong>：前者说博弈结构与支付是否为共同知识，后者说玩家行动时是否知道此前发生的行动。存在私人类型的是不完全信息；后行动者看不到之前某项行动，则属于不完美信息。两种情况可以同时存在。

## 三、示范题 A：三轮谈判中的异质折现

<strong>题目：</strong> 双方谈判分配总额 1。第 1 轮由玩家 1 报价，第 2 轮玩家 2 报价，第 3 轮玩家 1 报价；第 3 轮拒绝则双方得到 0。玩家 1 的每轮折现因子是 $`\delta_1=0.8`$，玩家 2 是 $`\delta_2=0.5`$。接受者无差异时接受。求第 1 轮即刻达成的分配。

<strong>答案：</strong> 玩家 1 得 $`0.9`$，玩家 2 得 $`0.1`$。

<strong>第一步：倒推第 3 轮。</strong> 最后报价者玩家 1 可以保留全部 1，因为玩家 2 拒绝后收益也是 0，按照约定会接受零额报价。这是第 3 轮实际发生时的收益，不需要再折现。

<strong>第二步：回到第 2 轮。</strong> 玩家 1 若拒绝，可以在下一轮得到 1，但从当前看须乘<strong>自己</strong>的折现因子：

```math
V_1^{\mathrm{reject},2}=\delta_1\cdot1=0.8.
```

因此第 2 轮玩家 2 必须给玩家 1 至少 $`0.8`$，自己可保留 $`0.2`$。这里使用的是接受者玩家 1 的折现因子。

<strong>第三步：回到第 1 轮。</strong> 玩家 2 若拒绝，在第 2 轮可保留 $`0.2`$，从第 1 轮看，其继续价值为

```math
V_2^{\mathrm{reject},1}=\delta_2\cdot0.2
=0.5\times0.2=0.1.
```

玩家 1 在第 1 轮只需给玩家 2 $`0.1`$，即可自己保留 $`0.9`$，双方达成协议。

<strong>最容易错的地方：</strong> 每轮发生变化的是接受者的身份，因此两次折现分别乘 $`\delta_1`$ 与 $`\delta_2`$；不能不加区分地反复乘报价者的折现率。对应练习：[第六讲习题 9、19](../exercises/lecture-06-exercises.md)。

## 四、示范题 B：知道后验概率，还须检验信号激励

<strong>题目：</strong> 企业有高质量 $`H`$ 与低质量 $`L`$ 两种私人类型，先验概率分别是 $`0.4`$ 和 $`0.6`$。企业发送信号 $`s\in\{0,1\}`$，投资者观察后决定投资 $`I`$ 或拒绝 $`R`$。投资者投资高质量企业收益 3、投资低质量企业收益 $`-2`$，不投资收益 0。企业获得投资则得 2，否则得 0；发信号 1 的成本对 $`H`$ 为 $`0.5`$，对 $`L`$ 为 3，发 0 成本为零。信号成本不因最终是否投资而免除。

验证候选策略：$`H`$ 发 1、$`L`$ 发 0；投资者见到 1 投资，见到 0 拒绝。它是否构成分离型 PBE？

<strong>答案：</strong> 构成分离型 PBE。均衡信念为 $`\Pr(H\mid1)=1`$、$`\Pr(H\mid0)=0`$；接收者行动和两类型发送者行为均最优。

<strong>第一步：由候选信号策略算后验。</strong> 两种信号都以正概率出现，因此适用 Bayes 法则：

```math
\begin{aligned}
\Pr(H\mid1)
&=\frac{1\cdot0.4}{1\cdot0.4+0\cdot0.6}=1,\\
\Pr(H\mid0)
&=\frac{0\cdot0.4}{0\cdot0.4+1\cdot0.6}=0.
\end{aligned}
```

<strong>第二步：检验投资者。</strong> 若相信高类型的概率是 $`\mu`$，投资的预期收益为

```math
U_I(\mu)=3\mu-2(1-\mu)=5\mu-2.
```

当 $`\mu\ge2/5`$ 时投资才是最佳反应。见到信号 1 后投资收益 3，高于拒绝的 0；见到信号 0 后投资收益 $`-2`$，应该拒绝。两处行动都与信念一致。

<strong>第三步：分别检验两类发送者偏离。</strong> 高类型发 1 的收益为 $`2-0.5=1.5`$；若改发 0，投资者拒绝，收益为 0，故不偏离。低类型发 0 的收益为 0；若模仿高类型改发 1，虽然得到投资，但净收益为 $`2-3=-1`$，也不偏离。

<strong>完整结论：</strong> 三件事同时成立：信念由均衡行为更新、投资者根据后验作最优决策、发送者每种类型都愿意按预设信号行动。本题两种信号都在路径上，无需额外为未出现的信号指定信念。对应练习：[第八讲习题 4、5、8](../exercises/lecture-08-exercises.md)。

## 五、示范题 C：Shapley 值存在，但核心为空

<strong>题目：</strong> 三人收益型 TU 博弈：所有单人联盟价值为 0，任意两人联盟价值为 1，三人联盟价值也为 1。计算 Shapley 值，并判断是否在核心中。

<strong>答案：</strong> Shapley 值为 $`(1/3,1/3,1/3)`$；它不在核心，而且核心为空。

<strong>第一步：平均边际贡献。</strong> 每位玩家处于完全对称的位置。在 $`3!=6`$ 种加入顺序中，某个人最先加入时增加价值 0；第二个加入时使联盟价值从 0 上升到 1，贡献 1；最后加入时联盟价值仍是 1，贡献 0。三个位置的概率各为 $`1/3`$，因此

```math
\phi_i=\frac{1}{3}\cdot0+\frac{1}{3}\cdot1+\frac{1}{3}\cdot0
=\frac{1}{3},\qquad i=1,2,3.
```

<strong>第二步：检验联盟退出。</strong> 核心需要效率性与所有两人联盟约束：

```math
\begin{gathered}
x_1+x_2+x_3=1,\\
x_1+x_2\ge1,\quad x_1+x_3\ge1,\quad x_2+x_3\ge1.
\end{gathered}
```

把三个不等式相加，得 $`2(x_1+x_2+x_3)\ge3`$，但效率性要求左边等于 2，矛盾。所以核心为空。Shapley 分配下任一双人联盟只得到 $`2/3`$，低于两人退出后能得到的 1，自然不稳定。

<strong>区别：</strong> Shapley 值衡量平均边际贡献；核心衡量任意联盟是否愿意退出。前者总能按公式计算，后者未必存在。对应练习：[第九讲习题 6、8、9、14](../exercises/lecture-09-exercises.md)及[综合题 7](comprehensive-practice.md)。

## 六、自己检查答案时，按四层复核

先核对<strong>模型层</strong>：同时定价与同时定量、完美与不完美信息、静态私人类型与动态信号，是否发生混淆。

接着核对<strong>变量层</strong>：混合概率是谁控制的、折现因子属于哪个人、收益属于行玩家还是列玩家、联盟不等式是收益问题还是成本问题。公式形式对了，变量归属错了，答案仍会反向。

再核对<strong>求解层</strong>：是否给出全部最佳反应、边界条件、混合支持集、路径外策略与每个类型的偏离约束。动态与不完全信息模型尤其不能用单个数值代替均衡论证。

最后核对<strong>解释层</strong>：写清楚某一策略为什么稳定、其他候选为什么失败，以及结论依赖的是行动时序、可信惩罚、私人信息、接受门槛还是联盟退出约束。
