## 学习方式

每讲尽量保持相同结构：

1. **基本概念**：明确博弈参与者、行动、策略、信息结构与支付。
2. **求解方法**：从最佳反应或逆向归纳出发，逐步计算均衡。
3. **经典案例**：把模型放回企业竞争、谈判、合同等实际情境。
4. **标准练习**：先独立完成题目，再对照逐步解析与易错点。
