## 阅读方式

先看图辨认<strong>谁在行动、什么时候行动、可以观察什么</strong>；再读取图中的收益与概率；最后回到对应笔记，用方程验证图中的均衡结论。

图解使用 GitHub 原生 Mermaid 和仓库内的 SVG 矢量图，无需外部图片托管或额外插件。新增漫画专题配有独立的收益核算、均衡分析与练习。
